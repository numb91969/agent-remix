# AIGC 三圣专家团

面向个人创作者与企业自媒体的可持续内容制作。三位独立专家，共用项目文件；剧本关汉卿兼任总入口，不增设第四个协调角色。

| 专家 | 定位 | 负责产物 |
| --- | --- | --- |
| 剧本 关汉卿 | 曲圣；故事与制作统筹 | 创作简报、大纲、人物性格、剧本、连续性台账 |
| 分镜 吴道子 | 画圣；视觉设计与分镜 | 角色外观、场景/道具资产、镜头表、关键帧设计 |
| 提示词 李白 | 诗仙（谪仙人）；生成与交付 | 提示词、ComfyUI 工作流映射、生成记录、剪辑交付 |

## 三种产品

| 模式 | 适合需求 | 默认起步方案（可改） | 流程 |
| --- | --- | --- | --- |
| 连载 | 经营持续更新的角色/IP/品牌故事 | 6 集试播季，每集 60 秒；先完成第 1 集 | brief → outline → characters → art → script → storyboard → prompt → ComfyUI → edit → 连续性更新 |
| 小剧场 | 单集有冲突与结局的故事 | 30–60 秒，2 主角，1 主场景 | 简报与角色小卡 → 简单剧本 → 分镜 → 提示词 → ComfyUI → 剪辑 |
| 短片 | 产品、氛围、概念、视觉动作 | 5–15 秒，1–3 镜 | 想法 → 提示词/最小镜头单 → ComfyUI → 导出 |

“短片”按叙事复杂度而非仅按秒数判断。有完整冲突与回收就用小剧场；跨集关系与伏笔需要延续才用连载。品牌露出服务剧情，不要求每集硬广或强制 CTA。

## 产品价值与成本

卖点是复用资产、跨集一致性、可改稿、可恢复的制作过程。衡量首集交付耗时、每集新增资产数、可用镜头比例、失败重试数、单集实际 GPU 时间和更新完成率；不承诺爆款、收益或零成本。

新人物、新场景、多人交互和复杂动作都消耗生成与校验时间。先短样、先低分辨率、优先稳定参考图和可控动作。生成重试默认每镜最多 2 次，失败后改镜头或报告阻塞，不无限消耗机器资源。

## 安装形式

`agents/` 是可直接发布的人格提示词；`skills/` 是重新融合的自包含技能，不调用其他已安装 skill。`publication/` 是从这两者生成的完整表单文本与独立 ZIP 包。发布包直接带文件，无软链、无密钥、无第三方生成服务 SDK。

正文创作使用 WorkBuddy 当前会话。出图和视频仅使用用户已有的本地/自有云电脑 ComfyUI 与已装模型；成片拼接使用已有 FFmpeg 或用户已有免费本地编辑器。没有执行环境时交付完整制作包，状态必须写“待生成”，不能称已成片。

不新增 .NET、Node、Remotion、HyperFrames、付费剪辑软件、云 TTS、素材订阅或外部 API。技能按正文中的逐项检查交付，不依赖原 novel-* 的校验器；打包脚本只在维护仓库时使用 Python 标准库，不属于专家运行依赖。自有 ComfyUI 的本地接口属于用户指定执行环境，不是第三方托管生成 API。

企业 Agent 运行于独立云端沙箱：它的 localhost 不是用户电脑。本机生成通过交付便携制作包给本地助理执行；已有且从沙箱可达的自有 ComfyUI 才能由企业 Agent 直接调度。本次不新增隧道、公开端口或云机器。
