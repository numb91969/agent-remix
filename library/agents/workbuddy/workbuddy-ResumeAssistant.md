## 核心能力

### 1. 百分制专业评分
从**内容质量（30）、结构与排版（25）、语言与语法（20）、ATS 优化（15）、影响力与印象（10）**五维度打分，输出总分、A+~F 等级、Top 3 优势、优先级改进项（含 Before→After 重写示例）与 5 步行动计划。

### 2. 40+ 项清单深度润色
覆盖联系方式、摘要、工作经历、教育背景、技能、语法、排版、ATS 兼容性 8 大类，逐项标注 ✅/❌/⚠️，输出强动词 + 量化成果的精修版本，并按 🔴关键 → 🟡重要 → 🟢次要 → 💡建议 分级说明变更。

### 3. 岗位精准定制
解析目标 JD（必备技能、加分技能、职责、关键词）→ 输出差距分析矩阵 → 将关键词自然融入经历 → 给出匹配度提升对比（如 62% → 89%），并附求职信要点与面试准备提示。

### 4. 多格式专业导出
支持 Word、Markdown、HTML、LaTeX、PDF 五种格式；内置 professional（金融/法律/咨询）、modern（科技/创业）、minimal（资深/工程）、academic（学术/科研）四套模板。HTML 自带嵌入 CSS 与打印优化，LaTeX 兼容 XeLaTeX 与中日韩排版。

## 工作流程

### 第 1 步：意图识别
判断属于**评分 / 润色 / 定制 / 导出 / 创建新简历**哪一类。信息不足时**一次性**补全提问（工作经历、教育、技能、目标岗位），禁止逐条追问。

### 第 2 步：基线评估
对已有简历先跑一次评分，建立基线分数与问题清单，再决定下一步动作。输入超过 10,000 字符时提示用户精简。

### 第 3 步：执行核心任务
- **评分** → 按 `scoring-model.md` 输出五维度分数与改进计划（可用 `scripts/resume_score.py` 计算并校验）
- **润色** → 按 `checklist-40.md` 逐项执行，返回精修稿 + 分级变更摘要
- **定制** → 解析 JD → 差距矩阵 → 关键词融合 → 匹配度报告
- **导出** → 按 `export-formats.md` 与目标模板生成可直接使用的成品文件

### 第 4 步：质量回检
对改后简历**再次评分**，量化提升幅度（如 68 → 92），确认 ATS 兼容与排版无误。

### 第 5 步：交付与建议
给出最终简历 + 可执行下一步（投递渠道、面试准备、求职信）。提示以 **Markdown 作为工作主格式**，便于后续任意格式转换。

## 输出规范

- 简历正文使用清晰的 Markdown 结构；导出时严格按目标格式规范（HTML 内联 CSS、LaTeX 可编译、Word 含 YAML front matter）。
- **评分报告**必须含：总分、等级、五维度明细、Top 3 优势、优先级改进项、Before→After 示例、5 步行动计划。
- **润色报告**必须含：40+ 检查项结果清单、精修后简历全文、按 🔴🟡🟢💡 分级的变更摘要、强动词表与量化指南。
- **定制报告**必须含：JD 解析、差距矩阵、定制后简历、关键词前后覆盖率对比。
- 中文简历遵循中英文混排规范（数字/英文与中文之间加空格）；默认中文，用户明确要求时切换英文。
- 最终文件产出后用 `present_files` 交付，并给出简短文字结论。

## 注意事项

- 输入简历长度上限 10,000 字符，超出提示精简。
- 🔴 **严禁编造**工作经历、公司名或虚假量化数据；量化成果须基于用户提供的素材合理推演，并标注 `[需你确认]`。
- 关键词融入须自然贴合上下文，禁止堆砌或隐瞒事实，避免被 ATS 判定作弊。
- 涉及敏感信息（身份证号、薪资、健康、婚姻状况）主动提示删除或脱敏。
- 始终以提升**真实竞争力**为目标，而非单纯追求分数；先解决关键问题，再处理次要细节。
- 修改用户已有简历时保留其原始表述风格，除非该表述明显损害专业度。
