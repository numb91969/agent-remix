# Exhibit 解剖学：一张麦肯锡图表由哪些零件组成

## 这份文件解决什么问题

上一版规范只管到"整页布局"和"用什么颜色"，**没有一条规则管单张图表的内部结构**。
结果是：色板对了、版式对了、数据也对了，但图表本身仍然是 Office 默认长相——
带 Y 轴、带横向网格线、图例挂在底部、数值要去对刻度。**"看着不像麦肯锡"的根因就在这一层。**

下面每一条都是从《麦肯锡中国季刊 / CEO 特刊》2021+ 语料反推出来的，都能机读校验。

---

## 一、六个零件（自上而下）

一张完整的麦肯锡 exhibit 恰好由这六个零件构成，**多一个少一个都不对**：

| # | 零件 | 规格 | 缺了会怎样 |
|---|---|---|---|
| 1 | **Action Title** | 36px Bold `#051C2C`，**一句完整的结论**，20–23 字≈一行 | 变成"XX 分析"式的标签，读者不知道该得出什么结论 |
| 2 | **口径副行** | 18–20px Regular 灰 `#7D7E81`，紧随标题下一行 | 数字没有口径，读者不知道单位/样本/年份，无法判断可信度 |
| 3 | **分割线** | 1px `#051C2C`，横贯 1168px | 标题与图混在一起，页面没有呼吸 |
| 4 | **图形区** | 内容区 ≥70%，见下文"二、图形区八条" | 变成文字页 |
| 5 | **Source 行** | 14px 灰，`资料来源：xxx，2025年` | 门禁直接 FAIL |
| 6 | **Footnote** | 14px 灰，`注1：不含港澳台`，仅在有口径例外时出现 | 口径歧义没处交代，只能塞进正文挤占空间 |

**没有图号。** 不要在标题左上方放 `图2` 这种角标：语料是杂志，图周围有正文要写
"如图3所示"，deck 一页就是一张图，没有引用对象。原刊的编号也是**写在标题这一行里**
（`图3:不准确、网络安全……` 同样的粗体黑色，见 `exemplars/01-bar-grey-track.png`），
本来就不是独立的浅灰小标签；真要交叉引用就照这个格式写进标题文本。

### 零件 1–3 的 y 坐标（1280×720 画布，固定值，不要自创）

标题从 y=72 起，顶部那段留白就空着，别因为没了图号把标题上移。

| 元素 | y | 高 |
|---|---|---|
| Action Title | 72 | 45（36px × 1.25，单行） |
| 口径副行 | 121 | 25 |
| 分割线 | 154 | 1 |
| **图形区** | **166** | **至 646，可用 480** |
| Footnote | 662 | 18 |
| Source | 682 | 18 |
| 页码（右对齐） | 682 | 18 |

**标题超过一行怎么办**：不是把内容区往下推，而是**把标题改短**。
36px 字在 1168px 宽下每行约 32 个中文字，结论句写不进 23 字说明结论还没提炼干净。
真的需要两行时，口径副行下移到 166、分割线到 199、图形区起点改成 211（可用 435px），
且该页图形必须相应压缩——**不许让图形区伸进页脚带**。

```jsx
{/* 零件 1–3 的标准骨架，每一张 exhibit 都从这段开始。注意：没有图号 */}
<Box style={{ position: 'absolute', top: 72, left: 56, width: 1168 }}>
    <Text style={{ fontFamily: '楷体', fontSize: 36, fontWeight: 'bold', color: '#051C2C', lineHeight: 1.25 }}>
        准确性而非合规，是企业落地生成式 AI 的第一道闸门
    </Text>
</Box>
<Box style={{ position: 'absolute', top: 121, left: 56, width: 1168 }}>
    <Text style={{ fontFamily: '楷体', fontSize: 18, color: '#7D7E81', lineHeight: 1.4 }}>
        受访企业中「正在着手解决该风险」的比例，%；n=1,491，2025年3月
    </Text>
</Box>
<Box style={{ position: 'absolute', top: 154, left: 56, width: 1168, height: 1, background: '#051C2C' }} />
```

### 口径副行必须写清楚的四件事

这一行是麦肯锡与"看起来像麦肯锡"之间差得最远的地方，也是最容易补齐的。格式：

```
<度量说明>，<单位>；n=<样本量>，<时点>
```

- **度量说明**：这些数字到底在数什么。「受访企业中正在着手解决该风险的比例」，
  而不是「风险占比」——后者读者会理解成完全不同的东西。
- **单位**：`%` / `亿元` / `万亿美元` / `pp`。**放在副行，不要重复标在每个数据标签上。**
- **样本量或口径范围**：`n=1,491` / `不含港澳台` / `A股上市公司口径`。
- **时点**：`2025年3月` / `2024财年` / `2026E`。预测值必须带 `E`。

不适用的项可省，但**度量说明与时点两项永远不能省**。

## 二、图形区八条（这八条决定"像不像"）

### 1. 零网格线

**横向网格线一条都不许有。** 麦肯锡图表里网格线出现率接近 0。
手绘图天然没有；用原生 `<Chart>` 的，交付前必须用 `$ED` 的
`slide_update_chart_gridlines(visible=false)` 关掉（饼图/环图不支持该接口，所以饼图别用原生）。

**唯一的例外**（见 `exemplars/06-dumbbell-gap.png`）：横向哑铃图这类需要读者**跨行比较横向位置**的图，
可以画极浅的**竖向**虚线刻度线。注意方向——禁的是横向网格线，以及 Office 默认那种深灰实线网格。
用这个例外时线色不得深于 `#CED0D1`，且必须是虚线。

### 2. 零 Y 轴

**没有 Y 轴、没有刻度、没有轴标签。** 量级信息靠三样东西传达：
①条端/线端直标数值；②`#E6E6E6` 灰 track 给出 100% 基准；③口径副行里的单位。
原生图表关不掉 Y 轴，这也是折线与横条**必须手绘**的根本原因。

### 3. 唯一的一条轴是基线

底部保留 1px `#B3B3B3` 基线（柱图、折线）。垂直方向什么都不留。
散点/2×2 是例外：它需要两条真实坐标轴，用 `#7D7E81` 1px。

### 4. 端点直标，不让读者对刻度

- 折线：**只标最后一个点**的值（20px Bold，与线同色，放在线端右侧 12px 处）。
  中间点如有拐点意义可加标，但一张图直标点数 ≤3。
- 柱/条：每根都标，放在条端外侧。
- 高亮项的数值用 Bold + 深色，非高亮用 Regular + `#7D7E81`。

### 5. 图例内联，不用 Office 图例

Office 图例挂在图表底部居中，一眼就是 PowerPoint 味。改成：
**绘图区左上角一行 24×3px 微线段 + 16px 标签**，或者**直接把系列名标在线端**（更麦式）。
系列只有一个时**不要图例**。

### 6. 一页只高亮一个

每张图只有一个系列/一根柱/一个气泡用 `#051C2C` 或 `#00A9F4`，
其余一律弱化为 `#AAE6F0` 或 `#CED0D1`。
**自检**：把图缩到 25% 大小眯眼看，如果说不出"该看哪"，这张图就得重做。

### 7. 排序有意义

条形图**一律降序**（或按逻辑顺序如时间/流程），绝不按字母序或数据源的原始顺序。
热力矩阵的行按总量降序排，最重要的行在最上面。

### 8. 纵向撑满，禁止矮图贴顶

内容区 166–646（可用 480px）。**墨水底边须到 y≥560**（约 85%），否则下半空白过大、
一眼机器排版。行/条数少于片段默认（热力 8 行、横条 8 条）时**加高行高/条高**填满，
公式见 `charts.md` §2/§3。不要把矮图块 `justifyContent:'center'` 垂直居中——
麦式是顶对齐、把图元本身拉高。`gate_check`「下半留白」会 WARN。

## 三、结论区：图右侧的那一栏

麦肯锡 exhibit 很少是"光秃秃一张图"。标准做法是**图占左侧 60–65%，右侧留一栏结论**：

```jsx
<Box style={{ width: 368, justifyContent: 'center', gap: 18 }}>
    <Box style={{ width: 48, height: 3, background: '#2251FF' }} />           {/* 装饰短线 */}
    <Text style={{ fontFamily: '楷体', fontSize: 26, fontWeight: 'bold', color: '#051C2C', lineHeight: 1.35 }}>
        准确性是第一道闸门                                                     {/* 8–12 字小结论 */}
    </Text>
    <Text style={{ fontFamily: '楷体', fontSize: 22, color: '#191919', lineHeight: 1.45 }}>
        56% 的受访企业把「输出不准确」列为正在着手解决的风险 [F]，比第二位高 3pp。 {/* 2–3 句，带证据标签 */}
    </Text>
</Box>
```

**结论区不是图注**。它要回答"所以呢"，必须包含一个**行动指向或判断**，
而不是把图上已有的数字复述一遍。写成"图中显示 56% 的企业……"就是失败的结论区。

宽度取 368–380px；再窄放不下 22px 正文，再宽图形区就压不到 70% 了。

## 四、自检清单（每页画完当场过一遍）

- [ ] Action Title 是完整结论句、20–23 字？
- [ ] 口径副行在？含度量说明 + 单位 + 样本 + 时点？
- [ ] 一条横向网格线都没有？没有 Y 轴？
- [ ] 数值直接标在条端/线端，读者不需要对刻度？
- [ ] 只有一个元素是深色高亮，其余弱化？
- [ ] 条目降序排列？
- [ ] 图例是内联微线段（或干脆没有），不是 Office 底部图例？
- [ ] 图右侧结论区回答了"所以呢"，不是复述数字？
- [ ] 墨水底边到了 y≥560？行少时已加高行高，下半没有大片空白？
- [ ] Source 行在？含出处 + 年份？

前六条 + 纵向撑满由 `../scripts/gate_check.py` 自动查，其余靠人眼。
