# 腾讯问卷导入格式（DSL）

> 每次问卷设计交付时，必须同时输出可直接复制到腾讯问卷「批量编辑」的纯文本版本。

## 格式规则

```
标题[题型][必答/选答]
选项1
选项2
...
```

## 题型标识

```
[单选题] [多选题] [矩阵单选题] [排序题] [量表题] [单行文本题] [多行文本题] [下拉题]
```

## 分页

```
===分页===
```

## 矩阵题格式

```
标题[矩阵单选题][必答]
列头1 列头2 列头3 列头4 列头5 列头6   ← 空格分隔
子问题1
子问题2
```

## 逻辑跳转标注（必须）

```
===逻辑跳转说明===
Q1选"在职技术人员" → Q3隐藏"准备明年校招"
Q1选"其他" → 跳转至结束页
Q2选"从未实习过" → Q17隐藏"实习亲身体验"
```

## 逻辑跳转说明表格式

每份问卷设计完成后，必须在末尾附上独立的「逻辑跳转说明表」：

| 触发条件 | 执行动作 | 原因 |
|---------|---------|------|
| Q1=在职技术人员 | Q3隐藏"准备明年校招" | 在职人员不会参加校招 |
| Q1=其他 | 结束问卷 | 非目标人群 |
| Q1=在校本科/硕博 | Q后续隐藏"5年以上经验"相关 | 逻辑矛盾 |

## DSL text 格式（API创建用）

将问卷方案转换为 `text` 参数时的语法：

```
问卷标题

引导语（可选）

1. 题目标题[题型][设置](描述)
选项A
选项B
...

=== 分页 ===

2. 下一题[题型]
选项...
```

### 题型对照表

| Rita 设计 | DSL 语法 | 备注 |
|-----------|---------|------|
| 单选题 | `[单选题]` | 默认题型，可省略 |
| 多选题 | `[多选题]` | |
| 量表题 | `[量表题]` + `1~5` | 数字范围表示 |
| 矩阵量表题 | `[矩阵量表题]` + `1~5` + 子问题 | |
| 开放题 | `[多行文本题]` | |
| 必答标记 | `[必答]` | 追加在题型后 |
| 选答标记 | `[选答]` | |
| 下拉题 | `[下拉题]` | |
| 排序题 | `[排序题]` | |

### 注意事项

- JSON 中换行必须用 `\n` 代替
- 选项**不需要**字母前缀（写 `满意` 不写 `A. 满意`）
- 题目内标题和选项之间**不能有空行**
- 量表范围用 `~`（如 `1~5`）

## 自动化路径

如 WorkBuddy 已连接 `tencent-survey`（会话工具列表出现 `create_survey`），**必须直接调用工具在线创建问卷**，DSL 格式仅作为附录保留供人工复核。⛔ 严禁把 DSL 甩给已连接的用户让其自行复制粘贴生成。仅当未连接时，DSL 纯文本才作为交付主体 + 附手动导入指引。
