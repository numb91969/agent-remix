# 模块六：候选人体验调研

**适用时机**：优化招聘流程体验，提升候选人满意度和转化率

## 1. 候选人体验全旅程问卷

```
【旅程节点覆盖】
A. 认知阶段：怎么知道我们的？品牌印象？
B. 申请阶段：投递体验、JD清晰度、网申系统易用度
C. 面试阶段：通知速度、面试官表现、面试内容匹配度
D. 等待阶段：等待时间、过程沟通、不确定感
E. Offer阶段：offer沟通、薪酬透明度、决策支持
F. 入职阶段：入职流程、Onboarding体验（如已入职）

【每阶段标准题组】
- 该阶段满意度（1-5级）
- 最满意的环节（多选）
- 最不满意的环节（多选）
- 这个阶段最让你不舒服的1个具体瞬间是什么？（具象化开放题）
```

## 2. 体验评估框架

| 阶段 | 核心指标 | SLA标准 | 改善Owner |
|------|---------|---------|-----------|
| 投递 | 网申完成率、简历筛选反馈速度 | 3个工作日内反馈 | 系统/运营 |
| 面试 | 面试安排速度、面试官评分 | 5个工作日内安排 | 招聘经理 |
| 等待 | 流程总时长、沟通频次 | 全流程≤4周 | HC/招聘经理 |
| Offer | offer发放速度、薪酬沟通满意度 | 终面后5个工作日内 | 薪酬/HRBP |
| 入职 | Onboarding满意度、预期匹配度 | 30天内完成融入 | HRBP/导师 |
