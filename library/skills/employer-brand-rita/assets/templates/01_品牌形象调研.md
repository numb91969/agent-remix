# 模块一：品牌形象调研（战略级）

**适用时机**：年度/半年度品牌健康度评估，了解目标人群怎么看我们

## 1. 标准问卷模板

```
【筛选题】确认人群身份（含跳转逻辑）
  - 学历/院校层级/专业方向/毕业年份/求职状态
  - 逻辑跳转规则示例：
    · 身份=在职技术人员 → 后续题隐藏"准备明年校招"选项
    · 身份=在校本科/硕博 → 后续题隐藏"在职X年"相关选项
    · 从未在目标公司实习 → 信息渠道题隐藏"实习亲身体验"选项
    · 身份≠目标人群 → 触发"感谢参与"结束页

【核心模块A】品牌认知
  - 提示前认知（开放联想：提到XX公司你想到什么？）
  - 提示后认知（给logo/名称，是否听说过？了解程度？）
  - 品牌形象词（语义差异量表 / 限选5个形容词）
  - NPS净推荐值（0-10标准量表）

【核心模块B】雇主品牌吸引力（9维度量表）
  - 薪酬水平 / 福利待遇 / 成长发展 / 环境氛围 / 公司名气
  - 业务水平 / 公司前景 / 工作强度 / 雇主品牌
  - 统一6分量表：非常差(0)→非常好(100)

【核心模块C】竞品对比
  - 最想去的公司TOP5（多选排序）
  - 各竞品雇主品牌吸引力横评（矩阵题）
  - 与竞品比，我们的优势/劣势各3项（限选）

【核心模块D】渠道与触点
  - 通过什么渠道了解到我们（多选）
  - 各渠道影响力评分
  - 过去半年让你印象最深的1个我们的品牌内容/活动是什么？（限写1个）

【收尾】具象化开放题
  - 说起我们公司，请给出你第一时间想到的3个关键词
  - 如果我们只能改善1件事来吸引你加入，那件事是什么？
```

## 2. 访谈提纲模板

> **交付规范（P0）**：访谈提纲一律交付**简版**，控制在 **5页以内**。

```
一、暖场（5min）：基本信息确认
二、品牌联想（10min）：第一印象、信息来源、认知变化
三、吸引力因素（15min）：什么吸引你/不吸引你？与竞品比？
四、决策影响（10min）：品牌印象对你投递/接offer的影响程度
五、建议（5min）：如果你是我们的品牌负责人，你会先做什么？
```

## 3. 分析框架

| 分析板块 | 核心指标 | 交叉维度 | 输出图表 |
|---------|---------|---------|---------|
| 认知度 | 提示前/后认知率 | 院校层级×专业 | 分组柱图 |
| 形象评价 | 各维度均分+排名 | 竞品横评 | 雷达图/热力图 |
| NPS | 推荐者/被动者/贬损者占比 | 年度对比 | KPI卡+趋势线 |
| 竞品格局 | TOP5投递意向分布 | 按专业/学历切 | 堆叠柱图 |
| 渠道有效性 | 各渠道触达率×转化贡献 | 按人群切 | 漏斗图 |
