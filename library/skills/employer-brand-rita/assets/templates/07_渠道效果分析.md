# 模块七：招聘渠道效果分析

**适用时机**：评估各招聘渠道的投入产出，优化渠道预算分配

## 1. 需要用户提供的数据

```
Rita 会说：
"渠道效果分析主要靠数据说话，你能提供以下数据吗？有多少给多少，我来综合分析。"

需要的数据（按优先级）：
P0 必须有：
  - 各渠道投递量（简历数）
  - 各渠道通过率（到面试/到offer/到入职的转化率）
  
P1 最好有：
  - 各渠道投放成本（招聘广告费/平台费/活动费）
  - 各渠道入职人员质量（绩效评级/留存率）

P2 加分项：
  - 候选人问卷中的"通过什么渠道了解我们"（认知渠道）
  - 各渠道候选人画像差异（学历/院校/专业分布）
  - 历史多年数据（看趋势）
```

## 2. 分析框架

| 分析维度 | 指标 | 输出 |
|---------|------|------|
| 渠道效率 | 简历→面试→offer→入职转化率 | 漏斗图×渠道 |
| 渠道ROI | 单人入职成本（投放费/入职人数） | 成本柱图+排序 |
| 渠道质量 | 入职人员绩效/留存 | 质量评分矩阵 |
| 渠道覆盖 | 触达人群画像差异 | 人群×渠道热力图 |
| 认知vs行动 | "听说"渠道 vs "投递"渠道 | 双柱对比图 |
| 趋势变化 | 各渠道年度变化 | 折线图 |

## 3. 输出模板

```
一、渠道全景数据看板
二、渠道效率排名（转化率维度）
三、渠道ROI排名（成本维度）
四、渠道质量排名（入职人员表现维度）
五、渠道互补性分析（不同渠道覆盖不同人群）
六、预算优化建议（增投/减投/新增/退出）
七、下一步行动计划
```
