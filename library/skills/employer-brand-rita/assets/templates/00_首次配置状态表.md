# 首次配置状态表模板

> Rita 执行完 `scripts/config_check.md` 中的 6 条检测后，用以下模板输出配置状态。
> 用实际检测结果替换 `✅ / ❌` 和方括号中的内容。

---

```
嗨！我是 Rita，你的招聘调研专家 👋

在开始之前，我先帮你检查一下工具配置状态：

📋 核心工具（建议先配好）：
✅ / ❌ 调研数据后端（MCP） — [已连接 / 未连接 → 请配置 rita，未注册请前往 https://campus123.woa.com/fofo]
✅ / ❌ 腾讯问卷 — [已连接 / 未连接 → 请到 WorkBuddy 右上角「连接器管理」页面，找到「腾讯问卷」点击信任]
✅ / ❌ 腾讯文档 — [已连接 / 未连接 → 请到 WorkBuddy 右上角「连接器管理」页面，找到「腾讯文档」点击信任]

🔍 口碑搜索能力：
✅ 小红书搜索 — 已就绪（网页搜索）
✅ / ❌ 脉脉搜索 — [已安装 agent-browser（可深度浏览脉脉帖子） / 未安装 → **强烈建议安装**，说一声我直接帮你装。脉脉是招聘口碑核心平台，安装后可浏览完整帖子]
✅ 微博搜索 — 已就绪（网页搜索）

🔄 版本状态：[✅ 已是最新 v2.0.0 / 🆕 发现新版 vX.Y.Z / 当前 v2.0.0（未发现更新源）]

口碑搜索中，小红书和微博已可以直接使用。
**脉脉是招聘口碑最重要的平台**，强烈建议安装 agent-browser 以获取更深入的脉脉数据（完整帖子+评论）。
没有 agent-browser 也能搜脉脉（用网页搜索），但数据深度有限。

标「❌」的是还没配好的核心工具，建议先配上（问卷创建和数据导出需要）。
需要我帮你安装 agent-browser 吗？或者直接说你的需求，我们开始吧！
```

> **若版本状态为「🆕 发现新版」**：在状态表之后追加一句升级询问——
> 「🆕 检测到 Rita 有新版本 **vX.Y.Z**（当前 v2.0.0）。本次更新：{release_note 摘要}。是否现在升级？回复"升级"我来帮你安装。」

---

## 使用说明

- 模板中的 `✅ / ❌` 根据实际检测结果二选一
- 方括号 `[A / B]` 中的内容根据检测结果选择对应分支
- 小红书和微博**固定显示 ✅**（使用WebSearch，无需检测）
- 脉脉根据 agent-browser 检测结果决定显示 ✅ 还是 ❌
- 版本状态根据检测5结果填写；查不到更新源时显示「当前 v2.0.0（未发现更新源）」，**不打扰用户**
