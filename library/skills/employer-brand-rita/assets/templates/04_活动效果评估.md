# 模块四：校园活动/宣讲效果评估

**适用时机**：宣讲会、tech talk、hackathon、校园开放日等活动后

## 1. 即时反馈问卷（8-12题，3分钟完成）

```
【满意度核心题】
Q1. 整体满意度（1-5星）[必答]
Q2. 各环节满意度（矩阵题）[必答]
    - 嘉宾分享质量 / 互动环节 / 答疑质量 / 现场组织 / 时间安排

【意向变化题】
Q3. 参加前对我们的就职意向（5级量表：非常不想→非常想）[必答]
Q4. 参加后对我们的就职意向（同上）[必答]
Q5. 意向变化原因（多选）[条件：Q4>Q3 或 Q4<Q3]
    加分项：了解到有趣项目/团队氛围好/技术实力强/薪酬有竞争力/...
    减分项：内容太官方/没有干货/与预期不符/...

【品牌认知题】
Q6. 今天让你印象最深的1个信息点是什么？（单行文本）[必答]
Q7. 你最想加入哪个部门/团队？（多选）[选答]

【收尾】
Q8. 你还参加了哪些公司的类似活动？（多选）[选答]
Q9. 如果下次活动只能改进1个环节，你最希望改哪个？为什么？（单行文本）[选答]
Q10. 是否愿意参加后续深度交流？（单选：是/否 + 留联系方式）[选答]
```

## 2. 效果评估分析框架

| 核心KPI | 计算方式 | 基准线 | 决策用途 |
|---------|---------|--------|---------|
| 整体满意度 | 均值 | ≥4.0/5.0 为优 | 活动质量判断 |
| 意向提升率 | (活动后意向>活动前) / 总人数 | ≥80% 为优 | 品牌转化效果 |
| NPS | (推荐者-贬损者)/总数×100 | ≥50 为优 | 口碑传播力 |
| 部门吸引力分布 | 各部门意向占比 | 对比历史 | 资源分配 |
| 竞品同台率 | 参加了竞品活动的占比 | 了解竞争格局 | 差异化策略 |

## 3. 报告模板结构

```
一、活动基本信息（时间/地点/规模/嘉宾）
二、核心KPI看板（满意度/意向提升/NPS）
三、各环节细项评分（找短板）
四、意向变化分析（加分/减分因素）
五、与历史场次对比（如有）
六、竞品同台分析
七、候选人原声精选（开放题精华）
八、改进建议（优先级排序）
```
