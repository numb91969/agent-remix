# 输出模板

以下模板按当前任务选用，不要求一次全部生成。材料中没有对应信息时，写“材料未提供”或省略该节，不得补写。默认正文只放简短来源锚点（如 `【S1-p8】`），完整的来源身份、加工方式和核验状态集中放在文末“依据说明”表；只有冲突、模型推断和待确认内容需要在正文就地展示完整三轴标记。

```markdown

```

## 三、一页纸总结

```markdown
# 一页纸复习总结

## 一句话主线
- 内容：
- 依据：【S1-p2；S2-00:05:10｜老师课件＋老师讲解｜多材料归纳｜已定位】

## 必须掌握
1. 知识点【S1-p8｜老师课件｜单一材料转述｜已定位】

## 关键公式、结论或方法
1. 公式或方法【S2-00:12:30｜老师讲解｜原文摘录｜已定位】

## 易错点
1. 易错点【S1-p10；S2-p12｜老师课件＋本人笔记｜多材料归纳｜部分支持】

## 待确认

## 下一次复习
```

通常包含 3—7 个知识点和 2—5 个易错点，但材料不足时以实际内容为准。未经确认的模型判断不写成“必考”“必须掌握”或“老师重点”。

## 四、概念卡片

```markdown
### 概念名称
- 卡片标识：课程标识｜章节｜概念
- 卡面问题：一个可独立回答的问题
- 答案要点：一到三条
- 易混消歧：没有则省略
- 核验状态：已定位 / 部分支持 / 存在冲突 / 模糊 / 缺失 / 待确认
- 复习资格：候选 / 可复习
- 依据：【来源｜来源身份｜加工方式｜核验状态】
```

一卡只测一个知识点。集合或枚举能拆则拆；相似概念必要时增加一张“最小区分条件”消歧卡。每次最多生成 10 张。生成后运行 `card_policy.py`：待确认、部分支持、模型补全或无可靠来源内容保留为候选卡且不排期；只有满足门禁的卡片才标记为可复习。

## 八、分批处理状态

```markdown
## 本批处理状态
- 批次：第 1 批 / 共 N 批
- 已处理来源与范围：
- 未处理来源与范围：
- 当前知识树版本：v0.1
- 待确认项：
- 当前结果性质：阶段性 / 完整
- 下一批起点：
```

材料未处理完时，结果必须标为“阶段性”，不得称为完整课堂笔记。

## 九、纠正影响清单

```markdown
## 本轮纠正
- 用户纠正：
- 已撤回或降级的原结论：
- 受影响来源/知识点：
- 受影响产物：正文 / 一页纸 / 卡片 / 对比表 / 题目 / 答案
- 重新对齐结果：
- 仍待确认：
```

纠正完成前，暂停继续生成依赖原结论的复习材料。

## 十、资料库写入摘要

```markdown
## 本批保存内容
- 课程：
- 课程主页：新建 / 复用
- 笔记：1 篇，标题为《》
- 概念卡：新增 N 张 / 更新 N 张
- 可复习：N 张；候选：N 张
- 未保存：N 项
```

该摘要用于写入前说明和写入后验收。用户未授权或写入失败时，将卡片保留在对话中，不写“已保存”。
