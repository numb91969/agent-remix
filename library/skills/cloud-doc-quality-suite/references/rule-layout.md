# 规则 4：排版格式检测

## 目的

检测目标文档中是否存在**标题层级跳跃、空段落过多、列表格式混乱、表格结构异常、标记未闭合**等排版问题。

## 适用条件（v1.7.0 新增前置门控）

本规则**仅适用于流式文本类文档**（`file_ext ∈ { docx, md, pdf, txt }`）。

**PPT/Excel 文件（`file_ext ∈ { pptx, xlsx }`）整体跳过本维度**，理由：

1. **PPT（`.pptx`）**：采用**页面式版式编辑**，其\"标题层级、列表、表格、段落结构\"由 PowerPoint **版式（Slide Layout）与占位符（Placeholder）**约束，属于页面视觉设计范畴，与流式文本的\"h1→h2→h3 层级链\"\"空段落数量\"\"Markdown 表格结构\"是完全不同的排版模型。若强行套用本规则会产生大量伪异常
2. **Excel（`.xlsx`）**：是**纯表格数据文件**（工作表 + 单元格网格），不存在\"标题层级、段落、列表、格式一致性\"等流式排版概念，本规则完全不适用

跳过时输出：
```json
{
  "维度名称": "排版格式检测",
  "检测状态": "已跳过（PPT/Excel 文件类型不适用排版规则）",
  "异常数量": 0,
  "问题列表": []
}
```

> 提示：PPT 的版式合规性可由\"文档结构质量评审\"（维度 1）通过与官方 `.pptx` 模板对比来覆盖；Excel 报价表的合规性由\"文档结构质量评审\"通过 `产品报价指引.xlsx` 模板对比覆盖。

## 工作流程

### Step 1：获取原始格式信息

需要获取以下标记格式：
- **标题层级标记**：Markdown `#` 层级 / HTML `<h1>`~`<h6>`
- **段落结构**：段落分隔、空行分布
- **列表标记**：有序 `1.2.3.` / 无序 `- * +` / HTML `<ul>/<ol>`
- **表格结构**：Markdown 表格 / HTML `<table>`
- **其他**：引用块、代码块、分割线

### Step 2：执行排版检测规则

> **核心原则：必须从原文出发，不要联想和推理，不要夸大问题**

#### 一、标题层级检测

| 检测项 | 判定异常条件 | 示例 |
|--------|-------------|------|
| 层级跳跃 | h1→h3（跳过h2）、h2→h4（跳过h3），以此类推 | `# 标题` → `### 子标题`（跳过 h2） |
| 层级倒置 | 文档首个标题不是 h1；父子层级关系不合理 | 以 h3 开始文档 |
| 重复标题 | 同一层级下出现完全相同的标题文字 | 两个 h2 都是"概述" |
| 空标题 | 有标题标记但无实际文字内容 | `## ` 或 `<h2></h2>` |

#### 二、空段落/空白异常检测

| 检测项 | 判定异常条件 |
|--------|-------------|
| 连续空段落过多 | Markdown 中连续 ≥3 个空行；HTML 中连续 ≥2 个空 `<p></p>` |
| 段落间距不一致 | 部分间隔 1 行，部分 ≥3 行（差异 ≥2 行才标注） |
| 末尾多余空行 | 文档末尾 ≥3 个连续空行 |

> 代码块内部的空行不在检测范围内；标题前后 1~2 个空行属正常排版。

#### 三、列表格式检测

| 检测项 | 判定异常条件 | 示例 |
|--------|-------------|------|
| 标记混用 | 同一列表中混用 `-` `*` `+` 或有序+无序 | `- A\n* B\n+ C` |
| 编号异常 | 编号不连续/重复/倒退/不从1开始（非嵌套） | `1.\n2.\n4.` |
| 缩进异常 | 子列表缩进不足/层级跳跃/同层缩进不一致 | |
| 空列表项 | 仅有标记无文字内容 | `- ` 或 `1. ` |

#### 四、表格结构检测

| 检测项 | 判定异常条件 |
|--------|-------------|
| 列数不一致 | 某行列数 ≠ 表头列数 |
| 分隔行缺失/错误 | 表头与表体间缺少 `\|---\|---\|` 或格式错误 |
| 空表格 | 仅有表头无数据行，或完全无内容 |

#### 五、格式一致性检测

| 检测项 | 判定异常条件 | 示例 |
|--------|-------------|------|
| 强调标记未闭合 | `**文字` 缺少结尾 `**`；`*文字` 缺少 `*` | |
| 代码块未闭合 | 三反引号开始但未结束 | |
| 引用块格式异常 | 混合使用 `>` 和非引用行导致断裂 | |

#### 六、不检测内容

1. **代码块内部内容**
2. **原始 HTML 嵌入代码片段**
3. **第三方嵌入内容**（iframe、嵌入式视频等）
4. **自动生成的内容**（目录 TOC、自动编号）
5. **图片 alt 文本和标题属性**

## 输出格式

```json
[{
  "问题位置": "问题所在的章节、段落或行范围",
  "问题类型": "枚举值之一（见下表）",
  "问题描述": "排版问题的具体描述，不超过40个汉字",
  "原文片段": "包含排版问题的原文片段（保留原始标记格式）",
  "修复建议": "针对该排版问题的具体修复建议",
  "修复示例": "修复后的正确格式示例"
}]
```

### 问题类型枚举

| 枚举值 | 说明 |
|--------|------|
| `HEADING_LEVEL_JUMP` | 标题层级跳跃 |
| `HEADING_LEVEL_INVERSION` | 标题层级倒置 |
| `HEADING_DUPLICATE` | 同一层级重复标题 |
| `HEADING_EMPTY` | 空标题 |
| `EMPTY_PARAGRAPH_EXCESSIVE` | 连续空段落过多 |
| `PARAGRAPH_SPACING_INCONSISTENT` | 段落间距不一致 |
| `TRAILING_BLANK_LINES` | 末尾多余空行 |
| `LIST_MARKER_MIXED` | 列表标记混用 |
| `LIST_NUMBER_ERROR` | 有序列表编号异常 |
| `LIST_INDENT_ERROR` | 列表缩进异常 |
| `LIST_ITEM_EMPTY` | 空列表项 |
| `TABLE_COLUMN_MISMATCH` | 表格列数不一致 |
| `TABLE_SEPARATOR_ERROR` | 表格分隔行错误 |
| `TABLE_EMPTY` | 空表格 |
| `MARKUP_UNCLOSED` | 强调标记未闭合 |
| `CODE_BLOCK_UNCLOSED` | 代码块未闭合 |
| `BLOCKQUOTE_FORMAT_ERROR` | 引用块格式异常 |

### 输出示例

```json
[{
  "问题位置": "第二章-产品概述",
  "问题类型": "HEADING_LEVEL_JUMP",
  "问题描述": "标题从 h1 直接跳至 h3，跳过了 h2 层级",
  "原文片段": "# 产品白皮书\n### 核心功能",
  "修复建议": "在 h1 和 h3 之间补充 h2 层级标题，或将 h3 降级为 h2",
  "修复示例": "# 产品白皮书\n## 产品概述\n### 核心功能"
}]
```

## 注意事项

- **严格基于原文和原始标记格式**：不做联想推理
- **区分格式与内容**：仅检测排版格式问题，不涉及内容准确性
- **尊重文档风格**：若风格内部一致则不判定为异常（如全部使用 h2 起始）
- **代码块豁免**：代码块内部格式不纳入检测
