# 规则 6：货币规范检测

## 目的

检测目标文档中**产品报价、案例金额、预算构成**等涉及货币单位的内容是否统一使用美元（USD / $），若发现使用了非美元货币单位则判定为货币单位不匹配。

## 适用场景

- 海外/国际版云计算产品文档的货币单位合规性审核
- 发布前检查非美元货币单位的报价内容
- 检查标杆案例、产品报价、预算构成、竞品对比中的货币单位一致性

## 适用条件（v1.7.0 新增前置门控）

本规则**仅适用于英文/海外/双语文档**（`language ∈ { en, mixed }`）。

**中文文档（`language == "zh"`）整体跳过本维度**，理由：

1. **业务定位**：中文文档面向国内客户，产品定价、案例金额、预算构成必须使用人民币（¥/￥/RMB/CNY/元/万元/亿元），这是**合规且必需**的默认单位，不构成异常
2. **符合外汇管理与广告法**：国内公开发布物中使用外币报价反而不合规
3. **避免误报**：中文语境中\"元\"字（人民币单位）大量出现，若强行套用美元规则会产生大规模误报

跳过时输出：
```json
{
  "维度名称": "货币规范检测",
  "检测状态": "已跳过（中文文档不适用货币规范）",
  "异常数量": 0,
  "问题列表": []
}
```

**双语文档（`mixed`）**：若英文段落中同时出现人民币与美元/其他货币混用，仍需按下述规则检测。

## 工作流程

### Step 1：获取目标文档全文

准备逐段扫描。

### Step 2：提取所有涉及货币/金额的内容

扫描范围包括但不限于：
- **产品报价**：定价、套餐价格、许可费用
- **案例金额**：合同金额、托管资产、交易金额
- **预算构成**：项目预算、费用拆分、总计金额
- **费用对比**：竞品价格对比、成本对比分析
- **消耗预估**：月消耗、年费用、日均成本
- **折扣信息**：折扣金额、优惠幅度

### Step 3：执行检测规则

> **核心原则：必须从原文出发，不要联想和推理，不要夸大问题**

#### 一、非美元货币单位检测

##### 1. 人民币单位检测

不匹配标识：`¥`、`￥`、`RMB`、`CNY`、`元`、`万元`、`亿元`、`人民币`
组合表达：`XX元/月`、`XX元/年`、`XX万元`、`总计XX元`

示例：
- "金额50万元/年" → 应转换为美元单位
- "预计月消耗<10万元" → 应转换为美元单位
- "某品牌A为6800元/月" → 应转换为美元单位

##### 2. 其他非美元货币单位检测

| 货币 | 不匹配标识 |
|------|-----------|
| 欧元 | `€`、`EUR`、`欧元` |
| 英镑 | `£`、`GBP`、`英镑` |
| 日元 | `¥`（日语境）、`JPY`、`日元`、`円` |
| 韩元 | `₩`、`KRW`、`韩元`、`won` |
| 新加坡元 | `S$`、`SGD`、`新加坡元`、`新币` |
| 其他 | 任何非 `$`(美元)、`USD` 的货币标识 |

#### 二、金额表达上下文分析

| 场景 | 判定规则 | 示例 |
|------|----------|------|
| 产品报价 | 所有含 `/月` `/年` `/天` `/次` 的价格必须使用 USD | "6800元/月" → 不匹配 |
| 标杆案例 | 合同金额/托管资产/交易额须使用 USD | "50万元/年" → 不匹配 |
| 预算与成本 | 总计及各分项/消耗预估须使用 USD | "总计250万元" → 不匹配 |
| 竞品对比 | 所有价格统一 USD，表头单位须为 USD | "单位：元" → 不匹配 |

#### 三、货币符号格式规范检测

| 子类型 | 规则要点 | 判定条件 | 反例 | 正例 |
|--------|---------|---------|------|------|
| 货币符号置于金额前、无空格、不加单位 | 货币符号（如 `¥`、`$`、`€`、`£` 等）须紧邻金额数字前，符号与数字之间**不留空格**，且金额后**不再重复附加货币中文单位**（如「元」「美元」） | ①符号与数字之间存在空格；②同一金额既用符号又在数字后加中文货币单位 | `¥ 1,234.56`（符号后带空格）<br>`¥1,234.56元`（符号+单位重复）<br>`$ 100`、`$100美元` | `¥1,234.56`<br>`$100`<br>`€99.00` |

**处理原则**：
- 属于**写作格式规范**问题，与货币单位不匹配（一~二节）并列输出。
- **若同一处金额既命中「非美元货币单位」又命中「符号格式」问题，需合并为一条输出**：`问题片段` 引用同一处原文，`修改建议` 中同时说明「货币单位换算」与「符号格式修正」两项要求，避免同一位置重复告警。
- 静态规则，无需外部依赖，正则即可判定。

#### 四、不检测内容（应跳过）

1. **非金额语境中的"元"字**：元素、元数据、元组、单元、元件等技术术语
2. **历史引用或法规原文**：直接引用的法律法规中的金额
3. **代码块中的内容**：代码示例、配置文件数值
4. **纯数字无单位**：未附带任何货币单位标识
5. **百分比和倍数**："提升50%"、"3倍增长"等
6. **折扣比率**："9.9折"、"85折"等（非金额）
7. **明确标注原始货币的转换说明**：如"约XX万元（折合约XX万美元）"

## 输出格式

```json
[{
  "问题片段": "问题所在目录、问题片段及上下文",
  "修改建议": "对应的正确建议"
}]
```

### 输出要求

1. 纯 JSON 格式，不含 Markdown 代码块符号
2. 无异常返回 `[]`
3. "问题片段" 包含所在目录/章节及足够上下文
4. "修改建议" 给出可操作的修复方向（提示按汇率换算，不自行计算）
5. 多轮校验结果完全一致

### 检测优先级

| 优先级 | 场景 | 说明 |
|--------|------|------|
| P0 - 严重 | 产品报价、竞品对比 | 直接面向客户，货币错误影响商务沟通 |
| P1 - 重要 | 预算构成、消耗预估、**货币符号格式**（位置 / 空格 / 单位重复） | 影响客户决策与品牌专业度 |
| P2 - 一般 | 标杆案例 | 不影响实际报价，但影响规范性 |

### 输出示例

```json
[{
  "问题片段": "【标杆案例-重保项目】金额50万元/年",
  "修改建议": "将"50万元/年"替换为美元单位，按当前汇率进行换算"
}, {
  "问题片段": "【竞品对比】某品牌A为6800元/月，某品牌B为41000元/月",
  "修改建议": "将所有价格替换为美元单位，按当前汇率进行换算"
}, {
  "问题片段": "【竞品对比表】竞品价格对比，单位：元",
  "修改建议": "将单位标注改为"单位：USD"或"单位：$""
}, {
  "问题片段": "【产品报价】套餐售价 ¥ 1,234.56元/月",
  "修改建议": "同一处金额同时存在货币单位与符号格式两类问题，需合并修正：①将"¥/元"替换为美元单位，按当前汇率换算；②修正符号格式——货币符号紧邻数字前、无空格、金额后不再重复中文单位（正例：$180/月）"
}]
```

## 注意事项

- **严格基于原文**：不做联想推理
- **区分金额与非金额语境**：准确区分"元"(货币) 与 "元素/元数据"(术语)
- **上下文判断**：结合上下文确认是否为货币金额
- **不做汇率换算**：仅标注问题，建议中提示"按当前汇率换算"
- **跳过特殊内容**：不检测代码块、纯数字、百分比、折扣比率
