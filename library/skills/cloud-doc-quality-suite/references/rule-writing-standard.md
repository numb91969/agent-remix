# 维度 5：产品写作规范检测

> 本规则文件供 cloud-doc-quality-suite 第五步加载，作为云产品文档「产品写作规范」维度的检测依据。
> 规则源自《腾讯云产品写作规范》（**v1.7.0 起精简为三大类**：用词 / 数字与数量 / 词汇表）。
>
> **v1.7.0 变更**：完整移除"空格与标点规范（W-SPACE-01~15）"类别。中英文空格、全/半角标点、括号引号规范等**排版层面**问题不再由本维度检测，避免与维度 4 排版格式检测和后续独立版式工具重叠。
>
> **严重等级变更**：本维度**不再对问题做严重等级（P0~P3）分级，也不输出任何严重等级字段**。检测只列出问题本身（规则、位置、原文、说明、建议），不评估严重程度、不输出问题分布（P0~P3 计数）。

---

## 1. 维度概述

| 项 | 内容 |
|----|------|
| 维度编号 | 5 |
| 维度名称 | 产品写作规范检测 |
| 检测对象 | 文档正文中所有自然语言文本（含标题 / 正文 / 列表 / 表格单元格） |
| 跳过对象 | 代码块、行内代码、URL 原文、版本号、参数名、SKU、API 字段、正式法律引用块、企业微信名 / 员工 ID |
| 输出键 | `writing`（合并后统一使用该键，原 `typo` 键并入） |

---

## 2. 核心原则

> **必须从原文出发，不做联想和推理，不夸大问题**

- 结合上下文判断是否为真实错误，避免误判专业术语
- 同一问题多处出现时每处独立列项，不合并
- 多轮一致性：相同输入产生完全相同的输出

---

## 3. 三大检测类别（聚合后规则总表）

### 类别 1：用词规范（W-WORD）

面向"字词是否用对、是否符合品牌语气、是否合规"的检测。**已聚合原 `rule-typo` 中的中文错别字、英文拼写与专有名词大小写等规则**。

| 编号 | 规则要点 | 正反例 / 触发关键词 |
|------|---------|--------------------|
| W-WORD-01 | 禁止错别字与谐音错别字（含形近字、音近词、成语错误、重复用词） | 反：己经→已经、未→末、土→士、折→拆；起用→启用、布署→部署；名落深山→名落孙山、迫不急待→迫不及待；非常常→非常、可以以→可以、的的→的；墙裂 / 童鞋 / 程序猿 / 人艰不拆 |
| W-WORD-02 | 避免口语化词语 | 反：不准 /……的话 / 就可以了 / 干……用 / 么 / 喔 / 挂掉 |
| W-WORD-03 | 避免程度 / 转折 / 冗余量词 | 反：较多、较好、完全地、基本地、决定性的、最后的、仅仅、事实上、值得注意的、当然、有些、非常、大量、一些、少许 |
| W-WORD-04 | 避免负面情绪词 | 反：杀死、踢出、被杀死、被踢出 |
| W-WORD-05 | 同一事物用词前后一致 | 正：全文统一使用「本地 PC」<br>反：先「本地 PC」后又用「电脑」 |
| W-WORD-06 | 相邻并列短语词性 / 结构一致 | 正：数据库管理、权限管理、数据导入<br>反：数据库管理、权限管理、导入数据 |
| W-WORD-07 | 禁用宗教 / 政治导向词 | 港澳台地域文案需特别注意 |
| W-WORD-08 | 禁用法律法规严禁词汇 | 反：最、第一、独家、绝对、永久（广告法敏感词） |
| W-WORD-09 | 「的 / 地 / 得」用法 | 形+的+名 / 副+地+动 / 动+得+副 |
| W-WORD-10 | 第一人称使用「腾讯云 / 我们」 | 反：小编、笔者 |
| W-WORD-11 | 用户称呼使用「您 / 用户」 | 反：你 |
| W-WORD-12 | 使用「账号 / 账户」 | 反：帐号、帐户 |
| W-WORD-13 | 举例使用「例如」 | 反：比如 |
| W-WORD-14 | 英文基础拼写正确 | 反：recieve→receive、occured→occurred、seperate→separate |
| W-WORD-15 | 英文形近词区分 | 反：form / from、then / than、its / it's、affect / effect |
| W-WORD-16 | 专有名词大小写规范 | 正：AWS、Tencent Cloud、Kubernetes、MySQL<br>反：AwS、tencent cloud、kubernetes、MySql |
| W-WORD-17 | 英文句首首字母大写 | 正：The server is running.<br>反：the server is running. |

---

> **v1.7.0：原「类别 2：空格与标点规范（W-SPACE-01~15）」整体移除**。中英文空格、全/半角标点、括号引号等排版细节不再由本维度检测。

### 类别 2：数字及数量规范（W-NUM）

| 编号 | 规则要点 | 举例 |
|------|---------|------|
| W-NUM-01 | 数值（整数 / 小数 / 百分比 / 分数 / 比例）必须用阿拉伯数字 | — |
| W-NUM-02 | 定型词组使用汉字数字 | 一批 / 百万级 / 星期五 |
| W-NUM-03 | 强调信息格式全文统一 | — |
| W-NUM-04 | 参数取值千分位与系统一致 | 系统不带千分位则文档也不带 |
| W-NUM-05 | 数值范围两端均带数词单位 | 正：10Mbps - 100Mbps；反：10 - 100Mbps |
| W-NUM-06 | 百分数数字与 `%` 之间无空格 | 正：1% |
| W-NUM-07 | 多位整数小数处理 | 可用「亿、万」；阿拉伯数字不能断开移行 |
| W-NUM-08 | 增加用「了 / 到」区分增 / 定量 | 「了」表增量、「到」表定量 |
| W-NUM-09 | 禁用「降低 N 倍 / 减少 N 倍」 | 应用「降低百分之几」 |
| W-NUM-10 | 日期时间格式规范 | 日期 `YYYY-MM-DD`；时间 `hh:mm:ss`；日期时间 `YYYY-MM-DD hh:mm:ss`；月 / 日个位需补零 |
| W-NUM-11 | 物理量必须阿拉伯数字 + 法定计量单位 | — |
| W-NUM-12 | 文件 / 证件号遵循本地规则 | — |
| W-NUM-13 | 同段不混用汉字与阿拉伯数字 | — |
| W-NUM-14 | 千分位英文逗号建议 | ≥1,000 三位一组，小数部分不加 |
| W-NUM-15 | 编号阿拉伯数字代替罗马数字 | 1 代替 I、2 代替 II |

**参考标准**：GB/T 15835-2011、GB/T 7408-2005、GB 3102.11-1993。

## 4. 跳过规则（豁免）

| 场景 | 跳过哪些规则 |
|------|--------------|
| 代码块 / 行内代码 | W-NUM-*、英文拼写相关（W-WORD-14~17） |
| URL 原文 | W-NUM-* |
| 版本号 / 产品 SKU | W-NUM-* |
| 表格内 SKU、参数名 | W-WORD-05 / W-WORD-06 |
| 正式法律文本引用块 | W-WORD-02 / W-WORD-03 |
| 国标 / 行标 / 地标分级表述 | W-WORD-08（建议联系法务复核而非直接判违规） |
| 企业微信名 / 员工 ID | 全部规则（如 sijinfang、rickyyuan） |

---

## 5. 输出字段规范

> 本维度**不输出严重等级**，每条问题仅包含以下字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| `规则编号` | 命中规则的稳定编号 | `W-WORD-11` |
| `规则名称` | 规则要点中文名 | `用户称呼规范` |
| `类别` | 所属三大类别名（用词规范 / 数字及数量规范 / 词汇表规范） | `用词规范` |
| `问题位置` | 章节 / 段落 / 行号 | `第 3 章 / 第 2 段` |
| `原文片段` | 命中的原文（≤80 字，含足够上下文便于定位） | `请点击"你的账号"…` |
| `问题说明` | 为何违反规则（不超过 30 个汉字为宜） | `面向用户的称呼应使用"您"或"用户"` |
| `建议修改` | 推荐表述（可直接替换错误片段的正确内容） | `请点击"您的账号"…` |

## 6. 输出 JSON 格式（套件汇总键：`writing`）

```json
{
  "维度名称": "产品写作规范检测",
  "检测状态": "已完成",
  "异常数量": 0,
  "类别统计": {
    "用词规范": 0,
    "数字及数量规范": 0,
    "词汇表规范": 0
  },
  "问题列表": [
    {
      "规则编号": "W-WORD-11",
      "规则名称": "用户称呼规范",
      "类别": "用词规范",
      "问题位置": "第3章 / 第2段",
      "原文片段": "请点击\"你的账号\"…",
      "问题说明": "面向用户的称呼应使用\"您\"或\"用户\"",
      "建议修改": "请点击\"您的账号\"…"

```

> 无异常时 `问题列表` 返回 `[]`，`异常数量` 返回 `0`，所有计数字段均为 `0`。
> 本维度**不输出 `严重等级` 字段，也不输出 `问题分布`（P0~P3 计数）**。

---

## 7. 执行约束

1. **基于原文**：严格基于文档实际文本进行检测，不做联想或推理
2. **遵循跳过规则**：代码块、URL、参数名、员工 ID 等场景不强制执行规范
3. **同一问题多处出现时每处独立列项**，不合并
4. **多轮一致性**：相同输入产生完全相同的输出
5. **上下文判断**：结合上下文确认是否为真实错误，避免误判专业术语
6. **不做等级分级**：不输出严重等级（P0~P3），不输出问题分布
