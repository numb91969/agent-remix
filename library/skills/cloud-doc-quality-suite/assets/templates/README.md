# 文档结构模板库（用于结构质量评审）

本目录的 **11 个官方模板文件**是「文档结构质量评审」（`references/rule-structure.md`）的依赖资源。
AI 在执行结构检测时，会根据识别出的文档类型加载对应模板（`.docx` / `.pptx` / `.xlsx`），逐章节/逐页对比目标文档与模板，判定是否结构完整。

> 模板均为腾讯云售前弹药库官方模板（Office 二进制格式），AI 解析时请优先使用对应的文档解析能力（如 `python-docx` / `python-pptx` / `openpyxl`）读取目录结构、章节标题与页面标题。

## 文档类型自动识别

AI 应根据以下优先级识别目标文档类型：

1. **文件名匹配**：若用户文件名含「白皮书 / 案例集 / 解决方案 / 产品介绍 / 彩页 / 竞品分析 / 快速入门 / 销售一指禅 / 交付 / POC / 报价」等关键词，直接映射到对应模板
2. **文件扩展名辅助**：`.xlsx` → 报价指引；`.pptx` → 优先匹配 PPT 类模板（案例集/解决方案/产品介绍/彩页/竞品分析）；`.docx` → 优先匹配 Word 类模板（白皮书/快速入门/销售一指禅/交付/POC）
3. **正文首页/封面标题语义匹配**：从目标文档的封面、首页或一级标题提取关键词后再匹配
4. **类型不明时**：以上均无法判定时，**跳过本维度检测**，不做兜底，不套用任何默认模板

## 章节匹配规则

- AI 应从模板中**提取一级章节标题 / 一级页面标题**作为「核心章节清单」
- 章节名称不需要完全一致，**语义等价即可**（如"产品简介" ≈ "产品概述"）
- 任一核心章节缺失 → 判定为「结构不完整」
- 模板中明显属于「示例占位 / 编写说明」的页面不计入核心章节

## SaaS 产品特殊规则

部分模板中涉及「产品架构 / 技术优势 / 部署架构」等技术章节，对 SaaS 类产品（腾讯乐享、腾讯会议、腾讯电子签、腾讯问卷等）**降级为可选检查项**。

## 如何扩展新模板

新增文档类型只需：

1. 将官方模板文件（`.docx` / `.pptx` / `.xlsx`）放入本目录，文件名保持「{文档类型}_模板.{ext}」格式
2. 在本 `README.md` 的「模板索引」表格追加一行
3. 在 `references/rule-structure.md` 的「适用文档类型」表中追加对应映射关系
