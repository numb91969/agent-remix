# TAPD 访问令牌配置指南

> **本文档为 `need_tapd_token` 错误的完整处理指引。**
> 当 MCP 工具调用返回 `stage: "need_tapd_token"` 时，按以下流程操作。

---

## 前置说明：这是什么意思？

操作 TAPD 需要证明「你是谁」。你需要提供一个 TAPD 个人访问令牌（Token），
配置到连接器中。**只需配置一次，以后永久生效。**

⚠️ **安全说明**：你的 Token 只会保存在你本地的工作台配置中，
不会出现在对话内容里，也不会被服务器记录。

---

## 第二步 A：我已有令牌，告诉我怎么配置

### 配置步骤

你的令牌需要填写到 MCP 连接器的请求头（Headers）中。
根据你使用的客户端，选择对应的方式：

---

#### 方式一：WorkBuddy 设置界面（推荐）

1. 点击左侧面板底部的 **⚙️ 设置**
2. 切换到 **连接器** 页面
3. 找到需要配置的连接器（见下方「我需要配置哪个？」），点击右侧 **⋮ 或编辑按钮**
4. 在配置编辑器中找到或添加 `"headers"` 字段：

```json
{
  "headers": {
    "X-Tapd-Access-Token": "这里粘贴你的令牌"
  }
}
```

5. 将 `这里粘贴你的令牌` 替换为你的真实令牌（一个很长的字符串）
6. 点击 **保存**（Save）

✅ 配置完成！回到对话，告诉我「已配置好」，我会重试之前的操作。

---

#### 方式二：直接编辑 mcp.json 文件（进阶用户）

打开文件 `~/.workbuddy/mcp.json`，
在对应的 MCP Server 配置中添加 `"headers"` 字段：

```json
{
  "mcpServers": {
    "<连接器名称>": {
      "...原有字段...",
      "headers": {
        "X-Tapd-Access-Token": "你的令牌值"
      }
    }
  }
}
```

保存后，在设置界面对应连接器上点击 **重新加载** 或重启连接。

---

### 我需要配置哪个连接器？

| 如果你正在用的功能是... | 配置这个连接器 |
|---|---|
| 创建/补全需求、AI读层、更新需求 | **`requirement-assistant`** |
| 直接查询/创建 TAPD 需求/缺陷 | **`tapd`** |
| 通过 proxy 调用 TAPD 工具 | **`tapd_mcp_http`** |

> 💡 **建议三个都配上**：它们用的是同一个令牌，配好后所有 TAPD 相关功能都能用。

---

### 配置检查清单（如果配完还是不行）

- [ ] Header 名字是 `X-Tapd-Access-Token`（注意大小写，不要漏掉 `X-` 前缀）
- [ ] 令牌值是完整的（没有多余空格、没有换行、没有被截断）
- [ ] 点了保存（不是改了但没存）
- [ ] 连接器状态显示为绿色/已连接（不是红色/断开）
- [ ] 如果之前已经配置过但换了新令牌，可能需要**断开再重新连接**

等待用户确认已配置完成，然后**直接重试原来的工具调用**。

若重试**仍然返回** `need_tapd_token`：
- 提示用户按上方「配置检查清单」逐项排查
- 特别提醒：Header 名拼写、令牌是否完整复制、保存按钮是否点击

## 第二步 B：我还不知道怎么获取令牌

### 获取 TAPD 个人访问令牌

**预计耗时：1 分钟**

#### 第一步：打开令牌页面

直接点击链接（需已登录 TAPD）：

🔗 [点击打开 TAPD 个人 Access Token 页面](https://tapd.woa.com/platform/myhome?not_direct=1&from=mcp#tab=tab-mytoken)

如果打不开，用手动路径：
**TAPD 网页 → 右上角头像 → 设置（Settings）→ 个人 Access Token（Personal Access Token）**

#### 第二步：新建令牌

1. 点击 **新建令牌（Create New Token）** 按钮
2. 填写信息：
   - **名称（Name）**：随便填，如 `WorkBuddy-MCP`
   - **权限（Scope）**：选 **只读（Read）** 就够了（如果你只需要查询需求）；如果还需要创建/修改需求，选 **读写（Read & Write）**
3. 点击 **创建（Create）/ 确定**

#### 第三步：复制令牌

⚠️ **令牌只显示一次！务必立即复制。**

1. 创建成功后页面会显示一串长长的字符（形如 `3f30634e9deaf6b5d8f0ec4439384b219429b486`）
2. 点击 **复制（Copy）** 按钮
3. **妥善保管**（相当于密码，不要分享给他人）

#### 第四步：回来配置

拿到令牌后，回到上面的「[第二步 A](#第二步-a我已有令牌告诉我怎么配置)」选项，按步骤填写到连接器 Headers 中即可。

---

> 📌 **小贴士**：
> - 令牌长期有效，除非你主动撤销或管理员强制吊销
> - 如果怀疑令牌泄露，随时回这个页面撤销（Revoke）并重新生成
> - 一个账号可以同时存在多个令牌（比如给不同工具各建一个）

等待用户获取并完成配置。

---

## 第二步 C：跳过

> 已跳过。如果您之后想使用 TAPD 功能，随时可以通过上述步骤配置令牌。

终止当前操作。

- 用户若主动在对话中粘贴了 Token，可直接接收并写入连接器配置
