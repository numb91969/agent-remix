# 展示模板：审批前简报（pre-approval-brief）

## 用途
在用户执行审批前，聚合 `DescribeWorkflowInstance` + `GetInstanceTaskList` + `ExportWorkflowInstanceList` + `GetInstanceTaskDetail` 的返回数据，一次性呈现「决策所需的全部上下文」，帮助用户判断该同意、拒绝还是转办/加签。

---

## 输出格式

````markdown
## 📝 审批前简报：{Title}

### 📄 基本信息

| 字段 | 值 |
|------|----|
| 流程单ID | `{InstanceId}` |
| 发起人 | {Creator} |
| 发起时间 | {CreateTime} |
| 所属流程 | {WorkflowName}（{WorkflowId}） |
| 当前节点 | **{CurrentTaskName}**（TaskId: `{TaskId}`） |
| 节点开始时间 | {TaskCreateTime} |
| 节点已停留 | ⏱️ {格式化时长} |
| 当前处理人 | {Handler，逗号分隔} |
| 审批方式 | {or=或签（任一人审批即可）/ and=会签（全部审批才通过）} |

---

### 📋 用户填写的字段值

| 字段名 | 值 |
|-------|----|
| {字段Name} | {字段值} |

> 枚举类型展示 Label，空值展示 `—`，数组值用逗号分隔。

---

### ⚙️ 当前节点支持的操作

| 能力 | 是否支持 |
|------|---------|
| 同意 (Agree) | ✅ 支持 |
| 拒绝 (Reject) | ✅ 支持 |
| 转办 (Transfer) | {✅ 支持 / ❌ 不支持} |
| 前置加签 (PreAddApprover) | {✅ 支持 / ❌ 不支持} |
| 后置加签 (NextAddApprover) | {✅ 支持 / ❌ 不支持} |
| 参议 (Consultant) | {✅ 支持 / ❌ 不支持} |
| 审批后是否可撤回 | {✅ 审批后可撤回 / ❌ 一旦提交不可撤回} |

> ⚠️ 若「审批后不可撤回」，请在确认前再三核对。

---

### 🎯 请选择你的操作

请回复：
- **「同意」** 或 **「Agree」**：审批通过（可附意见）
- **「拒绝 [意见]」** 或 **「Reject [意见]」**：审批驳回（建议附拒绝理由）
- **「转办 [rtx]」** 或 **「Transfer [rtx]」**：把当前任务转给他人（需节点支持）
- **「前置加签 [rtx]」**：在当前节点前追加一个审批人（需节点支持）
- **「后置加签 [rtx]」**：在当前节点后追加一个审批人（需节点支持）
- **「参议 [rtx]」** 或 **「Consultant [rtx]」**：邀请他人协助审议，审议后回到你（需节点支持）

示例：
- `同意，符合规范`
- `拒绝，材料不完整`
- `转办 justinke，请他处理`
- `参议 justinke，需要他先把关一下`

> 以上数据均来自流程平台（https://huijin.woa.com/flow/apply/detail/{InstanceId}）
````

---

## 时间格式化规则

| 耗时范围 | 展示格式 |
|---------|---------|
| < 60 秒 | `{n}秒` |
| < 60 分钟 | `{n}分钟` |
| < 24 小时 | `{n}小时{m}分钟` |
| ≥ 24 小时 | `{n}天{m}小时` |
