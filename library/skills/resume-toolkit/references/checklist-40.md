# 简历 40+ 项深度润色检查清单

逐项标注 ✅通过 / ❌不通过 / ⚠️待改进，最终输出「检查结果 + 精修稿 + 分级变更摘要」。

## A. 联系方式（6 项）
1. 姓名突出、字号最大
2. 手机号格式规范（如 `138-0000-0000`）
3. 邮箱为专业邮箱（非昵称邮箱）
4. 城市与意向城市标注
5. 含一个专业主页（LinkedIn / GitHub / 作品集）——与目标岗位相关时才放
6. 无敏感信息（身份证号、婚姻、健康、政治面貌）

## B. 摘要 / 个人简介（5 项）
7. 3 行内完成定位（身份 + 年限 + 核心能力）
8. 含 1 个量化背书（如"主导 X 项目，降本 18%"）
9. 与目标岗位关键词对齐
10. 无"吃苦耐劳/性格开朗"等空洞形容词
11. 无第一人称"我"

## C. 工作经历（12 项）
12. 倒序排列（最近在前）
13. 公司名 + 职位 + 起止年月齐全且格式统一
14. 每段 3-5 条要点，非流水账
15. 每条要点以**强动词**开头
16. 每条要点含**量化成果**
17. 采用「动作 + 对象 + 结果」结构（如"重构 X 模块，使 Y 指标从 A 降至 B"）
18. 体现职责递进（执行 → 负责 → 主导）
19. 体现跨部门协作与影响力
20. 相关经历详写、无关经历压缩或删除
21. 空窗期有合理解释（学习/项目/家庭）
22. 无行业黑话堆砌、无重复表述
23. 时态统一（现职用现在时，既往用过去时；中文用动词原形）

## D. 教育背景（4 项）
24. 学校 + 专业 + 学历 + 毕业年份齐全
25. 工作经历 >3 年时教育段压缩至 2-3 行
26. 含相关课程/GPA/奖学金（应届或转行时才保留）
27. 无高中及以下学历信息

## E. 技能（5 项）
28. 技能分板块（专业/工具/语言）
29. 技能与经历相互印证（写了就要在经历中体现）
30. 标注熟练度（精通/熟练/了解），不虚标
31. 优先列目标 JD 中的必备技能
32. 无"熟练掌握 Office"之类无差别技能占位

## F. 语言与语法（6 项）
33. 零错别字、零标点错误
34. 中英文混排规范（数字/英文与中文之间加空格）
35. 无第一人称、无第三人称自称
36. 无过度形容词与副词堆砌
37. 缩写首次出现给出全称
38. 全文术语、日期、数字格式统一

## G. 排版（5 项）
39. 页边距与行距统一，留白充足
40. 层级不超过 3 级（姓名 / 版块标题 / 条目）
41. 全文字体不超过 2 种
42. 年限对应：10 年内 1 页，10 年以上或学术岗最多 2 页
43. 无表格嵌套、文本框、页眉页脚承载关键信息

## H. ATS 兼容性（5 项）
44. 使用标准版块标题（工作经历 / 教育背景 / 技能 / 项目经验）
45. 关键岗位词与 JD 对齐且分布自然（摘要 + 经历 + 技能各出现）
46. 纯文本可解析（无图形化信息、无图片型 PDF）
47. 文件名规范（如 `张三-整车控制器工程师-5年.pdf`）
48. 无重复关键词堆砌（避免被判作弊）

## 强动词表（按场景）

| 场景 | 强动词 |
|------|--------|
| 主导/领导 | 主导、统筹、牵头、负责、带领、推动 |
| 改进/优化 | 重构、优化、简化、标准化、自动化、缩短、提升 |
| 从 0 到 1 | 搭建、创立、设计、开发、构建、实现 |
| 数据/分析 | 分析、诊断、建模、预测、归因、验证 |
| 协作/影响 | 协调、对接、推动落地、培训、赋能、说服 |
| 成果/收益 | 降本、增效、增收、缩短周期、降低故障率、提升良率 |

## 量化指南

| 原始表述 | 量化改造 |
|---------|---------|
| 负责多个项目 | 主导 3 个整车项目电控系统开发，均按期量产 |
| 提升了系统性能 | 优化控制策略，使能耗下降 12%、响应延迟从 80 ms 降至 45 ms |
| 参与团队管理 | 带领 5 人小组，建立周会与评审机制，缺陷流出率下降 30% |
| 做了大量测试 | 设计并执行 240 条 HIL 测试用例，Pass 率 98.7%，拦截 11 个重大缺陷 |
| 处理客户问题 | 处理 60+ 现场故障，平均闭环时间由 5 天缩短至 1.8 天 |

**量化三原则**：
1. 有真实数据 → 直接用
2. 无精确数据 → 用可核实区间（约 / 近 / 超），并标注 `[需你确认]`
3. 完全无法量化 → 用范围、频次、规模、对比替代（覆盖 N 个车型 / 服务 N 家客户）

## 变更分级说明

| 级别 | 含义 | 示例 |
|------|------|------|
| 🔴 关键 | 直接影响投递成功率，必须改 | 经历无量化成果、版块顺序错误 |
| 🟡 重要 | 明显提升专业度，建议改 | 弱动词、摘要空洞 |
| 🟢 次要 | 细节优化，可选 | 日期格式统一、行距微调 |
| 💡 建议 | 加分项，视岗位而定 | 增加作品集链接 |
