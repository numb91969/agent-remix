# 展示模板：流程相关单据列表（related-instance-list）

## 用途
渲染 `ListWorkflowInstance` 接口返回的某流程下相关流程单列表。

---

## 输出格式

```markdown
## 📋 流程相关单据：{WorkflowName}（{WorkflowId}）

共 {Total} 条流程单

| 流程单名称 | 流程单ID | 发起人 | 发起时间 | 状态 | 当前节点 | 当前处理人 |
|-----------|---------|--------|---------|------|---------|-----------|
| {Title截断到25字} | {Id} | {Creator} | {CreateTime} | {Status_Emoji} | {CurrentTaskName} | {CurrentHandler} |

> 发送流程单 ID（T 开头）可查看详情和审批进度。
```

---

## 状态 Emoji 映射

| Status 值 | 展示 |
|-----------|------|
| `Running` | 🔄 进行中 |
| `Succeed` | ✅ 已结束 |
| `Revoked` | ↩️ 已撤单 |
| `Failed` | ❌ 已驳回 |
| 其他 | ⚠️ 异常 |

---

## 空结果处理

```markdown
该流程下暂无相关流程单。

建议：
- 确认流程 ID（P 开头）是否正确
- 该流程可能尚未有人发起申请
- 尝试调整筛选条件（如去掉状态限制）
```

---

## 分页提示（有更多时追加）

```markdown
> 当前显示前 {Limit} 条，共 {Total} 条。如需查看更多，请告诉我「下一页」或「导出全部」。
```

## 输出后追加引导（场景一使用）

```markdown
---

💡 **还可以帮你做更多**：
- 📋 **更全/筛选**：需要查看全量流程单吗？或按状态、发起人、时间范围筛选？
- 📊 **导出表格（基础信息）**：需要我将流程单信息导出为 Excel 表格吗？
- 📑 **查看/导出字段值**：需要帮你查看该流程下所有流程单的**实际填写内容**吗？（Markdown 预览 + Excel 导出）
```

## 批量导出流程单输入字段值（子场景 2B 使用）

当用户要求批量查看/导出某流程下所有流程单的输入字段时，使用以下格式。

### Markdown 预览格式（预览若干条）

在 Markdown 中做数据预览（默认预览前 20 条即可，不做硬性 10 条限制），让用户快速确认数据是否正确。完整数据通过 Excel 导出。

````markdown
## 📋 批量导出流程单输入字段：{WorkflowName}（{WorkflowId}）

共 {Total} 条流程单，以下为预览：

| 流程单ID | 标题 | 状态 | 发起人 | 发起时间 | {输入字段Name1} | {输入字段Name2} | ... |
|---------|------|------|--------|---------|----------------|----------------|-----|
| T2026... | xxx | ✅ 已完成 | ritarqwang | 2026-04-09 | 值1 | 值2 | ... |
| T2026... | xxx | 🔄 进行中 | jamesye | 2026-05-12 | 值1 | 值2 | ... |
| ... | | | | | | | |

> 共 {Total} 条数据，完整数据已导出为 Excel → `{文件路径}`
````

**列顺序**：固定流程字段在前（流程单ID / 标题 / 状态 / 发起人 / 发起时间），动态输入字段在后。

**列表头**：输入字段列使用字段的 `Name`（中文名），不用 `Key`。

### 数据处理规则

| 数据类型 | 处理方式 |
|---------|---------|
| 枚举值 | 用 `DescribeWorkflow` 返回的 `Display.Enum` 将 Value 映射为 Label（如 `digital` → `数码电子`） |
| 空值 | 展示 `—` |
| 数组值 | 用逗号分隔 |
| 文件/链接 | 展示文件名（可点击） |
| 状态值 | 转中文 + Emoji（见状态映射表） |

### Excel 列结构

Excel 的列结构与 Markdown 预览表一致：

| 列名 | 来源 |
|------|------|
| 流程单ID | Id |
| 标题 | Title |
| 状态 | Status（转中文） |
| 发起人 | Creator |
| 发起时间 | CreateTime |
| {输入字段1 的 Name} | ParamsMap[字段Key1] |
| {输入字段2 的 Name} | ParamsMap[字段Key2] |
| ... | ... |
