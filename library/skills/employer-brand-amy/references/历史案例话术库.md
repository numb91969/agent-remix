## 一、舆情处理总框架（团队实际）

### 1.1 四象限决策树（数据×影响力）
舆情出现 → 判"数据高低 × 影响力（是否影响公司）" →
- 数据低+影响力低 / 数据高+影响力低 → **不处理**（不影响公司就不动，哪怕有热度）
- 数据低+影响力高 / 数据高+影响力高 → **处理**（影响公司就处理，哪怕还在初期）

### 1.2 五种处理手段
① 删帖（定平台规则→引入法务/公关）② 评论冲抵（定方向→定可用账号→发布）③ 转移矛盾（转话题引发新讨论 / 转关注对象引入个人账号）④ 官方回应（拟话术→定形式与平台→发布）⑤ 冷处理（持续监测）

### 1.3 小红书舆情 SOP（关键阈值：点赞+评论 35）
- **STEP1 定位当事人+安抚发帖人**
  - 情况1（联系了官号 或 点赞评论>35）：私信 + 评论区双回应
    - 私信文案核心："抱歉带来不好体验，非常重视，开通了专门反馈渠道 [官方反馈邮箱]，或请提供姓名+电话方便内部核实。期待未来一起做同事。"
    - 评论区文案核心："作为官方号先给你道歉，非常重视每位同学体验，请留意私信，我们将在私信同步方式与进展。"
  - 情况2（没联系官号 且 点赞评论≤35）：内部定位（联系BG招聘经理/校招系统负责人核查），**继续观察、每天截图至监测群、维持7天，无变化可不处理**。
- **STEP2 还原客观事实**：组织事实还原会，卷入招聘经理/BP/信用体系负责人/业务PR/雇主品牌，内部+外部双向还原（时间线+逐条质疑核实）。
- **STEP3 反馈当事人（面试官）**：告知违反信用分第X条→扣X分/关停权限→说明影响。
- **STEP4 反馈发帖人**：4段式——先道歉+说明动作 → 同步调查结果与定性 → 表明公司态度+改进计划 → 再次道歉及祝福。

### 1.4 投诉 case 调查 SOP（问当事双方的标准问题）
- **问招聘经理/面试官**：①还原面试（时间地点/问了什么/怎么问/怎么答）②针对投诉逐条（是否有此行为/前因后果/原话/语境）③常见违规预判（总时长？开摄像头没？约的什么时间？面试者何时情绪激动？）
- **问投诉人**：①还原面试 ②针对投诉逐条 ③常见违规 ④诉求是什么
- **诉求沟通**（招聘经理/面试官）：判定责任→需配合什么→愿意/不愿意（不愿意卷入BG HRD）
- **结果反馈（面试者）**：道歉→处理结果定性→诉求能否满足+原因→再道歉
- **结果反馈（面试官）**：处理结果定性→需配合什么

## 二、面试投诉案例（脱敏）

### 案例1：面试官被投诉案（判"较重违纪"）
- **投诉点**：①非HR却能获联系方式 ②冒充HR ③邀线下coffee非正式面谈 ④态度粗暴（多次不正面回答hc/是否正式面试，最后粗鲁删微信）
- **调查结论**：①②不成立（无违规）；③④属实，违反《面试官信用体系规范》——"招聘中因不当言行造成内外部舆论/不良影响，损害公司声誉/雇主品牌"。
- **定档**：性质恶劣、外网有不良影响，但未构成较高经济损失 → 判**"较重违纪行为"**（非高压线）。
- **处罚**：取消面试官权限+一年内不得申请+信用分清零。
- **善后**：集团联系候选人说明结果，争取删帖/隐藏面试官姓名，最小化对个人影响。
- **话术结构学习点**：开场表明身份+成立专项组+"力求每一方公平公正" → 列候选人核心投诉 → 逐条认定（哪些不成立/哪些属实）→ 引条例定档 → 明确处罚 → 善后安排。**坦诚、有依据、不护短也不过度。**

### 案例2：需求方无资格违规面试案（投诉邮件回应）
- **投诉点**：两名"面试官"实为需求方、无面试资格/系统权限、违规发起面试、建议"内推"被疑徇私。
- **回应结构（邮件）**：①收到反馈+致歉 ②说明已全面复盘调查 ③还原事实（岗位真实在招、两人是需求方但未取得面试资格故未走合规流程）④解释致电原因（系统无流程故需核实）⑤澄清"内推"是合规推广多年的项目、有亲属回避等制度，原意非徇私 ⑥对不恰当行为依规处罚+追责上级 ⑦再次致歉+表达持续完善制度的决心。
- **话术学习点**：**澄清误解 + 承认部分不当 + 解释制度合规性 + 处罚到位 + 诚恳收尾**。把"内推"这种易被误读为"走后门"的点主动解释清楚——按铁律10：不说"不是走后门"，要说"本意是通过更多渠道吸引人才"。

## 三、Offer 取消案例（脱敏）

### 案例1：牟利→岗位敏感取消案（给补偿）
- **情形**：候选人以公司offer身份帮人面试/改简历牟利；录用岗位为安全相关产品运营，敏感度高。
- **处理**：先核实事实（社媒id/是否发过offer信息/是否牟利）→ 告知"行为与敏感岗位不匹配，取消offer" → 补偿**[补偿档位·税前]+释放简历** → 保密提醒（高压线+追责）→ QA兜底 → 备媒体口径。
- **学习点**：岗位敏感类，强调"岗位特殊性"而非全盘否定个人；用补偿换协商一致+保密配合。

### 案例2：笔试作弊+重复注册取消案（原则不补偿）
- **情形**：历史笔试作弊（答案高度重合，技术二次核实）+ 校招重复注册简历（身份证验证重复后改用其他证件绕过）。
- **处理**：作弊/造假是高压线，无回旋 → 7个QA强支撑（不认可作弊/时间太久/通知太晚/法律途径/要补偿/难找工作）→ 不补偿（人性化可1个月）→ 三档预期结果（主动放弃 / 补偿换协商一致 / 直接取消）。
- **学习点**：诚信类取消最坚定，"正直是公司红线"反复强调；用技术核实作事实支撑；提前备好7个QA。

## 四、Offer 发放标准 SOP（详细版实习生）

来意 → 核对信息（身份证/邮箱务必个人非公司邮箱/学历/培养方式/就读地，注意GAP期风险）→ 介绍薪酬（分无薪酬/项目实习/常规三类）→ 确认态度（接受/考虑/拒绝分支）→ 提醒offer有效期（3自然日）→ 问竞企offer（必问：薪酬/岗位/工作地）→ 提醒保密（薪酬保密，泄露=高压线取消offer）。
> 学习点：信息核对极细（GAP期、邮箱类型、培养方式都有坑），保密和竞企offer是必做项。
