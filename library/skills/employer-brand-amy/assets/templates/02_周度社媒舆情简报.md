# 场景模板②：周度社媒舆情简报

> 经理说法："这周的社媒（小红书/脉脉）舆情情况如何？有哪些需要处理的？"
> 配套：`references/态势研判与走势预测模型.md`（第七章周期性态势研判）

---

## 触发识别
用户要求查看某时间段（本周/近7天/本月）某平台或全平台的舆情整体情况。

## 默认平台
- **核心**：小红书 + 脉脉（招聘口碑主阵地）
- 用户未指定时，至少覆盖这两个；如说"全网"则加视频号/公众号/微博/网媒。

## 执行流程

```
① 确认参数：时间窗口（默认近7天）+ 平台（默认小红书+脉脉）+ 品牌（默认腾讯）
    ↓
② 各平台搜索（小红书 web_search 优先/有截图直接读、脉脉 agent-browser）
    ↓
③ 情感标注 + 数据采集（互动量、发布时间）
    ↓
④ 套态势研判模型：情绪趋势打分 + 四象限定性
    ↓
⑤ 挑出"需处理项"逐条出研判卡（紧急度排序）
    ↓
⑥ 输出《周度舆情简报》
```

## 输出模板

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 [品牌] 社媒舆情周报（[日期范围]）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
监测平台：小红书 / 脉脉 [/ 其他]
总声量：XX 条 | 环比：↑/→/↓ XX%

【整体态势】
· 情绪指数：[正X% − 负Y% = ±Z]（环比 ↑改善/↓恶化）
· 态势定性：🔴风险期 / 🟠隐患期 / 🟡热议期 / 🟢平稳期
· 异常波动：[哪天/哪事件导致情绪变化]

【情感分布】
正面 ████████░░ XX%
中性 ███░░░░░░░ XX%
负面 █████░░░░░ XX%

【分平台速览】
· 小红书：XX条，[一句话——主要在聊什么、情绪如何]
· 脉脉：XX条，[一句话]

【⚠️ 需处理项】（按紧急度排序）
🔴 P1 [事件] — [平台] — 当前数据 — [→见研判卡]
🟡 P2 [事件] — [平台] — [→建议动作]
🟢 P3 [事件] — 监测即可

【下周盯防】
1. [潜在引爆点/话题]
2. [友商动态连带影响]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 要点
- **不只罗列，要给态势判断**（四象限）——经理要的是"现在安不安全"。
- "需处理项"必须**按紧急度排序**，并标注响应时限。
- 高优先级项直接附研判卡或链接到处置方案。
- 脉脉数据优先 agent-browser 深采；登录墙→请经理协助登录。
