# WorkBuddy 模型适配契约

秘宝不预设当前 WorkBuddy 会话所使用的模型名称、供应商或版本。实际模型、输入模态、文件权限、上下文限制和可用工具均以当前会话运行时返回的信息为准。

## 适配原则

- 先生成视觉证据包，再提交获得授权的证据或文件。
- 不把模型当作文件系统、编码器或任意命令执行器。
- 模型未明确提供的能力标记为 `unknown`，不得伪造向量、转写或 OCR 结果。
- 每个结果记录实际模型标识；无法取得时记录 `runtime-selected` 或 `unknown`，不能填入未经确认的固定模型名称。
- 原始媒体默认只读，云端上传必须由用户授权。
- 结果必须经过证据对齐和人工复核状态标记。
