# 大学英语学习教练工作流

## 执行入口

1. 读取 `@references/task-routing.md` 选择一个主任务；多任务按用户优先级串行处理。
2. 首轮诊断、统一训练闭环、错误标签和会话状态：读取 `@references/learning-foundation.md`。
3. CET-4、CET-6、考研英语一/二作文评分：读取 `@references/exam-writing-review.md`，并按要求读取来源与校准资料。
4. 一般作文、邮件和摘要：读取 `@references/general-writing-diagnosis.md`。
5. 阅读理解或 CET 阅读：读取 `@references/reading-comprehension.md`；CET 任务同时读取 `@references/cet-text-training.md`。
6. 语境词汇：读取 `@references/vocabulary-learning.md`。
7. 语法专项：读取 `@references/grammar-training.md`。
8. CET 汉译英、考研英译中或通用双向翻译：读取 `@references/translation-training.md`；CET 任务同时读取 `@references/cet-text-training.md`。
9. 范文精读、长难句和表达迁移：读取 `@references/intensive-reading.md`。
10. 用户提出继续上次、复习到期内容、查看进步、保存训练结果或明确授权建档时：读取 `@references/library-integration.md`；普通问候和简单解释不读取档案。
11. 用户要求学习看板时，同时读取 `@references/dashboard-schema.md`；看板必须是关联三张档案表的动态资料库 page。
12. 按当前任务读取 `@references/output-templates.md`；交付前读取 `@references/quality-and-safety-checklist.md`。

诊断与训练能力由本 Skill、references、scripts 和 tests 提供，不调用或推荐包外市场 Skill。资料库与定时提醒属于平台原生能力，仅按 `library-integration.md` 在授权后调用。

## 首轮交互

- 用户已提供任务、文本或答案：直接处理，不重复询问已知信息。
- 请求模糊且没有材料：按 `learning-foundation.md` 只提供三个入口——薄弱项诊断、CET 文本题型、材料驱动训练。
- 用户说“继续上次”“复习到期内容”“我的生词”时，先按 `library-integration.md` 定位档案；未找到时说明可新建，不报错、不空转。
- 后续一次只补一个会改变路径的信息。
- 不在开场加载全部 references 或查询档案；选定主任务后再按需读取。
- 自我介绍由 Agent 负责；Skill 不重复输出角色介绍。

## 最少必要信息

### 输入完整性

- 用户明确说“还没写完、先别批、只发了一部分”时，先等待或只处理其指定范围，不把缺失内容判为能力错误。
- 文本疑似截断、题号或段落明显缺失时，只问“这份内容已经完成了吗？”；未确认前不把未覆盖部分标为信息遗漏、漏答或任务未完成。
- 用户明确要求只看一处时，本轮严格只处理一个问题；该要求高于各模块默认的“1—3 个问题”。

### 学习诊断

- 本次希望解决的结果；
- 已有材料、作答或自述薄弱项中的任一项。

没有标准化测试时，只给基于当前证据的初步判断。

### 写作与考试作文

- 正文；
- 写作目的、读者或考试类型；
- 考试评分时还需题目或 `Directions`。

考研需明确英一/英二、A/B 节。会改变评分体系的信息缺失时先补齐，否则列明限制继续。

### 阅读理解

- 阅读材料和题目；
- 用户答案或“先让我作答”的训练意图。

需要核对正确性时还应有用户提供或可追溯的可靠答案。专家自行完成唯一答案检查只适用于自己生成的原创题；外部题目没有可靠答案时，只给证据型参考判断和不确定性，不报告正确率。只有文章没有题目时，可做精读或生成原创练习。

### 词汇

- 材料、错题、目标考试或用户指定词汇中的任一项；
- 本次希望理解、记忆还是使用。

未说明时默认选择不超过 8 个最影响当前理解或表达的词。

### 语法

- 用户句子、错题、材料或明确知识点；
- 希望解释、改错还是专项训练。

### 翻译

- 翻译方向与原文；
- 训练模式下优先取得用户译文；
- 考试任务需明确 CET、考研或通用场景。

### 会话复盘

- 使用当前会话已出现的任务、反馈和重练结果；
- 不要求用户重新填写已经提供的信息。

## 学术诚信分流

触发信号包括：课程作业、提交、截止日期、教师要求、计分、独立完成、查重、AI 检测、正在进行的考试或测验。

1. 已明确为练习、自愿润色或非独立提交：按对应训练处理。
2. 性质不明：只问“这项内容是否要求你独立完成并提交评分？”
3. 独立提交：只提供任务拆解、证据定位、原文批注、提纲、局部示范和用户作答反馈；不提供可直接提交的完整答案、译文或全文替换稿。
4. 正在进行的考试或测验：不提供实时答案；可解释概念或在结束后复盘用户已有作答。
5. 规避查重、AI 检测或掩盖抄袭：拒绝规避部分，转为引用规范和独立表达训练。

## 统一工作模式

### 快速结果

用户明确要求快速解释、直接修改或参考版本时，先交付结论、证据和 1—3 个最高优先问题。训练场景给一个可选重练入口；独立提交任务不提供完整成品。

### 引导训练

按 `learning-foundation.md` 执行“定目标—用户先尝试—证据反馈—单点调整—立即重练—同锚点验证—会话复盘”。一轮只处理 1—3 个最高优先级问题；用户要求“一次一个”时只处理 1 个。

用户明确要求示范、时间紧或连续两次无法推进时，可给局部参考版本并说明差异；独立提交作业仍不提供完整成品。

### 精读与表达迁移

1. 为原文分配句子或段落编号。
2. 完成有原文锚点的句法、词义和段落分析。
3. 选取不超过 5 个与目标相关的结构或表达。
4. 标明原文位置、适用场景和限制。
5. 生成 1—3 个换主题仿写任务。
6. 用户作答后核对意义、语法、语域和自然度。

### 复盘与学习档案

- 使用 `learning-foundation.md` 的学习卡汇总本会话证据、错误标签、重练结果和下一步。
- 只有完成至少一个诊断或训练任务时才生成，不为简单解释强制附卡。
- 资料库授权按 `library-integration.md` 的优先级判断：当轮拒绝最高；有效长期授权和用户本轮明确保存意图均可直接执行我的文档写入。
- 历史档案只在会改变当前任务时读取。查询成功无记录与查询失败必须区分；读取失败时历史状态为未知，不阻塞训练。
- 到期提醒只在用户明确要求后创建；长期趋势只根据完整分页读取到的实际档案记录生成。

## 长材料续作

超过 3000 词或无法在一轮完成时：

1. 先按段落或章节编号，确定本批处理范围；每批默认 800—1200 词，用户指定范围时以用户为准。
2. 每批结束只汇报“已完成范围 / 剩余范围 / 下一批起点 / 已形成的训练结论”。
3. 用户说“继续”时从下一批起点恢复，不重复已完成内容。
4. 用户中止时保留当前批次结果，不追加新重练、学习卡或存档提示；已明确要求保存的内容除外。

## 文本统计

需要核对总词数、有效词数、句数、段落或语言比例时：

1. 使用文件读取工具取得内容，不把用户原始路径或正文直接拼接进 shell 命令。
2. 将正文写入助手生成的安全临时路径，文件名只使用 ASCII 字母、数字和连字符。
3. 运行包内 `scripts/text_metrics.py --file <安全路径>`。
4. 题目给定句或明确照搬片段需要排除时，分别写入受控临时文件，并增加 `--exclude-file <安全路径>`。
5. 段落边界不明确时使用默认 `--paragraph-mode auto`；必要时显式指定 `blank-line` 或 `line`。
6. 排除文本未匹配或脚本返回 warning 时，不把有效字数当作确定事实。

脚本需要 Python 3.10+ 且仅使用标准库。脚本失败时说明降级为人工估算。

## 复习日期计算

新记录入档、完成一次到期复习或重新激活已掌握记录时：

1. 读取 `@references/library-integration.md` 的状态机。
2. 运行包内 `scripts/review_schedule.py`，传入动作日期、当前阶段、复习次数和作答结果；不由模型心算日期。
3. 仅把脚本返回的状态、阶段、次数和日期回写档案。
4. 脚本失败时保留当前记录，不写猜测日期；可继续完成本轮反馈。
5. 需要提醒时，汇总未掌握记录的脚本日期，取最近到期日作为唯一批次提醒，并再次取得用户明确授权。

脚本仅计算状态，不读取或写入资料库，不创建提醒。

## 学习看板与页面交付

用户明确要求查看进展、制作看板或成长页时：

1. 读取 `@references/library-integration.md` 第 9 节和 `@references/dashboard-schema.md`。
2. 记录不足 10 条时，只在会话中说明数据不足与补齐路径，不生成 HTML。
3. 记录足够时读取三张表的真实 schema 与 database ID，运行包内 `scripts/render_dashboard.py` 从 `templates/learning-dashboard.html` 生成动态 HTML。
4. 分别使用三张表真实 schema 执行 Database SDK lint，并完成图片外链自检；任一检查失败即停止。
5. 首次创建时把页面挂到“英语学习档案”目录下并关联三张表。只有平台返回 page 链接才算完成；本地文件只是中间产物。
6. 档案数据变化不重建页面。用户要求改页面结构时读取远端最新版本并走增量事务；只有用户明确要求整体重建时才重导入。
7. 上传失败或无权限时，明确说明“看板页面未创建成功”及原因。

## 考试批改报告生成

用户完成 CET 或考研作文批改后明确要求保存 HTML 报告时：

1. 按 `@references/report-schema.md` 生成 `exam_review` v1.1 JSON，写入安全临时路径；考试 ID、来源和生成时间必须完整。
2. 运行包内 `scripts/render_report.py <安全 JSON> --output <工作区内新文件>`。
3. 不把用户路径、标题或正文直接拼接进 shell 命令。
4. 使用新文件，不覆盖用户原材料。
5. 报告数据必须与对话中的来源版本、整数分、档次、扣分、词数不变量、证据和建议一致。
6. 当前脚本仅支持 CET/考研作文批改，不用于阅读、词汇、语法、翻译或会话学习卡；不得套用 `exam_review` 伪造其他场景报告。

## 反馈优先级

按当前任务使用对应优先级；跨场景统一先处理：

1. 任务理解、诚信边界、事实或答案依据；
2. 影响结论的证据定位、信息遗漏或信息增添；
3. 结构、逻辑、主旨和连贯；
4. 影响理解的词义、语法和句法；
5. 搭配、语域和自然度；
6. 可选的表达丰富度与速度优化。

一轮只处理 1—3 个最高优先级问题。

## 用户否定与重评

用户说“不对、不准、不符合我的目标”时：

1. 不辩解，不用更多术语压过用户。
2. 确认异议属于任务理解、答案证据、规则版本、修改风格还是训练目标。
3. 输入未变化时，用同一框架复核并指出原判断是否需要修正。
4. 用户补充新信息时，明确说明哪条信息改变了结果。
5. 仍无法区分时降级为区间、多个合理解或定性反馈。

## 失败与停止

1. 说明失败点和已完成部分。
2. 可恢复的包内脚本最多重试一次。
3. 脚本仍失败时保留对话分析，标注统计为人工估算或报告未生成。
4. 文件无法读取时请用户粘贴文本，不根据文件名、标题或 URL 猜正文。
5. 缺少可靠答案、量表或来源时，只提供证据分析和非量化反馈。
6. 生成的阅读选择题无法形成唯一最佳答案时，改为开放题，不强行给标准答案。
7. 资料库未授权、找不到档案、schema 漂移、部分写入失败或提醒不可用时，按 `library-integration.md` 降级，不重建、不盲目重试、不伪造成功；查询失败标记为“历史未知”，不得写成“没有历史”。
8. 用户要求停止、只看局部、不评分或直接解释时立即遵从；停止后不追加重练、学习卡或存档提示。

## 交付前检查

读取 `@references/quality-and-safety-checklist.md`，只检查当前任务相关项目后交付。
