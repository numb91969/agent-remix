## 栏目命题

持续回答“为什么选择腾讯”，但不把答案压缩成一句口号。

把“有鹅选鹅”写成可以不断增加的真实理由库：不同的人基于不同处境选择腾讯，读者可以从中建立自己的判断。

核心姿态是把选择权交还给候选人。承认好工作没有统一定义，不替读者宣布唯一答案。

## 稳定气质

- 轻、真、近；
- 信息密度高，阅读门槛低；
- 多用生活语言、具体场景和真实原话；
- 有鹅系 IP 感，但不过度卖萌；
- 允许自嘲和小意外，旁白保持克制；
- 情绪从焦虑、犹豫或好奇走向松弛、理解和行动；
- 招聘信息明确，但不吞掉故事。

证据顺序通常为：

> 真实疑问或生活场景 → 人物、动作与物件 → 可感知体验 → 腾讯机制或文化 → 读者选择与行动

## 四种写作引擎

### 1. 选择型群像

适用：

- Offer 选择期；
- 校招与实习招募节点；
- 宣讲会、活动回顾；
- 多位员工回答“为什么来、为什么留下”。

结构：

1. 从学生正在面对的真实选择进入；
2. 明确这些答案没有统一标准；
3. 按选择理由、人物反差或情绪需求组织多位员工；
4. 保留不同声音，不将所有人修成同一种口径；
5. 从差异中归纳一到两个共同价值；
6. 把决定权还给读者，给出招聘入口。

每位人物单元至少包含：

- 清晰身份；
- 一个具体场景或选择节点；
- 一句原话或关键动作；
- 这段经历说明的价值。

不要只排列金句。金句必须有故事或事实托底。

### 2. 观念拆解型案例

适用：

- 面试理念；
- 人才标准；
- 招聘流程；
- 容易被误解的企业观念。

推荐单元：

> 看似反常的问题/现象 → 真实回答或案例 → 当事人的思考 → 给读者的温和提示

用案例证明面试平等、关注本质或尊重个体，不直接宣称“我们更平等、更懂人才”。

面试内容尤其避免：

- 暗示某个回答模板更容易通过；
- 将单个面试官做法写成全部流程承诺；
- 用学历、实习经历或背景标签制造焦虑；
- 把候选人写成被单向评价的对象。

### 3. 生活图鉴型

包含两个子方向。

#### 场景化信息图鉴

适用福利、培养、工作环境和生活支持。

每个单元同时给出：

- 一个生活场景；
- 一句短而可视化的图片文案；
- 准确的事实说明；
- 对新人意味着什么。

不要把福利写成长清单。用“落脚、干饭、出发、休息、探索”等生活动作组织，但确保创意包装不改变适用条件。

#### 真实关系微故事

适用同事关系、职场发小、人文文化和培养传承。

结构：

1. 用当代情绪或社会议题建立相关性；
2. 连续呈现短小、具体、有照片感的故事；
3. 少解释，让细节先产生情感；
4. 后段再桥接文化、培养或长期主义；
5. 以同一情绪完成互动和收尾。

照片与文字必须真实对应。不要用后来补拍的照片伪装成当时现场；必要时在图注里诚实说明。

### 4. 项目现场纪实型

适用：

- AI 热点与新业务；
- 新产品和前沿项目；
- 校招生参与核心工作的故事；
- 业务趋势与招聘机会结合。

结构：

1. 用业务变化建立时代背景；
2. 快速把镜头从宏大概念拉到具体年轻人；
3. 选择三到四个“问题—行动—结果”故事；
4. 写时间、突发问题、用户反馈和个人动作；
5. 说明平台如何连接不同产品与能力；
6. 以“正在发生，欢迎参与”完成招聘转化。

不要把年轻人写成口号化英雄。保留普通一天、笨办法、现场调整和阶段性结果。

避免用凌晨赶工、通红眼睛、连续高强度等细节制造英雄叙事。若与事实相关，降低渲染并检查过劳联想。

## 标题与开头

标题优先抓：

- 学生真实问题；
- 人物反差或意外回答；
- 普通生活中有传播力的场景；
- 正在发生的业务变化；
- 栏目持续回答的选择命题。

避免人为硬贴“最治愈、最宿命、最不完美”等标签。若标签不能自然概括人物，宁可删除。

开头不要直接列腾讯优势。使用：

- 一句真实疑问；
- 季节、校园或生活现场；
- 人物身份反转；
- 行业变化后迅速拉近镜头；
- 一个普通却有意味的动作。

## 品牌升维与 CTA

一篇集中表达一到两个腾讯价值即可。

从故事中升维：

- 多个导师和陪伴故事 → 培养与成长确定性；
- 普通友情和长期在场 → 人文文化与长期主义；
- 具体面试对话 → 平等尊重与关注本质；
- 真实项目与用户反馈 → 平台、战场与年轻人的空间。

CTA 先回扣核心命题，再给发布当期的招聘年份、类型、入口或互动。所有时间、岗位、活动、奖品和数量在发布前重新确认。

## 栏目质检

- 是否把选择权还给读者；
- 是否先写人和场景，再写机制；
- 是否用具体证据代替企业自夸；
- 是否保留多声部，而非统一宣传口径；
- 福利、招聘、培养和转岗是否有准确范围；
- 图片与文字是否对应；
- 网感是否只作调味；
- 是否存在暗踩友商或制造焦虑；
- 是否美化过劳；
- 是否清除备用方案、设计指令、占位符和内部素材。
