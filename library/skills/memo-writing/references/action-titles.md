# 行动标题（Action Title）——麦肯锡叙事的灵魂

> 这是决定一份 deck / 报告"像不像咨询"的第一要素。普通 PPT 写"话题标签"，
> 咨询 PPT 写"结论判断"。丁笃行的每一页标题、每一份 memo 的每一节标题都必须是行动标题。

## 一、Label title vs Action title（最核心的区别）

- **Label title（禁止）**：只说"这页讲什么话题"。例：`市场分析`、`竞争格局`、`财务概览`、`问题总结`。
  读者看完还得自己去正文里找结论。
- **Action title（必须）**：一句**完整的判断句**，直接给出这页的结论。例：
  > `中国企业级 Agent 市场将在未来三年进入供给集中期，头部平台的生态规模将成为主要竞争壁垒`

判断一个标题是不是 action title 的三个测试：
1. 它是**完整句子**吗？（有主语 + 动词 + 判断，不是名词短语）
2. 只读这一句，不看正文，读者**能 get 到本页结论**吗？
3. 它包含**必要的数字/时间/范围**吗？（"市场将增长" 弱 → "市场将在 2028 年前翻倍至 12.3B" 强）

## 二、行动标题的写法（5 步，来自 Slideworks）

1. 找出这一页**唯一**的核心信息（一页只证明一个结论）。
2. 把"如果我口头讲这页会说的那句话"写下来。
3. 改写成一句**能独立理解**的完整句子（去掉"如图所示""可以看到"这类依附正文的话）。
4. 删掉页面上所有**不支撑这个标题**的内容（标题决定取舍）。
5. 连续读完所有页的标题，检查它们是否**自成一条故事线**（见下）。

## 三、"只读标题就能理解全论证"——故事板纪律

麦肯锡 deck 的黄金标准：**把所有页的行动标题抽出来单独读，应该像读一段完整的论证。**
所以正式做 deck 前，丁笃行必须先产出一份**只有行动标题的骨架**（标题故事板），例如：

1. WorkBuddy 已建立国内领先规模，但专业场景的深度供给仍是主要增长约束
2. 金融、法律和内容创作贡献了最高频的专业任务需求
3. 当前供给数量充足，但高质量资产占比和复用率仍然偏低
4. 低复用主要由评测不足、分发错配和缺少持续优化机制导致
5. 建议建立"生产—评测—分发—反馈—优化"的资产自进化闭环
6. 三项机制预计可在两个季度内显著提升成功率和复用率

**只读这六句，就能理解完整论证** → 才算合格的故事线。骨架通不过这个测试，不许进入填充细节阶段。

## 四、标题与证据一致性（严查）

- 标题里的每个判断、每个数字，正文/图表里**必须真的有证据支撑**。
- 标题说"翻倍"，图表就必须显示翻倍；标题说"最高频"，就必须有对比数据证明它最高。
- 标题与正文不一致 = 一眼假，是硬伤。交付前逐页核对：**标题的断言，本页证据兑现了吗？**

## 五、常见反模式（写到就打回重写）

- ❌ 名词短语标题：`XX 分析` / `XX 概览` / `关于 XX 的思考`
- ❌ 空洞总结（strategyU 重点）：`我们发现了三个问题` / `公司需要实施五项举措`——
  这类"看起来有结构"但没洞察。真正的总结要说清这些问题的**共同性质**，或这些行动的**共同结果**。
  改法：`三个问题共同指向同一个根因：缺少持续优化闭环` / `五项举措共同服务于把复用率从 15% 提到 40%`。
- ❌ 疑问句标题：`我们该进入欧洲市场吗?`（标题给答案，不是抛问题）
- ❌ 半截判断：`市场在增长`（增长多少？到什么时候？对我们意味着什么？）
