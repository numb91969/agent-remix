# 半导体 · 行业分析框架（双透镜）

> ⚠️ **本文件是分析框架，不是数据快照。最后校订：2026-08。**
> 文中所有数字仅作**口径示例**——告诉你这个指标长什么样、单位是什么、量级在哪，
> 一律带 `as-of` 标注。**动笔前必须重新取数**（`neodata` 研报召回 / `westock consensus` /

## 0. 速查

**一句话结构**：半导体是**弱成长、强周期**的成熟产业——增长来自下游应用拓展与单机硅含量提升，
波动来自「需求变化 → 库存错配 → 产能投放滞后」的传导时滞。**技术是根因，产能是变量，库存是放大器。**

**两个透镜的分界**：

| 你被问的是 | 走哪个透镜 |
|---|---|
| 要不要自建晶圆厂 / 国产替代先攻哪一环 / 选哪个制程节点 / 车规芯片要不要自研 / 这条产业链格局如何 | **§2 咨询透镜** |
| 周期到哪一段了 / 盈利拐点在哪 / 这轮是不是「这次不一样」/ 该给多少倍 | **§3 行研透镜** |

两个透镜**共用 §1 的价值链与指标口径**——口径只定义一次，避免两边算出两个数。

## 1. 产业地基（两透镜共用）

### 1.1 价值链与利润分布

```
基础支撑：EDA/IP  ──┐
                   ├──→ 设计(Fabless) ──→ 制造(Foundry/IDM) ──→ 封测(OSAT) ──→ 终端
设备 / 材料 ────────┘
```

价值量分布呈 **「设计 > 晶圆制造 > 设备 > 封测 > 材料」**（券商通行口径 as-of 2023-2026），
形态上是微笑曲线：**上游设备材料与下游设计利润最厚，中游纯代工最薄**。

但**别停在「哪个环节利润高」——要回答「哪个环节利润弹性最大」**。判断这一条用三个变量，
不要凭印象：

| 变量 | 怎么量 | 含义 |
|---|---|---|
| 供给集中度 | CR3 / HHI（按金额） | 越集中，涨价传导越顺 |
| 客户可替代性 | 切换供应商的验证周期（月） | 验证越长，在手份额越稳 |
| 产能弹性 | 从下单到产能落地的时滞（月） | 时滞越长，短缺期利润弹性越大 |

**示例量级**（as-of 2026-05，须复核）：先进制程（7nm 以下）代工份额高度集中于台积电（>80%）；
EDA 与核心 IP 前三家合计接近 78%；DRAM/NAND 三大厂控制约 95% 产能。
**这类集中度数字每年都在动，中国厂商份额尤其在爬——必须现查。**

### 1.2 核心驱动变量

每一侧挑 2-3 个**可量化、可追踪**的变量，不要写「技术进步」这种不能落到数字的词。

| 侧 | 变量 | 追踪方式 | 为什么是它 |
|---|---|---|---|
| 需求 | 云厂商 AI 资本开支（季度指引） | 四大云 capex 指引汇总 | 当前周期最强单一驱动 |
| 需求 | 终端出货量（手机/PC/车/服务器） | 季度出货报告 | 决定基本盘而非增量 |
| 需求 | **单机硅含量**（美元/台） | 拆机 BOM、厂商披露 | 出货不增、含量增也能拉动需求 |
| 供给 | 晶圆产能（万片/月，**12 寸当量**） | SEMI fab 展望、公司扩产公告 | 分子 |
| 供给 | 稼动率 / 产能利用率（%） | 代工厂季报 | 毛利率的第一驱动 |
| 供给 | 设备交期（月） | 设备厂在手订单与指引 | 决定新增供给多久到位 |
| 政策 | 出口管制清单变动 | 官方清单原文 | 会瞬间改写可得性假设 |
| 政策 | 产业补贴投放（金额与投向） | 大基金/CHIPS/欧盟芯片法案 | 改变扩产节奏与成本曲线 |

### 1.3 关键指标与口径（本行业最容易翻车的地方）

| 指标 | 定义 | 单位 | 口径陷阱 |
|---|---|---|---|
| 全球销售额 | 厂商出货金额 | 亿美元 | **WSTS 与 SIA 口径不同**（SIA 常用三月移动平均），跨源比较前先确认；不要拿季度值年化 |
| 产能 | 名义 vs 有效产能 | 万片/月 | **必须换算 12 寸当量**；8 寸与 12 寸片直接相加是硬错 |
| 稼动率 | 投片量 / 产能 | % | 分母是名义还是有效？公司口径常年不一致，跨公司比较基本无效 |
| ASP | 平均售价 | 美元/颗、美元/片 | **ASP 上涨可能只是产品结构变了**（mix shift），不等于提价；必须与出货量拆开看 |
| B/B ratio | 订单额 / 出货额 | 倍 | >1 表示需求扩张，是领先指标；单月噪声大，看三月移动 |
| 库存天数（DOI） | 存货 / 日均成本 | 天 | **原厂库存与渠道库存要分开**，否则同一批货被数两次；渠道库存往往查不到，标 [A] |
| 良率 | 合格晶粒 / 总晶粒 | % | 不同节点、不同产品的良率**不可比**；新节点爬坡期 6-18 个月是常识但要按案例校准 |
| 制程节点 | 3nm / 5nm / 28nm | — | **是营销命名，不是物理栅长**，跨厂商不可直接比较能力 |
| 自给率 / 国产化率 | 国产供给 / 总需求 | % | **本行业最容易被玩坏的口径**：按金额还是数量？「在中国生产」还是「中国企业生产」？外资在华厂算不算？不写清定义的国产化率数字一律不可用 |
| 单机硅含量 | 半导体价值 / 台 | 美元/台 | 口径含不含存储差别巨大 |

### 1.4 数据源地图

| 你要什么 | 去哪 | 频率与时滞 |
|---|---|---|
| 全球市场规模与分产品增速 | WSTS（季度统计 + 春/秋预测）、SIA（月度） | 季度数据滞后约 1-2 个月 |
| 设备支出与晶圆厂扩产 | SEMI（设备出货、fab 展望） | 季度 |

| **周期领先指标** | 台积电月营收（次月上旬）、韩国半导体出口（次月 1 日）、北美设备出货 | **月度，是全链最快的三个体温计** |
| 中国口径 | 中国半导体行业协会、海关总署集成电路进出口 | 月度 |

### 1.5 周期定位

半导体是**三层周期叠加**，谈「周期到哪了」必须先说清在谈哪一层：

| 层 | 名称 | 长度 | 驱动 | 观察指标 |
|---|---|---|---|---|
| 长 | 产品周期 | ≈10 年 | 技术迭代（新应用取代旧应用） | 主导应用更替、单机硅含量台阶 |
| 中 | 产能周期（朱格拉） | 3-4 年 | 企业资本开支 | capex 指引、设备出货、新 fab 投产表 |
| 短 | 库存周期（基钦） | 3-6 个季度 | 供需短期错配 | 库存天数、B/B、ASP 环比 |

**定位动作**（不要凭感觉说「已经见底」）：库存天数是否连续两季下行 → B/B 是否回到 1 以上 →
ASP 环比是否转正 → 稼动率是否回升 → 头部 capex 指引是否上修。**五个里对上三个才算拐点成立**，
且要注明各指标的 as-of 日期。

## 2. 咨询透镜（决策者 = 企业高管 / 董事会）

### 2.1 该行业的典型咨询问题

要不要自建晶圆厂或封测产能 / 国产替代先攻哪一环 / 押先进制程还是成熟制程特色工艺 /
车规或 AI 芯片要不要自研 / 并购标的怎么排序 / 面对出口管制的供应链重构方案。

### 2.2 框架组合

| 问题 | 框架组合 | 各自验证什么 |
|---|---|---|
| 产能投资（要不要建厂） | 产能周期定位（§1.5）+ 单位经济学（每片晶圆现金成本）+ 客户验证周期（§2.3） | 分别回答：投产时点会撞上周期哪一段、成本能否进入行业前几分位、建成后多久才有真实收入 |
| 国产替代排序 | **卡点矩阵（§2.3）** + 瓶颈解除的系统乘数 + 需求确定性 | 不是「哪个最卡」，而是「解除后能带动多少下游产值」 |
| 节点/工艺路线选择 | 成本曲线 + 客户结构 + 产能弹性 | 先进制程是军备竞赛（赢家通吃），成熟节点是特色工艺与客户黏性之战，两者的胜负手完全不同 |
| 竞争格局（structure 题） | 五力 + 集中度演变（CR3/HHI）+ 价值链利润分布 + 战略群组 | 结论必须是**结构性判断**（几超几强、出清到哪一步、谁出局），不是配置建议 |

### 2.3 行业特有分析动作（通用框架给不了的那部分）

**① 卡点矩阵**——半导体咨询的招牌动作，把「国产替代/供应链安全」从口号变成可排序的清单：

六类瓶颈（**设备 / 材料 / EDA / IP 与架构 / 制造工艺 Know-how / 先进封装**）× 三个维度
（技术代差年数、供给集中度、可绕开性）→ 落到热力矩阵。
**禁止把六类瓶颈混成一个「国产替代」变量**——它们的解除时间尺度差 2-3 倍，混在一起等于没分析。

**② 客户验证周期**——决定「做出来之后多久才有收入」，是产能决策里最常被漏掉的一项：
车规（AEC-Q100 等）通常以年计，消费类以季度计。示例量级须按具体品类现查校准。

**③ 产能爬坡曲线**——fab 从动土到量产以年计，量产后还有良率爬坡期。
做投资回收测算时**必须把爬坡期的低良率成本算进现金流**，否则 IRR 系统性偏乐观。

**④ 硅含量拆解**——回答「需求还能不能涨」时，把需求拆成「终端台数 × 单机硅含量」，
两个因子的驱动力完全不同：台数看宏观与换机周期，含量看架构演进。

### 2.4 结论形态样例与高频误判

**合格结论**（结构性、带条件、可执行）：
> 不自建 12 寸产线。以长约锁定 X 万片/月成熟节点产能，把资本投向先进封装与测试，
> 24 个月内把封装良率做到 Y%；若出口管制扩大到 Z 类设备，则触发预案 B。

**高频误判**：

| 误判 | 为什么错 |
|---|---|
| 把「国产替代」当单一变量 | 六类瓶颈时间尺度差 2-3 倍，必须拆开排序 |
| 把制程数字当能力 | 节点命名是营销名，跨厂商不可比 |
| 漏掉客户验证周期 | 产能建好但拿不到订单，现金流表全错 |
| 用行业增速当公司增速 | 行业 +100% 时绝大多数公司远低于此，结构分化极大 |
| 政策可行性等同商业可行性 | 有补贴不代表有客户、有良率、有毛利 |

## 3. 行研透镜（决策者 = 投资人）

### 3.1 典型问题

周期走到哪一段 / 盈利拐点何时出现 / 「这次是不是不一样」/ 该用什么锚、给多少倍 /
哪个假设一翻转结论就翻。

### 3.2 盈利驱动拆解式（按环节，不能混用）

| 环节 | 收入拆解 | 毛利率驱动 |
|---|---|---|
| 设计（Fabless） | 出货量 × ASP | 晶圆采购成本、产品结构、流片费用摊销 |
| 代工（Foundry） | 产能 × 稼动率 × 晶圆单价 | **稼动率是第一驱动**；新 fab 折旧压制毛利 12-24 个月；制程结构 |
| 存储 | bit 出货量 × 每 bit 价格 | bit 成本下降速度（制程微缩）vs 价格跌速 |
| 设备/材料 | 客户 capex × 自身份额 | 在手订单与递延收入是**领先指标**，比当期收入更早反映拐点 |
| 封测 | 封装颗数 × 单价（先进封装单价数量级更高） | 稼动率、先进封装占比 |

### 3.3 供需平衡表与成本曲线

**供需平衡表**（存储、成熟制程等同质化品类必做）：

```
供给 = 期初有效产能 + 新增投产（按投产表逐季）− 退出/转产
需求 = 分应用 bit（或晶圆）需求加总
缺口率 = (供给 − 需求) / 需求   →   映射到价格方向
```

**成本曲线**：把各厂**现金成本**从低到高排序。价格跌到边际产能的现金成本附近时，
减产压力出现，通常是价格见底的机制性信号——比「跌得够多了」这种直觉可靠得多。

### 3.4 估值锚与可比口径

| 环节 | 主锚 | 交叉验证 | 为什么 |
|---|---|---|---|
| 存储 | 传统是 **P/B**；2026 年起市场在争论切向 **P/E** | 正常化 EPS 倍数、EV/EBITDA、FCF | 产品同质、资本开支巨大、盈利剧烈波动 → 历史用 P/B 穿越周期。长协（LTA）与 HBM 提升盈利能见度后，卖方开始改用 P/E（as-of 2026-05~08，**属进行中的争论，不是定论，引用时必须注明日期与分歧双方**） |
| 代工 | 能见度高时 P/E；下行期回落到 P/B | ROIC、EV/EBITDA | 重资产但客户黏性强 |
| 设计 | P/E / PEG；未盈利用 P/S | 研发费用率、单客户集中度 | 轻资产、成长属性 |
| 设备 / 材料 | 成熟用 P/E；成长期用 P/S | **在手订单 / 收入** | 订单先行于收入 |

> 🔴 **周期股估值第一铁律**：**盈利峰值时 PE 最低，低谷时 PE 最高甚至为负。**
> 所以「前瞻 PE 只有个位数」不是安全边际，往往是周期顶部信号。
> 持续经营价值必须用**正常化盈利**（3-5 年平均）算，不能用峰值或谷底。
> **同时使用「峰值 EPS」和「成长股倍数」是双重乐观**，是本行业最常见的估值事故。

### 3.5 命门假设与敏感性

列出「一旦翻转，结论就翻」的假设，并给出各自的观察哨：

| 命门假设 | 翻转会怎样 | 观察哨 |
|---|---|---|
| AI 资本开支的持续性 | 需求端最强驱动消失，全链条重估 | 云厂季度 capex 指引、加速器出货 |
| 供给纪律（扩产是否克制） | 扩产失控 → 价格崩塌，回到经典周期剧本 | 新增投产表、设备订单 |
| 长协能否穿越下行 | 若下行期长协被重谈，盈利能见度叙事瓦解 | 合同履约、预付款转收入 |
| 出口管制与关税 | 直接改写可得性与成本假设 | 官方清单原文 |

**敏感性至少做两维**（如价格 × 稼动率、bit 增速 × ASP），单点估计不可交付；
做法与呈现见 `valuation-modeling` 的假设翻转测试与敏感性表。

## 4. 两个透镜都会踩的坑

1. **用行业增速当公司增速。** WSTS 口径的全行业增速（as-of 2026-08 的全年 +108% 属存储驱动的极端值）
   不能套到任何单一公司或细分赛道上——同期不同环节增速差一个数量级。
2. **只看金额不看量。** 价格暴涨期金额增长会掩盖出货量下滑，必须同时看 bit/晶圆出货。
3. **国产化率口径混用。** 金额口径与数量口径、「在华生产」与「中国企业生产」结论能差一倍。
4. **跨源直接相减。** WSTS 全球口径与海关进出口口径、第三方份额口径互不兼容，不可混算。
5. **拿峰值利润外推。** 无论是咨询的产能测算还是行研的估值，都必须做周期正常化。
6. **把制程节点当技术能力排序。** 节点是营销命名。
7. **忽略时滞。** 需求变化传导到产能落地以年计，「现在缺货」与「两年后过剩」经常是同一件事。
