# 银行与非银金融 · 行业分析框架（双透镜）

> ⚠️ **本文件是分析框架，不是数据快照。最后校订：2026-08。**
> 文中数字仅作**口径示例**，一律带 `as-of`。**动笔前必须重新取数**
> （监管口径季度数据、上市银行财报、`neodata` 研报召回、`westock consensus`）。
> **直接把本文件的示例数字抄进交付物 = 交付事故。**
> 息差与资产质量按季度变，一次 LPR 或存款挂牌利率调整就能改写全年测算。

## 0. 速查

**一句话结构**：银行不是"卖产品"的生意，是**用资本撬动资产负债表赚利差、再用拨备吸收风险**的生意。
所以它的所有战略与估值问题最终都收敛到一个闭环：

```
ROE × (1 − 分红率) = 内生资本补充速度 ≥ 风险加权资产(RWA)增速
```

**这个闭环是银行一切经营约束的源头。** 息差被压→ROE 下降→内生资本补充跟不上→
要么放慢扩张、要么外部融资摊薄。示例（as-of 2026）：若维持 RWA 6–7% 的增速，
理论净息差底线大约在 1.44%–1.57%，而彼时商业银行净息差已在 1.42% 左右——
**这就是"稳息差"成为行业核心经营诉求的真正原因，不是因为好看，是因为不稳就扩不动。**

**本赛道第一口径陷阱（必须先讲）**：**不良率不是资产质量。**
不良率是存量比率，可以被**核销、转让、分母扩张**同时稀释，是最容易被"管理"的指标。
判断资产质量必须用**不良净生成率**（还原核销后的真实新增，前瞻性最强）
配合**关注率与逾期率**（先行指标）。只看不良率平稳就说风险可控，是本赛道最常见的失误。

**两个透镜的分界**：

| 你被问的是 | 走哪个透镜 |
|---|---|
| 资负结构怎么调 / 零售还是对公 / 中收怎么做 / 网点与数字化 / 区域行怎么突围 / 格局 | **§2 咨询透镜** |
| 息差见底没有 / 资产质量真实水平 / 利润增速可不可持续 / 该给多少 P/B | **§3 行研透镜** |

## 1. 产业地基（两透镜共用）

### 1.1 收入结构与利润生成

```
营业收入 = 净利息收入 + 中间业务收入 + 其他非息收入
           (生息资产 × 净息差)   (手续费佣金)   (投资收益/公允价值变动)
                 ↓
        − 业务及管理费 = 拨备前利润(PPOP)
                 ↓
        − 信用减值损失(拨备) = 税前利润 → 净利润
```

> 🔴 **PPOP 是判断银行真实盈利能力的核心指标，不是净利润。**
> 拨备计提有相当的裁量空间，**是最常用的利润平滑器**：拨备覆盖率高时少提拨备即可释放利润。
> 因此**净利润增速可以在营收下滑时依然为正**。
> 看到"净利润正增长"时的第一个动作永远是：拆开看 PPOP 增速和拨备计提的变化。
> **营收降、PPOP 降、净利润升 = 靠拨备反哺，不可持续。**

其他非息收入里的债券投资收益同样是低质量收入——**利率下行时兑现浮盈可以显著美化营收，
但这是一次性的，且卖掉的债券以后不再贡献利息**。

### 1.2 核心驱动变量

| 侧 | 变量 | 追踪方式 |
|---|---|---|
| 量 | 生息资产规模增速 | 受**资本充足率与 RWA 硬约束**（见 §0 闭环） |
| 价 | **净息差（NIM）** | 最核心变量；示例 as-of 2026Q1：上市银行约 1.37%，同比降幅收窄至约 0.03pct |
| 价·资产端 | 贷款重定价（LPR + 加点压缩）、债券配置盘收益率、债务置换 | 示例测算（2026 全年，须复核）：贷款重定价约 −7.5BP（其中 LPR 约 −2.5BP、加点压缩约 −4.9BP）、配置盘债券约 −5BP、债务置换约 −3BP |
| 价·负债端 | **存款到期重定价** | 当前最大的正向变量；示例：全年到期重定价规模可达约 84 万亿元，改善息差约 0.15pct，可对冲资产端约 0.10pct 的下行 |
| 风险 | 信用成本、不良净生成 | 示例 as-of 2026-03：商业银行不良率约 1.51%、关注率约 2.17%、拨备覆盖率约 203% |
| 结构 | 零售 vs 对公 | 示例：零售端（消费贷/信用卡/经营贷）压力尚存，对公改善形成对冲 |
| 中收 | 财富管理、投行、托管 | 与资本市场景气度和费率政策高度相关 |
| 政策 | LPR、存款利率自律上限、降准、资本新规 | 单次调整即可改写全年测算 |

> ⚠️ **存款重定价红利是前高后低的，绝不可线性外推。**
> 示例测算（as-of 2026）：全年存款成本率改善约 14.7BP，但分季度是
> Q1 约 9.9BP / Q2 约 2.6BP / Q3 约 1.7BP / Q4 约 0.5BP。
> **拿 Q1 的改善幅度乘以四，会把全年息差算高一倍以上。** 这是本赛道最容易犯的算术错误。

### 1.3 关键指标与口径

| 指标 | 定义 | 单位 | 口径陷阱 |
|---|---|---|---|
| **净息差 NIM** | 净利息收入 / 生息资产平均余额 | % | 期初期末均值 vs 日均余额口径不同；**商业银行整体口径与上市银行口径不同**（示例：1.42% vs 1.37%），跨源比较必错 |
| 净利差 Spread | 生息资产收益率 − 计息负债成本率 | % | 与 NIM 不同（NIM 含免息资金贡献），**两者不可混用** |
| **不良率 NPL** | 不良贷款 / 贷款总额 | % | **见 §0**：受核销、转让、分母扩张三重稀释 |
| **不良净生成率** | (期末不良 − 期初不良 + 核销转出) / 贷款 | % | **判断真实资产质量必用**；示例 as-of 2025A：上市银行测算约 0.83% |
| 关注率 / 逾期率 | 潜在风险贷款占比 | % | **先行指标**，通常领先不良率 1–2 个季度；关注率抬升而不良率平稳，是风险后置的信号 |
| 拨备覆盖率 | 拨备余额 / 不良贷款 | % | 既是安全垫也是**利润调节器**；下降未必是坏事（可能是核销加速），须结合拨贷比看 |
| 拨贷比 | 拨备余额 / 贷款总额 | % | 比拨备覆盖率更不易被不良口径影响 |
| 信用成本 | 当期计提拨备 / 贷款 | % | 直接影响利润，是"隐藏利润"的主要开关 |
| **PPOP** | 拨备前利润 | 亿元 | **真实盈利能力看这个**，不是净利润 |
| 核心一级资本充足率 | — | % | 决定扩表空间，是 §0 闭环的约束端 |
| RWA 增速 | 风险加权资产增速 | % | 与规模增速不同（结构调整可以省资本） |
| 成本收入比 | 业务管理费 / 营收 | % | 营收下滑时会被动抬升，不等于费用失控 |
| ROE / ROA | — | % | ROE = ROA × 权益乘数；**高 ROE 可能来自高杠杆而非高盈利能力，必须拆开** |

### 1.5 周期定位

银行的周期是**利率周期 + 信用周期的叠加**，且两者不同步：

| 层 | 驱动 | 观察指标 | 当前示例（as-of 2026，须复核） |
|---|---|---|---|
| 利率周期 | 货币政策、LPR、存款定价 | 息差走势、重定价节奏 | 息差呈"L 型"筑底，降幅显著收窄，部分银行环比回升 |
| 信用周期 | 经济景气、风险暴露与出清 | 不良净生成、关注率、行业集中度 | 整体平稳，零售承压、对公改善 |
| 资本周期 | 扩表意愿与资本补充 | 资本充足率、RWA 增速、再融资 | 内生资本补充约束扩表速度 |

**定位动作**：先看息差的**环比方向**（不是同比幅度）→ 再看负债端红利还剩多少（重定价规模与节奏）→
再看资产端定价能否企稳（取决于实体融资需求）→ 最后看不良净生成有没有恶化。
**息差见底的真正确认，在负债端红利用完之后仍能守住**——高息存款重定价进入后半程时，
后续走势就更多取决于资产端，也就是实体需求能否带动资产定价上行。

## 2. 咨询透镜（决策者 = 银行管理层 / 董事会）

### 2.1 典型问题

资产负债结构怎么调 / 零售还是对公、投哪块 / 中收怎么做起来 /
网点与数字化怎么取舍 / 区域性银行怎么突围 / 财富管理怎么打 / 风险偏好定在哪。

### 2.2 框架组合

| 问题 | 框架组合 | 各自验证什么 |
|---|---|---|
| 资负结构优化 | **息差归因拆解（§2.3）** + 重定价缺口分析 + 资本占用对比 | 息差压力来自哪一段、哪些结构调整能省资本 |
| 业务组合选择 | **RAROC / EVA 排序（§2.3）** + 客群价值 + 交叉销售 | 高收益业务未必创造价值——要扣掉风险成本与资本成本 |
| 零售 vs 对公 | 风险调整后收益 + 周期错位 + 客群基础 | 两者的信用周期不同步，可对冲 |
| 中收突破 | 收入池分解 + 能力差距 + 费率政策风险 | 财富管理是收入池最大处，但费率受政策影响 |
| 数字化与网点 | 单客服务成本曲线 + 客群迁徙 + 场景获客 | 成本节约 vs 客户流失的净效应 |
| 区域行突围 | 战略群组 + 本地份额 + 差异化定位 | 全国性打法在区域行身上通常不成立 |

### 2.3 行业特有分析动作

**① 息差归因拆解（本赛道的招牌动作）**

把息差变动**逐项分解到 BP**，资产端与负债端分开：

```
Δ净息差 = [资产端] 贷款重定价(LPR 部分 + 加点压缩部分) + 债券配置盘重定价 + 债务置换 + 结构变化
        + [负债端] 存款到期重定价 + 挂牌利率下调 + 存款结构(活期占比/久期) + 主动负债成本
        + [政策] 降准等
```

**做这个拆解的价值在于：它区分了"会自然发生的"与"能被管理层影响的"。**
LPR 重定价是被动承受的，加点幅度、存款久期结构、活期占比是能管的。
战略建议只能建立在后者上。**同时必须按季度铺开，因为负债端红利前高后低（见 §1.2 警告）。**

**② RAROC / EVA 排序（业务取舍的正确尺子）**

```
RAROC = (收入 − 运营成本 − 预期损失) / 经济资本
EVA   = 风险调整后利润 − 经济资本 × 资本成本率
```
银行选业务**不能按收益率排序，必须按风险与资本调整后排序**。
高定价业务往往对应高预期损失与高资本占用，扣完可能是负贡献。
**"这块业务收益率高所以要做大"是本赛道最典型的错误建议。**

**③ 资本闭环校验（每个扩张建议都要过这一关）**

任何"做大规模"的建议，都必须回答：
按建议的增速，RWA 会增长多少 → 内生资本补充（ROE × 留存率）够不够 →
不够的话资本充足率会掉到哪 → 是否触及监管底线 → 需不需要外部融资、摊薄多少。
**过不了这一关的增长建议不能出。**

**④ 重定价缺口分析**——按重定价期限把资产与负债分桶，看利率变动时哪端先动、动多少。
决定了这家银行在降息/加息周期中是受益还是受损，是资负管理的基础动作。

### 2.4 结论形态样例与高频误判

**合格结论**：
> 压降 A 类高资本占用低 RAROC 业务 X 亿，腾出的资本转投 B 客群（RAROC 高 Y pp）；
> 负债端把三年期定存占比从 M% 压到 N%、活期占比提升，测算可改善息差 Z BP。
> 组合后 RWA 增速控制在 6%，内生资本可覆盖，无需外部融资。

**高频误判**：

| 误判 | 为什么错 |
|---|---|
| 用不良率论证资产质量 | 存量比率会被核销与分母稀释 |
| 用净利润论证经营改善 | 拨备可以反哺利润，要看 PPOP |
| 按收益率排序选业务 | 必须用 RAROC/EVA |
| 建议扩张不算资本 | 过不了 §0 闭环 |
| 存款红利线性外推 | 前高后低 |
| 混用商业银行与上市银行口径 | 两套口径数值不同 |
| ROE 高就说盈利能力强 | 可能来自高杠杆 |

## 3. 行研透镜（决策者 = 投资人）

### 3.1 典型问题

息差见底没有 / 资产质量的真实水平 / 利润增速可不可持续 / 分红能不能维持 /
该给多少 P/B / 什么会证伪。

### 3.2 盈利驱动拆解式

```
净利润 = 生息资产规模 × 净息差 × (1 + 中收占比调整) × (1 − 成本收入比) × (1 − 信用成本率) × (1 − 税率)
              ↑ 受资本约束      ↑ 核心变量                              ↑ 最大的利润调节器
```

**四个必查的质量问题**：
1. 营收增长里，**净利息收入**贡献多少、**其他非息（债券浮盈）**贡献多少？后者是一次性的。
2. 净利润增速与 PPOP 增速的差额有多大？差额就是拨备反哺的量。
3. 规模增长消耗了多少资本？资本充足率的变化方向是什么？
4. 不良净生成率与关注率的方向，和不良率的方向一致吗？**不一致时以前两者为准。**

### 3.3 息差与资产质量的前瞻推演（替代供需平衡表）

银行没有供需平衡表，对应位置的硬功夫是**逐季度的息差与信用成本推演**：

```
下一年息差 = 当期息差 + Σ(资产端各项 BP) + Σ(负债端各项 BP) + 政策项
             （必须按季度铺开，因为重定价节奏不均匀）

信用成本   = 不良净生成率 × 覆盖倍数 ± 拨备政策调节
             （问：拨备覆盖率还有多少释放空间？释放完了怎么办？）
```

**"拨备还能释放几年"是本赛道最有价值的问题之一**，因为它直接决定利润增速的可持续期限。

### 3.4 估值锚与可比口径

| 锚 | 何时用 | 怎么用 |
|---|---|---|
| **P/B（主锚）** | 常态 | 银行是资产负债表生意，P/B 与 ROE 强相关：**P/B ≈ (ROE − g) / (COE − g)**。给多少倍要从 ROE 与风险倒推，不能靠历史分位 |
| 股息率 | 红利视角 | 需同时检验**分红率的可持续性**——分红率提高会削弱内生资本补充，与扩表速度冲突（§0 闭环） |
| P/E | 辅助 | 银行 P/E 天然低，跨行业比毫无意义 |
| **隐含不良率反推** | 判断悲观定价 | 从当前 P/B 反推市场隐含的资产质量假设，回答"市场是不是已经price in 了坏账" |
| P/EV、P/NBV | **保险**（非银） | 寿险专用锚，与银行完全不同 |
| P/B + ROE | **券商**（非银） | 与市场景气度强相关，注意周期位置 |

> 🔴 **本赛道估值第一提醒**：**P/B 的高低必须由 ROE 与风险解释，不能由历史分位解释。**
> 「现在 P/B 处于历史低位所以便宜」是无效论证——如果 ROE 中枢下移了，
> 低 P/B 就是新的合理水平。**先回答 ROE 中枢去哪了，再谈估值。**
> 另外注意：**银行与保险、券商的估值锚完全不同**（P/B vs P/EV vs P/B+周期），不可混谈。

### 3.5 命门假设与敏感性

| 命门假设 | 翻转会怎样 | 观察哨 |
|---|---|---|
| 息差见底 | 决定营收方向，是最大的单一变量 | 环比息差、重定价进度、LPR 动向 |
| 负债红利的剩余空间 | 用完后息差取决于资产端 | 高息存款到期节奏（注意前高后低） |
| 资产端定价能否企稳 | 取决于实体融资需求 | 新发放贷款利率、信贷结构 |
| 资产质量（尤其零售） | 信用成本上行会吃掉息差改善 | 不良净生成、关注率、逾期率 |
| 拨备释放空间 | 决定利润增速可持续几年 | 拨备覆盖率、拨贷比 |
| 资本与分红的平衡 | 高分红与扩表二选一 | 资本充足率、RWA 增速、分红率 |

敏感性至少做 **净息差 × 信用成本** 的双维表（这是银行盈利最主要的两个杠杆）。

## 4. 两个透镜都会踩的坑

1. **用不良率代表资产质量。** 用不良净生成率 + 关注率。
2. **用净利润代表盈利能力。** 用 PPOP，拨备是调节器。
3. **把债券浮盈当经常性收入。** 一次性，且卖掉后不再生息。
4. **存款重定价红利线性外推。** 前高后低。
5. **混用商业银行 / 上市银行口径。** 数值不同。
6. **混用 NIM 与净利差。** 两个不同指标。
7. **不算资本就建议扩张。** 过不了 §0 闭环。
8. **按收益率而非 RAROC 选业务。** 忽略风险与资本成本。
9. **用历史分位论证 P/B 便宜。** 先回答 ROE 中枢。
10. **银行、保险、券商混用估值锚。** P/B、P/EV、P/B+周期各不相同。
