## 0. 速查

**一句话结构**：具身智能是**三层叠加**的生意，三层的赚钱逻辑完全不同：

```
智能层（VLA 基座 + 世界模型 + 数据工厂） ← 壁垒在数据，不在算法
本体层（丝杠/减速器/电机/传感器/整机）   ← 规模制造，量价反向赛跑
场景层（工业 → 物流 → 商服 → 家庭）       ← 决定整条链的现金流
```

**只谈本体层的分析（讲丝杠、减速器、BOM 降本）是不完整的**——
公开共识 as-of 2026 是：**VLA 架构已经收敛、开源把算法差距拉平了，
真正的壁垒从模型架构迅速转移到了数据工厂的规模与效率。**
具身智能的数据不能从互联网爬取，必须靠机器人在真实物理世界里操作产生，
这让数据采集与回流成了中游最被低估、也最决定胜负的一环。

**本赛道的两个第一口径陷阱（都必须先讲）**：

**① 演示视频不是自主运行。** 判断一段机器人演示前必须问四件事：
是否遥操作、是否加速播放、是否剪辑拼接、是否 unseen 场景。
**这是本赛道最泛滥的信息污染源**，也是外行与内行判断分歧最大的地方。

**② 采集的数据量不是可用的数据量。** 遥操作采到的原始数据要经过清洗与对齐，
**行业经验示例：采集一天的数据,真正能喂给模型的常常不到 10%。**
用"累计采集小时数"论证数据壁垒，等于用招标量论证收入。

**另一件必须先讲的事（承自本体层）**：**「拿到定点」不是收入。**
供应链公告里的"送样""定点通知""通过验证"距离确认收入还隔着小批量、量产爬坡、
良率达标、客户放量几道关，每道以季度计、每道都可能卡死。

**两个透镜的分界**：

| 你被问的是 | 走哪个透镜 |
|---|---|
| 切哪一层 / 自建数据工厂还是用开源基座 / 场景怎么选 / 产能怎么铺 / 进整机厂供应链 / 格局 | **§2 咨询透镜** |
| 出货与泛化能否兑现 / 谁在降本曲线里保得住毛利 / 现在是主题期还是兑现期 / 给多少倍 | **§3 行研透镜** |

## 1. 产业地基（两透镜共用）

### 1.1 三层价值链与竞争分层

```
智能层  物理世界基础模型（VLA 基座）→ 世界模型 → 数据工厂（采集·清洗·标注·回流）
          ↓
本体层  核心零部件（丝杠·减速器·电机·传感器·芯片）→ 整机集成
          ↓
场景层  工业制造 → 仓储物流 → 商业服务 → 医疗护理 → 家庭
```

**智能层内部还有一层竞争分级**（这是判断一家公司位势的关键）：

| 级别 | 谁在这一层 | 靠什么立足 | 可持续性 |
|---|---|---|---|
| 基座层 | 具备大模型与算力资源的巨头 | 提供能理解基本物理规律的 VLA 基座 | 强，但玩家极少 |
| **数据工厂层** | 拥有高效、海量、多样私有数据的机器人公司 | 用场景私域数据在基座上深度微调，形成特定领域（3C 组装、餐饮服务等）的专家模型 | **当前最现实的壁垒所在** |
| 场景集成层 | 系统集成商 | 交付"本体+数据+模型+部署"全栈 | 弱，易被上下游挤压 |

**本体层的价值与毛利分布**（示例 as-of 2026，口径见下方警告，须复核）：

| 环节 | 产业链价值占比 | 毛利率区间 | 结构判断 |
|---|---|---|---|
| 上游核心零部件 | 约 48% | 约 35–55% | 技术壁垒最高、价值量最大 |
| 中游整机本体 | 约 35% | 约 20–35% | **利润天花板被锁死**：下游对整机价格敏感，对上游议价空间有限 |
| 下游应用集成 | 约 17% | 约 15–25% | 劳动与工程密集 |

> ⚠️ **BOM 占比数字在公开材料里口径打架，引用前必须先问分母。**
> 常见两套：执行器系统（电机+减速器+丝杠）占**硬件成本** 65–73%，
> 或占**整机 BOM** 43–52%。两者相差悬殊，因为一个分母是硬件、一个含结构件与其他。
> **不写清分母的 BOM 占比数字一律不可用。**

**规模效应在两端极不对称**（环节选择的关键依据）：出货量从百台级到千台级时，
减速器等零部件的单位成本可降三到四成（模具摊销+批量采购+工艺优化同时起效），
而整机组装的单位成本降幅不到一成——**组装是劳动密集环节，规模效应弱。**

### 1.2 核心驱动变量

**智能层**：

| 变量 | 说明与追踪方式 |
|---|---|
| **VLA 架构收敛度** | as-of 2026 头部 manipulation 模型基本都是 VLA，且多采用**「System 2 慢思 + System 1 快控」双系统**；架构趋同意味着差异化不在这里 |
| 控制频率 | 快控频率是量产门槛：示例——手臂连续控制的商用门槛被普遍对标到 **200Hz 量级**（S2 侧通常在 7–9Hz） |
| **世界模型的角色** | 当前主要用于**生成合成训练数据**而非直接做控制：先用世界模型生成合成轨迹，再训 VLA。示例：有方案用百万小时级视频 + 仅数十小时真机数据训出可 zero-shot 规划的世界模型 |
| **数据飞轮** | 采集 → 精炼 → 训练 → 部署 → **回流**；有量产场景的玩家可以让每一次成功与失败自动标注回流，形成自我造血 |
| 数据采集方案 | 遥操作（领航员—跟随者式开源方案已成双臂操作事实标准）、腕戴式视觉采集（采集与本体解耦、泛化潜力更好）、空间计算设备手部追踪 |
| 泛化能力 | 长尾任务的泛化是当前主攻方向；瓶颈分三类：**数据瓶颈、长时程任务瓶颈（状态与因果链跟踪）、控制瓶颈（预判动作对环境的影响）** |

**本体层与场景层**：

| 变量 | 说明与追踪方式 |
|---|---|
| 头部整机厂量产节奏 | 全赛道节拍器：产线点火、试产、爬坡公告 |
| 出货量（分自用/商用/样机） | 示例 as-of 2026：全球估算 5–8 万台；2024 年约 5,000–6,000 台；2030 年目标百万级 |
| **BOM 成本曲线** | 示例：当前约 3–3.5 万美元/台，目标下探 2 万美元 |
| 关键工艺瓶颈产能 | 丝杠磨削良率与高端磨床依赖、六维力传感器标定产能、空心杯电机绕线 |
| 国产化率（分部件） | 示例：核心零部件仍有约 50–70% 依赖进口（另有口径称减速器不到三成、高端伺服不到四成、控制器约五成）——**口径差异极大，须复核** |
| **场景落地订单** | **工业场景订单最明确**（环境固定、交付需求清晰），是现阶段规模化落地的首选试炼场 |

### 1.3 关键指标与口径

**智能层（这一层的口径最容易被包装，必须逐条核）**：

| 指标 | 口径陷阱 |
|---|---|
| **演示成功率** | **什么任务、什么环境、多少次尝试、允不允许重试、seen 还是 unseen 场景？** 五问缺一，成功率数字无意义。**泛化能力只能用 unseen 场景的数据说话** |
| **数据规模** | **采集时长 / 轨迹条数 / 有效数据量是三个数**；清洗对齐后可用比例常远低于直觉（示例：不到 10%）。另外**真机数据与仿真合成数据不等价**，混在一起报总量是常见包装 |
| 数据多样性 | 比总量更重要：多少个场景、多少种物体、多少个本体平台。**同一场景刷 10 万条的价值远低于 100 个场景各 1 千条** |
| 控制频率 | S2 与 S1 的频率差一个数量级，**报的是哪个必须写明** |
| 模型参数量 | 与实际能力弱相关，不可作为壁垒证据 |
| 专利数量 | 示例：全球具身智能专利年申请量已达万件级、VLA 专利增速极高——**但专利数不等于能力，只能作为热度指标** |

**本体层**：

| 指标 | 口径陷阱 |
|---|---|
| **出货量** | **含不含厂商自用、开发者样机、演示机？** 各家口径不一，差异可达数倍 |
| 单机 BOM | 目标值 vs 当前值常被混用；是否含研发摊销、结构件、软件 |
| 部件成本占比 | **分母是"硬件成本"还是"整机 BOM"必须写明**（见 §1.1 警告） |
| 单机价值量 | **会随降本持续下降**，不能用当期值乘远期出货量做市场空间——最常见的高估手法 |
| 关节数 | 人形约 30–40 轴 vs 工业机器人 6 轴，零部件用量是 5–7 倍；**跨品类单机用量不可套用** |
| **定点 / 送样 / 量产** | **三者完全不同**（见 §0）；公告里的"定点"只表示获得供货资格 |
| 良率 | 丝杠磨削、传感器标定是当前瓶颈；**良率不达标时产能数字没有意义** |

### 1.4 数据源地图

| 你要什么 | 去哪 | 频率 |
|---|---|---|
| 模型能力与技术路线 | 论文与开源仓库（VLA/世界模型/数据集）、技术报告 | 持续 |
| 演示的真实性 | 原始视频与技术说明（查遥操作/加速/剪辑/场景是否 unseen） | 事件驱动 |
| 整机厂量产节奏（全赛道节拍器） | 头部整机厂财报、业绩会、产线公告 | 季度/事件 |
| 出货量与市场预测 | 第三方研究机构（**务必记录口径与含不含自用**） | 季度/年度 |
| 供应链定点与产能 | 上市公司公告、投资者关系记录、扩产项目 | 事件驱动 |
| 场景订单 | 整机厂与集成商的中标/试点公告 | 事件驱动 |
| 一致预期与研报 | `westock-data consensus`、`neodata`（`data_type=doc`） | 随时 |

### 1.5 周期定位

本赛道不是产能周期，是**渗透率曲线最左端 + 预期驱动**：

| 阶段 | 特征 | 观察指标 |
|---|---|---|
| 主题期 | 预期先行，股价对订单消息高度敏感 | 定点公告数、市值/远期空间 |
| **兑现期（当前，as-of 2026）** | 量产节奏、良率、泛化能力成为分水岭 | 实际出货量、供应链收入确认、毛利率、unseen 场景成功率 |
| 业绩驱动期 | 场景批量交付 | **工业与物流场景能否在 1–2 年内实现批量交付——这是估值逻辑从主题投资切到业绩驱动的分界线** |

**定位动作**：先看整机厂产线状态（点火/试产/爬坡/量产）→ 再看供应链**收入端**是否真的开始确认
（不是定点数量）→ 再看智能层的泛化证据是否从 demo 升级到现场 → 最后看毛利率有没有被降本压垮。
**前两者背离时——定点满天飞但收入没动——说明还在主题期。**

## 2. 咨询透镜（决策者 = 企业高管 / 董事会）

### 2.1 典型问题

切哪一层（模型 / 数据 / 零部件 / 整机 / 集成）/ 自建数据工厂还是用开源基座 /
自研关键部件还是外采 / 场景怎么选、先攻哪个 / 产能铺多大、什么节奏 /
怎么进头部整机厂供应链 / 要不要海外建厂。

### 2.2 框架组合

| 问题 | 框架组合 | 各自验证什么 |
|---|---|---|
| 切哪一层 | 三层价值链 + **智能层竞争分级（§1.1）** + 自身能力匹配 | 基座层进不去、集成层守不住，数据工厂层是多数玩家的现实位置 |
| 自建数据 vs 用开源 | **数据飞轮闭环诊断（§2.3）** + 单位数据成本 + 场景独占性 | 没有场景出货就没有回流，数据工厂建不起来 |
| 场景选择 | 场景可控性 × 付费意愿 × 数据回流价值 | 工业场景环境固定、需求明确，且回流数据质量最高 |
| 环节选择（本体） | 价值链利润分布 + **规模效应不对称性（§1.1）** + 工艺能力 | 零部件端毛利高且规模效应强，整机天花板被锁死 |
| 产能决策 | **定点转化漏斗（§2.3）** + 出货情景 × 单机用量 | 按定点铺产能会严重过剩 |
| 自研 vs 外采 | 单位成本曲线 + 规模临界点 + 卡脖子期权价值 | 低于临界规模自研更贵，但关键工艺被卡时要算期权 |

### 2.3 行业特有分析动作

**① 数据飞轮闭环诊断（智能层的招牌动作）**

```
采集 → 精炼(清洗·对齐·标注) → 训练 → 部署 → 回流 → 再采集
```
逐段问四件事：**这一段的成本是多少、有效率是多少、周期多长、是否自动化。**
重点看**回流段是否闭合**——有真实场景出货的玩家，每一次成功与失败都能自动标注回流，
形成自我造血；没有出货的玩家只能靠雇人遥操作采集，成本线性上升、数据多样性有限。
**"有没有闭合的回流"是判断数据壁垒真伪的唯一标准**，比累计采集小时数可靠得多。

**② 泛化能力的证据分级（对抗演示污染）**

把任何能力主张按证据强度排序，**只有第 3 级以上可以进结论**：

| 级 | 证据 | 可信度 |
|---|---|---|
| 0 | 剪辑演示视频、加速播放 | 不可用 |
| 1 | 遥操作演示 | 只证明硬件本体可动 |
| 2 | 实验室自主、seen 场景、允许重试 | 弱 |
| 3 | **unseen 场景自主、公开成功率与尝试次数** | 可用 |
| 4 | **真实产线连续运行、有节拍与稼动率数据** | 强 |

**③ 定点转化漏斗（本体层的招牌动作）**

```
送样 → 定点 → 小批量试产 → 量产爬坡 → 客户放量 → 收入确认
```
逐段标注**转化率**与**时滞（季度）**，再乘出货情景，才得到可用于产能决策的数字。
**直接拿定点数量做测算，等于假设每段转化率都是 100%。**

**④ BOM 降本路径拆解**——把目标降本额分解到三条路径并各给贡献度：
规模化采购、国产替代、工艺与设计优化（如一体化关节模组减少零件数）。
**降本目标必须能被这三条加总覆盖，否则那个 BOM 目标就是拍的。**

**⑤ 单机价值量衰减测算**——做市场空间时**必须让单机价值量随出货量下降**，
而不是用当期单价乘远期台数。两者结果可以差一倍以上。

### 2.4 结论形态样例与高频误判

**合格结论**：
> 不做基座、不做整机：切"工业场景数据工厂 + 丝杠"两点。
> 先用 A 场景的出货把回流闭环跑通（当前回流未闭合，数据成本线性上升），
> 12 个月内把 unseen 场景成功率做到 X%；丝杠产能按「定点 × 转化率 40% × 中性出货」
> 铺到 Y 万根/年，先把磨削良率做到 Z% 再扩二期。

**高频误判**：

| 误判 | 为什么错 |
|---|---|
| 用演示视频论证能力 | 遥操作/加速/剪辑/seen 场景四道水分 |
| 用累计采集时长论证数据壁垒 | 有效数据率可能不到 10%，且回流未必闭合 |
| 把真机数据与仿真数据混报 | 两者价值不等价 |
| 只讲本体不讲智能层 | 壁垒已从算法转到数据，硬件同质化快 |
| 用定点数量推业绩 | 漏斗每段都有转化率与时滞 |
| 用当期单机价值量 × 远期出货 | 降本是设计目标不是意外 |
| 按工业机器人套单机用量 | 关节数差 5 倍以上 |
| 赌整机的规模效应 | 规模效应主要在零部件端 |

## 3. 行研透镜（决策者 = 投资人）

### 3.1 典型问题

出货与泛化能否兑现 / 降本曲线下谁保得住毛利 / 现在是主题期还是兑现期 /
数据壁垒是真是假 / 该用什么锚、给多少倍 / 什么会证伪。

### 3.2 盈利驱动拆解式

```
零部件公司收入 = 整机出货量 × 单机用量(件/台) × 单件均价 × 自身份额
                                    ↑ 稳定           ↑ 持续下行      ↑ 竞争决定
整机公司收入   = 出货台数 × 整机售价（同样持续下行）
智能层收入     = 场景付费（项目制/订阅/按产出）— 当前多数玩家规模极小，估值靠期权
毛利率驱动     = 良率 + 产能利用率 + 上游议价 − 降价传导
```

**关键结构**：出货量与单价方向相反。**收入能不能涨，取决于出货量增速是否跑赢单价降幅；
毛利率能不能守住，取决于自身降本速度是否快于售价降幅。** 两条都要单独测算。

### 3.3 兑现度检验（本赛道替代供需平衡表的东西）

早期赛道没有稳定的供需平衡表，替代动作是**兑现度检验**：

| 检验项 | 问什么 | 不合格的表现 |
|---|---|---|
| 收入确认 | 具身智能相关收入占比多少、环比在不在涨 | 只有定点公告、收入零贡献 |
| 毛利率 | 新业务毛利率是否高于公司平均 | 靠低价换定点，毛利率被拖低 |
| 产能与良率 | 扩产是否伴随良率披露 | 只讲产能不讲良率 |
| 客户结构 | 是否进入头部整机厂的量产序列 | 只有样机与非量产客户 |
| **泛化证据等级** | 能力主张停在证据分级第几级（§2.3） | 只有 demo 与遥操作 |
| **数据回流是否闭合** | 有没有真实场景出货带来的自动回流 | 靠雇人采集，成本线性上升 |

### 3.4 估值锚与可比口径

| 阶段 | 主锚 | 交叉验证 | 常见误用 |
|---|---|---|---|
| 主题期（收入未兑现） | 市值 / 远期市场空间 | 单机价值量、份额假设 | **用当期单价乘远期台数**把空间算大一倍 |
| 兑现初期 | P/S；关注在手订单与收入确认节奏 | 毛利率、客户结构 | 把定点当订单 |
| 业绩驱动期 | P/E | ROIC、产能利用率 | 不换锚 |
| 一级市场智能层标的 | 轮次定价 / ARR 倍数（做法见 `ai-application.md` §3.4） | 场景付费的真实规模 | 用二级市场倍数硬套 |
| 传统工业自动化业务 | P/E | 下游资本开支周期 | 与具身业务混在一个倍数里 |

> 🔴 **本赛道估值第一提醒**：**市场空间测算必须让单价随规模下降。**
> 「单机价值量 × 远期出货量」是最流行也最容易高估的算法——降本是这个行业的前提条件，
> 不是风险，漏掉它等于假设需求打开却不用降价。
> **第二提醒**：多数上市标的当期具身智能收入占比极低，**主业与具身业务必须分部估值**，
> 用整体 P/E 既看不清主业也看不清期权。

### 3.5 命门假设与敏感性

| 命门假设 | 翻转会怎样 | 观察哨 |
|---|---|---|
| 头部整机厂量产节奏 | 全赛道节拍器，推迟即全链条预期下修 | 产线状态、采购招标、交付公告 |
| **泛化能力突破速度** | 决定这门生意是"工业特种设备"还是"通用生产工具"，量级差一个数量级 | unseen 场景成功率、长时程任务表现 |
| 工业/物流场景批量交付 | 估值逻辑从主题切到业绩的分界线 | 试点转批量的订单公告 |
| 降本速度 vs 售价降幅 | 决定毛利率能否守住 | 单件均价、毛利率季度变化 |
| 良率突破（丝杠磨削等） | 决定产能是否真实可用 | 良率披露、扩产落地 |
| 数据壁垒真伪 | 决定智能层的溢价能否维持 | 回流是否闭合、数据多样性 |
| 供应链自主可控 | 核心零部件进口依赖度高，地缘摩擦有中断风险 | 国产化率、二供导入 |

敏感性至少做 **出货量 × 单机价值量** 与 **份额 × 毛利率** 两组双维表。

## 4. 两个透镜都会踩的坑

1. **演示视频当能力证据。** 查遥操作/加速/剪辑/unseen 四件事。
2. **采集时长当数据壁垒。** 有效数据率低，且回流未必闭合。
3. **真机数据与仿真数据混报。**
4. **只分析本体层。** 壁垒已从算法转到数据，硬件同质化快。
5. **定点当收入。** 送样/定点/量产/确认收入是四件事。
6. **单机价值量不衰减。** 降本是前提条件，不是风险。
7. **BOM 占比不写分母。** 硬件成本口径与整机 BOM 口径差异悬殊。
8. **出货量口径混用。** 含不含自用与开发者样机。
9. **按工业机器人套用量。** 关节数差 5 倍以上。
10. **主业与具身业务混估。** 必须分部。
