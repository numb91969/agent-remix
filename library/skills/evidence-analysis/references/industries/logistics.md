## 0. 速查

**一句话结构**：快递是**规模经济与网络密度决定成本、竞争强度决定价格**的生意。
长期矛盾只有一句话：**件量一直在涨，单票收入一直在跌，"送得越多、赚得越少"。**
所以本赛道所有分析最终都落在一个问题上：
**单票收入的降幅和单票成本的降幅，哪个更快？**

**本赛道第一口径陷阱（必须先讲）**：**加盟制公司报表里的"单票收入"和行业平均单票收入不是一回事。**
示例（as-of 2026 前后）：行业平均单票收入约 7.5–7.7 元（含末端派费的全链条口径），
而通达系上市公司披露的单票收入约 2 元左右（**总部口径**，不含加盟网点收取的派费等）。
两者相差三四倍。**跨口径比较、或拿行业单票收入去算通达系收入，是硬错。**
更进一步：**直营制（如顺丰，单票收入十几元）与加盟制（约 2 元）商业模式不同，
单票收入根本不可比**——比的应该是单票毛利与网络效率。

**两个透镜的分界**：

| 你被问的是 | 走哪个透镜 |
|---|---|
| 价格战打不打 / 网络怎么加密 / 加盟还是直营 / 产能投在哪 / 增量业务选哪个 / 格局 | **§2 咨询透镜** |
| 涨价能不能持续 / 单票盈利修复多少 / 谁的兑现路径最清晰 / 该给多少倍 | **§3 行研透镜** |

## 1. 产业地基（两透镜共用）

### 1.1 商业模式与成本结构

```
电商快递（加盟制）：总部赚"中转 + 面单"→ 网点赚"揽收 + 派送"
时效快递（直营制）：全链路自营，赚服务溢价
快运 / 供应链 / 跨境：项目制或合约制，逻辑更接近 B2B 服务
```

**加盟制与直营制是两套完全不同的生意**：

| 维度 | 加盟制（通达系） | 直营制（顺丰等） |
|---|---|---|
| 报表单票收入 | 总部口径，约 2 元量级 | 全链路口径，十几元量级 |
| 成本项 | 中转 + 运输（总部可控）；末端成本在网点 | 全成本自担 |
| 价格传导 | **总部调价未必传导到网点**——网点在"保客户"和"保利润"间可能变通执行 | 统一执行 |
| 弹性 | 单票成本降 1 分 × 百亿件 = 巨额利润，**经营杠杆极高** | 结构与客户分层驱动 |
| 风险 | 网点稳定性、末端服务质量 | 重资产、固定成本刚性 |

> 🔴 **加盟制的经营杠杆是本赛道最重要的结构特征**：单票收入与单票成本都以"分"为单位变动，
> 但乘上百亿级件量后，几分钱的差额就决定了利润的数量级。
> **所以本赛道的分析精度必须做到"分"，笼统说"价格上涨"没有任何信息量。**

### 1.2 核心驱动变量

| 侧 | 变量 | 追踪方式 |
|---|---|---|
| 量 | 件量增速 | 示例 as-of 2026Q1：业务量约 477.3 亿件、同比约 +5.8%，**已从高增长换挡到中低个位数** |
| 量 | **件量"挤水分"** | 反内卷与电商合规趋严下，特价件与刷单件出清，件量增速回落但**结构改善** |
| 价 | 行业平均单票收入 | 示例：2025 全年同比约 −6.3% 至约 7.51 元；2026 前五月回升约 +1.9% 至约 7.67 元 |
| 价 | **产粮区底价政策** | 价格的实际锚：示例——义乌单票价格下限上调 0.1 元至 1.2 元；广东底价整体上调 0.4 元/票至 1.4 元以上 |
| 价 | 燃油附加费 | 油价上行时部分省市加收，是价格修复的助推项 |
| 价 | 产品结构 | **单票收入上升未必是涨价**：大客户占比、退货件/逆向物流占比、并购并表都会抬高单票收入 |
| 成本 | 单票中转 + 单票运输 | 自动化设备、路由优化、装载率、无人车 |
| 监管 | 反内卷治理 | 从座谈会与倡议升级到制度规则与常态化监管 |
| 增量 | 跨境、供应链一体化、即时零售冲击 | 决定第二曲线 |

> ⚠️ **"量增价跌"扭转的判定标准是：收入增速 > 件量增速。**
> 示例 as-of 2026Q1：快递业务收入约 3,690.2 亿元、同比约 +6.8%，高于件量增速约 5.8%——
> 这才是价格修复的直接证据。**只看单票收入涨了几分钱，可能只是结构变化。**

### 1.3 关键指标与口径（本赛道翻车重灾区）

| 指标 | 定义 | 口径陷阱 |
|---|---|---|
| **单票收入** | 收入 / 件量 | **见 §0**：行业口径 vs 总部口径 vs 直营口径，三者差数倍，绝不可混比 |
| **单票成本** | 中转 + 运输（+ 派费） | 加盟制公司披露的通常是**总部可控成本**，不含末端；比较前必须对齐 |
| **单票毛利/净利** | — | **比单票收入有意义得多**——单票收入涨若伴随揽派成本同步上涨，盈利可能没变 |
| 件量 | 业务量 | 是否含"挤水分"前的特价件/刷单件；口径变化会造成同比失真 |
| 市占率 | 件量份额 | 加盟制份额受网点稳定性影响，短期波动不代表结构变化 |
| 装载率 / 中转效率 | 成本端指标 | 是单票成本下降的真实来源，比"降本增效"这四个字有用得多 |
| 并购并表 | — | **会同时抬高单票收入与件量**，须剔除后看内生 |
| 时效达成率 / 破损率 | 服务质量 | 价格战期间容易被牺牲，是竞争回归服务的先行指标 |

> **一个必须掌握的辨析**：某公司单票收入 +9% 但件量 −5%（"量减价升"），
> 另一公司单票收入 +8% 但揽派成本同步上升。
> **两者都不是"涨价成功"**——前者是主动放弃低价件、后者是客户结构变化。
> **判断真实的价格修复，只能看单票毛利。**

### 1.5 周期定位

本赛道是**竞争周期**驱动，且有明确的可观测节奏：

| 阶段 | 特征 | 观察指标 |
|---|---|---|
| 价格战 | 件量高增、单票收入跌、利润塌 | 单票收入同比、网点亏损面 |
| **监管介入 / 反内卷** | 底价托底、特价件出清 | 产粮区底价政策、件量增速回落 |
| **价格修复（示例 as-of 2026）** | 收入增速 > 件量增速 | 单票收入同比转正、单票毛利改善 |
| 份额再集中 | 龙头凭成本优势提份额 | CR 变化、尾部退出 |
| 新一轮 | 增量放缓后重启抢存量 | 返利、补贴、大客户优惠**暗降** |

> 🔴 **本赛道最重要的判断纪律**：**反内卷能抬高价格底线，但不能替企业建立壁垒。**
> 件量增速放慢后，争夺存量客户的动机依然存在，
> 价格战完全可能以**返利、补贴、大客户优惠**的形式重新出现——从"明争"转向"暗斗"。
> 所以判断价格修复是否可持续，不能只看公布的单票收入，
> 要看**单票毛利**与**网点/快递员是否真的分享到改善**。
> 只有当竞争从低价抢件转向时效、退货服务、供应链能力与客户结构，
> 这个行业才算走出"送得越多、赚得越少"的循环。

## 2. 咨询透镜（决策者 = 物流企业高管）

### 2.1 典型问题

价格战跟不跟、跟到什么程度 / 网络在哪里加密 / 加盟还是直营、怎么管网点 /
自动化投在哪、回收期多久 / 增量业务选哪个（跨境/快运/供应链）/ 大客户要不要接。

### 2.2 框架组合

| 问题 | 框架组合 | 各自验证什么 |
|---|---|---|
| 价格决策 | **单票经济模型（§2.3）** + 竞争对手成本位置 + 规模弹性 | 降价换来的量能否把单票成本压得更低 |
| 网络布局 | **网络密度—成本曲线（§2.3）** + 流量流向分析 | 哪条线路/哪个区域加密的边际收益最大 |
| 加盟 vs 直营 | 控制力 × 资本强度 × 服务一致性 | 两套模式的成本结构与风险完全不同 |
| 自动化投资 | 单票成本节约 × 件量 ÷ 投资额 = 回收期 | 分是很小的单位，但乘件量后回收期可能很短 |
| 增量业务选择 | 市场吸引力 × 网络复用度 | 能复用现有网络的增量业务边际成本最低 |
| 大客户取舍 | 单票毛利 + 峰值负荷成本 | 大客户单价低、且可能拉高峰值产能需求 |

### 2.3 行业特有分析动作

**① 单票经济模型（本赛道的招牌动作，精度必须到分）**

```
单票收入（面单 + 中转 + 派费或全链路收入）
− 单票中转成本（分拣自动化率、场地效率）
− 单票运输成本（装载率、路由优化、干线车型）
− 单票派送成本（末端密度、快递员效率）
= 单票毛利  →  × 件量 = 毛利总额
```
**三条纪律**：单位精确到分；口径必须写明是总部口径还是全链路口径；
**必须给出"单票成本 vs 件量"的弹性曲线**——回答"件量再涨 10%，单票成本能降几分"，
这是价格决策的唯一依据。

**② 网络密度—成本曲线**

快递的成本优势来自**密度**：同一条线路上的件量越多，装载率越高、单票运输成本越低；
同一个区域的派件越密，快递员单位时间派件数越多、单票派送成本越低。
分析动作：按线路/区域画「件量密度 vs 单票成本」散点 →
识别**未达规模临界点**的线路（这些是加密的优先目标）和**已过临界点**的线路（这些是利润来源）。
**这也解释了为什么份额领先者的成本优势会自我强化——密度是正反馈。**

**③ 价格传导校验（加盟制专有）**

总部宣布调价后，必须验证三件事：网点是否实际执行（还是用返利变通）、
网点的盈亏状况是否改善、快递员派费是否同步调整。
**示例（as-of 2025–2026）：某产粮区网点测算保本单价约 1.6 元，
而当地长期价格维持在 1 元左右——在这种状态下宣布的调价，
如果网点仍在亏损，价格就不可能真正稳住。**
**只看总部公告不看网点盈亏，是本赛道最容易被表象骗到的地方。**

**④ 增量业务的网络复用度评估**——跨境、快运、供应链、退货逆向物流，
按"能复用多少现有网络资产"排序。复用度高的增量业务边际成本低、见效快；
复用度低的等于重新建一张网，要按新业务的资本开支来评估。

### 2.4 结论形态样例与高频误判

**合格结论**：
> 不在全域跟价，只在 A 类高密度线路（已过规模临界点、单票成本低于对手 X 分）跟到 Y 元；
> B 类未达临界点的线路停止降价、转为加密件量。
> 自动化投 Z 亿元，测算单票中转成本降 M 分，按当前件量回收期约 N 个月。
> 若网点亏损面 6 个月内未收窄，暂停跟价。

**高频误判**：

| 误判 | 为什么错 |
|---|---|
| 混用行业/总部/直营单票收入 | 差数倍 |
| 用单票收入判断盈利改善 | 要看单票毛利 |
| 把结构变化当涨价 | 大客户、退货件、并表都会抬高单票收入 |
| 只看总部调价不看网点执行 | 加盟制的价格传导会失真 |
| 忽略并购并表 | 会同时抬高件量与单票收入 |
| 用总体成本做线路决策 | 密度差异决定线路间成本天差地别 |
| 认为反内卷等于建立了壁垒 | 价格战会以返利暗降的形式回来 |

## 3. 行研透镜（决策者 = 投资人）

### 3.1 典型问题

涨价能不能持续 / 单票盈利能修复到什么水平 / 谁的兑现路径最清晰 /
份额会怎么变 / 该给多少倍 / 什么会证伪。

### 3.2 盈利驱动拆解式

```
利润 = 件量 × (单票收入 − 单票成本)
       ↑ 行业增速 × 份额        ↑ 密度 + 自动化 + 装载率
                    ↑ 竞争强度 + 产品结构 + 监管底价
```

**经营杠杆极高**：件量以百亿计，单票毛利每变动 1 分，利润就变动数亿元。
**因此预测的精度要求远高于一般行业——单票毛利估错 2 分，利润就错 20%。**

**必查的三个质量问题**：
1. 单票收入上升里，**真实提价**贡献多少、**结构变化（大客户/退货件/并表）**贡献多少？
2. 单票成本下降里，**规模效应**贡献多少、**一次性因素（油价/补贴）**贡献多少？
3. 单票毛利有没有真的改善？**这是唯一不会骗人的指标。**

### 3.3 价格与成本的双轨推演（替代供需平衡表）

```
价格轨：产粮区底价政策 + 监管强度 + 件量增速（增速越低越有抢量动机）
        → 单票收入方向
成本轨：件量增长带来的密度提升 + 自动化投放节奏 + 油价
        → 单票成本方向
两轨相减 → 单票毛利 → × 件量 = 利润
```

**做这个推演时必须区分：兑现路径清晰的公司和不清晰的公司。**
纯电商快递公司（单票价格止跌 + 单票成本下降）**较容易直接反映到利润和现金流**；
而业务涵盖时效、快运、国际、供应链的综合物流公司，反内卷只是众多业绩因素之一，
**传导链条更长、更不确定**。这个差异往往解释了同一时期不同标的股价的分化。

### 3.4 估值锚与可比口径

| 场景 | 主锚 | 说明 |
|---|---|---|
| 电商快递（加盟制） | **P/E**，交叉验证单票净利 × 件量 | 周期性来自竞争而非产能；底部盈利被压缩时 P/E 会失真，可辅以 EV/件量 |
| 时效快递（直营制） | P/E、EV/EBITDA | 重资产，折旧影响大，EBITDA 口径更可比 |
| 快运 / 供应链 | EV/EBITDA、P/S | 盈利波动大，早期看收入与网络规模 |
| 跨境物流 | P/E，但注意周期性 | 运价波动大，高点 P/E 低是陷阱 |
| 横向比较 | **单票净利 + 单票成本** | 比市值口径更能反映竞争力差异 |

> 🔴 **本赛道估值第一提醒**：**不要用同一个锚横比加盟制与直营制。**
> 两者的单票收入差数倍、成本结构完全不同、资本强度不同。
> 有意义的横比只有两个维度：**单票毛利/净利**（盈利能力）和**单票成本**（效率）。
> 另外，**"反内卷"带来的估值修复必须由单票毛利验证**——
> 价格底线抬高本身不构成壁垒，如果利润没有兑现，估值修复就是抢跑。

### 3.5 命门假设与敏感性

| 命门假设 | 翻转会怎样 | 观察哨 |
|---|---|---|
| 监管与产粮区底价的持续性 | 决定价格底线是否守得住 | 底价政策、监管会议、执行力度 |
| **价格战是否以返利形式重来** | 最大的隐性风险 | 单票毛利（而非单票收入）、网点返利 |
| 件量增速 | 增速越低，抢存量的动机越强 | 邮政局月度数据 |
| 单票成本下降空间 | 决定盈利修复的上限 | 自动化投放、装载率、密度 |
| 网点与快递员的分配 | 末端不稳会反噬服务与份额 | 网点亏损面、派费水平、离职率 |
| 即时零售与新业态的分流 | 长期需求结构变化 | 即时零售订单量、履约模式变化 |

敏感性至少做 **单票收入 × 单票成本**（直接给出单票毛利矩阵）与 **件量 × 单票毛利** 两组。

## 4. 两个透镜都会踩的坑

1. **混用单票收入口径。** 行业 / 总部 / 直营，差数倍。
2. **用单票收入判断盈利。** 要用单票毛利。
3. **把结构变化当涨价。** 大客户、退货件、并购并表都会抬高单票收入。
4. **加盟制与直营制横比单票收入。** 商业模式不同。
5. **只看总部调价不看网点盈亏。** 价格传导会失真。
6. **精度不到"分"。** 经营杠杆极高，粗略估算等于没算。
7. **忽略件量口径变化。** "挤水分"会造成同比失真。
8. **把反内卷当壁垒。** 价格战可能以返利形式回来。
9. **用总体成本做线路决策。** 密度决定线路间成本差异巨大。
