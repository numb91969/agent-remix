## 0. 速查

**一句话结构**：AI 原生应用是**「用免费或低摩擦获客抢占工作流入口，再决定向谁收钱」**的生意。
它与传统 SaaS 有两处根本不同，**这两处决定了所有分析动作**：

1. **推理成本是可变成本。** 传统 SaaS 的边际成本近零，AI 应用每一次调用都在烧钱。
   毛利率不再是结构性的 80%+，而是**定价与 token 成本赛跑的结果**——
   检索问答类可以做到 90% 毛利，重推理/长上下文类可能只有 40–60%。**先问毛利率，再谈估值。**
2. **付钱的人可能不是用的人。** 用户免费、第三方买单（广告主、药企、雇主）是一条真实且高效的路径，
   它绕开了企业软件动辄十几个月的销售周期。**这条路径的所有指标都和订阅制不一样。**

**本赛道第一口径陷阱（必须先讲）**：**ARR 不是审计过的收入。**
一级市场的 ARR 通常是**把某个月（甚至某周）的收入 × 12** 得到的年化值，
且各家对"含不含一次性项目、含不含已签未交付、含不含试用期"处理不同。
增速极快时，年化值会**系统性高于**同期实际确认收入。
**看到"ARR 达到 X 亿"的第一个动作是问：哪个月年化的、含什么、谁说的。**
公开材料里同一家公司同一年份出现相差 2–3 倍的 ARR 是常态。

**两个透镜的分界**：

| 你被问的是 | 走哪个透镜 |
|---|---|
| 该不该做、做哪个场景 / 免费还是收费 / 向谁收钱 / 怎么绕开长销售周期 / 会不会被基座吞掉 | **§2 咨询透镜** |
| 这个模式能不能成 / 单位经济算不算得过来 / 估值贵不贵 / 什么会证伪 | **§3 行研透镜** |

## 1. 产业地基（两透镜共用）

### 1.1 四种变现结构（先归类，再分析）

**AI 原生应用的分析必须先归到变现结构，因为四种的指标体系完全不同：**

| 结构 | 谁付钱 | 核心指标 | 代表形态 |
|---|---|---|---|
| **① 免费 + 第三方买单** | 广告主 / 药企 / 品牌 | 渗透率、使用频次、**CPM 与 ARPU**、变现强度 | 面向专业人群的免费工具，靠精准广告变现 |
| ② 个人订阅（PLG） | 用户自己 | MRR、留存队列、转付费率、CAC 回收期 | 面向个人的效率工具 |
| ③ 企业订阅 / 席位 | 企业 | ARR、NRR/GRR、席位数、销售周期 | 面向组织的专业工具（做法见 `enterprise-software.md`） |
| ④ 按产出计费 | 企业 | 单次任务价格、任务量、交付成功率 | Agent 类，替代人力工时 |

> **多数成功的 AI 应用会跨结构迁移**：先用 ① 或 ② 做到用户渗透，
> 再向 ③ 走高（如打通企业系统后收席位费）。
> **迁移期是分析最容易出错的时候**——两套指标混着报，
> 增长看起来很好但其实是口径切换。**必须要求分结构披露。**

### 1.2 核心驱动变量

| 侧 | 变量 | 说明与追踪方式 |
|---|---|---|
| 获客 | **摩擦度** | AI 应用最大的结构性优势是绕开长销售周期。示例（as-of 2026）：某医疗 AI 工具靠"对医生免费 + 不触碰病历数据"两点，绕开了医疗行业约 18 个月的销售周期，自下而上拿到 40%+ 的美国医生渗透率 |
| 获客 | 渗透率与频次 | 专业人群的渗透率是变现的基础；示例：该工具月度临床问诊调用量达千万次量级 |
| 变现 | **单位注意力的价格** | 专业场景的广告溢价可以极高：示例 CPM 约 70–1,000+ 美元，而通用社交平台约 5–15 美元，对应 ARPU 约 124 美元/年 |
| 变现 | **变现强度的自我克制** | 关键的战略变量：有公司明确表示若开满广告位收入可达当前的数倍，但为保用户体验主动不做——**分析时不能默认"空间=收入"** |
| 成本 | **推理成本 / token 成本** | 决定毛利率；示例：检索问答型可做到约 90% 毛利率 |
| 壁垒 | 独家内容与数据 | 与权威内容源的独家合作、私有数据回流 |
| 壁垒 | 工作流嵌入深度 | 与行业系统（如 EHR、CRM、IDE）打通后切换成本骤升 |
| 风险 | **被基座模型吞掉** | 上游通用模型能力外溢，直接覆盖应用层功能 |
| 监管 | **监管定位的选择** | 是本赛道的重要战略动作：示例——把产品定位为"信息检索工具"而非"诊断设备"，从而不需要走医疗器械审批路径 |

### 1.3 关键指标与口径（本赛道翻车重灾区）

| 指标 | 口径陷阱 |
|---|---|
| **ARR** | **见 §0**：年化口径、含什么、谁说的。一级市场无审计，媒体转述常层层放大 |
| 收入增速 | 极高基数效应；**"同比 +1,800%" 这类数字要看绝对值基数**，从 500 万到 1 亿和从 5 亿到 10 亿完全不是一回事 |
| **用户数** | 注册 / 验证 / 月活 / 日活 / 付费，**五个口径**；专业工具还要区分"注册"与"通过资质验证" |
| **渗透率** | **分母是什么？** 全体从业者、目标细分人群、还是活跃执业者？分母换一个，渗透率能差一倍 |
| ARPU | 分子是广告收入还是总收入、分母是全体用户还是活跃用户 |
| CPM | 与展示位置、场景强相关；**不同场景的 CPM 不可平均** |
| **毛利率** | **含不含推理成本？** 部分公司把推理成本计入研发费用而非营业成本，毛利率会被显著美化 |
| 留存 | 免费工具的留存与付费留存是两件事；**免费产品的高留存不能证明付费意愿** |
| 使用量 | 调用次数 / 会话数 / 任务数，口径不一；且**调用量增长可能来自单任务调用变多，不是用户变多** |
| 估值 | 一级市场估值是**轮次定价**，反映的是少数股份的边际成交价，**不等于整体公允价值**，且常含优先清算权等条款 |

### 1.4 数据源地图

| 你要什么 | 去哪 | 注意 |
|---|---|---|
| 收入、用户、估值 | 一级市场数据库、公司官方披露、创始人访谈 | **必须标注来源主体**，公司自述与第三方测算要分开标 |
| 融资与轮次定价 | 融资公告、投资机构披露 | 注意条款结构，估值不等于公允价值 |
| 产品能力与迭代 | 产品发布、技术博客、用户社区 | 社区反馈是留存的先行指标 |
| 竞争与替代 | 上游基座模型的能力发布 | **判断"会不会被吞掉"的主要窗口** |
| 监管与合规 | 目标行业主管部门原文 | 中美差异极大 |
| 上市可比公司 | `westock-data consensus`、`neodata`（`data_type=doc`） | 用于给一级标的找倍数锚 |

> ⚠️ **本赛道数据质量普遍低于二级市场行业。**
> 交付时必须把「公司自述 / 第三方测算 / 媒体转述」三类来源分开标注证据等级，
> 不能混成一句 `[F]`。多数情况下公司自述的经营数字只能标 `[A]` 并注明出处。

### 1.5 中美差异（跨地域分析前必读）

| 维度 | 美国 | 中国 |
|---|---|---|
| 变现路径 | 专业广告市场成熟，第三方买单可直接跑通 | 医疗、金融等行业的广告合规约束更严，纯广告模式落地难度高 |
| 常见组合 | 免费 + 广告 → 企业订阅 | 基础功能免费 + 高级订阅 + 合规数字化营销 + 数据/研究服务的**多元组合** |
| 支付方 | 商业保险与雇主主导 | 医保主导，价格受政策约束（相关框架见 `medtech.md`） |
| 监管 | 按产品定位区分审批路径 | 数据出境、算法备案、行业专项合规 |
| 获客 | 自下而上 PLG 可绕开采购 | 机构采购权重更高，自下而上更难穿透 |

**结论：变现结构不可跨地域照搬。** 看到"中国版某某"这类类比时，
第一件事是检查**变现路径是否在本地成立**，而不是比较产品形态。

### 1.6 周期定位

| 阶段 | 特征 | 观察指标 |
|---|---|---|
| 能力验证期 | 用户增长快，无收入 | 留存、频次 |
| **渗透期（多数标的当前所处）** | 渗透率快速抬升，变现刚起步 | 渗透率、首个变现结构的跑通 |
| **变现期** | 从①②向③④迁移，ARPU 抬升 | 分结构收入披露、单客价值变化 |
| 稳态 | 增速回落，看留存与提价 | NRR、毛利率、竞争格局 |

**定位动作**：先看渗透率是否还在快速抬升 → 再看变现结构有没有跑通第一条 →
再看是否已开始向更高单客价值的结构迁移。
**渗透率见顶而变现结构未跑通，是这类公司最危险的位置。**

## 2. 咨询透镜（决策者 = 创始团队 / 战略投资方 / 想做 AI 应用的企业）

### 2.1 典型问题

该不该做、做哪个场景 / 免费还是收费、向谁收钱 / 怎么绕开长销售周期 /
壁垒建在哪 / 会不会被基座模型吞掉 / 什么时候从免费转向收费。

### 2.2 框架组合

| 问题 | 框架组合 | 各自验证什么 |
|---|---|---|
| 场景选择 | **注意力价值 × 决策金额矩阵（§2.3）** + 工作流可嵌入性 | 场景的注意力值不值钱、能不能嵌进工作流 |
| 变现结构选择 | 四种结构对照（§1.1）+ 本地合规可行性 | 谁最愿意为这群用户的注意力/产出付钱 |
| 获客路径 | **摩擦拆解（§2.3）** | 把阻碍采用的每一道摩擦逐条拆掉，这是 AI 应用最大的结构性机会 |
| 壁垒建设 | **抗基座侵蚀检验（§2.3）** | 哪些能力是通用模型变强后依然存在的 |
| 定价与毛利 | 单位调用成本 × 使用强度 vs 定价 | 毛利率是不是结构性的 |
| 从免费转收费 | 留存队列 + 付费意愿测试 | 免费的高留存不等于付费意愿 |

### 2.3 行业特有分析动作

**① 摩擦拆解（本赛道最有价值的动作）**

AI 应用最大的结构性机会不是"模型更强"，而是**把采用门槛一条条拆掉**。
把目标场景的采用链路铺开，逐条标注摩擦与拆解手段：

```
付费审批 → 免费
采购流程 → 绕开采购，直接触达个人使用者
合规审查 → 调整产品边界（如不触碰敏感数据、不做需审批的功能定位）
学习成本 → 用自然语言交互替代培训
集成工期 → 先做独立入口，跑通后再谈系统集成
```
**示例（as-of 2026）**：某医疗 AI 靠"对医生免费""不作为诊断设备上市因而不需器械审批"
"绕过医院采购直接向医生个人开放，邮箱注册即用"三条，
把行业惯常的十几个月决策周期压缩到几分钟。
**每拆掉一道摩擦，可触达人群就上一个台阶——这是这类公司增速异常高的真正原因，
不是模型比别人强。**

**② 注意力价值 × 决策金额矩阵（变现结构选择）**

第三方买单模式能不能成，取决于两件事：
**这群用户的注意力值不值钱**（他们的决策是否直接牵动第三方的收入），
以及**是否存在成规模的既有预算池**（新模式通常是从旧预算里抢，不是凭空创造）。
两者都满足时，免费 + 第三方买单的 ARPU 可以远高于订阅制。
示例：临床决策场景的用户注意力直接关联处方行为，而对应的医疗营销预算池规模以百亿美元计，
所以专业广告 CPM 能达到通用平台的几十倍。
**反过来，用户注意力不影响任何第三方收入的场景，就只能老实向用户收钱。**

**③ 抗基座侵蚀检验（判断壁垒真伪）**

对每一项声称的壁垒问一句：**如果通用基座模型下一代能力翻倍，这项壁垒还在吗？**

| 壁垒类型 | 抗侵蚀性 | 说明 |
|---|---|---|
| 模型微调能力 | **弱** | 基座变强会直接抹平 |
| 产品交互与体验 | 弱—中 | 可被复制 |
| **独家内容/数据授权** | **强** | 基座拿不到就是拿不到 |
| **私有数据回流闭环** | **强** | 需要真实使用量才能产生 |
| **工作流与系统集成深度** | **强** | 切换成本来自这里 |
| 合规资质与信任背书 | 强 | 尤其在受监管行业 |
| 用户规模本身 | 中 | 除非形成双边网络效应 |

**只有"强"那几项能进结论。** 把壁垒写成"我们模型效果更好"，等于没有壁垒。

**④ 单位经济与推理成本压力测试**——按使用强度做三档情景
（轻度/中度/重度用户），算各档的单用户推理成本与变现收入。
**重点检验重度用户是否亏钱**——AI 应用与传统 SaaS 的关键区别就在于
**用得越多亏得越多的可能性真实存在**，而这在订阅制定价下会被平均值掩盖。

### 2.4 结论形态样例与高频误判

**合格结论**：
> 做 A 场景不做 B：A 的用户决策直接牵动第三方预算池（规模 X 亿）且工作流可嵌入。
> 首年走"免费 + 第三方买单"绕开采购（拆掉付费审批与合规两道摩擦），
> 目标渗透率 M%；壁垒押在独家内容授权与回流数据，不押模型效果。
> 第 18 个月起打通 C 系统转企业合约，把 ARPU 抬 N 倍。
> 若重度用户单位推理成本超过 Y，先改定价再扩量。

**高频误判**：

| 误判 | 为什么错 |
|---|---|
| 把 ARR 当审计收入 | 年化口径，且无审计 |
| 用增速百分比论证成长性 | 极低基数下的百分比没有信息量 |
| 假设"广告位空间 = 收入" | 公司可能主动克制以保体验 |
| 用传统 SaaS 的毛利率假设 | 推理成本是可变成本 |
| 用免费产品的留存推付费意愿 | 两件事 |
| 把"模型效果好"当壁垒 | 基座变强会抹平 |
| 跨地域照搬变现路径 | 合规与支付方结构不同 |
| 渗透率不写分母 | 分母换一个差一倍 |

## 3. 行研透镜（决策者 = 投资人，含一级市场）

### 3.1 典型问题

这个模式能不能成 / 单位经济算不算得过来 / 增长质量如何 /
估值贵不贵、该用什么锚 / 什么会证伪。

### 3.2 盈利驱动拆解式

```
① 免费 + 第三方买单：收入 = 用户数 × 渗透率 × 使用频次 × 变现强度 × 单位价格(CPM)
                              ↑ 已高时增长要靠后三项
② / ③ 订阅：       收入 = 付费用户/席位 × 客单价 × (1 − 流失率)
④ 按产出：         收入 = 任务量 × 单任务价格 × 交付成功率

毛利率 = 1 − (单位推理成本 × 使用强度) / 单位收入
净利率 = 毛利率 − 获客成本率 − 研发（含模型训练与算力）
```

**必查的三个质量问题**：
1. 增长来自**用户数**还是**变现强度**？前者有天花板（渗透率上限），后者以体验为代价。
2. 毛利率是否随使用强度下降？**下降说明单位经济没跑通，规模化会放大亏损。**
3. 收入结构是否在切换（从广告转订阅）？切换期的同比数字**不可比**。

### 3.3 模式可行性检验（替代供需平衡表）

一级标的没有供需平衡表也没有可靠财报，对应位置的硬功夫是**模式可行性检验**：

| 检验项 | 问什么 | 不合格的表现 |
|---|---|---|
| 渗透率天花板 | 目标人群还剩多少空间 | 渗透率已高但收入靠渗透率增长 |
| 变现强度余量 | 当前开放了多少变现位 | 已开满却仍按高增长外推 |
| 单位经济 | 重度用户是否亏钱 | 只给平均值不给分档 |
| 留存质量 | 免费与付费分别留存多少 | 只报免费留存 |
| 壁垒抗侵蚀 | §2.3 检验通过几项"强" | 只有模型效果 |
| 收入可验证性 | 数字来自公司自述还是第三方 | 全部自述且口径不一 |

### 3.4 估值锚与可比口径（一级市场专用，与其他行业文件不同）

**本赛道多数标的未上市，P/E、P/B、EV/EBITDA 全部失效。** 可用的锚只有：

| 锚 | 怎么用 | 陷阱 |
|---|---|---|
| **ARR 倍数（EV/ARR）** | 主锚。与增速、毛利率、留存三者挂钩：高增速 + 高毛利 + 高留存才配高倍数 | **ARR 口径不统一（§0）**，倍数分母本身就不可比 |
| **轮次定价** | 最近一轮投后估值 | 反映的是**少数股份的边际成交价**，且常含优先清算权等条款，**不等于整体公允价值**；热度高时会显著超前基本面 |
| 单用户价值（市值/用户数） | 交叉验证 | 用户口径必须统一（注册？活跃？付费？） |
| 对标上市可比公司 | 用二级同类业务的倍数做锚，再给流动性折价 | 一级与二级的增速与阶段差异大，折价幅度是主观项，须写明 |
| 潜在市场空间反推 | 市值 ÷ 可触达预算池 | **预算池是抢存量还是创增量必须说清** |

> 🔴 **本赛道估值第一提醒**：**估值上涨本身不是基本面证据。**
> 一级市场标的在短期内估值翻数倍的情形很常见，
> 它反映的是**融资市场的供需与稀缺性**，与经营改善不是一回事。
> **写"估值半年涨了 X 倍所以模式被验证了"，是把结果当原因。**
> 正确的做法是：先用 §3.3 的可行性检验判断模式，再看估值是否与之匹配。
> **第二提醒**：由于 ARR 口径混乱，**给倍数前必须先把 ARR 口径统一到同一定义**，
> 否则倍数比较毫无意义。

### 3.5 命门假设与敏感性

| 命门假设 | 翻转会怎样 | 观察哨 |
|---|---|---|
| **渗透率还有多少空间** | 渗透见顶后增长只能靠变现强度，而后者有体验上限 | 渗透率、新增注册速度 |
| 变现强度的可提升幅度 | 决定收入天花板 | 已开放变现位比例、ARPU 趋势 |
| 单位推理成本走势 | 决定毛利率结构 | 模型成本曲线、使用强度变化 |
| **被基座模型吞掉** | 最大的单一风险 | 上游模型的能力发布与产品边界扩张 |
| 结构迁移能否成功 | 从广告转企业订阅能否把 ARPU 抬起来 | 分结构收入披露、企业合约数 |
| 监管定位的稳定性 | 定位若被重新认定，合规成本骤升 | 主管部门口径变化 |
| 独家内容/数据授权的续约 | 强壁垒的有效期 | 合作协议期限与排他条款 |

敏感性至少做 **渗透率 × 变现强度**（收入天花板）与 **使用强度 × 单位推理成本**（毛利率）两组。

## 4. 两个透镜都会踩的坑

1. **ARR 当审计收入。** 年化口径、无审计、口径不一。
2. **用增速百分比论证成长性。** 低基数下的百分比无信息量。
3. **估值上涨当基本面验证。** 把结果当原因。
4. **用传统 SaaS 毛利率假设。** 推理成本是可变成本。
5. **只给平均单位经济。** 重度用户可能亏钱。
6. **渗透率不写分母。**
7. **用户数口径混用。** 注册/验证/月活/日活/付费是五个数。
8. **假设变现空间等于收入。** 公司可能主动克制。
9. **把"模型效果好"当壁垒。** 基座变强会抹平。
10. **跨地域照搬变现路径。** 合规与支付方结构不同。
11. **收入结构切换期做同比。** 口径已变，不可比。
12. **来源不分级。** 公司自述、第三方测算、媒体转述必须分开标。
