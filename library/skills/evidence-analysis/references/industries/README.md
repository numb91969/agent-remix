# 行业分析框架库（双透镜）· 路由

通用框架（五力/PESTEL/BCG/DCF）不分行业，任何赛道产出都长一个样。
本目录给热门赛道各沉淀一份**行业专属**框架：**产业地基 + 咨询透镜 + 行研透镜**。

---

## 🔴 数据时效硬约束（用之前先读这一段）

**这些文件是分析框架，不是数据快照。**

- 文中所有数字仅作**口径示例**——说明这个指标长什么样、单位是什么、量级在哪，
  一律带 `as-of YYYY-MM` 标注。
- **使用时必须重新取数**：任何要写进交付物的规模/份额/增速/产能/估值倍数，
  动笔前必须实际调用 `neodata-financial-search`（`data_type=doc` 召回研报）/
  `westock-data consensus`（一致预期）或联网检索，取当期值。
- **直接引用本目录里的示例数字进交付物 = 交付事故**，等同于凭记忆编数字。
- 每份文件标有 `最后校订：YYYY-MM`。**超过 12 个月未校订时，框架仍可用，但数字口径需整体复核。**

可以放心复用的是：价值链结构、指标定义与口径陷阱、框架组合、分析动作、
估值方法论、命门假设清单。**不能复用的是：任何具体数字。**

---

## 🔴 两条使用前置（决定这套框架用不用得上）

### ① 地域口径：本目录默认中国市场

除 `ai-application.md`（已含中美对照）外，**所有文件的政策、支付方、监管、竞争口径
都是以中国市场写的**——集采、LPR 与存款自律上限、产粮区底价、反内卷强标、
新能源入市的电价机制，这些在别的市场根本不存在。

**分析海外标的时，可迁移的是价值链结构、分析动作与估值方法论；
必须重建的是政策与支付方那一整块**，包括监管主体、定价机制、准入门槛、补贴与税收。
**拿中国集采框架去分析美国医疗公司、拿中国信贷政策去分析美国银行，会错得很离谱。**
交付前在方法说明处写明：哪些部分是原框架、哪些是为该地域重建的。

### ② 粒度：本目录是行业级，不直接回答单公司问题

被问到某一家具体公司（尤其是**未上市**公司）时，行业文件的可用部分是有限的：

| 章节 | 单公司问题下能不能用 |
|---|---|
| §1.3 关键指标与口径 | ✅ **最有用**，口径陷阱直接适用 |
| §2.3 行业特有分析动作 | ✅ 直接适用 |
| §3.5 命门假设清单 | ✅ 直接适用，作为尽调提纲 |
| §1.1 价值链 / §1.2 驱动变量 | ⚠️ 只作背景，用来定位这家公司在链条的哪一环 |
| §3.4 估值锚 | ⚠️ **上市标的适用；未上市标的多数失效** |

**未上市标的的估值锚另有一套**：P/E、P/B、EV/EBITDA 都用不了，
可用的是 ARR 倍数、轮次定价、单用户价值、对标上市可比再给流动性折价——
**完整做法见 `ai-application.md` §3.4，那一节对所有一级市场标的通用，不限于 AI 应用。**
同时注意一级市场的数据质量：多数经营数字来自公司自述且无审计，
**必须把「公司自述 / 第三方测算 / 媒体转述」分开标证据等级，不能混成一句 `[F]`。**

# 三级回退路由

**遇到一个行业，按 L1 → L2 → L3 的顺序找框架，命中即停。**

```
L1  精确命中：行业在下面的路由表里            → 直接用那份文件
L2  相似原型借用：不在表里，但能归到某个生意原型 → 借同原型范本的「方法」，口径自己重建
L3  通用框架：原型也归不了                    → 回退 ../framework-library.md，但照搬本目录骨架
```

**永远不要跳过 L2 直接掉到 L3。** 通用框架产出的东西所有行业长得都一样，
而同原型的行业文件里，周期定位方法、分析动作、估值锚逻辑往往可以直接迁移——
**这三样才是行业文件真正值钱的部分。**

**原型不是按行业名分的，是按「这门生意靠什么赚钱、什么决定它的利润」分的。**
所以看起来八竿子打不着的两个行业，可能共用同一套分析方法。

| 原型 | 利润由什么决定 | 可直接借用的方法 | 估值锚特征 | 范本文件 |
|---|---|---|---|---|
| **A 强周期制造** | 供需缺口决定价格，产能是主变量 | 供需平衡表、现金成本曲线、三层周期定位、出清五步判定 | 底部 P/B、**顶部 P/E 骗人**，换锚时点最关键 | `semiconductor.md`、`renewables.md` |
| **B 规模制造 + 经营杠杆** | 单位经济学 × 销量，固定成本摊薄 | 单位经济学拆解、盈亏平衡销量、产能利用率、量价反向赛跑 | P/S → P/E 的切换时点 | `nev.md`、`embodied-ai.md`（本体层） |
| **C 瓶颈租金 / 数据壁垒** | 利润归最紧的那一环，且瓶颈会迁移；数据是新的瓶颈形态 | 瓶颈识别与迁移追踪、利润池转移、capex 持续性检验、数据飞轮闭环诊断 | 折旧与资本开支假设是命门 | `ai-compute.md`、`embodied-ai.md`（智能层） |

### 怎么判断原型：问四个问题

| 问 | 答案指向 |
|---|---|
| **1. 价格由谁定？** | 市场供需 → A；自己按成本加成 → B；第三方支付方（医保/政府）→ E；平台自定且靠补贴博弈 → F；利率环境与牌照 → I；**用的人不付钱、第三方买单 → J** |
| **2. 成本随规模怎么变？** | 靠产能利用率 → A/B；靠网络密度 → F；边际成本近零 → G；**随使用量线性上升（推理成本）→ J**；不随规模变（重研发）→ D |
| **3. 收入是一次性还是持续的？** | 一次性交易 → A/B/H；持续订阅/续费 → G；存量资产生息 → I；广告/合约且随渗透率走 → J |
| **4. 最大的不确定性是什么？** | 周期与产能 → A；研发成败 → D；政策 → E；竞争补贴 → F；瓶颈迁移或数据壁垒真伪 → C；复购能否建立 → H；**被上游能力吞掉 → J** |

**四问指向同一个原型 → 放心借用。指向两个原型 → 按「决定利润的第一变量」选主原型，
最多借两个，且必须说明各借了什么。四问答案发散 → 说明这是个新形态，走 L3。**

### L2 借用纪律（三条，必须遵守）

**① 可借「方法」，不可借「口径」。**
周期定位方法、§2.3 的分析动作、§3 的估值锚逻辑与命门假设结构——这些可以直接迁移。
但 **§1.3 的关键指标与口径必须为目标行业重建**：口径陷阱是每个行业独有的，
硬套过来会制造出比没有框架更危险的错误（因为它看起来很专业）。

**② 必须在输出里声明借用。**
在方法说明处写明：本次分析借用了 `X.md` 的哪些方法、因为两者同属 Y 原型、
以及哪些部分是为本行业重建的。**不声明就等于假装有专属框架，是诚信问题。**

**③ 借完要补口径陷阱。**
交付前必须补上该行业特有的、外行会踩而内行都知道的那 2–3 条口径陷阱
（参考各文件 §0 的「第一口径陷阱」写法）。补不出来就说明对这个行业的理解还不够，
应当先补研究而不是硬出结论。

## L3 · 通用框架回退（原型也归不了时）

回退到 `../framework-library.md` 的通用框架，但**仍须照搬本目录的骨架结构**：
先定价值链与关键指标口径 → 再分咨询/行研两个透镜 → 最后写命门假设。

**并且必须在交付前补齐两样东西**：该行业的**关键指标口径陷阱**，
以及**结论的证伪条件**。没有这两样，通用框架产出的就是那种「五力四个格子填满、
但换个行业名照样成立」的东西——这正是本目录存在的原因。

## 两个透镜怎么选

| 问题的疑问词 | 走哪个 | 输出形态 |
|---|---|---|
| 该不该做 / 怎么增长 / 选哪条路 / 格局如何 / 怎么改组织 | **咨询透镜**（默认） | 六段合约 + 结构性判断；**禁评级、目标价、仓位** |
| 值不值这个价 / 盈利拐点在哪 / 估值多少 / 什么假设一翻转结论就翻 | **行研透镜**（需明确触发） | 盈利驱动拆解 + 估值区间 + 敏感性；**禁把格局题答成配置建议** |

判断不了就按咨询透镜走，并在开头一句话说明你按哪个透镜作答、为什么。
两种模式的输出合约、免责与落款**互斥，不混用**——详见 `../../memo-writing/references/output-contract.md`。

**保留的红线（任何模式都不放宽）**：
问「格局」不许答成「买 A 配 B 避 C」；不虚构投研团队角色；不出交易仪表盘式的 HTML 产物。

## 每份文件的固定骨架

```
顶部    时效声明 + 最后校订日期
§0      速查：一句话结构 + 本行业第一口径陷阱 + 两透镜分界

§5      语料出处（可核实来源 + 检索日期）
```

关键设计：**价值链与指标口径只写一遍**放在 §1 地基层，两个透镜引用同一套口径，
避免同一个指标在两处被算出两个数。

## 新增一个行业时

1. 照抄上面的骨架，**联网检索最新一手**（券商研报公开摘要、咨询公司公开报告、行业协会白皮书）。
2. §1.3 的口径陷阱是这类文件价值最高的部分——**必须写出这个行业特有的、
   外行会踩而内行都知道的那几条**（如新能源车的分母塌缩、创新药的总交易额、
   器械的中标价≠出厂价、快递的总部口径单票收入、具身智能的演示视频与有效数据率、
   AI 应用的 ARR 年化口径）。
3. §2.3「行业特有分析动作」必须是通用五力给不了的东西，否则这份文件没有存在价值。
4. §5 留可核实来源与检索日期，本地麦肯锡语料只标「方法论参照」不作数字来源。
5. 回到本文件更新三处：**L1 路由表**（含生意原型列）、**L2 原型表的范本文件**、
   以及若该行业原先在「常见行业原型归属参考」里，把它从那张表移除。
