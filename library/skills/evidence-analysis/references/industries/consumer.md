# 新消费 · 行业分析框架（双透镜）

> ⚠️ **本文件是分析框架，不是数据快照。最后校订：2026-08。**
> 文中数字仅作**口径示例**，一律带 `as-of`。**动笔前必须重新取数**
> （国家统计局社零、公司财报与经营数据、`neodata` 研报召回、`westock consensus`）。
> **直接把本文件的示例数字抄进交付物 = 交付事故。**
> 本赛道品牌生命周期短、爆品迭代快，一年前的品牌排名与增速经常已经完全变了。

## 0. 速查

**一句话结构**：新消费的分析框架正在从**渠道竞争**转向**心智竞争**。
传统消费研究围绕「门店数量、经销商体系、终端覆盖率、单店模型、坪效」展开——
只要能开店铺货就能增长；新消费的核心资产变成了**用户心智、IP、复购与社群**。
**但这不是说旧框架失效了**——渠道与单店模型仍是底座，只是不再是胜负手。

**本赛道第一口径陷阱（必须先讲）**：**GMV 不是收入，加盟商零售额不是品牌方收入。**
GMV 含退货、含未支付订单；加盟模式下品牌方只确认供货收入与加盟费，
终端零售额可能是其数倍。**混用这两组口径是消费分析最常见的硬错。**

**两个透镜的分界**：

| 你被问的是 | 走哪个透镜 |
|---|---|
| 品类怎么选 / 直营还是加盟 / 渠道怎么配 / 定价怎么定 / 出海去哪 / 品牌怎么建 | **§2 咨询透镜** |
| 增长能不能持续 / 高估值撑不撑得住 / 单店模型健不健康 / 给多少倍 | **§3 行研透镜** |

## 1. 产业地基（两透镜共用）

### 1.1 价值链与利润分布

```
供应链（研发·代工·制造） → 品牌 → 渠道（直营/加盟/电商/即时零售） → 用户 → 复购与社群
                              ↑
                          内容与 IP（种草、联名、社交货币）
```

利润分布的判断要点：

| 环节 | 利润逻辑 |
|---|---|
| 供应链 | 代工毛利薄；**自建供应链的价值在于响应速度与品控，不在于省钱**（低于规模临界点时更贵） |
| 品牌 | 溢价来源；毛利率高低直接反映心智强度 |
| 渠道 | 直营吃全部零售差价但承担全部固定成本；加盟让渡差价换扩张速度与轻资产 |
| 内容 / IP | **可沉淀为长期资产**，也可能只是一次性买量费用——区别在于能否复用与延展 |

### 1.2 核心驱动变量

| 侧 | 变量 | 追踪方式 |
|---|---|---|
| 需求 | 社零总额与分品类增速（**分母**） | 国家统计局月度；判断是行业问题还是公司问题 |
| 需求 | 消费结构迁移 | as-of 2026 的主流判断：从「购置资产」转向「消费体验」、从家庭消费转向个人消费、从物质满足转向精神满足——**这是本轮新消费叙事的地基，引用时须注明是趋势判断而非可验证数字** |
| 需求 | 品类景气度（宠物、潮玩、银发、旅游等） | 第三方规模测算，**口径差异极大，须注明来源** |
| 供给 | 门店净增（新开 − 关店） | 公司经营数据 |
| 供给 | 新品上市节奏与爆品命中率 | 公司披露、电商榜单 |
| 效率 | 复购率、会员活跃、内容传播 | 公司披露（口径普遍不统一，须逐家核对定义） |
| 成本 | 原材料、租金、人工、流量成本 | 现货价、公司费用率 |

### 1.3 关键指标与口径（本赛道翻车重灾区）

| 指标 | 定义 | 单位 | 口径陷阱 |
|---|---|---|---|
| **GMV** | 成交总额 | 亿元 | **含退货、含未支付、含平台补贴**，与确认收入差距可能极大；不同平台 GMV 口径互不兼容 |
| 收入 | 会计确认收入 | 亿元 | **加盟模式下品牌方收入 ≈ 供货收入 + 加盟费，远小于终端零售额**；对比同行前必须先确认商业模式 |
| 同店销售增长（SSSG） | 可比门店销售同比 | % | **「同店」定义各家不同**（开业满 12 个月？满 18 个月？含不含翻新期），跨公司不可直接比 |
| 门店数 | 期末门店 | 家 | **只看净增会掩盖关店**；必须要到「新开 / 关闭」两个数 |
| 单店模型 | 单店收入、成本、回本周期 | 元、月 | 直营与加盟的单店模型是两张表；**加盟商的单店模型健康与否决定扩张可持续性**，但品牌方财报里看不到 |
| 复购率 | 复购用户 / 总用户 | % | **时间窗口（30/90/365 天）与统计口径（按人/按订单）不同，数字能差一倍** |
| 会员数 | 注册会员 | 万人 | 注册 ≠ 活跃 ≠ 付费；只报注册数的公司要警惕 |
| CAC / LTV | 获客成本 / 用户生命周期价值 | 元 | CAC 含不含内容与达人分成、含不含老客复购的分摊？LTV 的年限假设是什么？**两者口径不一致时 LTV/CAC 完全没有意义** |
| 毛利率 | — | % | 含不含运费与平台佣金，各家处理不同 |
| 渠道库存 | 经销商与门店库存 | 亿元/月 | 品牌方收入可以靠压货做出来；**必须用终端动销交叉验证** |

### 1.4 数据源地图

| 你要什么 | 去哪 | 频率 |
|---|---|---|
| 社零总额与分品类 | 国家统计局 | 月度 |
| 公司经营数据（门店、同店、GMV） | 财报与经营公告 | 季度/月度 |
| 电商销售与榜单 | 第三方电商数据服务 | 月度 |
| 品类规模测算 | 第三方咨询报告 | 年度；**口径差异极大，务必注明来源与测算方法** |
| 终端动销与价格 | 渠道调研、比价数据 | 不定期，标 [A] |
| 一致预期与研报 | `westock-data consensus`、`neodata`（`data_type=doc`） | 随时 |

### 1.5 周期定位

| 层 | 驱动 | 观察指标 |
|---|---|---|
| 宏观消费周期 | 收入预期与消费信心 | 社零增速、储蓄率 |
| 品类生命周期 | 渗透率曲线所处位置 | 品类增速、新进入者数量 |
| **品牌生命周期** | 流量红利 → 心智沉淀（或衰退） | 新客占比、复购率、自然流量占比 |
| 库存/渠道周期 | 压货与去化 | 渠道库存月数、终端动销 |

**本赛道最关键的定位问题是「品牌处在生命周期哪一段」**：
早期靠流量红利起量的品牌，若在红利消退前没能把复购率与自然流量占比做起来，
就会掉进「营销停投即失速」的陷阱。**判断依据是复购率与自然流量占比的趋势，不是当期增速。**

## 2. 咨询透镜（决策者 = 品牌方 / 零售商高管）

### 2.1 典型问题

进哪个品类 / 直营还是加盟 / 渠道组合怎么配（线下、电商、即时零售）/
定价与价格带怎么定 / 出海去哪、用什么模式 / 品牌怎么从流量转向心智 / 门店网络怎么优化。

### 2.2 框架组合

| 问题 | 框架组合 | 各自验证什么 |
|---|---|---|
| 品类选择 | 品类吸引力矩阵（规模 × 增速 × 集中度 × 毛利结构）+ 自身能力适配 | 有没有钱赚、能不能赢 |
| 直营 vs 加盟 | 单店模型（两张表）+ 扩张速度 × 控制力权衡 + 现金流节奏 | 直营慢而重、控制强；加盟快而轻，但**加盟商赚不到钱就一定会崩** |
| 渠道组合 | 渠道经济性对比（毛利 − 履约 − 获客）+ 用户重叠度 | 别把「多渠道」当战略，要算每条渠道的净贡献 |
| 定价 | 价格带地图 + 价值感知测试 + 竞品定位 | **价格与价值感知背离是新消费最典型的死法**（高价但产品力与体验撑不住） |
| 品牌建设 | 流量→心智的转化路径 + 复购与自然流量指标 | 判断营销支出是买量还是建资产 |

### 2.3 行业特有分析动作

**① 单店模型（本赛道的招牌动作）**

```
单店月收入 = 客流 × 转化率 × 客单价 × 复购系数
单店月毛利 = 单店收入 × 毛利率
单店月净利 = 单店毛利 − 租金 − 人工 − 折旧摊销 − 分摊费用
回本周期  = 单店开办成本 / 单店月净利
```

**加盟模式必须同时做两张表**：品牌方的账和加盟商的账。
**加盟商回本周期过长时，扩张会在 12-24 个月后集中反噬**（关店潮、串货、价格失控）——
这是只看品牌方财报永远看不到的风险。

**② 流量→心智转化诊断**——区分「买来的增长」和「沉淀下来的资产」：
看新客占比、复购率、自然流量（非付费）占比、搜索指数中品牌词占比的趋势。
**四项里有三项在恶化而收入仍在增长，说明增长完全靠加投放买来，不可持续。**

**③ 价格带地图**——把自身与竞品的所有 SKU 铺在「价格 × 价值感知」平面上，
识别空白带与拥挤带。**新消费的高频死因是定价进入了「价格已到高端、体验仍是大众」的错位区。**

**④ IP 与内容资产盘点**——判断内容投入是费用还是资产：
能否跨品类复用、能否延展新品、社群是否自发产生内容。
**只有单一爆款而没有 IP 矩阵的公司，估值最终会回归基本面**（as-of 2026 的行业共识判断）。

### 2.4 结论形态样例与高频误判

**合格结论**：
> 加盟为主、直营做样板店（控制在 X 家以内）。加盟商单店回本周期必须压到 Y 个月以内，
> 否则暂停区域扩张。价格带从 A 段上移至 B 段，同步把包装与门店体验投入提到 Z%；
> 若 6 个月内复购率未从 P% 提升至 Q%，回退定价。

**高频误判**：

| 误判 | 为什么错 |
|---|---|
| GMV 当收入 | 含退货、含补贴；加盟下更是两回事 |
| 只看品牌方账不看加盟商账 | 加盟商不赚钱，扩张一定反噬 |
| 用增速判断品牌健康度 | 加投放就能买到增速；要看复购与自然流量 |
| 价格先行、体验滞后 | 价格与价值感知背离是典型死法 |
| 把内容投放当品牌资产 | 不可复用的投放是费用不是资产 |
| 忽略关店数 | 净增掩盖门店质量问题 |

## 3. 行研透镜（决策者 = 投资人）

### 3.1 典型问题

增长能不能持续 / 高估值有没有基本面支撑 / 单店模型健不健康 /
爆款公司会不会一年就打回原形 / 该给多少倍。

### 3.2 盈利驱动拆解式

| 模式 | 收入拆解 | 利润驱动 |
|---|---|---|
| 连锁（直营） | 门店数 × 单店收入 × 开店节奏 | 同店增长、租金人工占比、爬坡期门店占比 |
| 连锁（加盟） | 加盟店数 × 单店供货额 + 加盟费 | **加盟商健康度**（不健康则开店停滞、关店上升） |
| 品牌（电商为主） | 用户数 × 购买频次 × 客单价 | 获客成本、退货率、平台佣金 |
| IP / 潮玩 | IP 数 × 单 IP 收入 × 生命周期 | IP 孵化成功率、复购与收藏属性、跨品类延展 |

### 3.3 增长质量的三条验证线

新消费的高估值能否成立，**at minimum 要过三关**（券商 2026 中期策略框架）：

| 线 | 问什么 | 用什么指标 |
|---|---|---|
| **增长** | 收入利润能否持续，海外/新品类/新 IP 有没有新增量 | 分渠道分品类收入结构、新品贡献率 |
| **效率** | 高估值能否被利润与现金流支撑 | 毛利率、销售费用率、经营现金流/净利润 |
| **积累** | IP、用户、内容、社群能否沉淀为可复用资产 | 复购率、自然流量占比、IP 矩阵宽度、跨品类延展成功案例 |

**三条线只过一两条的公司，估值会回归传统消费中枢。**

### 3.4 估值锚与可比口径

| 类型 | 主锚 | 交叉验证 | 常见误用 |
|---|---|---|---|
| 传统消费龙头 | P/E、DCF | 现金流稳定性、分红 | — |
| 连锁扩张期 | P/E + **开店空间测算** | 单店模型、同店增长 | 用「理论天花板店数」线性外推，忽略加盟商经济性与关店 |
| 新消费高成长 | P/E / PEG，辅以三条线验证（§3.3） | 复购率、自然流量占比、IP 矩阵 | 用一次性爆款利润给成长股倍数 |
| 亏损期新锐 | P/S | 单位经济学（UE 转正路径） | 只看 GMV 增速 |

> 🔴 **本赛道估值第一提醒**：**新消费的高估值溢价来自「资产化能力」而非「当期增速」。**
> 一个只有单一爆款、没有 IP 矩阵与复购沉淀的公司，无论当期增速多高，
> 估值终将回归传统消费品中枢。判断溢价该不该给，用 §3.3 的三条线，不要用增速。

### 3.5 命门假设与敏感性

| 命门假设 | 翻转会怎样 | 观察哨 |
|---|---|---|
| 复购率能否维持 | 决定获客投入是资产还是费用 | 分月同期群（cohort）复购曲线 |
| 开店空间与加盟商回报 | 决定扩张能走多远 | 关店数、加盟商回本周期、单店同比 |
| 爆款的可复制性 | 一次性爆款 vs IP 矩阵，估值中枢差数倍 | 新品贡献率、第二曲线 |
| 流量成本 | 直接压毛利与净利 | 销售费用率、投放 ROI |
| 品类景气度 | 行业退潮时个体难独善 | 品类增速、新进入者数量 |

敏感性至少做 **同店增长 × 开店数** 与 **复购率 × 获客成本** 两组双维表。

## 4. 两个透镜都会踩的坑

1. **GMV 当收入。** 含退货与补贴；加盟下终端零售额 ≠ 品牌方收入。
2. **同店口径不统一就横比。** 「同店」定义各家不同。
3. **只看净增门店。** 必须拿到关店数。
4. **复购率不写窗口。** 30 天与 365 天口径差一倍。
5. **LTV/CAC 两边口径不一致。** 算出来的比值没有意义。
6. **用增速代替健康度。** 加投放就能买增速。
7. **忽略加盟商的账。** 品牌方财报看起来好的时候，加盟商可能已经在关店。
8. **用一次性爆款利润外推。** 爆款有生命周期，IP 才有复用性。
