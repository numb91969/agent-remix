## 0. 速查

**一句话结构**：这是一条**制造端严重过剩、需求端被电网与电价机制约束**的产业链。
制造环节的胜负由**现金成本曲线 + 政策强标出清**决定；
应用环节（电站、储能）的胜负由**收益模型（IRR）能不能算得过来**决定。
**两端的分析方法完全不同，混着谈必然说不清楚。**

**本赛道第一口径陷阱（必须先讲）**：**招标 ≠ 中标 ≠ 并网 ≠ 出货。**
示例 as-of 2026H1：国内大储 EPC 累计招标约 304.8GWh、中标约 263.89GWh，
而同期新增并网储能仅约 60.26GWh。**三个数字相差数倍，各自回答的问题完全不同**——
招标看意向、中标看订单、并网看真实落地。拿招标量论证需求兑现，是本赛道最普遍的放大手法。

**两个透镜的分界**：

| 你被问的是 | 走哪个透镜 |
|---|---|
| 要不要扩产/停产 / 走哪条技术路线 / 出海去哪 / 一体化还是专业化 / 格局如何出清 | **§2 咨询透镜** |
| 出清到哪一步了 / 盈利何时筑底 / 电站 IRR 撑不撑得住 / 该给多少倍 | **§3 行研透镜** |

## 1. 产业地基（两透镜共用）

### 1.1 价值链与利润分布

```
光伏：多晶硅 → 硅片 → 电池 → 组件 ─┐
                                    ├→ 电站开发运营 → 上网/自发自用
储能：锂电芯 → PCS/BMS → 系统集成 ─┘
风电：主机 → 塔筒·叶片·轴承 ────────┘
辅材：玻璃·胶膜·边框·银浆·支架
```

**过剩期的利润逻辑与扩张期完全相反**：

| 情形 | 利润流向 |
|---|---|
| 扩张期（需求 > 产能） | 最紧的环节拿走利润（历史上是硅料） |
| **过剩期（当前，as-of 2026）** | 利润流向**现金成本最低**与**技术领先不受强标冲击**的环节；多数环节靠近盈亏平衡 |
| 政策强标出清后 | 先出清、集中度先提升的环节盈利先修复 |

**储能与光伏主链的盈利能力已经分层**（示例 as-of 2026）：储能景气度与盈利普遍优于光伏主链，
且储能价格与盈利有明显区域分层——海外成熟市场优于国内。**做储能不能用国内价格推全球盈利。**

### 1.2 核心驱动变量

| 侧 | 变量 | 追踪方式 |
|---|---|---|
| 需求 | 新增装机（分国内/海外、集中式/分布式） | 行业协会与能源主管部门月度；示例 as-of 2026：全球光伏新增约 547GW、同比约 −11%，为近年首次回落；国内自 2025 年高位回落 |
| 需求 | **电网消纳与承载能力** | 本轮最硬的需求约束——不是没人想装，是电网接不下 |
| 需求 | 储能装机与出货 | 示例 as-of 2026：预计国内锂电储能装机约 253GWh（+44%）、全球装机需求约 588GWh（+62%） |
| 供给 | 产能利用率/开工率 | 示例：光伏多环节产能利用率约五成 |
| 供给 | **产量的自发收缩** | 示例 as-of 2026H1：多晶硅产量约 53.8 万吨（−9.8%）、组件产量约 201.3GW（−35.1%）——产量下行是出清的先行证据 |
| 价格 | 组件/电芯/硅料价格 | 示例：组件价格自 2023 年累计跌约 66%，2026 年中已在 0.75 元/W 以下，触及多数企业现金成本线 |
| 政策 | **能耗能效强制性国标** | as-of 2026-07 发布、2027-01 实施、设半年过渡期；是"反内卷"从引导转向刚性约束的标志 |
| 政策 | 电价与容量机制 | 示例：独立储能容量补偿标准约 165–370 元/kW·年；新能源入市后电站收益模型被重写 |
| 成本 | 碳酸锂等原材料 | 直接决定储能集成环节的短期盈利 |

### 1.3 关键指标与口径（本赛道翻车重灾区）

| 指标 | 定义 | 单位 | 口径陷阱 |
|---|---|---|---|
| **招标 / 中标 / 并网** | 三个不同阶段 | GWh | **见 §0**，差数倍，绝不可混用或相加 |
| 装机量 | 新增并网容量 | GW | **交流侧（AC）还是直流侧（DC）？** 组件出货是直流口径、电网装机常是交流口径，中间隔着容配比，直接比较是硬错 |
| 组件出货 vs 装机 | 出货含库存与在途 | GW | 两者不同步，年度差额就是渠道库存 |
| 储能容量 | 功率(GW) vs 容量(GWh) | GW / GWh | **两个维度不能互换**，必须同时给出时长（2h/4h） |
| 产能利用率 | 产量/产能 | % | 名义产能含长期停产产线；**有效产能口径才有意义** |
| 组件价格 | 元/W | 元/W | 含不含运费、含不含税、是否为含辅材的整机；不同口径差别显著 |
| 现金成本 | 不含折旧的可变成本 | 元/W | **出清判断的核心指标**，与完全成本不同；价格跌破现金成本才是真正的退出压力 |
| **IRR** | 项目收益率 | % | **全投资 IRR vs 资本金 IRR 差异巨大**（杠杆放大）；是否含配储成本、按什么电价假设、利用小时取多少，四项不写清则 IRR 无意义 |
| 利用小时 | 年发电小时 | h | 受消纳与限电影响，规划值与实际值差距可能很大 |
| 在手订单 | 已签未交付 | GWh | 储能集成商**签单与交付存在 6–12 个月时间差**，在手订单不等于当期收入，且期间成本会变 |
| 转换效率 | 组件效率 | % | 强标按效率划线（示例：TOPCon 三级门槛 23.2%），**是出清测算的直接输入** |

### 1.5 周期定位

这是**典型的产能周期行业**，可直接借用 `semiconductor.md` §1.5 的三层周期思路，
但本赛道的出清多了一个**政策强制变量**：

| 层 | 驱动 | 观察指标 |
|---|---|---|
| 产能周期 | 扩产与出清 | 开工率、产量增速、破产重整案例、扩产计划取消 |
| **政策出清** | 能耗/效率强标划线 | 不达标产能规模、过渡期节点、并购整合 |
| 价格周期 | 供需缺口 | 价格 vs 现金成本曲线的相对位置 |
| 需求侧 | 电网消纳与电价机制 | 消纳红线、容量电价落地、市场化交易电价 |

**定位动作**（判断"出清到哪一步"）：价格是否跌破现金成本 → 产量是否已自发收缩 →
是否出现实质性退出（破产/重整/转产，而非口头减产）→ 集中度是否提升 → 价格是否止跌。
**五步走完才算出清完成，只看到"价格很低"就说"底部到了"是最常见的误判。**

## 2. 咨询透镜（决策者 = 制造企业 / 电站开发商高管）

### 2.1 典型问题

要不要扩产、停哪条线 / 押哪条技术路线（TOPCon / BC / 其他）/
出海去哪、用什么模式 / 一体化还是专业化 / 要不要做储能 / 电站投不投。

### 2.2 框架组合

| 问题 | 框架组合 | 各自验证什么 |
|---|---|---|
| 扩产 / 停产 | **现金成本曲线定位（§2.3）** + 产能周期定位 + 强标达标测算 | 自己在成本曲线的哪个分位、扛不扛得过出清、现有产线达不达标 |
| 技术路线选择 | 强标门槛 + 效率提升路径 + 成本溢价能否覆盖 | 不达标产线会被强制清退，**技术选择在这一轮不是加分项而是生存项** |
| 出海 | 市场吸引力 × 贸易壁垒矩阵 + 本地化要求 + 区域价格分层 | 海外价格与盈利显著优于国内，但关税与本地化门槛决定能否吃到 |
| 一体化 vs 专业化 | 各环节成本曲线 + 周期对冲效果 + 资本开支强度 | 一体化能对冲单环节亏损，但资本开支重、转身慢 |
| 电站投资 | **IRR 拆解（§2.3）** + 消纳风险 + 光储协同 | 收益模型能不能算过来，取决于电价机制与消纳，不是组件多便宜 |

### 2.3 行业特有分析动作

**① 现金成本曲线定位（制造端的招牌动作）**

把行业内各家产能按**现金成本**从低到高排序，标出当前市场价的位置。
**价格线以右的产能就是出清候选**。再叠加自身位置，回答两个问题：
能不能扛过这轮、以及出清完成后自己的份额会变成多少。
**注意用现金成本而不是完全成本**——企业在跌破完全成本时会继续生产，跌破现金成本才停。

**② 强标出清测算（这一轮特有）**

政策把能耗与效率画成硬线，出清量可以直接算：
按门槛逐环节筛选不达标产能规模 → 扣除过渡期内可技改的部分 → 得到净出清量。
示例量级（as-of 2026，须复核）：硅料低效产能出清约 70–80 万吨（约占总产能 30%）；
传统 PERC 组件基本无法达标；TOPCon 低效产能出清约 20–30%；BC 路线基本不受冲击。
**这是本轮和以往纯市场化出清最大的不同——出清速度由政策日历决定，可以排期。**

**③ 电站 IRR 拆解**

```
IRR ← 年发电量(装机 × 利用小时) × 上网电价
      − 运维成本 − 配储成本 − 财务费用
      ÷ 初始投资(EPC 造价)
```
四个假设必须逐一写明并做敏感性：**电价机制（是否市场化交易）、利用小时（消纳限电）、
配储要求、资本金比例**。当前趋势是通过光储一体化与提高自发自用比例来平滑收益。

**④ 储能收益来源拆解**——国内大储收益由**现货价差交易 + 辅助服务 + 容量补偿**三块构成，
三块的政策稳定性完全不同（容量补偿最稳、现货价差波动最大）。
**只算其中一块的 IRR 会系统性偏高或偏低。**

### 2.4 结论形态样例与高频误判

**合格结论**：
> 停 A 基地两条 PERC 线（强标下无技改价值），资金转投 B 技术路线扩 X GW；
> 出海优先 C 市场（价格分层最高且无本地化强制要求），以 D 模式落地。
> 若组件价格 12 个月内未回到 E 元/W 以上，二期停投。

**高频误判**：

| 误判 | 为什么错 |
|---|---|
| 用招标量论证需求 | 招标/中标/并网差数倍 |
| 交流与直流口径混算 | 中间隔着容配比 |
| 用完全成本判断出清 | 企业跌破完全成本仍会生产 |
| "价格很低所以是底部" | 出清要走完五步（§1.5） |
| IRR 不写假设 | 全投资/资本金、电价、利用小时、配储四项不写清则无意义 |
| 用国内储能价格推海外盈利 | 区域价格分层显著 |
| 忽略签单到交付的时间差 | 6–12 个月内成本已经变了 |

## 3. 行研透镜（决策者 = 投资人）

### 3.1 典型问题

出清到哪一步了 / 盈利何时筑底回升 / 哪个环节先修复 / 电站与储能的收益能否兑现 /
该用什么锚、给多少倍。

### 3.2 盈利驱动拆解式

| 环节 | 收入拆解 | 利润驱动 |
|---|---|---|
| 硅料/硅片/电池/组件 | 出货量(GW) × 单价(元/W) | **单位盈利（分/W）** 是核心指标；产能利用率 + 现金成本分位 |
| 辅材（玻璃/胶膜/边框/银浆） | 出货量 × 单价 | 原材料传导能力、格局集中度（辅材常比主链格局好） |
| 储能集成 | 出货(GWh) × 单价(元/Wh) | **签单与交付 6–12 个月时间差 + 碳酸锂成本波动**决定毛利率，区域结构决定盈利分层 |
| 逆变器/PCS | 出货台数或 GW × 单价 | 海外占比是盈利关键 |
| 电站运营 | 装机 × 利用小时 × 电价 | 消纳、电价机制、融资成本 |

### 3.3 供需平衡表与成本曲线

制造环节**必须做供需平衡表**（做法见 `semiconductor.md` §3.3，结构完全通用）：

```
供给 = 有效产能 × 可达开工率 + 新增投产 − 强标出清 − 自然退出
需求 = 国内装机 + 海外装机 + 渠道库存变动（注意 AC/DC 换算）
缺口 → 价格方向 → 单位盈利
```

**本赛道相对半导体多一项**：强标出清量是**可以按政策日历排期的确定项**，
不像纯市场出清那样只能猜。这让供需平衡表的可预测性明显更高。

### 3.4 估值锚与可比口径

| 环节 | 主锚 | 交叉验证 | 说明 |
|---|---|---|---|
| 制造（周期底部） | **P/B** | 单位盈利（分/W）、现金成本分位 | 盈利为负或接近零时 P/E 失效，与存储芯片同理（见 `semiconductor.md` §3.4） |
| 制造（盈利修复后） | P/E | ROE、产能利用率 | **锚的切换时点是最大误差来源** |
| 辅材/逆变器 | P/E | 海外收入占比、格局集中度 | 格局较好，盈利波动小于主链 |
| 储能集成 | P/E | 在手订单、交付节奏、区域结构 | 注意订单与收入的时间差 |
| 电站运营 | **DCF / IRR**，或 P/B 与股息 | 现金流稳定性、融资成本 | 属公用事业属性，不能用制造业倍数 |

> 🔴 **本赛道估值第一铁律**：**周期底部 P/E 失效、周期顶部 P/E 骗人。**
> 与半导体同理——盈利峰值时 PE 最低。判断"底部"要用现金成本曲线与出清进度（§1.5 五步），
> 不能用"跌了多少"。**同一家公司在出清前后应该换锚，换锚判断错误比估值区间算错影响更大。**

### 3.5 命门假设与敏感性

| 命门假设 | 翻转会怎样 | 观察哨 |
|---|---|---|
| 强标执行力度与过渡期 | 是本轮出清速度的最大变量 | 政策原文、过渡期节点、地方执行 |
| 需求（电网消纳与电价机制） | 决定供需缺口的分母 | 消纳红线、市场化电价、容量机制落地 |
| 碳酸锂等原材料价格 | 直接决定储能集成毛利率 | 现货价、长协结构 |
| 海外贸易壁垒 | 海外是当前盈利最好的市场，壁垒抬升直接打穿 | 目的国关税与本地化要求 |
| 技术路线切换速度 | 决定现有产能的残值 | 效率进展、新产能投产结构 |

敏感性至少做 **组件价格 × 开工率** 与 **电价 × 利用小时（电站侧）** 两组双维表。

## 4. 两个透镜都会踩的坑

1. **招标 / 中标 / 并网混用。** 差数倍。
2. **交流与直流口径混算。** 中间隔着容配比。
3. **GW 与 GWh 互换。** 储能必须同时给时长。
4. **用完全成本判断出清。** 该用现金成本。
5. **"跌得够多了"当底部。** 出清要走完五步。
6. **IRR 不写四项假设。** 全投资/资本金、电价、利用小时、配储。
7. **用国内价格推海外盈利。** 区域分层显著。
8. **忽略订单到收入的时间差。** 储能集成 6–12 个月，期间成本已变。
9. **把制造与运营用同一套估值锚。** 一个是周期制造、一个是公用事业。
