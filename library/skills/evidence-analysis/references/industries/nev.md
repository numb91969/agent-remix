> 文中数字仅作**口径示例**，一律带 `as-of`。**动笔前必须重新取数**
> （乘联分会/中汽协月度数据、`neodata` 研报召回、`westock consensus`）。

## 0. 速查

**一句话结构**：中国新能源车已过「渗透率爬坡期」，进入**存量竞争 + 出口驱动**阶段。
增长不再来自电动化替代本身，而来自**海外市场与单车价值量提升**；
利润则被价格战与原材料价格双向挤压。

**本赛道第一口径陷阱（必须先讲）**：**渗透率创新高不等于卖得更多。**
示例 as-of 2026-07：新能源零售渗透率 65.1% 创历史新高，但当月新能源乘用车零售
95.1 万辆同比 −3.9%、1–7 月累计同比 −12.5%——因为分母（总乘用车零售）跌得更快
（当月 −20.9%）。**分母塌缩会推高渗透率**。任何用渗透率论证「需求旺盛」的分析，
不同时给出绝对量就是错的。

**两个透镜的分界**：

| 你被问的是 | 走哪个透镜 |
|---|---|
| 出海先去哪个市场 / 要不要自研电池或芯片 / 渠道用直营还是经销 / 价格战怎么应对 / 格局如何 | **§2 咨询透镜** |
| 单车盈利拐点在哪 / 谁能活下来 / 出口能贡献多少利润 / 该给多少倍 | **§3 行研透镜** |

## 1. 产业地基（两透镜共用）

### 1.1 价值链与利润分布

```
锂/镍钴 → 正负极·电解液·隔膜 → 电芯/电池包 → 三电系统 ─┐
                                                        ├→ 整车 → 渠道/售后 → 充换电与能源服务
              芯片·智驾软件·域控制器 ───────────────────┘
```

**利润在链条上是漂移的**，跟着两个变量走：

| 变量 | 利润流向 |
|---|---|
| 碳酸锂等原材料价格 | 价格高时利润上移到资源与电池，价格低时下移到整车 |
| 供需松紧（产能利用率） | 紧张环节拿定价权 |

**整车环节的利润高度分化**——同一年份里有公司单车赚钱、有公司单车巨亏，
**用行业平均单车利润分析任何一家公司都是错的**。

### 1.2 核心驱动变量

| 侧 | 变量 | 追踪方式 |
|---|---|---|
| 需求 | 总乘用车市场规模（**分母**） | 乘联分会月度零售，本赛道最容易被忽略的变量 |
| 需求 | 新能源渗透率（分品牌类型看） | 示例 as-of 2026-04：自主 80.1%、豪华 26.1%、主流合资 14.1%——**结构差异极大** |
| 需求 | **出口量与出口结构** | 海关与中汽协；示例 as-of 2026：新能源乘用车出口预期约 280–330 万辆、同比约 +40%（卖方预测口径，须复核） |
| 供给 | 产能利用率与新车投放节奏 | 公司产能公告、新车上市表 |
| 成本 | 碳酸锂等原材料价格 | 现货与长协价；示例 as-of 2026Q1：原材料涨价带来单车成本压力约 5,000–10,000 元（研报口径，须复核） |
| 政策 | 购置税优惠、以旧换新补贴、双积分 | 政策原文；示例：2026 年起新能源购置税减半征收并设上限 |
| 政策 | 海外关税与本地化要求 | 目的国政策原文 |

### 1.3 关键指标与口径（本赛道翻车重灾区）

| 指标 | 定义 | 单位 | 口径陷阱 |
|---|---|---|---|
| 销量 | 批发 / 零售 / 上险 三口径 | 万辆 | **批发是厂家出货**（含压给渠道的库存），**零售是终端成交**，**上险是真实上路**。三者能差出一个月的库存量。跨口径比较是最常见的硬错 |
| 渗透率 | 新能源 / 总量 | % | ① 零售口径还是批发口径 ② 含不含出口 ③ 乘用车还是含商用车 ④ 狭义还是广义乘用车。**更关键：分母塌缩会推高渗透率**（见 §0） |
| 新能源定义 | 是否含 PHEV / 增程 | — | 纯电与插混增程的口径差异会显著改变结论；出口结构里插混占比近年提升明显 |
| 单车售价 ASP | 收入 / 销量 | 万元 | 含不含增值税？含不含选装与软件？出口 ASP 与国内不可直接比 |
| 单车利润 | 毛利或净利 / 销量 | 元/辆 | **含不含积分收入、补贴、金融与售后**？口径不同能翻倍。整车厂常年披露口径不一 |
| 出口量 | 整车出口 | 万辆 | **整车出口 vs 散件（KD/SKD）海外组装**含义完全不同（关税、利润率、本地化程度都不同） |
| 电池装机量 | GWh | GWh | **装机量 ≠ 产量 ≠ 出货量**；装机口径只算装到车上的 |
| 交付量 | 已交付 | 辆 | 与「订单」「锁单」不是一回事，新势力宣传常混用 |

### 1.4 数据源地图

| 你要什么 | 去哪 | 频率与时滞 |
|---|---|---|
| 零售/批发销量、渗透率、分品牌结构 | 乘联分会（乘用车市场信息联席分会） | 月度，次月上中旬 |
| 行业总量与商用车 | 中汽协 | 月度 |
| 真实终端交付 | 交强险上险数 | 周/月，第三方整理 |
| 出口量与目的国结构 | 海关总署、中汽协 | 月度 |
| 电池装机与份额 | 动力电池产业创新联盟 | 月度 |
| 原材料价格 | 现货报价机构 | 日/周 |
| 一致预期与研报 | `westock-data consensus`、`neodata`（`data_type=doc`） | 随时 |

### 1.5 周期定位

| 层 | 驱动 | 观察指标 |
|---|---|---|
| 政策周期 | 补贴/购置税退坡与刺激接力 | **退坡前抢装、退坡后透支**，是本赛道最强的季度扰动源；跨年同比必须做政策错期调整 |
| 产品周期 | 换代与新车投放密度 | 新车上市表、单车生命周期销量曲线 |
| 原材料周期 | 锂等资源价格 | 现货价、库存 |
| 渠道库存周期 | 批发与零售的差额累积 | 库存系数、批零差 |

**定位动作**：先做政策错期校正，再看批零差与库存系数，最后看新车投放节奏。
**不做政策错期校正的同比数据在本赛道基本没有解释力。**

## 2. 咨询透镜（决策者 = 企业高管 / 董事会）

### 2.1 典型问题

出海先去哪个市场、用什么模式（整车出口 / KD / 建厂）/ 要不要垂直整合电池与芯片 /
渠道用直营还是经销 / 价格战跟不跟 / 智驾自研还是外采 / 产品线怎么收敛。

### 2.2 框架组合

| 问题 | 框架组合 | 各自验证什么 |
|---|---|---|
| 出海市场选择 | **市场吸引力 × 进入壁垒矩阵**（§2.3）+ 单车经济学（出口 vs 国内）+ 政策风险 | 需求规模与增速、关税与本地化要求、渠道与售后可建性 |
| 出海模式 | 整车出口 / KD / 本地建厂的三方案 NPV + 政策情景 | 关税与本地化要求变化时哪个方案更稳健 |
| 垂直整合 | 自制 vs 外采的单位成本曲线 + 规模临界点 + 期权价值 | 低于临界规模时自制永远更贵；同时要算被卡脖子的期权价值 |
| 价格战应对 | 单车经济学 + 竞对成本曲线 + 弹性测算 | 降价换量能否覆盖毛利损失，取决于自身在成本曲线的位置 |
| 竞争格局（structure 题） | 集中度演变（CR5/HHI）+ 产能利用率 + 出清路径 | 结论是**结构性判断**（几超几强、谁出局、CR5 走向），不是配置建议 |

### 2.3 行业特有分析动作

**① 单车经济学（本赛道的招牌动作，两个透镜共用）**

```
单车收入(ASP)
 − 单车 BOM（电池是最大单项）
 − 单车制造费用（与产能利用率强相关）
 − 单车折旧摊销（固定成本 / 销量，规模效应主要来源）
 = 单车毛利
 − 单车期间费用（研发、销售、管理 / 销量）
 = 单车净利
```

**必须逐项标注口径**（含不含积分、补贴、软件收入）。这是本赛道所有决策的公共底座——
出海值不值、降价跟不跟、要不要自制，最后都落到这张表上。

**② 规模临界点**——固定成本摊薄是整车盈利的核心机制。求出「单车净利转正」所需年销量，
再对照产能与订单。**低于临界规模的产品线，靠降价扩量往往越卖越亏。**

**③ 出海市场矩阵**——市场吸引力（规模、增速、电动化渗透、消费能力）×
进入壁垒（关税、本地化要求、渠道与售后、充电基础设施、政治风险）。
**避开传统汽车工业强国的正面竞争、优先新兴市场**是近年的通行策略（as-of 2026），
但要用矩阵算出来，不能直接抄结论。

**④ 政策错期校正**——凡涉及同比的分析，先把补贴/购置税退坡节点标在时间轴上，
识别抢装与透支月份，否则会把政策扰动误读为需求趋势。

### 2.4 结论形态样例与高频误判

**合格结论**：
> 出海优先级：A 市场（整车出口，12 个月内建 X 家门店）> B 市场（KD 组装，绕开关税）
> > C 市场（暂缓，本地化要求触发建厂门槛）。国内产品线从 N 个收敛到 M 个，
> 停产单车净利为负且年销低于临界规模 K 的车型；若关税上调超过 P 个百分点，B 方案切换为本地建厂。

**高频误判**：

| 误判 | 为什么错 |
|---|---|
| 用渗透率论证需求旺盛 | 分母塌缩会推高渗透率（§0） |
| 用行业平均单车利润推某家公司 | 整车利润极度分化 |
| 混用批发/零售/上险 | 差额就是渠道库存 |
| 忽略政策错期 | 抢装与透支会制造假趋势 |
| 把出口量当出口利润 | 整车出口与 KD 的利润结构完全不同 |
| 垂直整合默认更省钱 | 低于规模临界点时自制更贵 |

## 3. 行研透镜（决策者 = 投资人）

### 3.1 典型问题

单车盈利拐点何时到 / 价格战何时结束 / 出口能贡献多少利润 / 谁能活到出清之后 /
电池与整车的利润分配怎么变 / 该给多少倍。

### 3.2 盈利驱动拆解式（按环节）

| 环节 | 收入拆解 | 利润驱动 |
|---|---|---|
| 整车 | 销量 × ASP（国内/出口分开算） | 单车经济学（§2.3）；**出口单车净利通常显著高于国内**（示例 as-of 2026 卖方口径约为国内 2 倍，须复核），出口占比是利润弹性的关键 |
| 电池 | 出货 GWh × 单价（元/Wh） | **单位盈利（元/Wh）** 是核心指标；产能利用率 + 原材料传导时滞 |
| 材料 | 出货量 × 单价 | 加工费模式的看单吨盈利，资源属性的看价格弹性 |
| 零部件 | 配套量 × 单价 | 客户结构、单车配套价值量、出海配套 |
| 智驾软件 | 选装率 × 单价 或 订阅 | 研发摊销与选装率是两个命门 |

### 3.3 供需与出清

整车不做严格供需平衡表，做**产能利用率与出清路径**：

```
行业名义产能 vs 实际销量  →  利用率
利用率长期低位 + 单车净利为负  →  出清压力
出清路径：停产车型 → 产能转让/代工 → 品牌退出
```

电池与材料环节则**必须做供需平衡表**（口径与做法见 `semiconductor.md` §3.3），
因为它们是同质化、可测产能的制造业。

### 3.4 估值锚与可比口径

| 环节 | 主锚 | 交叉验证 | 常见误用 |
|---|---|---|---|
| 整车（盈利稳定） | P/E | 单车净利、出口占比、EV/EBITDA | 用亏损期的 P/S 与盈利期的 P/E 混着比 |
| 整车（尚未盈利） | P/S | 单车毛利转正时点、现金消耗速度 | 只看销量增速不看单车毛利 |
| 电池 | P/E + **单位盈利（元/Wh）** 交叉验证 | 产能利用率、长协结构 | 只看 GWh 份额不看单位盈利 |
| 材料 | 周期属性用 P/B 与单吨盈利；加工费模式用 P/E | 成本曲线位置 | 把资源价格高点的盈利外推 |
| 零部件 | P/E / PEG | 单车配套价值量、客户集中度 | 忽略客户绑定风险 |

> 🔴 **本赛道估值提醒**：整车是**经营杠杆极高**的生意——固定成本占比大，
> 销量小幅波动会放大成利润大幅波动。因此**盈利拐点前后的估值锚必须切换**
> （P/S → P/E），切换时点判断错误是最大的估值误差来源。

### 3.5 命门假设与敏感性

| 命门假设 | 翻转会怎样 | 观察哨 |
|---|---|---|
| 价格战烈度 | 决定单车毛利，直接决定盈利拐点 | 官降频次与幅度、新车定价带 |
| 出口增速与关税 | 出口是当前主要利润来源，关税上调直接打穿 | 目的国政策、月度出口数据 |
| 原材料价格 | 电池与整车的利润分配随之漂移 | 锂价现货与长协 |
| 政策接力 | 退坡后是否有新刺激，决定总量 | 政策文件 |
| 产能利用率 | 经营杠杆放大器 | 产销率、库存系数 |

敏感性至少做 **销量 × 单车净利** 与 **出口占比 × 关税** 两组双维表。

## 4. 两个透镜都会踩的坑

1. **渗透率陷阱。** 分母塌缩推高渗透率；必须同时给绝对量与分母走势。
2. **口径混用。** 批发/零售/上险、含不含出口、含不含插混增程，四个维度都要写清。
3. **行业平均掩盖极端分化。** 整车单车利润的方差极大，平均值几乎没有解释力。
4. **忽略政策错期。** 抢装与透支会造出假的趋势线。
5. **出口量当出口利润。** 整车出口、KD、本地建厂的利润结构完全不同。
6. **电池只看份额不看单位盈利。** GWh 第一但元/Wh 亏损的情况真实存在。
7. **忽略经营杠杆。** 销量小变动 → 利润大变动，线性外推必错。
