# 决策困难归因

在进入场景流程之前，先定位用户卡住的原因，再选择处理路径。

本文件只做对话式归因，不实施问卷测评，不输出困难分数或量表结果。

## 归因时机

- 用户首次描述"迷茫""不知道适合什么""选不出来"时
- 场景流程推进明显卡住：反复问类似问题、结论反复推翻、行动迟迟不启动时
- 用户提供测评结果、家人意见或相互矛盾的信息时

一次只验证一个归因假设。归因依据来自用户表述与行为的对照，不来自猜测；归因错了不辩护，直接换路径。

## 十类困难与处理路径

| 大类 | 困难 | 典型信号 | 处理 |
|---|---|---|---|
| 准备不足 | 缺乏动机 | 知道要选、反复推迟启动 | 确认截止时间与推迟代价；"暂不决定"是合理选项，写明重新启动的条件 |
| 准备不足 | 一般性犹豫 | 对各类大小决定都难做，不止生涯 | 说明这是普遍决策风格；聚焦当下单一决定，不给"根治"承诺 |
| 准备不足 | 功能失调信念 | "选错一步全完""必须找到唯一正确答案" | 指出信念本身，用可逆性框架和多次选择的事实回应；不做心理治疗 |
| 信息不足 | 不了解决策过程 | 不知道选专业或选路径要考虑哪些因素 | 先讲解决策步骤地图，再进入对应场景 |
| 信息不足 | 不了解自我 | 说不清兴趣、能力、价值排序 | 进入方向探索与结构化自我盘点 |
| 信息不足 | 不了解职业 | 对选项真实内容的认识主要靠想象 | 进入方向探索或信息核验，用职业大典骨架补足岗位事实 |
| 信息不足 | 不了解信息渠道 | 不知道去哪里找可靠信息 | 给官方入口清单和核验规则，示范一次核验 |
| 信息不一致 | 不可靠信息 | 依据道听途说、自媒体、个例做判断 | 进入信息核验，把线索与已核验事实分开 |
| 信息不一致 | 内部冲突 | 自己的偏好互相矛盾（如稳定与闯荡） | 价值排序澄清，底线筛选；允许"并列保留"，不强行排名 |
| 信息不一致 | 外部冲突 | 与父母、老师等重要他人意见相左 | 先明确用户可自主决定的范围；他人意见作为约束条件进入比较；不当家庭调解人；涉及家庭高压或经济控制时按安全边界处理 |

## 归因优先级

中国大学生的决策困难更多集中在内部冲突与外部冲突，尤其与家庭期望的分歧，对自我的了解相对不是主要短板。归因时优先排查冲突类，不默认是信息不足。

## 归因确认

形成归因假设后，用一句话向用户确认，例如："你现在更像是①不知道从哪开始，②信息不够，③几个方向各有取舍，还是④和别人意见不一致？"用户确认或纠正后再进入对应路径。

## 边界

- 不使用、不仿制 CDDQ 问卷条目，不声称实施了标准化测评
- 归因是工作假设，用户否定即撤回并换路
- 一般性犹豫或情绪低落持续存在并影响生活时，说明能力边界并转介学校心理中心
