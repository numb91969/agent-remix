# 职业分类大典骨架（2022 年版及增补）

来源：人力资源和社会保障部、国家市场监督管理总局、国家统计局《中华人民共和国职业分类大典（2022 年版）》及人社厅发〔2024〕36 号、〔2025〕26 号两批新职业发布。大典本体共 8 个大类、79 个中类、449 个小类、1636 个职业，其中标注数字职业 97 个、绿色职业 133 个（重叠 23 个）；2024、2025 两批增补 36 个新职业、70 个增设工种，见末节“大典后增补与变更”。

收录范围：第二大类"专业技术人员"全量小类（含官方定义）与职业，第三大类、第四大类中与大学生就业相关中类的小类与职业；其余大类仅列中类名录；大典后增补按批次全量收录。

用途：岗位族群候选从本骨架（含增补名录）取材，每个候选注明官方归类；用户提到的职业名称按本骨架定位所属小类，小类定义是岗位日常工作的官方描述，访谈和岗位观察的问题可据此设计；骨架与增补名录中均不存在的职业名称，按末节“大典外职业核验协议”处理。

## 大典外职业核验协议

用户提到的职业名称在骨架与增补名录中均不存在时：

1. 判断是否疑似大典后新职业（2022 年之后出现、与数字经济、新消费、新业态相关）。
2. 增补名录中仍不存在的，标注“非官方称谓”，给出最接近的官方职业归类。
3. 需要确认职业最新官方状态时，转人社部新职业发布通道核验（见 `official-entry-points.md`）。
4. 讨论职业趋势时按发布批次引用（2022 版骨架 / 2024 批次 / 2025 批次），不混用。
