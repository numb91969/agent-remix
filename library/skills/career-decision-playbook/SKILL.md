# Career Decision Playbook

## 使用时机

当大学生需要探索专业或职业方向、比较转专业与升学路径、处理毕业去向选择、核验关键事实、验证方向、纠正已有判断或复盘行动结果时使用。

Agent 只负责识别场景和维持角色。本 Skill 负责困难归因、决策方法、停止条件、来源规则、纠偏方式和交付结构。

## 执行协议

1. **归因定位**：用户迷茫或流程卡住时，先按 `difficulty-router.md` 判断卡住的原因（动机、信念、信息缺口、信息冲突），再进入场景；归因不替代场景判断。
2. **锁定当前决定**：明确用户现在要决定什么、候选是什么、截止时间和影响范围；问题过大时收缩到未来三至十二个月内的一项选择。
3. **获取最小充分信息**：一次只问一个会改变判断的问题。已有信息不重复询问。
4. **建立决策状态**：记录底线条件、可权衡偏好、已有证据、关键未知、现实约束和可逆性。
5. **执行当前场景方法**：按场景路由生成候选、比较方案、核验事实、设计验证或更新判断。
6. **停止无增量分析**：当继续追问、打分或检索不再增加决策信息时，转入阶段结论或行动验证。
7. **只交付当前需要的结果**：先使用轻量输出；用户要求系统分析或选择高成本、难逆时再展开完整模板。
8. **留下复盘入口**：写明下一项动作、完成标准和何时根据新证据更新。

## 证据与候选规则

- 区分已核验事实、个人证据和待验证假设。
- 方向探索只有一项经历时，只生成二至四个**未排序的待验证候选**，不得表述“更适合”或“当前更倾向”。
- 形成方向倾向前，至少补充一项不同场景的经历，或主动获得一项反例、排斥体验或现实限制。
- 每个候选都要写支持证据、反证或限制、关键未知和下一项验证。
- 岗位族群候选从 `occupations-catalog.md` 的官方骨架取材，每个候选注明官方归类；专业类比较以 `majors-catalog.md` 的官方目录为口径。
- 不把兴趣问卷、自评量表、人格标签或单次体验当成职业结论。
- 不输出无依据的精确适配率，不用单一总分覆盖底线条件。

## 事实核验协议

进入信息核验前先判断当前是否具备可用的查询能力或用户材料：

- **具备查询能力**：只核验会改变选择的三项以内事实，优先官方原始来源（国家级入口见 `official-entry-points.md`），并按 `source-policy.md` 记录来源、日期、适用对象和风险等级。
- **用户提供材料**：先判断发布主体、日期、适用范围和是否完整，再决定能否标记为已核验。
- **无查询能力、页面不可访问或查询失败**：不得凭模型记忆补全。输出“待核验清单 + 建议官方入口（按 `official-entry-points.md`）+ 用户可提供的材料 + 对决策的影响”。
- **只有搜索摘要、转载、自媒体或匿名经验**：仅作为问题线索，不能标记为已核验。
- **来源冲突**：列出冲突，优先适用对象更精确、日期更新、主体更权威的来源；仍无法确认时转介执行部门。

## 用户否定与换路

当用户说“不符合我”“你理解错了”“这个结论不准”或提供反证时：

1. 不辩护、不继续强化原结论。
2. 确认问题属于事实错误、偏好权重变化、现实约束遗漏、目标理解错误还是新证据出现。
3. 撤回受影响的结论或分数，不保留已失效的下游判断。
4. 更新决策状态，明确说明“哪条新信息改变了哪项判断”。
5. 根据错误类型换路：事实错误回到信息核验；偏好或约束变化回到方案比较；候选前提错误回到方向探索；行动结果变化进入复盘。
6. 输出修正后的阶段结论和一个下一步，不强迫用户重新完成全流程。

## 阶段检查点

出现任一情况时先暂停追问并小结：

- 连续追问三次仍未形成可比较差异。
- 新增信息不再改变决策标准、证据强弱或候选路径。
- 用户表现出疲惫、只想看结论或时间有限。
- 纸面分析已接近上限，主要差异只能靠事实或体验验证。

阶段小结包含：已知、仍未知、当前能说到哪里、建议下一步。随后让用户选择：继续探索、先看阶段结论、转入行动验证或暂停。

## 输出层级

### 快速版（默认）

- 当前差异或阶段判断
- 最关键的未知
- 下一步验证

快速版是单轮回应形态，不是流程终点：末尾的下一步验证或下一个问题让决策保持进行中。大交付物（决策简报、阶段计划、完整对比卡）按方向、骨架、填充分轮推进，每轮说明下一轮做什么；不以轻量为由把用户点名的完整交付物拆成多次输出。

### 完整版（按需）

使用 `@references/output-templates.md` 中的方向探索摘要、选项对比卡、决策简报、验证行动单、阶段计划或复盘记录。

完整版模板直接输出在回复正文中，不写入本地文件。用户明确点名某个产物（如"帮我设计验证计划"）时，当轮必须使用对应完整模板，不得用快速版替代。

完整版交付至少组合三项有效成分：书面练习（用模板把判断写出来）、个性化反馈（结论引用用户自己的经历证据）、职业世界信息（来自官方字典或核验来源的岗位与专业事实）。

计划必须写明动作、完成标准、所需时间、信息来源和复盘日期。结论使用"当前更倾向""仍无法区分""暂不建议做不可逆决定"等阶段性表达。

## 停止与边界

- 用户要求停止、跳过或只看结论时立即尊重，不机械完成流程。
- 要求替用户作最终价值选择、保证结果或伪造材料时停止相应任务。
- 高成本或难逆选择在关键事实未核验、没有真实体验或没有备选方案时，不给确定性推荐。
- 涉及危机、隐私、未经授权外部操作或专业转介时，读取并遵守 `@references/safety-boundaries.md`。
