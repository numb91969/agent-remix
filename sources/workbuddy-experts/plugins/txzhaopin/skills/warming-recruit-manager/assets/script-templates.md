# 保温话术模板库

本文件为场景 B 的话术正文模板，**不读入 context，按需 copy 对应模板使用**。

模板选择规则见 [../references/warming-scripts.md](../references/warming-scripts.md) 第 5 节"阶段判定与模板选择"。

同一候选人可能有多个合适模板，按优先级：**风险干预 > 阶段任务 > 日常陪伴**。

---

## S1_welcome — 首次欢迎话术

**适用场景**：刚签约、导师未绑定（`mentor_bound = false` AND `signed_time ≤ 7 天内`）
**建议渠道**：企业微信文字消息
**建议时机**：签约后 1-3 个工作日内，工作日 10:00-11:00 或 15:00-16:00

```
{候选人姓名}你好，

我是腾讯{BG/部门}的招聘经理{你的中文名}，很高兴正式和你建立联系！

恭喜你签约腾讯{岗位名称}岗位，团队上下都非常期待你的加入。

接下来从签约到入职这段时间，我会作为你的主要对接人，负责协调入职流程、同步团队信息，有任何问题随时找我。

{学术亮点/回巢认同/行业背景 Hook —— 根据画像注入}

接下来我会尽快为你安排一位导师{导师姓名}，他/她会在技术和团队融入上给你支持。入职前有任何疑问，随时跟我或导师沟通。

期待在{预计入职月份}月见到你！

{你的中文名}
腾讯{BG/部门} 招聘经理
```

**使用建议**：
- 发送后预期 24-48h 内会有回复
- 如 3 天无回复，可再发一条轻量问候
- 本轮重点在"建立连接"，不要追问是否有其他 offer

## S2_first_touch — 导师首次建联脚本

**适用场景**：导师已绑、首次沟通未发生（`mentor_bound = true AND first_contact_done = false`）
**建议渠道**：企业微信文字消息（由导师发送）
**建议时机**：导师绑定后 1 周内

```
{候选人姓名}你好，

我是腾讯{BG/部门}的{导师姓名}，接下来我会作为你的导师，在入职前后帮你熟悉团队和技术栈。

欢迎加入{团队/中心名称}！我们团队主要负责{业务方向简述}，技术栈涵盖{技术关键词}。

{学术深度/能力认同 Hook —— 根据画像注入，不引述面评原话}

入职前如果你有时间，可以先了解一下{推荐学习资料/技术文档}，不用有压力，入职后我们会有系统的培训安排。

有任何关于技术、团队或者工作生活的问题，随时在企微上找我。

期待和你共事！

{导师姓名}
```

**使用建议**：
- 导师发送后，招聘经理可同步跟进一条"已为你安排导师"的确认消息
- 本轮重点在"专业引路"，建立导师的专业认同感
- 高潜人才可由更高级别管理者追加一条欢迎消息

## S3_welcome_pack — 欢迎包发送话术

**适用场景**：已首次沟通、资料未发（`first_contact_done = true AND welcome_material_sent = false`）
**建议渠道**：企业微信文字消息 + 文件/链接
**建议时机**：首次沟通后 3-5 个工作日

```
{候选人姓名}你好，

距离你入职还有{天数}天，这边为你准备了一份入职欢迎包，包含以下内容：

📋 入职流程指南 —— 报到当天的时间安排和所需材料
🏢 办公环境介绍 —— 办公地点、工位区域、食堂/交通指引
📖 团队新手手册 —— 团队架构、技术栈入门、常用工具
🎁 新人福利清单 —— 宿舍/补贴/保险等福利说明

{落地关怀 Hook —— 如果工作地与归属地不一致，补充住宿/交通协助信息}

建议入职前一周通读一遍流程指南，提前准备好报到材料。如果有任何不清楚的地方，随时问我。

期待你正式加入团队的那一天！

{你的中文名}
```

**使用建议**：
- 确保所有链接和文件在发送前可正常访问
- 如候选人未回复，3 天后可由导师接力提醒一次
- 临近入职 30 天时建议再发一次入职倒计时话术（S5）

## S4_routine — 月度关怀

**适用场景**：日常陪伴期（`welcome_material_sent = true AND days_to_entry > 30`）
**建议渠道**：企业微信文字消息
**建议时机**：每月 1 次或每 2-3 周 1 次，工作日 10:00-11:00

```
{候选人姓名}你好，

最近一切顺利吗？距离你入职还有{天数}天，想跟你同步一下近况。

{团队动态/行业资讯/学习资料 —— 选 1-2 项，如团队近期成果、技术分享、行业新闻}

{长周期陪伴 Hook —— "离入职还有一段时间，团队这边会陆续同步信息"}

毕业论文/答辩/手续那边如果有什么需要协调的，随时告诉我。入职时间如果有变动也不用担心，我们这边可以灵活配合。

有什么我能帮到你的，随时说 :)

{你的中文名}
```

**使用建议**：
- 保持轻量、开放式，不追问是否有其他 offer
- 间隔 ≥ 14 天未互动时改用 S6_reengage 重新建联话术
- 每次同步的信息要有实质内容，避免空泛问候

---

## S5_pre_entry — 入职倒计时话术

**适用场景**：临近入职（`0 < days_to_entry ≤ 30`）
**建议渠道**：企业微信文字消息 + 电话/语音（建议至少 1 次 1v1）
**建议时机**：入职前 30 天 / 14 天 / 7 天 / 3 天，分阶段发送

```
{候选人姓名}你好，

入职倒计时{天数}天！这边有几件准备事项想提前跟你对齐：

✅ 报到材料：身份证、毕业证/学位证、银行卡、体检报告（详见欢迎包指南）
✅ 入职时间：{预计入职日期}，上午 {时间} 到 {办公地点} 报到
✅ 交通住宿：{落地关怀 —— 住宿安排/交通指引/报到当天联系人}

{临门一脚 Hook —— "入职临近，有几件准备事项想提前跟你对齐"}

入职当天会有专人在前台接应你，帮你办理工卡、领电脑、安排工位。导师{导师姓名}和直接上级{上级姓名}也会在团队等你。

最后几天如果有什么变动或需要协助的，第一时间联系我，我来协调。

期待很快见到你！

{你的中文名}
```

**使用建议**：
- 30 天 / 14 天 / 7 天 / 3 天 各发一次，内容递进（材料→时间→当天安排）
- 7 天内建议追加 1 次 1v1 语音沟通，确认最终入职意向
- 如候选人有犹豫信号，立即升级为 S7_risk_check 风险干预

## S6_reengage — 重新建联话术

**适用场景**：长期未互动（`days_since_last_interaction ≥ 14`）
**建议渠道**：企业微信文字消息
**建议时机**：发现 ≥ 14 天未互动后尽快发送

```
{候选人姓名}你好，

有一阵子没联系了，最近怎么样？

{重新建联由头 —— 选一个自然切入点：
  a) "团队最近在做{项目/技术方向}，想到你可能会感兴趣"
  b) "看到你学校/专业最近有个{新闻/赛事}，很厉害"
  c) "入职流程这边更新了一些信息，想同步给你"}

距离你预计入职还有{天数}天，想确认一下你那边的情况是否顺利。如果有任何变动或需要调整的地方，随时跟我说，我们这边可以配合安排。

有什么我能帮到你的，随时找我聊 :)

{你的中文名}
```

**使用建议**：
- 以"近况同步/入职准备"为由头，避免问责式表达
- 不直接追问是否有其他 offer，用开放式问题引导候选人主动分享
- 如连续 2 次无回复（间隔 3-5 天），升级为 S7_risk_check 并由招聘经理亲自跟进

## S7_risk_check — 风险干预话术

**适用场景**：有风险信号（`risk_level = high`，如 `cm_fb_result` 非空、拒签原因出现、沟通意愿明显下降）
**建议渠道**：电话/语音沟通为主，企微文字为辅
**建议时机**：发现风险信号后 24h 内，由招聘经理亲自出面

```
{候选人姓名}你好，

最近收到你的一些反馈，想跟你认真聊一聊。

我理解签约后到入职这段时间，你可能会有一些新的考虑或顾虑，这完全正常。我想做的不是给你施压，而是想了解你真实的想法，看看我们这边有没有能配合调整的地方。

{关怀问询 Hook —— 不直接指出顾虑，用开放式问候引导}

如果你方便的话，我想约你一次 1v1 的语音沟通，{建议时间}，大概 20-30 分钟，咱们聊聊：
- 你目前的想法和顾虑
- 团队这边能提供的支持和调整
- 入职时间和安排上是否有需要灵活处理的地方

不管最终你的决定是什么，我都希望你能做出对自己最好的选择。我们这边会尽力配合。

期待和你聊聊。

{你的中文名}
```

**使用建议**：
- ⚠️ 此模板由**招聘经理亲自**发送，不委托导师或上级
- 优先用电话/语音，文字消息仅作为约沟通的引子
- 沟通中不承诺具体 offer 条款，但可表达团队调整意愿
- 沟通后如实记录候选人反馈到 `cm_feedback`，便于后续追踪
- 高潜人才的风险干预可升级由更高级别管理者参与

## 模板选择优先级

当多个模板同时适用时，按以下优先级取第一个：

| 优先级 | 模板 | 条件 |
|---|---|---|
| 1（最高） | S7_risk_check | `risk_level = high` |
| 2 | S1_welcome | `mentor_bound = false AND signed_time ≤ 7 天` |
| 3 | S2_first_touch | `mentor_bound = true AND first_contact_done = false` |
| 4 | S3_welcome_pack | `first_contact_done = true AND welcome_material_sent = false` |
| 5 | S5_pre_entry | `0 < days_to_entry ≤ 30` |
| 6 | S6_reengage | `days_since_last_interaction ≥ 14` |
| 7（最低） | S4_routine | 默认日常陪伴 |

---

## 合规红线（所有模板通用）

- ❌ 不涉及薪酬具体数字
- ❌ 不涉及具体团队/项目名承诺
- ❌ 不出现"保证 / 一定 / 绝对"等绝对化表达
- ❌ 不引用候选人未公开的个人信息（GPA、家庭情况等）
- ❌ 不让候选人做放弃其他 offer 的书面承诺
- ❌ 不引述面评中对候选人的负面描述
- ❌ 敏感字段（手机号、身份证等）不出现在话术中
- ✅ 所有个性化 Hook 来自画像特征，不编造不存在的信息

详细禁用语清单见 [../references/warming-scripts.md](../references/warming-scripts.md) 第 8 节。
