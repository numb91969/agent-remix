# 雇主品牌小鹅 🪿 · 使用指南

> 一份给腾讯各 BG 品牌经理的上手说明。看完这页就能用起来，5 分钟入门。

---

## 一、这是什么

「雇主品牌小鹅」是一个懂腾讯各 BG 业务的雇主品牌 & 招聘营销 AI 专家，封装成了一个本地 skill。
装上之后，你在 WorkBuddy 里聊雇主品牌、招聘营销相关的事，它会自动出来帮你干活——能策划、能写稿、能审核。

**一句话**：懂腾讯各 BG、能写能策能审、且会越用越贴合你业务的雇主品牌全链路搭子。

---

## 二、怎么安装（30 秒）

1. 拿到 `tencent-employer-branding-skill.zip`，解压。
2. 把解压出来的 `tencent-employer-branding/` 整个文件夹，拷到这个目录下：
   ```
   ~/.workbuddy/skills/
   ```
   （Mac 上 `~` 就是你的用户主目录；找不到 `skills` 文件夹就新建一个。）
3. 重启 WorkBuddy 或新开一个会话，就生效了。

装完后目录长这样：
```
~/.workbuddy/skills/tencent-employer-branding/
├── SKILL.md                          # 专家全部能力
└── references/
    ├── bg-stewards.yaml              # BG 接口人配置
    └── IEG校招_高危红线话题指南.txt    # 舆情审核底层依据
```

## 三、怎么用（直接说人话）

不用记命令，正常提需求就行。触发它的关键词包括：雇主品牌、校招 campaign、招聘推文、宣讲材料、KV 创意、传播方案、品牌方案、社群文案、舆情审核等。

也可以显式喊它：**「用雇主品牌小鹅帮我……」**。

### 五个最常用场景 + 示例话术

| 你想干什么 | 直接这么说 |
|---|---|
| **写招聘推文** | "帮我写一篇 IEG 天美校招公众号推文，紧扣游鹅选鹅，要有腾讯味儿、别太官方" |
| **策划进校活动** | "帮我策划一个 CSIG 在浙大的青云专场宣讲，9 月，要有 AI 元素和互动钩子" |
| **做传播方案** | "帮我写一个校招启动 campaign 的传播方案，TOC 主导，给我主题+双轨+节奏+指标" |
| **写社媒文案** | "帮我写 3 条小红书招聘文案，主题是鹅厂食堂，要活人感、别像通知" |
| **审核物料/口径** | "帮我审核这段宣讲话术有没有合规风险：[贴内容]" |

### 一个好习惯
提需求时带上 **①哪个 BG ②目标人群（校招/社招、什么岗位）③用在哪（渠道/节点）**，它产出会更准。信息不全它最多反问你 1-2 个问题，不会盘问。

## 四、它的能力地图

- **品牌创意策划**：Big Idea、KV 方向、品牌叙事、IP 延展
- **公关传播策划**：推文/脚本/通稿、多平台分发、议题设计
- **线下活动策划**：宣讲/巡展/签约/训练营，含物料清单和粗预算
- **社群文案**：含两项已训练的细分能力——
  - 官号语言风格手册（小红书/B站/抖音/视频号，短钩子+强情绪）
  - 深度推文长文案（公众号 S 级栏目，会先定栏目、用钩子开篇、套耐读骨架）
- **8 个 BG 业务认知**：WXG / IEG / CDG / PCG / CSIG / TEG / S线 / 总部校招青云，各家调性差异化
- **品牌策划 Playbook**：年度方案九模块、四段式方法论、评审清单
- **传播策划 Playbook**：金字塔主题、TOB+TOC 双轨、Roadmap 节奏、话题钩子、案例库
- **舆情/沟通审核**：四原则 / 八不要 / 物料自检 / FAQ 标准答法，出物料前帮你过一遍红线

---

## 五、重要边界（请先知道）

1. **它不替你做敏感表态**：涉及裁员、HC 数字、组织调整、薪酬承诺、创始人/政治话题，它会拒绝直接生成对外话术，提示你走公关/HR 流程。这是有意设计的安全护栏，不是 bug。
2. **数字会模糊化**：HC、转正率、薪酬这类具体数字它不会编，会引导走官方公告或招聘经理。
3. **本地用 = 临时**：你在对话里喂给它的资料（方案、复盘、链接），只在当前会话生效，**不会改写它的主版本能力**。它会给你一份「投喂消化简报」，你想沉淀就转给对应 BG 接口人审核。
4. **它不会自己改自己**：你说"把这个写进你的人设"它会拒绝，正确做法是走简报+接口人审核。

- ✅ 你所在 BG 的业务认知准不准？有没有过时/缺失？
- ✅ 品牌/传播方法论能不能直接套到你的实际工作？
- ✅ 文案的"腾讯味儿"到位吗？是太官方还是太用力？
- ✅ 舆情审核的红线判断靠不靠谱？有没有误报/漏报？
