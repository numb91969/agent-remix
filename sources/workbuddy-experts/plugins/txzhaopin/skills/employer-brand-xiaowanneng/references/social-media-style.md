# 社媒短文案语言风格手册

> 来源：基于腾讯招聘官号（小红书 / B站 / 抖音 / 视频号）真实文案样本提炼。适用于「小完能」在处理社媒平台招聘内容时调用。

## 1. 人设核心

把官号写成一个会说人话的"鹅"，不是冷冰冰发布器。

- 常用自称："鹅""小鹅""抽象员工""天才同事"
- 整体气质：**有活人感、会自嘲、会接梗的同事感**
- 不是 PR 通稿机器人，不是硬凹年轻的尬聊者
- 读者看完的感觉应该是"这个账号背后坐着真人"

## 2. 标题打法

优先用"情绪钩子 + 反差场景 + 口语问题"起手，**少用传统官宣标题**。

### 四种高频写法

| 类型 | 特征 | 示例 |
|---|---|---|
| **生活切口** | 用具体日常场景降低距离 | "在鹅厂食堂，来份免费火锅……"<br>"腾讯最神人的工位，我帮你们找到了" |
| **抽象叙事** | 用"抽象员工/神人"等梗制造好奇 | "腾讯抽象员工在浙大雷霆薅鸡蛋的一天"<br>"全网最神人的老资历🐧" |
| **强节奏梗化** | emoji + 梗 + 节奏感 | "⚡当我用古法鬼畜来推荐 AI 岗位⚡"<br>"⚡25 年末梗和 26 年初梗的完美融合⚡" |
| **提问/邀约式** | 直接向读者发问引发互动 | "你们会不会字多不看呀😧"<br>"你最期待发布会上的哪款游戏？" |

标题判断标准：**读者看到第一眼会不会想点开？** 如果像企业新闻通稿标题，重写。

## 3. 正文语气与结构

先像朋友聊天，再自然带出招聘信息。

**常见结构：**

> 一个具体画面 / 吐槽开头 → 讲故事或讲感受 → 带出直播 / 活动 / 岗位 / 投递动作

**避免：** 一上来就官宣口吻（"近日，我司隆重举办……"）。

正文里允许出现：
- 吐槽自己、吐槽工作日常的自嘲
- "说实话""讲真""不瞒你说"这类口语过渡
- 对话感（"你有没有想过……""是不是很离谱"）

## 4. 高频修辞动作

- **短句断行、口语停顿、留白分隔**——增强节奏感，适合移动端扫读。
- **合理使用 emoji** 做语气词和情绪钩子：🐧 👏 😧 ⏰ 🔥 ⚡。但不要满屏堆砌，emoji 是调味不是主菜。
- **自问自答、转折、反差**："今天还直播吗？答案是——继续。"
- **适度自嘲和拟人**："你带故事，我带嘴"、"求个好评哇"、"好吧，我说这么多其实是想问大家可否三连互动一下~"

## 5. 内容母题

高频出现的五类选题方向：

| 母题 | 说明 | 适用场景 |
|---|---|---|
| **食堂 / 园区 / 工位 / 日常生活** | 用具体生活场景降低距离感 | 日常运营、品牌温度 |
| **抽象员工 / 同事群像** | 用人物感和梗感替代传统雇主品牌说教 | 人物故事、团队展示 |
| **直播预告 / 互动征集** | 提前抛问题，邀请用户带故事/图片/问题进直播间 | 活动预热、互动拉新 |
| **校园行 / 游戏 IP 联动** | 把岗位曝光包装成线下好玩活动，而不是纯宣讲 | 校招季、游戏工作室 |
| **长视频播客式人物故事** | 用真实履历、非典型经历、第一性原理强调启发性和陪伴感 | 深度内容、人物访谈 |

## 6. 平台适配规则

同一件事在不同平台的表达要有差异，不是一篇稿到处发。

### 小红书

- **标题**要更像一句会让人点开的口语反应
- 封面字和首句要抓情绪，适合"我发现…""原来…""这也太…"这类轻表达
- 正文偏**情绪钩子 + 轻口语**，信息密度适中
- 话题标签（#）是重要流量入口，需精心选

### B站

- 可以更**抽象、更二创、更鬼畜**
- 允许标题更长、更梗化
- 正文可以更像 **live 感聊天或 vlog 独白**
- 弹幕文化可融入（"前方高能""弹幕护体"）
- 适合做系列内容（连载、合集）

### 抖音

- 保留抽象梗和强钩子，但**句子更短，信息更前置**
- **3 秒内要给到冲突点或画面点**
- 适合快节奏、强视觉的内容
- 字幕/封面文字比正文更重要

### 视频号

- 比 B站**更克制**、比公众号**更松弛**
- 保留温度感和口语感，但减少过密梗和过度鬼畜
- 适合"**真诚分享 + 轻互动 + 顺带转化**"
- 受众年龄层偏广，用梗需考虑大众理解度

## 7. 转化收口规则

岗位 / 投递 / 直播预约信息**不要一开始硬砸出来**，而是放在故事后半段自然出现。

常用收口方式：

- "欢迎大家来直播间互动"
- "和我们一起做同事"
- "0 经验也能来参加"
- "投递链接在评论区/主页"

**原则：先建立情绪连接，再给行动入口。**

## 8. 禁忌提醒

- ❌ 不要写成传统 PR 稿
- ❌ 不要堆内部黑话（除非目标受众能看懂）
- ❌ 不要过度玩梗导致信息点丢失
- ❌ 不要只剩热闹没有岗位价值
- ❌ 不要为了年轻化而低幼化
- ❌ 不要踩低友商或行业（只做加法不做减法）
- ❌ 不要用"工具人""螺丝钉""把你当产能"等内部吐槽视角对外表达

## 9. 默认输出要求

当用户让你写小红书 / B站 / 抖音 / 视频号的招聘内容时：

1. 默认先给出一个**"活人感标题"**
2. 正文必须有人物、场景或情绪切口
3. 再植入岗位 / 活动信息
4. **不要直接写成通知公告**

## 与公众号文案的关系

| 维度 | 社媒短文案 | 公众号深度推文 |
|---|---|---|
| 核心目标 | 短钩子 + 强情绪 + 即时互动 | 长留存 + 建立信任 + 说清一件事 |
| 阅读时长 | 30 秒 - 2 分钟 | 5 - 15 分钟 |
| 结构 | 一击即中 | 有起承转合 |
| 同一个梗 | 一句标题 | 展开成故事/答疑/群像 |
| 转化路径 | 点链接 / 进直播间 / 关注账号 | 阅读完成 → 底部 CTA |

**写公众号长文时不要把社媒文案拉长，换一套"耐读"的结构。** 公众号深度推文请继续使用 style-youe.md / style-qingyun.md 的写作引擎。
