## 1. 内核归因

```
EVP：这一局，由你主导（Play your Game）
        │
        ├── 顶尖战场（舞台）── 你的作品被全球玩家看见
        ├── 成长快（主角感）── 年轻人成长快，校招生也能独当一面
        ├── 大神同行（队友）── 团队藏龙卧虎，纯粹热爱、追求极致
        └── 够稳健（底盘）── 业务扎实有规划，职业路径看得见
                        │
                游鹅选鹅的底气
```

**两组归因象限：**

| 象限 | 支柱 | 回答的问题 |
|---|---|---|
| **环境够顶** | 顶尖战场 + 大神同行 | 腾讯游戏多强？ |
| **对我够好** | 成长快 + 够稳健 | 对我多值？ |

**一句话对外内核：**

> **游鹅选鹅——顶尖战场，大神同行，这一局由你主导。**

## 3. 支柱一金句库：顶尖战场

**打"成就感"与"势能"**

- **高阶观点**："你的才华，配得上世界级的舞台。"
- **高阶观点（补充）**："在别处你的作品是简历上的一行，在这里它是几千万人的周末。"
- **文案抓手**："做影响世界的爆款" / "让世界，玩到你的名字"

### 推文 / 采访金句库

> "判断一个想法值不值得做，我们只问一句：它能不能让全世界的玩家，愿意为它熬一个通宵。"

> "你做的不是一个版本、一个皮肤，你做的是几千万人下班后最想打开的那个图标。"

> "在 IEG，'上线'两个字的分量，是全球服同时点亮的那一刻——你会记一辈子。"

> "别人问你做什么的，你可以指着应用商店榜首说：那个，我做的。"

> "我们要的不是把游戏做完的人，是想让自己的作品，出现在地球另一端某个玩家屏幕上的人。"

## 4. 支柱二金句库：校招跑得快

**打"个人价值"——以好玩为绝对标准的共识圈层**

要夸年轻人"升得快、跑得快、贡献大"时，一定顺手夸一句带他的导师 / 团队有多么包容、专业、格局。

- **高阶观点**："在这里，资历不是天花板，玩家说了算才是。"
- **文案抓手**："年轻不是被照顾的理由，是被听见的底气" / "好点子不问工龄"

### 推文 / 采访金句库

> "不论年资，不论层级。当提案摆在桌上，大家只有一个共识：哪个更能让玩家觉得爽，就听哪个的。"

> "在 IEG，最动人的不是'后浪推前浪'，而是新锐灵感与老兵经验碰撞出的巨大能量。"

> "最牛的团队，就是敢让新人提最疯狂的想法，并且有老兵陪着他们把疯狂变成现实。"

> "在 IEG 跑得快，有身经百战的'大神'在下面托住了你。"

> "在 IEG，新人最爽的瞬间，是自己提的那个'疯狂想法'，真的被做进了游戏里，还被玩家夸了。"

> "我们不让新人'先熬三年再说'，我们让新人'先上手，大神在旁边兜底'。"

> "成长快的秘密不是被催着跑，是有人愿意把真正重要的事交给你，再陪你把它做成。"

> "在这里衡量你的，不是来了几年，是你让玩家多爽了几分。"

> "最好的成长，是你提的方案被采纳那天，采纳它的人比你还兴奋。"

## 6. 支柱四金句库：够稳健

**打"安全感"与"确定性"**

年轻人怕的不是辛苦，是"辛苦了却不知道通向哪"。这一柱给的是**底气**——让前三柱的热血有一个能长期燃烧的底盘。

- **高阶观点**："敢让你放心热爱的平台，才配得上你的长期主义。"
- **文案抓手**："把热爱，做成一辈子的事。" / "热血可以一时，我们想陪你打很多年。"

### 推文 / 采访金句库

> "好游戏不是赌一把，是日复一日打磨出来的——所以我们也不赌你的成长，我们陪你慢慢变强。"

> "在 IEG，你不用担心'做完这个项目去哪'，因为这里永远有下一个值得你 all in 的好局。"

> "我们不追风口，我们做能陪玩家走很多年的游戏——也想做能陪你走很多年的平台。"

> "热爱能不能当饭吃？在 IEG，能，而且这碗饭，够你吃很久。"

> "真正的稳，不是一成不变，是无论行业怎么变，你手里始终有能打的牌、脚下始终有站得稳的地。"

> "我们给你的不是一份'先干着看看'的工作，是一条你能看清下一步、下下一步在哪的路。"

## 7. 对外翻译原则（只做加法不做减法）

**核心原则：对外话术只做"加法"（我们有什么），不做"减法"（别人没什么）。**

学生痛点心里清楚就行，话术里不点破——用我们的优势正面回应，比踩别人更高级，也更安全。

### 禁用的内部吐槽视角 → 可用替代

| 禁用（内部吐槽视角） | 问题 | 替代为（正向对外） |
|---|---|---|
| 不被当工具人 | 暗示别处把人当工具人，踩低行业 | 一进来就有人带你打真正的项目 |
| 不是螺丝钉 | 同上，负面预设 | 你的想法有最大的舞台 |
| 把你当人，不只当产能 | "产能"是内部黑话+负面 | 因为热爱聚在一起，也被好好照顾 |
| 游戏行业起起落落 | 主动提行业风险，反向劝退 | 平台够稳，陪你打长线 |

### 四支柱文案抓手全景（连起来是一条情绪线）

| 支柱 | 核心抓手 | 情绪 |
|---|---|---|
| 顶尖战场 | 做影响世界的爆款 / 让世界玩到你的名字 | 够燃 |
| 校招跑得快 | 好点子不问工龄 | 我能行 |
| 与大神同行 | 和一群疯子，做让世界疯狂的事 | 有同类 |
| 够稳健 | 把热爱，做成一辈子的事 | 够安心 |

**有舞台 → 我能行 → 有同类 → 能长久**，四柱合起来既够热血，又给得了底气。

## 8. IEG 内容落地锚点

使用游鹅选鹅内核时，优先从以下角度切入：

- **强极客化**：宣传垂直领域做到极致的"神仙"和"怪才"
- **纯粹职场人设**：传达 IEG 是"对游戏痴迷者绝对友好的团队环境"
- **游戏 IP 联动**：王者/和平精英/英雄联盟等 IP 的雇主品牌化使用
- **工作室文化**：天美/光子/北极光/魔方等不同工作室的气质差异
- **玩家共鸣**：用"玩家"身份建立候选人与业务的情感连接

## 9. 栏目质检

使用游鹅选鹅内核时，逐项检查：

- [ ] 内容是否命中至少一个支柱（顶尖战场/成长快/大神同行/够稳健）
- [ ] 对外表达是否只做加法、没有踩低行业或友商
- [ ] 是否避免了"工具人/螺丝钉/产能"等内部吐槽视角
- [ ] 金句是否有故事或事实托底（不只是空洞口号）
- [ ] 是否保留了 IEG 的游戏感和热爱气质
- [ ] EVP 归因是否清晰（最终回到"这一局由你主导"）
