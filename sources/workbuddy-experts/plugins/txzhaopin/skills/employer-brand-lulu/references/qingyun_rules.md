## 关键规则速览

### ⑤ 友商提及（零容忍）

青云课题为对外宣传材料，友商名必须删除。
- 完整友商清单见 terminology.yaml

### ⑦ 不合理高门槛

- 论文≥3篇顶会一作 → 不合理
- 工作经验≥2年 → 不合理
- "有顶会论文经验优先" → 合理（弹性表述）
- ⚠️`要求1篇一作顶会`（即使必选）→ **合理，不标红**。青云面向硕博可达标；只有过量（≥3篇/多篇/6篇）才不合理。

### 前置：先按"需求确认"列过滤范围
表内若有"保留不变/沿用旧版""非大模型/不报课题"标记 → 本轮不审。只审"新增/修改/空"。

### 字数尺度
描述超600字很普遍，只标特别夸张(≥1000字)，600-950字不标。

### ⑩ 招聘要求写法规范（易漏，务必单独过一遍）
- **编号**：应按"1. 2. 3."。用"- 项目："、纯换行、冒号式的 → 标🟡并给编号版改写稿。
- **三段式**：学历专业 / 技术技能 / 软性素质。缺软性素质等 → 💡建议补充。
- **过简/残缺**：仅1-2句、几十字、缺学历专业或技能（如"编程基础扎实/有兴趣"这类泛化短句）→ 🟡，给补齐改写稿，缺的要素用`【建议补充：xx】`占位不编造。
- **模板重复**：多条招聘要求雷同 → 提示差异化。
- ⚠️踩坑：第一轮易只查内容合规(友商/院校/门槛)，漏掉招聘要求写法规范，务必补查。

### 表格操作踩坑
- 读/写某列前先抽查真实值验证：列名可能与内容不符(踩坑:招聘经理实际在O列非N列，N列是工作地点)。
- 回写审核结果用openpyxl从原表真实末列后新增列，别覆盖原有列(如"雇主反馈")；输出新文件不覆盖原始待审文件；缺的要素用【建议补充:xx】占位。

### ⑧ 院校歧视

禁用词：985/211/双一流/C9/顶尖院校/知名院校/名校/重点大学

### ⑨ 实习时间

"实习≥X月""每周≥X天""全职实习优先"等均不宜出现在宣传材料中。
