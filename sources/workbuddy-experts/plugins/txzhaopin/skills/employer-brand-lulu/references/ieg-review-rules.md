# IEG 雇主品牌审核规则（特化版）

> 基于 IEG 游鹅选鹅对外表达的实战审核经验沉淀。
> 适用场景：IEG 校招进校活动、宣讲会、空宣直播、海报/推文等对外物料。

---

## 一、IEG 核心红线（在通用六不要基础上叠加）

### R-IEG1 ⚠️ 保密产品对外展示确认

**这是 IEG 最高频踩雷点。**

- **强制动作**：任何对外材料中出现具体游戏产品名 / 项目代号时，必须标注：
  > ⚠️ **请与业务团队确认：该产品/项目是否可对外展示？是否已获得对外披露授权？**
- **典型风险场景**：
  - 进校宣讲 PPT 中放了未公开新游的截图/Logo/名称
  - 嘉宾介绍中提到"参与了 XX 项目"而该项目尚未官宣
  - 海报/推文中使用了未上线产品的美术素材
- **审核输出格式**：
  - 🔴 必须修改：已明确不可对外展示的产品信息 → 建议替换为已公开产品或模糊化处理（"某头部 MOBA 产品""某开放世界项目"）
  - 💡 待确认：无法判断是否可对外 → 标注"需业务团队确认授权状态"

### R-IEG2 友商产品名字零容忍

**比通用规则更严格——IEG 行业特性导致友商提及概率更高。**

| 禁止层级 | 规则 | 示例 |
|---------|------|------|
| 🔴 绝对禁止 | 出现竞品**公司名字** | "米哈游""网易游戏""暴雪" |
| 🔴 绝对禁止 | 对竞品做**直接评价/对比** | "比XX做得好""XX的XX功能不行" |
| 🟡 高度敏感 | 题目/内容中**针对具体竞品游戏做玩法/运营拆解** | "原神的抽卡机制分析""永劫无间的战斗系统研究" |
| ✅ 可接受 | 考察候选人对**行业大品类的研究** | "你对开放世界品类有什么看法？""MOBA 品类的未来趋势" |

**实操判断标准**：
- 青云课题题目如果出现具体竞品游戏名 + 拆解其玩法/运营 → 🟡 建议改为品类层面讨论
- 面试题中提到竞品作为背景知识（如"你玩过哪些游戏"）→ ✅ 正常
- 宣讲/推文中任何形式的竞品对比 → 🔴 必须删除

### R-IEG3 IEG 进校活动专项

> 完整规范详见内部文档「IEG 进校审核规范」（本地调用，对外不暴露来源）。
> 以下为已内化的核心审核要点：

#### 3.1 进校宣讲 PPT 加审项

| 维度 | 规则 | 级别 |
|------|------|------|
| **保密产品** | 所有出现的游戏产品名/截图/Logo，逐一确认对外授权 | 🔴 |
| **嘉宾内容** | 技术嘉宾分享内容不含未公开项目细节、不暴露内部工具链 | 🔴 |
| **院校互动** | 不做院校排名对比、不暗示"某学校更好" | 🟡 |
| **现场环节** | 互动问答预设 QA 不含敏感问题（薪酬、加班、竞品对比） | 🔴 |
| **伴手礼/物料** | 周边礼品不含未授权 IP 元素 | 🔴 |

#### 3.2 进校活动文案加审项

| 维度 | 规则 |
|------|------|
| 学校名称 | 使用官方全称，不加主观修饰（"顶级""最好"） |
| 活动描述 | 不夸大参与收益（"参加就能拿 offer"类表述禁用） |
| 转发语/邀请函 | 不含内部流程细节（面试轮次、审批时间等） |

### R-IEG4 空宣直播专项

> 完整规范详见内部文档「空宣直播规范」（本地调用，对外不暴露来源）。
> 以下为已内化的核心审核要点：

#### 4.1 直播前审核清单

| 维度 | 规则 | 级别 |
|------|------|------|
| **直播标题** | 不含夸张承诺（"来了就录用""保offer"） | 🔴 |
| **主播/嘉宾口播稿** | 逐句过审，重点查：薪酬暗示、加班表态、竞品提及、未公开信息 | 🔴 |
| **弹幕管理预案** | 是否准备了敏感问题应对话术（薪酬/裁员/竞品/加班） | 💡 |
| **屏幕共享内容** | 共享的 PPT/代码/编辑器界面不含保密信息 | 🔴 |
| **背景环境** | 直播背景不含未公开产品海报/白板上的内部代号 | 🟡 |

#### 4.2 直播中高频风险话术

| 风险类型 | 危险表述示例 | 安全替代 |
|---------|-------------|---------|
| 薪酬暗示 | "我们的薪资很有竞争力" | "我们提供有吸引力的综合回报" |
| 加班表态 | "基本不加班" / "看项目" | "我们关注工作与生活的平衡" |
| 承诺性 | "投了就有机会" | "欢迎投递，我们会认真评估每一份申请" |
| 竞品比较 | "比别家更自由" | "我们重视创作者自主性" |

## 三、IEG 审核输出模板

当识别到 IEG 相关内容时，在通用审核报告基础上追加：

```markdown
## 🎮 IEG 特化审核补充

### 保密产品检查
- [ ] 已逐项确认所有产品名/截图的对外授权状态
- 发现 X 处待确认项（见上方 💡 标注）

### 竞品规避检查
- [ ] 无竞品公司名
- [ ] 无直接竞品评价/对比
- [ ] 青云课题/面试题中的竞品引用已改为品类层面讨论

### 进校/直播专项（如适用）
- [ ] 嘉宾口播稿已逐句过审
- [ ] 弹幕/互动预案已准备
- [ ] 屏幕共享内容无泄密风险
```
