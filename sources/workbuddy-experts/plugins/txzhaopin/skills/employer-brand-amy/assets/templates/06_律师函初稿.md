# 场景模板⑥：律师函初稿（删帖/打码维权）

> 经理说法："这条造谣的要出律师函" / "脉脉/小红书有不实信息要删，帮我起个律师函" / "实名被曝光了要打码"
> 配套：`references/分平台删帖与维权处置指南.md`（⭐⭐ 平台差异）+ `references/历史案例话术库.md`
> 适用：场景3处置中判定"严重"（造谣不实/实名曝光/已发酵）需走删帖/打码维权时。

## 一、先选函的类型（两种）

| 类型 | 发给谁 | 用途 | 何时用 |
|------|--------|------|--------|
| **A. 协助删除函**（致平台） | 脉脉 / 小红书 / 微博等**平台方** | 要求平台**协助删除/屏蔽/断链**侵权内容 | 主流：走平台投诉删帖（本次范本即此类） |
| **B. 警告/告知函**（致发帖人） | 发帖的**个人/账号** | 要求其**自行删除、停止侵权、消除影响** | 能定位到发帖人、或平台路径走不通时 |

> 多数雇主品牌 case 用 **A（致平台协助删除函）**——这也是脉脉/小红书删帖维权的标准动作。

## 二、律师函必备 7 要素（缺一不可）

1. **抬头**：律所名称 + 地址（受腾讯委托方）
2. **标题 + 文号**：如「关于停止散布不实言论的协助函」+「(年份)XX律知函字 XXXX 号」
3. **致函对象**：平台（贵平台）或发帖人
4. **委托与事由**：律所受深圳市腾讯计算机系统有限公司委托，指派 XX 律师，就平台用户发布不实言论侵犯腾讯合法权益事宜致函
5. **事实陈述 + ⭐不实之处逐条对照**：说明涉事主体性质 → 平台用户发布了什么不实内容 → **逐条"帖称X / 实际Y / 故为不实"** + 侵权链接清单
6. **法律依据**（标准块，见 §四，可直接复用）
7. **声明诉求**（删除/书面反馈整改/保留诉讼追责）+ 落款（律所+日期+联系邮箱）+ 附件（维权授权书）

> ⭐ **关键优化点**：真实范本只列了"帖子名称 + 链接"。Amy 初稿应**在每条侵权内容后补一句"实际情况为……，故该内容失实"**，把"为何不实"写实——这是说服平台/法务采信、也是后续诉讼的事实底座。

## 四、标准法条块（直接复用，照录原文）

> 这 4 条是名誉权 + 网络侵权"通知-删除"规则的核心，几乎所有雇主品牌不实言论删帖均适用，Amy 可直接整段套入。

- **《民法典》第一百一十条**："法人、非法人组织享有名称权、名誉权和荣誉权。"
- **《民法典》第一千零二十四条**："民事主体享有名誉权。任何组织或者个人不得以侮辱、诽谤等方式侵害他人的名誉权。"
- **《民法典》第一千一百九十五条**："网络用户利用网络服务实施侵权行为的，权利人有权通知网络服务提供者采取删除、屏蔽、断开链接等必要措施。网络服务提供者未及时采取必要措施的，对损害的扩大部分与该网络用户承担连带责任。"
- **《民法典》第一千一百九十七条**："网络服务提供者知道或者应当知道网络用户利用其网络服务侵害他人民事权益，未采取必要措施的，与该网络用户承担连带责任。"

> 📌 1195/1197 是"通知-删除"规则的法律抓手：平台被通知后不及时删 → 承担连带责任，这是促平台配合删帖的关键压力点。

## 五、平台差异提醒（出函时同步告知经理生效预期）

| 平台 | 出函后预期 |
|------|-----------|
| **脉脉** | 删帖：**发律师函投诉成功后 → 先沉底（非搜索不可见）→ 48h 后删除**（网信办要求）。实名曝光：一律打码护隐私（**名字变 `***`**，本人投诉即可；他人协助打码也需本函）。 |
| **小红书** | 投诉成功 → **帖子立即删除**。若帖引用的原信息源已删 → 原源已删也可作删帖证据，可附入函中。 |

## 附：真实范本结构提炼 🔒（内部 few-shot，仅供学结构分寸）

> 来源：腾讯就脉脉"天美J2工作室被合并"不实言论出具的协助函（广东盾元律师事务所，2023.12.8）。**含真实主体/链接，机密，仅供学习函件结构与措辞分寸，不外传、不照抄具体内容。**

- **类型**：A 类（致脉脉平台·协助删除函）
- **结构**：抬头(律所) → 标题"关于停止散布不实言论的协助函" → 文号 → 致脉脉 → 委托事由(受腾讯委托/指派律师) → 事实(天美J2为腾讯内部工作室，平台用户发"被合并"消息不实) → 侵权链接清单(8条) → 4 条法条 → 三项诉求(逐条列8个话题/帖名+链接·书面反馈·保留追责) → 落款盖章+邮箱 → 附维权授权书
- **可借鉴**：①事实陈述极简克制(一句"内容不实，属虚假消息，对声誉造成不良影响") ②法条用 110+1024(名誉权) + 1195+1197(通知删除连带责任) 组合 ③诉求把每条侵权帖的"名称+链接"列全，便于平台精准定位删除
- **本模板优化**：原函未对每条帖"为何不实"作对照说明 → Amy 初稿应补"实际情况为X"，强化事实底座与说服力。
