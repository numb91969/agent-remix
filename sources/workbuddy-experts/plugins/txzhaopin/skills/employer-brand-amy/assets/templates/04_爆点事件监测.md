# 场景模板④：爆点事件监测（关键词驱动 · 多平台）

> 经理说法："有没有什么爆点事件？"（围绕用户提供的方向性关键词，如 字节/京东/腾讯/裁员/离职 等）
> 配套：`references/态势研判与走势预测模型.md`

---

## 触发识别
用户要求扫描某些**方向性关键词**下，全网有没有正在发酵或值得关注的爆点/热点事件。

## ⭐ 关键：方向性关键词由用户提供
- 用户给关键词（如"字节""京东""裁员""离职""应届生"），Amy 围绕这些词全网扫描。
- 如用户只说"看看有没有爆点"未给关键词 → **一轮反问**："想盯哪些方向？比如友商名（字节/京东）、议题（裁员/离职/校招），还是我们自己品牌？"

## 平台覆盖（6 大平台，全覆盖不跳过）

> 🟢 **没装 MCP/skill 也能跑**：下表带 MCP/skill 的平台，本地没装时**一律降级用 `web_search`**（平台内置、人人可用）。覆盖度略降但找帖/估热度/判断照常做，绝不因缺工具而不干活。

| 平台 | 工具（首选 → 降级） |
|------|------|
| 小红书 | web_search（site:限定/关键词，优先）/ 有截图直接读 / MCP 仅抓评论时用 |
| 脉脉 | agent-browser 深采（装了用）→ **web_search + site:maimai.cn**（没装的默认手段） |
| 视频号 | web_search + 微信生态搜索 |
| 公众号 | wechat-article-search skill（装了用）→ **web_search**（搜狗微信/关键词，没装的默认手段） |
| 微博 | weibo MCP（装了用，GET_TRENDINGS 看热搜）→ **web_search + site:weibo.com**（没装的默认手段） |
| 网媒/新闻 | web_search × 多轮 + web_fetch 验证 |

## 执行流程

```
① 确认/获取方向性关键词
    ↓
② 6 平台逐一扫描（关键词 × 平台矩阵）
    ↓
③ 筛出"爆点候选"：高互动/快增长/已上榜/媒体介入
    ↓
④ 每个爆点套研判模型快速打分（发酵概率+紧急度）
    ↓
⑤ 区分：与我品牌相关 vs 纯行业动态
    ↓
⑥ 输出《爆点事件监测报告》
```

## 要点
- **关键词驱动**，方向由用户定，Amy 不自行假设盯什么。
- **6 平台全覆盖**，微博必看热搜（GET_TRENDINGS）。
- 区分清楚"涉我品牌"（要处置）vs"纯行业动态"（参考/借势）。
- 友商负面可能是**借势机会**，但提示慎蹭（审时，避免落井下石招黑）。
- 每个爆点给明确动作建议，不只罗列。
