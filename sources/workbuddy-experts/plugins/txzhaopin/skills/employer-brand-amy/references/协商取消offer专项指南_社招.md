# 协商取消 Offer 专项指南（社招权威文档沉淀）

> 来源：团队官方文档《协商取消offer的专项讨论-针对社招》（集团组织优化背景下批量协商取消 offer 的权威 SOP）。
> 适用：**社招**协商取消 offer。实习生取消另见《Offer取消沟通指引》§八（规则不同：不主张赔偿、转推荐为主）。
> ⚠️ 核心法律性质：公司自身原因取消录用通知书 = **缔约过失责任**，每个 case 必拉 PR/ER/法务评估备案。

---

## 一、潜在风险（为什么这事高危）

### PR 侧 4 大高风险
1. **业绩质疑**（高）：寒冬中"取消 offer"比裁员更罕见，外界会看空公司运营。
2. **品牌形象**（高）：质疑诚信、对应聘者不负责、打乱求职节奏；违约谈判本身高关注。**求职者弱势形象易引发共情扩散 + 劳动仲裁**；个体补偿差异也可能因爆料引发次生危机。
3. **监管压力**（高）：可能被质疑违背国家"稳就业"政策、不担社会责任，引政府部门关注，极端个案风险。
4. **竞对相关**（中）：被曲解为"画饼抢人才再反悔"的恶意竞争。

### 法律侧
- 公司因自身原因取消 offer，违背承诺、损害应聘者信赖利益（为入职已与原单位解约等），违诚信原则 → **承担缔约过失责任**。
- 补偿无明确法定标准，按应聘者**实际经济损失**（原单位工资/股权/奖金、面试差旅等）+ 证明材料；无法举证时，**司法判例多酌情判 1-3 个月工资**。

## 二、对外引导口径（⭐⭐ 重要·记死）

### 总口径：绑定"组织优化"，不单独拆解、不说个案具体原因
- **候选人不知情时，对外一般不说明具体原因**，以"**组织架构调整等不可抗力**"为主因——避免暴露细节引发更大舆情发酵。
- 与整体组织优化项目**保持一致**，差异性风险点以**第三方方式**回应。
- 标准引导话术（第三方口吻）：
  > "一直以来我们秉持创业心态，根据社会发展和业务需求持续进行组织优化，保持人才合理流动……今年员工总数仍会维持增长。面对全球市场环境变化与产业结构调整，公司将以健康可持续为原则，强健肌体，为社会创造更多价值。"

### 三角度对冲素材
- **行业角度**：整体行业承压，取消部分 offer 是不得已（微软/Wayfair/京东等均有先例，降本增效是大趋势）。
- **公司角度**：高速扩张后沉淀有合理性；业务调整致岗位需求变化；同时**仍在能力匹配岗位正常发 offer**。
- **候选人角度**：切实承担雇主责任、保障权益、提供活水渠道、弥补损失。

### 子弹释放节奏
- **时间点：财报后**，与组织优化节奏对齐，避免单独拆解引发热度。
- 在组织优化解读稿中**前置**嵌入 offer 相关风险应对素材。
- 按舆情热度**有序释放**第三方解读稿 / KOL 稿 / 可视化物料；知乎微博净水投诉 + 对冲引导。

## 三、落地流程（招聘经理操作主线）

```
1 部门决定是否协商取消（是否敏感岗、是否引发过激行为；高风险人群取消需 ER/法务/公关单独评估）
    ↓
2 ⭐内部分流优先：内部其他业务有需求 → 先分流（变更部门即可，不用谈取消）
   · 分流避免周期过长影响体验：内部面试一次定、2 天内完成；认可可免面直接调岗
    ↓（分流不成）
3 Review 招聘流程，确认候选人是否符合录用标准：
   · 不符合录用标准 → 走公司正常取消 offer 流程
   · 符合录用标准 → 走协商取消补偿审批流程；沟通时表示"业务后续有用人需求会优先考虑该候选人"
    ↓
4 确认协商取消 → 招聘经理卷入集团 PR、ER、法务协调应对；整体动作与 PA、雇主品牌拉通
    ↓
5 协商一致 → 走法务邮件模板 + 薪酬接口人发函 + 候选人回执 + 付款 SOP（见§五）
```

> ⚠️ **协商同时必须暂停入职流程**：通知入职端暂停，避免"这边谈取消、那边推电子签约/办入职手续"。已定入职日期的联系 SDC 中止流程；**至少提前 1 天（建议 2 天）放弃入职流程**（入职当天/前一天会发合同电子签）。

## 四、补偿标准

| 候选人状态 | 申请补偿金范围 |
|-----------|--------------|
| 未提出离职 | 不高于 **1 个月** offer 工资 |
| 口头提出、未离职 | 不高于 **2 个月** offer 工资 |
| 已离职（不涉及迁居） | 不高于 **3 个月** offer 工资 |
| 已离职（涉及迁居） | 不高于 **3 个月** offer 工资 + 迁居成本 |

- **补偿金额以 kenny 审批金额为准**；offer 工资指**税前**；面试差旅费按正常报销。（⚠️ 审批人 kenny 可能随组织调整变化，**提交审批前请先联系 kathyliang 确认审批人是否有变化**）
- 补偿税务：此类民事补偿**暂作不征税处理**（非工资薪金/偶然所得），告知候选人**以到账金额为准**，税以国家最新规定为准、人选自行处理。
- 申请网站：fpp.woa.com/apply-guide；付款必须由经办人（招聘经理）主动发起、审批后付款。

## 五、正式邮件 + 付款 SOP（严格用公司模板）

```
步骤一：招聘经理用【法务提供的内容模板】完善信息（有补偿填补偿数据）→ 复制进邮件正文
步骤二：发送给薪酬接口人：
   · jerocai@tencent.com（无长期激励）
   · ozzhang@tencent.com（有长期激励）
   邮件需含：候选人姓名/邮箱、原计划入职时间、不晚于何时发出
   ⚠️ 取消邮件发出时间必须【早于候选人原计划入职时间】
步骤三：薪酬接口人向候选人发《协商一致取消腾讯公司录用 OFFER》邮件，抄送招聘经理+leader
   ⚠️ 务必核对候选人邮箱（尤其 QQ 数字邮箱），发错收件人有极大舆论风险
步骤四：候选人回执（固定格式确认+开户行/账户名/账号）→ 薪酬接口人转招聘经理 → 核对一致 → 推动付款
```

回执格式（候选人填）：
> 本人______，确认经双方协商一致，同意取消腾讯公司于__年__月__日发放的录用 offer，并同意补偿方案。本人已知晓并同意邮件内容及意思，自愿履行保密义务。账户信息：开户行/账户名称/账号。

## 六、关键 Q&A 铁律（招聘经理必记）

| # | 问题 | 答 |
|---|------|----|
| 1 | 公司要求把发出的 offer 都取消？ | **否**。只是提供工具/指引，是否用结合业务慎重决策 |
| 2 | 可单方通知取消再付补偿？ | **不可**。这是**协商解除**，必须充分坦诚沟通争取理解 |
| 3 | 先沟通再申请补偿？ | 可**预沟通**了解期望；**确切金额必须邮件获批后**才与候选人确认（避免谈的与批的不一致扩大风险） |
| 4 | 范围数量控制？ | **严格控制**，取消成本纳入**部门成本考核**，招聘 leader/BP/HRD 把控 |
| 5 | 每个 case 都要拉 PR/ER/法务？ | **是**。前期卷入评估风险 + 备案 |
| 6 | 内部分流？ | **优先分流**，能分流就不谈取消 |
| 7 | 用什么沟通？ | **公司座机电话**，尽量不书面，避免留记录、降风险 |
| 8 | 沟通陷入僵局？ | 卷入招聘 leader、ER 一起谈 |
| 9 | 有统一话术？ | 各 BG 原因/场景差异大，**BG 自行细化**话术 |
| 10 | 取消影响候选人入职其他腾讯岗位？ | **不影响**，仍可面其他岗并录用 |
| 11 | 沟通节奏？ | 先内部对齐，与内部人员优化同频 |
| 12 | 海外 offer 适用？ | **原则不取消**；需取消联动 ER/法务评估当地法律；超范围补偿 case by case 报 GM/HRD |

## 八、一句话总纲

> 社招协商取消 offer = **缔约过失·高舆情风险**。铁律：① 内部分流优先；② 必协商不可单方；③ 金额邮件获批后才谈、以 kenny 批为准；④ 座机沟通少留痕；⑤ 同步暂停入职、取消邮件早于入职日；⑥ 每 case 拉 PR/ER/法务+备案；⑦ 对外绑组织优化口径、财报后释放、不拆个案细节。
