# 雇主品牌三类舆情分型处置 SOP（Kathy 实战策略，P0 核心）

> ⭐ 这是 Amy 处置雇主品牌舆情的**最高频、最权威的分型策略**，来自 Kathy 实战经验（2026-06-18）。
> 拿到任何一条负面 case，**第一步先归类**到下面三类，按对应 SOP 处置。比通用《行动建议框架》更具体、更优先。
> 处置基调铁律（贯穿三类）：**话不要说太满**——如"不当属实，会严肃处理"即可，不承诺过头细节。

## 速查总表

| 类型 | 典型表现 | 处置基调 | 核心动作 |
|------|---------|---------|---------|
| **① 裁员** | 裁员、优化、N+X、变相裁员 | **不下场，对冲为主**（先向PR报备） | 向PR报备 + 淡化为"业务调整也很正常"，对冲引导，不官方下场 |
| **② 工作体验差** | 🟢B类一般吐槽（差/加班多/不公）｜🔴A类激进敏感（PUA/骚扰/不当言论/暴力裁撤/KPI逼退） | **先二级分类** | B类：澄清/轻对冲；A类：属实即移交内审+对外模糊表态 |
| **③ 面试体验差** | 🟢B类流程瑕疵（迟到/未开摄像头/时间短）｜🔴A类敏感越界（歧视/骚扰/侮辱/泄密/公平争议） | **先二级分类** | B类：依《面试官条例》扣分；A类：移交内审/合规+从重处罚 |

> ⭐ **②③ 必须先做二级分类**：同一大类里，🟢B类（一般）走常规处理，🔴A类（激进/敏感，踩法律或价值观高压线）必须重点对待、属实即移交内审/合规。详见下方各类的子类拆分。

## ① 裁员类舆情

**典型**：裁员、组织优化、N+X 补偿争议、"变相裁员"、业务线收缩。

**处置基调**：**一般不正面回应**，**以对冲为主**。
- 裁员是企业经营常态，正面回应反而坐实、放大、引来更多关联讨论（垒堆效应）。
- 对冲方向是**淡化、正常化**，把它放回"正常商业行为"的框架。

**动作要点**：
1. **向 PR 报备**：第一时间向相关 PR 同步报备（让 PR 知悉、评估是否有更高层面风险），但**报备 ≠ 下场**，处理主力仍是对冲。
2. **不官方下场回应**（除非已 P0 上热搜/媒体大规模跟进，才考虑统一口径声明）。
3. **对冲为主（主要处理手段）**：投放理性中性内容，把舆论从"冷血裁员"拉回"业务调整很正常"。
   - 对冲方向示例：
     - "业务调整、人员流动在大厂很正常，没必要过度解读"
     - "互联网公司每年都有结构优化，这是行业常态"
     - "有 N+X 补偿其实已经比很多公司规范了"（如补偿合理）
4. **监测为主**：盯发酵趋势，是否有大V/媒体把单一裁员上升为"行业寒冬""无良资本"叙事。
5. 调用《水军对冲方案策划》算对冲量+配比，**主打"正常化/理性化"**，不洗白、不卖惨。

> ⚠️ 不做：不发"我们很遗憾"式官方表态（=坐实+授人以柄）、不与离职员工公开对线。
> 📌 报备与对冲的关系：报备是"让 PR 知情备案"，对冲是"实际处理动作"。两者并行——先报备 PR，主力仍走对冲。

## ② 工作体验差舆情

**典型**：上司 PUA、工作量大/加班多、同事相处不愉快、晋升涨薪不公平、职场霸凌、职场骚扰、不当言论、暴力裁撤等。

**处置基调**：**先做二级分类**——同样是"工作体验差"，一般吐槽和激进/敏感事件的处理完全不同。先判断属于 B 类（一般）还是 A 类（激进敏感），再判断是否属实。

### 🟢 B 类：一般工作体验吐槽（按常规处理）
**范围**：说"差/不好""加班多/工作量大""同事相处不愉快""晋升涨薪不公平""食堂/通勤/环境一般"等普通吐槽。
**处置**：
- **不属实 / 片面** → 客观澄清（话术公式 + 可核实依据），或正面内容平衡氛围。
- **属实但不严重** → 低风险监测 + 轻量对冲即可，不必上内审。
- 基调：这是雇主品牌的"日常水温"，不放大、不应激，氛围调节为主。

### 🔴 A 类：激进 / 敏感事件（重点处理，需进一步分类）
> 以下子类**性质严重、易触法律或价值观高压线、极易发酵**，必须重点对待，**属实即移交内审**，不能当普通吐槽处理。

| A 类子类 | 典型表现 | 处理基调 |
|---------|---------|---------|
| **A1 职场 PUA / 精神打压** | 长期言语贬低、精神控制、孤立打压 | 属实→移交内审/HR，对外模糊表态"零容忍" |
| **A2 职场骚扰（性骚扰/肢体）** | 性骚扰、肢体越界、性暗示言论 | **最高敏感**：第一时间移交内审/合规，可能涉法律，对外极克制，必要时配合法务 |
| **A3 不当言论 / 价值观** | 歧视性、侮辱性、违背公序良俗的言论 | 属实→移交内审 + 对外明确"不代表公司价值观" |
| **A4 暴力裁撤 / 违规操作** | 逼迫离职、威胁恐吓、违规调岗、变相裁员手段 | 属实→移交内审/合规，注意与①裁员区分（这是"手段违规"非"裁员本身"） |
| **A5 KPI / 绩效相关激进做法** | 末位淘汰逼人、绩效打压、不合理KPI逼退 | 核实是否制度问题 vs 个人行为，属实→内审+评估是否需调整制度口径 |

**A 类统一处理流程**：
1. **立即升级 + 移交内审 / 合规 / HR**，品牌侧配合调查，**绝不自行定性、绝不护短**。
2. **对外模糊公布结果 + 表明态度**（话不说满）：
   - 标准表态："经核实，相关情况属实，公司高度重视，已严肃处理"
   - **不说**处罚细节、不点责任人姓名、不承诺超能力范围的结果。
   - A2（骚扰）类**额外克制**：可能涉及当事人隐私和法律程序，对外只表态度，不透露任何案情细节。
3. **公关话术绝不替代调查**——A 类属实问题，对冲/话术只是辅助，核心是走内审走流程。
4. 调查节奏：调查中→"正在核实"；有结果→"已严肃处理"，不展开。

> **B↔A 判断口诀**：是不是踩了**法律红线（骚扰/暴力/歧视）或价值观高压线**？踩了 → A 类重点处理；只是体验/待遇层面的不满 → B 类常规处理。拿不准按 A 类（高一级）走。

## ③ 面试体验差舆情

**典型**：面试官行为不当（态度傲慢/不当提问/不开摄像头/迟到）、面试者不服面试结果、面试中的歧视/骚扰等。

**处置基调**：**先做二级分类**——同为"面试体验差"，一般流程瑕疵和敏感越界事件处理力度完全不同。先分 B 类（一般）/ A 类（敏感），再走"表态→跟进查证→依规处罚"。

### 🟢 B 类：一般面试流程瑕疵（按《面试官管理条例》常规处理）
**范围**：面试官迟到、未开摄像头、临时改时间、面试时间过短、态度一般、流程沟通不到位等。
**处置**：标准三步——
1. **先表明态度**：感谢反馈、重视候选人体验、会认真核实。
2. **跟进查证**：调系统记录/时长/沟通记录，逐条区分 属实 / 不属实 / 部分属实。
3. **依规处罚**：对查实违规项按《面试官信用体系积分细则》扣信用分，对外说明"已依据制度处理"。
> 参考案例：投诉"态度傲慢"（改时间/不开摄像头/时间短）→ 查证仅"未开摄像头且未沟通"属实 → 依细则扣信用分 → 对外说明依规处理。

### 🔴 A 类：敏感 / 越界事件（重点处理，需进一步分类）
> 以下子类涉及法律/价值观高压线或公平性争议，**易快速发酵且杀伤品牌**，不能当普通流程瑕疵处理。

| A 类子类 | 典型表现 | 处理基调 |
|---------|---------|---------|
| **A1 歧视类** | 性别/年龄/婚育/地域/院校/外貌歧视提问或言论 | 属实→移交相关部门 + 对外明确"违反招聘平等原则，已处理"，态度坚决 |
| **A2 骚扰 / 不当越界提问** | 性暗示、"能否陪酒"、私生活越界、冒犯性问题 | **高敏感**：移交内审/合规，对外克制表态，必要时配合法务 |
| **A3 侮辱 / 攻击候选人** | 贬低人格、嘲讽学历背景、地图炮 | 属实→依条例从重处罚 + 对外致歉表态 |
| **A4 泄密 / 违规操作** | 面试中泄露业务机密、索贿、违规承诺 | 触高压线→立即处理，移交合规 |
| **A5 面试者不服结果（公平性争议）** | 质疑评判不公、走后门、内推黑幕 | 招聘决策本身通常不违规，**重点澄清流程公正性**，不纠缠个体结果；若涉影响其他候选人公平→可能是高压线，需慎重 |

**A 类统一处理流程**（在 B 类三步基础上升级）：
1. **先表态**（更慎重、更高规格）：明确公司对该类行为零容忍。
2. **跟进查证 + 升级**：除查面试记录外，涉法律/骚扰的**移交内审/合规/法务**，不只走信用分。
3. **依规从重处罚 + 对外表态**（话不说满）："经核实存在不当行为，已依据相关规定严肃处理"，A1/A2 必要时附致歉，但不透露细节。
4. **防范措施对外可见**：强调将加强面试官行为规范与培训（A 类尤其要给"防重演"的信号）。

> **B↔A 判断口诀**：是不是涉及**歧视 / 骚扰 / 侮辱 / 泄密 / 公平性黑幕**？是 → A 类重点处理；只是迟到/未开摄像头/时间短等流程瑕疵 → B 类常规处理。拿不准按 A 类走。

### 📏 面试官处罚依据：《面试官行为信用体系》四层级（团队实际口径）

> 📚 **权威全文见 `references/面试官行为信用体系.md`**（五类不当行为明细+量化扣分细则+权限取消+谁执行+联系人）。🔒 **该文件是内部处理依据，可给招聘经理参考，但绝不在任何对外沟通文件/话术/回应中引用**（对外只说"已依据公司相关规定严肃处理"）。下面是速查简版。

对面试官的处罚对照这**四层级**定性（按"造成后果的严重程度"落档，来自面试官较重违纪案等实战）：

| 层级 | 定性标准 | 典型处罚 |
|------|---------|---------|
| **日常信用行为** | 围绕行为专业度/时效性/面试质量三维度，单项不达标 | **暂停**权限（连续两次面试质量不达标→取消），邮件通知本人+上级，需修课后重开 |
| **违纪行为** | 引发投诉（一般流程瑕疵、内部不正当竞争如挖猎已offer候选人） | 扣信用分（发生一次**扣45分**）；**同周期2次违纪→取消权限+一年不得申请** |
| **较重违纪行为** | 导致公司声誉/形象/价值观/雇主品牌受到**损害**或**一定经济损失** | **取消面试官权限+一年内不得申请+信用分清零**（面试官较重违纪案即此档） |
| **高压线行为** | 导致公司声誉/雇主品牌受到**严重损害**或**大额经济损失**（《阳光行为准则》在招聘场景的展现，如泄露机密给候选人） | 依《腾讯阳光行为准则》处罚+取消权限+一年内不得申请，移交合规，可能追责到上级 |

> 对应关系参考：B 类流程瑕疵 ≈ 日常信用/违纪（暂停/扣分）；A 类敏感越界视影响程度 ≈ 较重违纪/高压线。
> 判定流程：集团 + BG 侧共同研讨，结合"是否造成损害/经济损失/外网影响"定档。
> **谁执行**：高压线/较重违纪→**集团面试官管理团队**主导(BG协助邀约)；违纪/日常→**BG招聘侧**主导(集团可协助)。
> 处理后可联系候选人说明结果，**争取删帖或隐藏面试官姓名**，最小化对个人的不良影响。

## 三类通用铁律

1. **先归类再处置**：任何 case 先判断属于①②③哪类，再走对应 SOP。
2. **话不说满**：对外表态留余地——"属实会严肃处理"级别，不承诺细节、不说责任人。
3. **属实/严重 → 走流程**：②③的严重属实问题必须走内审/管理条例，公关不替代调查。
4. **裁员特殊**：①裁员不正面回应、以对冲正常化为主，与②③的"表态+跟进"逻辑不同。
5. **强弱身份自检**：我方是"强者"，不打压发帖者、不卖惨。
6. **处理人链路**：**涉事 BG 业务 PR 主办**、**雇主品牌接口人 同步**把口径；BG PR 无法处理 → **集团 PR + 雇主品牌接口人 联合处理**。涉品牌策略/需渠道执行/P0火警 → 同步 雇主品牌接口人，由其协调 Naomi/Bonnie（经理本地可能没装这些专家）；②③需调查 → 移交内审 + 同步 雇主品牌接口人 知悉。
