# 风险内容辨识库（招聘宣传审稿红线词表）

> Amy 的"审稿"能力底座。回答经理高频问题：**「这个材料帮我看看有没有风险？」**
> 适用对象：招聘推文、JD、宣讲话术、海报文案、KOL投放稿、offer话术、校招物料、社媒帖子等一切对外招聘宣传内容。
> 用法：拿到一份材料 → 逐条比对下方红线 → 输出《内容风险审核报告》（模板见 assets/templates）。

---

## 风险分级总则

| 等级 | 含义 | 处置 |
|------|------|------|
| 🔴 **红线（必改）** | 触及法律法规/平台规则/价值观高压线，可能引发投诉、监管、舆情 | 必须删改，不得发布 |
| 🟡 **黄线（建议改）** | 不违法但易引发误解、过度承诺、留下把柄 | 强烈建议调整 |
| 🟢 **提示（优化）** | 表述可更稳妥、更专业 | 可选优化 |

> 🔑 **审稿 = 标准库 + 定制化关注**：本辨识库（下方 1-9 类）是**标准红线库**，每次审稿默认全过；但每份材料常有业务方/法务/老板特别交代的个性化点（某数据未脱敏、某 KOL 不能提、本次必须规避竞品名等）。**收到材料先问一句"有没有这次特别要盯的点"**，把定制化关注并入本次审核（执行细节见 `assets/templates/01_内容风险审核.md`）。用户说没有就只走标准库，不阻塞。

---

## 一、🔴 虚假承诺 / 过度承诺（最高频翻车点）

招聘宣传一旦写死，未来兑现不了就是"诈骗"口实，且会被截图传播。

| 红线表述 | 问题 | 建议改法 |
|---------|------|---------|
| "入职即转正""offer 100%转正" | 转正有考核，写死=虚假承诺 | "提供完善的转正培养机制" |
| "代码直接 merge""实习就能主导项目" | 夸大实习权限，易被在职员工打脸 | "参与真实项目，有 mentor 带教" |
| "薪资不封顶""年薪百万不是梦" | 诱导性夸大，留口实 | 给真实区间或"具薪资竞争力" |
| "包升职""两年升 P7" | 晋升承诺无法保证 | "清晰的晋升通道" |
| "不加班""955""准时下班" | 与真实工作强度不符，最易被脉脉/小红书打脸 | "弹性工作"或不提，不写死 |
| "免笔试/免面试直通" | 破坏招聘公平性，影响其他候选人 | 删除 |
| "稳定不裁员""铁饭碗" | 任何企业都不能承诺 | 删除 |

> **核心原则（Kathy 五字诀·克制）**：宁可少说，不可瞎说。给事实让候选人判断，不替公司吹牛。

---

## 二、🔴 薪资 / 福利夸大与违规

| 红线表述 | 问题 |
|---------|------|
| 编造或夸大薪资数字、用极端个例当普遍 | 虚假宣传 |
| "薪资行业第一""碾压友商" | 绝对化+贬低同行（见第五条） |
| 把"可能拿到"的总包说成"保底" | 误导 |
| 福利写"无限"（无限假期/无限零食）但实际有限制 | 留把柄 |
| 隐瞒附加条件（如"高薪"但需签超长服务期/高额违约金） | 涉嫌欺诈 |

---

## 三、🔴 歧视性表述（法律红线 + 舆情高发）

《就业促进法》《劳动法》明令禁止就业歧视。这类内容一旦被截图，必上社媒。

| 类别 | 红线词示例 | 说明 |
|------|-----------|------|
| **性别** | "限男性""男士优先""女生慎投""适合男生" | 违法 |
| **年龄** | "35岁以下""仅限应届""年轻团队拒绝大龄" | 违法+反压榨情绪雷区 |
| **婚育** | "已婚已育优先""未婚勿扰""三年内无生育计划" | 违法，女性议题极敏感 |
| **地域** | "不要XX地人""限本地户籍" | 地域歧视 |
| **院校** | "非985/211不要"（写进公开文案） | 内部可筛，公开写=舆情雷 |
| **外貌/身高** | "形象气质佳""限身高170+"（非特殊岗位） | 涉嫌歧视 |
| **健康/其他** | 涉及乙肝、残障、宗教、政治面貌的限制性表述 | 违法 |

> ⚠️ 性别 + 婚育 是雇主品牌舆情的"核弹级"雷区，一旦踩中直接关联"反特权/反压榨"社会情绪。

---

## 四、🔴 绝对化用语（《广告法》风险）

《广告法》禁用绝对化用语，招聘海报/推文同样适用。

| 禁用词 | 替代 |
|--------|------|
| 最好/最强/第一/顶级/最佳雇主 | "领先的""头部的"（且需有依据） |
| 唯一/独家/史无前例 | "少数""稀缺" |
| 100%/绝对/必定/永远 | 删除或限定条件 |
| 国家级/世界级（无认证） | 删除夸大定语 |

> 例外：有官方认证/榜单背书的可引用，但必须**标注来源和年份**（如"XX机构2025最佳雇主榜TOP10"）。

---

## 五、🔴 贬低/影射竞品

| 红线 | 说明 |
|------|------|
| 直接点名贬低友商（"比XX强""别去XX那种血汗工厂") | 不正当竞争 + 招黑 |
| 影射性对比（"某些大厂只会画饼") | 虽不点名，仍易被对号入座引战 |
| 截取友商负面新闻做对比图 | 高风险，易引发对方公关反击 |

> 原则：只说自己的好，不踩别人。竞品对比仅用于**内部策略分析**（Naomi/Vicky 用），不进对外文案。

## 六、🟡 内部信息泄露

| 黄线 | 说明 |
|------|------|
| 出现未公开的业务数据/战略/组织架构 | 保密风险 |
| 暴露内部审批流程、HC 真实数字、内部代号 | 不对外 |
| 截图含内部系统界面/工位/工牌/内网内容 | "鹅厂vlog"式翻车源头 |
| 提及未发布的产品/项目 | 保密+合规 |

## 七、🟡 政治 / 民族 / 价值观敏感

| 黄线/红线 | 说明 |
|----------|------|
| 涉及国家、地区表述不规范（港澳台必须表述为"中国香港/中国台湾/中国澳门"） | 🔴 红线，曾有问卷把台湾与中国并列翻车 |
| 涉及宗教、领土、历史的不当玩梗 | 🔴 高压线 |
| "996是福报""狼性""加班是奋斗"类价值观输出 | 🟡 反压榨情绪雷区，慎用 |
| 物化女性/性别对立的营销梗 | 🔴 价值观红线 |
| 蹭社会热点/灾难/公共事件做营销 | 🟡 审时——时机不对必翻车 |

## 八、🟢 表述优化提示（专业度）

- 数据/排名/荣誉 → 必须带来源和年份（可溯源）
- 员工故事/case → 确认已脱敏、已获本人同意
- 引用媒体报道 → 核实链接有效、表述未断章取义
- 关键词精简 → 3 个核心卖点 > 6 个散点
- 技术岗文案 → 技术亮点优先，不堆砌虚词

## 九、📝 质量把控（审稿同时必做，非舆情风险但影响专业度）

> Amy 审稿 = 舆情风险（上面1-8类）**+ 内容质量**。一篇推文哪怕没踩红线，错别字、断链一样会让候选人对雇主品牌打折扣。质量问题按 🟡/🟢 标注。

### 1. 错别字 / 用字规范 🟡
- 同音字、形近字误用（"founder"写成"flounder"、"账号"写成"帐号"、"在线"写成"再线"）
- 公司名/产品名/人名拼写（腾讯/Tencent、青云计划等专有名词必须准确，大小写一致）
- 中英文混排空格、全半角混用（如"AI岗位"vs"ＡＩ岗位"）
- 数字/单位错误（"10k"与"1万"、"P7"职级写法一致性）

### 2. 语法 / 语病 🟡
- 句子成分残缺（缺主语/谓语）、搭配不当
- 标点错误（一逗到底、中英文标点混用）
- 语序混乱、歧义句
- 长句过长导致读不通（建议拆句）
- 时态/口径前后不一致

### 3. 内嵌链接可用性 🔴/🟡（**必须实际验证**）
> 断链 / 错链是高频翻车点：推文里"投递入口"打不开 = 直接损失候选人 + 显得不专业。

- **逐个提取材料中的链接**（报名入口、JD页、官网、二维码指向的URL、KOL投放稿里的跳转链）
- **用 web_fetch 实际打开验证**：
  - 能否正常访问（非404/500/超时）→ 打不开标 🔴
  - 跳转目标是否正确（是不是指向该说的页面，有没有跳错/跳到登录墙）→ 错链标 🔴
  - 是否过期（活动报名链接是否还在有效期）→ 过期标 🟡
  - 二维码：提示"二维码需人工扫码核验指向"（Amy无法扫码，列为待人工确认项）
- 链接文案与实际指向是否一致（写"点击查看薪资"实际跳到首页 → 🟡）

### 4. 格式 / 排版 🟢
- 标题层级、序号连续性（1、2、4 跳号）
- 列表格式统一、空行/分段合理
- 图文对应（"如下图"是否真有图、图注是否正确）
- 字体规范：正式材料正文微软雅黑（Kathy 规范）

### 5. 事实/数据一致性 🟡
- 同一份材料内数据前后矛盾（开头说"3000岗位"结尾说"5000"）
- 引用的时间/地点/职级与事实是否相符
- 数据单位、百分比加总是否合理（占比相加是否=100%）

## 审稿执行 Checklist（拿到材料逐条过）

### A. 舆情风险（红线优先）
```
□ 1. 有没有写死的承诺？（转正/晋升/薪资/不加班/不裁员）
□ 2. 薪资福利数字真实可兑现吗？有无隐藏条件？
□ 3. 有没有性别/年龄/婚育/地域/院校歧视表述？
□ 4. 有没有"最/第一/100%"等绝对化用语？
□ 5. 有没有贬低或影射竞品？
□ 6. 有没有内部敏感信息/未公开内容？
□ 7. 国家地区表述规范吗？有无价值观/政治敏感？
□ 8. 数据来源可溯源吗？员工case脱敏授权了吗？
□ 9. 蹭的热点时机合适吗？（审时）
□ 10. 整体调性匹配品牌定位吗？（克制/精准/简洁/安全/专业）
```

### B. 质量把控（同步必做）
```
□ 11. 有没有错别字/专有名词拼写错误？
□ 12. 有没有语法错误/语病/标点错误/歧义句？
□ 13. 内嵌链接逐个 web_fetch 验证过吗？能打开？跳转正确？没过期？
□ 14. 二维码指向是否已标注"需人工扫码核验"？
□ 15. 格式排版规范吗？（序号/列表/图文对应/字体）
□ 16. 数据/事实前后一致吗？（无自相矛盾、占比加总合理）
```

## 输出原则（沿用 Kathy + KOL 沟通原则）

- **「建议」不「禁止」**：对 KOL/业务方的稿子，说"建议调整为…"，不说"你这不行"。
- **标红线、给改法**：不只指出问题，必须给可直接替换的安全表述。
- **分级呈现**：🔴必改 / 🟡建议改 / 🟢可优化，让用户分清轻重缓急。
- **宁严勿松**：拿不准的，按高一级风险提示，由经理决策。
