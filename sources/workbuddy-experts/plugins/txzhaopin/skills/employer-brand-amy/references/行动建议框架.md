# 行动建议框架（短期灭火 + 中期改善 + 长期预防）

> Amy 的"开药方"能力。承接《态势研判与走势预测模型》的研判卡——研判定性后，这里给出**结构化、可执行**的三层行动方案。
> 回答经理高频问题：**「我要怎么处理这个 case？」**
> 核心原则（来自方法论）：**先止损、再解释、后修复**。

---

## 一、三层结构总览

| 层级 | 时间窗 | 目标 | 关键词 |
|------|--------|------|--------|
| **短期·灭火** | 0-72h | 止血、控制扩散、定调 | 快、准、稳 |
| **中期·改善** | 1-4周 | 修复信任、正面覆盖、解决实际问题 | 真诚、兑现 |
| **长期·预防** | 1-3月+ | 堵住源头、制度化、避免重演 | 治本 |

> 不是每个 case 都要三层全做。**P0/P1 必须三层都有；P2 以短期+中期为主；P3 通常只需监测+轻量预防。**

---

## 二、短期·灭火（0-72h）

### 核心决策树：要不要回应？

```
研判紧急度
    ├─ P0/P1 → 必须回应（做第一个定调的人）
    ├─ P2 → 视发酵趋势，备好预案，够阈值才动
    └─ P3 → 不主动回应，监测+轻量对冲
```

### 灭火动作清单 —— 腾讯 5 大处理手段（团队实际口径）⭐

> 来自团队真实 SOP（舆情处理方案脑图）。判定"处理"后，从这 5 种手段中按场景选取（可组合）：

| 手段 | 适用 | 落地路径 | 要点 |
|------|------|---------|------|
| **① 删帖/打码** | 不实/造谣/实名曝光等**严重**内容、可走平台规则 | **判严重 → 备证据/律师函初稿 → 通知 雇主品牌接口人+业务PR → 法务/PR发起** | **分平台打法不同**，详见《分平台删帖与维权处置指南》：小红书一般不删(优先对冲)、严重才删；脉脉删需律师函、先沉底48h后删；实名优先打码 |
| **② 评论冲抵** | 搜索长尾型负面（小红书/知乎）、评论区氛围差 | **确定冲抵方向 → 确定可用账号 → 发布** | 即水军对冲，详见《水军对冲方案策划》算量+配比 |
| **③ 转移矛盾** | 单点负面、有可转移空间 | **转移话题**（引发新讨论）/ **转移关注对象**（引入个人账号） | 把焦点从公司转向话题或个体，降低品牌直接承压 |
| **④ 官方回应** | P0/P1、已扩散、我方为"强者"、需定调 | **拟定回复话术 → 确定发布形式与平台 → 发布** | 第一时间原则；套话术公式；正面解释非打压 |
| **⑤ 冷处理** | 热度低/纯情绪/小号、不影响公司 | **持续监测**（监测7天规则） | 不回应即最优解，避免反向引流 |

**辅助动作**（配合上述 5 手段）：
- 私信/一对一沟通：可联系到当事人、误解类——表达重视，线下解决，避免公开对线。
- 联系作者修改：公众号不实内容——沟通而非强压，提供事实依据。
- 举报违规：网暴个人信息/造谣——走平台规则折叠低质内容。

> 💬 **②评论冲抵 = 水军对冲**：必须调用 `references/水军对冲方案策划.md` 产出完整方案——算**需要多少条**、**分别什么内容**（维度×渠道配比）、投放节奏和收尾条件，方案同步 雇主品牌接口人 协调 Bonnie 落地成稿。不可只写一句"建议对冲"。
> ⚖️ **①删帖/打码** 是**重手段**：必须先判"严重"、备好删帖依据（不实言论证据 or 律师函初稿），再通知 雇主品牌接口人 + 业务线 PR 协助，最终由法务/PR 发起。**分平台打法差异大**——小红书一般不删(优先对冲)、投诉成功即删；脉脉删需律师函且先沉底48h后删；脉脉实名优先打码(本人投诉最快)。详见 `references/分平台删帖与维权处置指南.md`。不可擅自大规模删评（易被指控评反噬）。

### 灭火话术公式（来自方法论第七章，可直接套）

> **表明态度 → 还原客观事实 → 处理依据与结果 → 防范措施**

回应思路升级：用「**原因/代价/追根**」替代旧套路「辩解/表态/许诺」：
- ❌ 旧：我们做了什么（辩解）→ 深表遗憾（表态）→ 将来更好（许诺）
- ✅ 新：为何发生（原因）→ 我们如何处理/付出什么代价（代价）→ 如何避免重演（追根）

### 灭火三条铁律
1. **先止损**：先控制扩散，别急着辩白。
2. **身份自检**：我方若是"强者"，绝不打压"弱者"，要正面解释——大家想听强者解释。
3. **拒绝被害者思维**：不博委屈、不卖惨（雷军内部讲话反例）。

### 时间节奏（各平台响应窗口）
- 微博：4 小时内（热搜放大快）
- 小红书/抖音：当天（搜索长尾，可稍缓但要覆盖）
- 公众号：24h 内联系作者
- 脉脉：以监测为主，少回应（越回应越热）

## 三、中期·改善（1-4周）

灭火只是止血，中期要**修复信任 + 解决暴露出的真实问题**。

### 1. 正面内容建设
- 找对应平台的真实账号/员工，产出正面内容覆盖搜索结果
- 不是刷量，而是用真实体验稀释负面（混入合理"小缺点"提升可信度）
- 针对负面戳中的痛点，定向输出正面证据（被吐槽加班→输出弹性/项目成就感故事）

### 2. 实际问题整改
> ⭐ 关键：如果负面**属实**，公关话术救不了，必须推动业务侧真改。
- 把舆情暴露的真问题反馈给对应业务/HR 团队
- 跟踪整改进度，作为后续回应的"代价/追根"素材
- 例：面试官被投诉态度差 → 推动面试官培训/信用分制度落地

### 3. 口径统一
- 产出《对内对外口径表》，确保 HR/PR/业务/客服回应一致
- 高频追问的标准答法、禁用表述清单

### 4. 情绪恢复监测
- 跟踪负面情绪指标恢复曲线（环比研判模型的情绪趋势打分）
- 正面内容覆盖效果评估
- 判断是否可以收尾 or 需追加动作

## 四、长期·预防（1-3月+）

治本，避免同类事件重演。

### 1. 源头治理
| 高频源头 | 预防措施 |
|---------|---------|
| 员工个人爆料（7成危机来源） | 推动《员工社交媒体使用规范》宣导+报备制度 |
| 招聘宣传翻车 | 所有对外物料过 Amy 风险辨识库审稿 |
| 面试官/HR 行为 | 面试官信用体系、行为红线培训 |
| 时机踩雷 | 建立敏感时间节点日历（审时） |

### 2. 制度化沉淀
- 把本次 case 写入《舆情案例库》（含研判卡+处置复盘）
- 更新水军词库/话术库/红线词表
- 高频问题进 FAQ

### 3. 预警机制建设
- 关键词监测常态化（本品牌+友商+高风险词）
- 设定各平台预警阈值自动盯防
- 定期态势研判报告（周/月）

### 4. 复盘报告
```
事件复盘：
- 起因 → 发酵路径 → 处置动作 → 效果
- 响应是否及时？定级是否准确？
- 哪些动作有效/无效？
- 沉淀到哪个库（话术/红线/案例）？
- 预防措施 owner + 截止时间
```

## 六、处理人链路与升级（BG业务PR主办 · 雇主品牌接口人同步 · 集团PR联合兜底）

> ⚠️ 经理电脑上可能没装 Bonnie/Naomi，渠道/品牌协同由 雇主品牌接口人 协调，不假设能直接调用其他专家。

- **Amy 出方案（决策大脑）** → 定基调、定动作、写话术、定级、备材料。
- **主要处理人 = 涉事 BG 业务 PR**（IEG/WXG/CSIG/TEG…按内容归属）→ 牵头执行删帖/维权/对外回应。
- **被同步人 = 雇主品牌接口人**（S3-招聘活水部-品牌内容团队）→ 雇主品牌侧知会+口径把关，处理过程中同步给她。
- **升级兜底**：BG PR 无法处理/跨BG/影响过大 → **集团 PR + 雇主品牌接口人 联合处理**。
- **需渠道侧执行**（水军词产出、找KOL做正面覆盖、评论区维护排期）→ 方案同步 **雇主品牌接口人** → 由其协调 **Bonnie** 落地。
- **涉及品牌策略层面**（要调品牌定位/EVP/传播方向）→ 同步 **雇主品牌接口人** → 由其协调 **Naomi**。
- **P0 火警** → 立即同步 **雇主品牌接口人** + 推动 BG/集团 PR 联动。
- 一句话：Amy 把方案做到位 → **交涉事 BG 业务 PR 主办、同步 雇主品牌接口人** → BG 搞不定则集团 PR + 雇主品牌接口人 联合。
