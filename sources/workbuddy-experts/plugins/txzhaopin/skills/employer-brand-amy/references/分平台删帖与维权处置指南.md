# 分平台删帖与维权处置指南（小红书 / 脉脉差异化打法）

> ⭐⭐ 团队真实实操口径（Kathy 给定，2026-06-23）。
> 这是对《行动建议框架》「①删帖」手段的**平台级细化**——同样是"删帖"，小红书和脉脉的可行性、前置条件、生效路径完全不同，必须分平台对症下药。
> **核心原则**：删帖是重手段、有成本（被指控评、留证据风险、需法务/PR背书），不到"严重"不轻易用；能用对冲解决的优先对冲。

---

## 〇、总决策：先判"严不严重"，再决定删不删

```
负面帖出现
   ↓
判断严重程度（按《态势研判模型》四象限 + P级 + 是否实名/不实/造谣）
   ├─ 不严重（情绪吐槽/局部、未造谣、未实名、热度未破阈值）
   │      → 不投诉删帖，以「中评/好评对冲」为主（见《水军对冲方案策划》）
   │
   └─ 严重（造谣不实 / 实名曝光 / 已发酵破阈值 / 影响公司）
          → 立即交 **涉事 BG 业务 PR**（主办）+ 同步 雇主品牌接口人（知会/把口径）
          → 走"删帖/打码"维权流程（需证据 or 律师函，见下分平台）
          → BG PR 搞不定 → 升级到 集团 PR + 雇主品牌接口人 联合处理
```

> 📌 **第一道闸**：删帖不是默认动作。**小红书一般不投诉删帖**；多数 case 优先对冲。只有"严重"才上删帖维权。
> 📌 **第二道闸**：一旦定为"严重需删帖"，**Amy 不自己删**——交**涉事 BG 业务 PR 主办**（IEG/WXG/CSIG/TEG… 按内容归属），**同步 雇主品牌接口人（S3-招聘活水部-品牌内容团队）**知会把关；BG PR 无法处理 → 升级**集团 PR + 雇主品牌接口人 联合处理**。由他们走平台/法律路径。

## 一、小红书（XHS）处置打法

### 1.1 不严重 → 中好评对冲为主（不投诉删帖）
- 小红书**一般不走投诉删帖**（平台删帖门槛高、易被反噬、长尾搜索靠对冲稀释更有效）。
- 不严重的负面 → 用**中评/好评对冲**压低可见度（详见《水军对冲方案策划》：算条数+定内容配比+排节奏）。

### 1.2 严重 → BG 业务 PR 主办 + 同步 雇主品牌接口人
触发"严重"（造谣不实 / 实名 / 已发酵破阈值 / 实质影响公司）时：
1. **交涉事 BG 业务 PR 主办**（按内容归属），**同步 雇主品牌接口人** 知会把口径；BG PR 无法处理 → 升级**集团 PR + 雇主品牌接口人 联合处理**。
2. 若需要 BG/集团 PR 协助**删帖**，Amy 必须**提前出具删帖依据**（二选一或叠加）：
   - **证据材料**：根据帖中**相关不实言论**逐条出具反驳证据（事实/记录/截图/制度依据，证明帖子内容失实）。
   - **律师函初稿**：包含帖中**明确不实之处**的逐条列举（见下 §三 律师函要点）。
3. **特殊证据情形**：若小红书帖子是**引用其他信息源**（转载/搬运），而该**原信息源已被删除** → 原信息源已删本身**也可作为删除本帖的证据**（覆巢之下、引用源已不存在）。

### 1.3 投诉成功 → 帖子立即删除
- 小红书投诉/维权一旦成功，**帖子立即删除**（即时生效，无延迟）。

## 二、脉脉处置打法

### 2.1 删帖 → 同样需要律师函
- 脉脉删帖**也需要律师函**（含不实之处，要求同 §三）。
- 走 BG 业务 PR 主办 + 同步 雇主品牌接口人 的路径（BG PR 搞不定 → 集团 PR + 雇主品牌接口人 联合）。

### 2.2 脉脉两种处置效果区分：打码 vs 删帖沉底 ⭐⭐

> 脉脉有**两种不同的处置动作**，效果和前置条件完全不同，别混：

| 处置动作 | 适用 | 前置条件 | 生效效果 |
|---------|------|---------|---------|
| **打码** | 曝光个人实名（护隐私） | 本人投诉即可（他人协助需律师函） | 帖中**名字变成 `***`**（隐去实名，帖子本身还在） |
| **删帖（沉底→删）** | 造谣/不实/泄密等需整帖删除 | **发律师函投诉**（律师函是前置） | **发函投诉后帖子先沉底**（非搜索状态看不到）→ **48h 后正式删帖**（网信办监管时序） |

**关键厘清**：
- **打码 ≠ 沉底**。打码只是把名字打成 `***`，帖子仍在；**沉底是"删帖"流程的第一步**。
- **沉底的前置是"发律师函投诉"**——不是随便投诉就会沉底，而是**律师函送达投诉成功后**，帖子才先沉底、48h 后删除。
- 所以：只想护隐私 → 走打码（名字变 `***`，门槛低）；要整帖消失 → 走删帖（**先备律师函** → 投诉 → 沉底 → 48h 删）。

> ⚠️ 告知经理预期：脉脉删帖"律师函投诉成功 ≠ 立刻消失"，会**先沉底（非搜索不可见）→ 48h 后删**。监控期把这 48h 算进去，别误判"投诉没生效"。

### 2.3 脉脉实名曝光 → 一律打码（保护员工隐私 ⭐⭐）

> **总原则：只要曝光了名字（员工/面试官/GM/候选人等任何个人实名），为保护员工隐私，一律建议打码处理。** 不论帖子内容属实与否、热度高低——实名本身就该打码，这是隐私保护的硬动作。

> 🚨 **主动识别·主动提示（硬规则，不可遗漏）**：Amy 研判**任何**帖子时，都要**主动扫一遍有没有出现人名**（真实姓名、花名/英文名如 lori、可对应到具体个人的昵称/职务+姓氏）。**只要出现任何人名，无论这条 case 整体定级多低（哪怕 P3 不处理、哪怕只是被路人在评论区提到），都必须在研判结论里主动加一条"🔒 实名提示：帖中出现人名【X】，建议打码处理（本人投诉最快）"。** 不要等"判定需处理"才提——发现人名就提，这是独立于"删不删帖"的隐私保护动作。
>
> 📌 人名打码 ≠ 帖子要处理：一条 P3 不处理的帖，只要含人名，照样给"建议打码"的提示（处理动作是打码护隐私，不是删帖、不升级整体定级）。两件事分开判。

- 处置目标 = **打码**（把曝光的名字隐去，**名字变成 `***`**，帖子本身仍在），不一定要整帖删除。
- **打码处置三级链路**（沿用原打码建议，逐级上升）：
  1. **先建议本人投诉** —— 被曝光实名的当事人**自己去脉脉投诉打码**，生效最快（平台优先响应本人维权），且无需律师函；**投诉通过后名字变 `***`**。
  2. **本人处理不了 → 找业务 PR** —— 由涉事 BG 业务 PR 协助处置（他人/公司协助打码需提供**律师函**）。
  3. **业务 PR 还处理不了 → 找集团 PR + 雇主品牌接口人** —— 上升到集团 PR 与 雇主品牌接口人 联合处理。

```
脉脉曝光实名（任何个人名字，含GM）
   → 一律打码（保护员工隐私）
   ① 先建议【本人投诉】打码（最快，无需律师函）
        ↓ 处理不了
   ② 找【业务 PR】协助（他人协助打码需律师函）
        ↓ 还处理不了
   ③ 找【集团 PR + 雇主品牌接口人】联合处理
```

> 📌 **GM 被实名同理**：GM 也是员工，写了 GM 名字 → 建议打码，优先 GM 本人投诉；本人不便 → 业务 PR → 集团 PR + 雇主品牌接口人。
> 📌 **打码 vs 删帖（效果与门槛不同）**：
> - **打码** = 本人投诉即可（他人协助需律师函）→ **名字变 `***`**，帖子还在，护隐私门槛低。
> - **删帖** = 内容造谣/不实/泄密时走 → **需发律师函投诉** → 帖子**先沉底（非搜索不可见）→ 48h 后删**。
> 两者可叠加：先打码护隐私（名字变`***`），若内容还不实再发律师函走删帖（沉底→48h删）。

## 三、删帖/维权材料要点

### 3.1 证据材料（适用：帖子内容不实）
针对帖中**每一条不实言论**，逐条对应出具：
- 事实经过还原（时间线/客观记录）
- 反驳证据（聊天记录、面试记录、制度条文、流程截图等）
- 明确指出"帖中说 X，实际是 Y，证据为 Z"

### 3.2 律师函初稿（必含"不实的地方"）
Amy 出**律师函初稿**时，**必须逐条列明帖子中不实/失实之处**，要素：
1. **主体**：腾讯（或对应主体）委托/声明方
2. **指向**：涉事帖子链接 + 发布账号 + 发布时间
3. **核心**：**逐条列举不实言论**（"帖文称……，与事实不符，实际情况为……"）——这是律师函的命门，必须具体到条
4. **诉求**：要求平台/发帖人删除/更正/打码 + 停止传播
5. **依据**：名誉权/虚假信息/侵权相关条款（最终由法务定稿）
6. **落款与时限**：要求处理的期限

> ⚠️ Amy 出的是**初稿**（把"不实的地方"列扎实、结构搭好），**最终须经法务定稿**后才正式发出。
> 📋 **完整填空模板 + 标准法条块 + 真实范本** 见 `assets/templates/06_律师函初稿.md`（含致平台"协助删除函"模板、民法典110/1024/1195/1197四条照录、腾讯"天美J2"真实范本结构🔒）。

### 3.3 引用源已删（小红书特有）
- 若负面帖**引用/转载已删除的信息源** → 把"原信息源已删除"作为删本帖的证据之一（引用基础已不存在）。

## 四、平台差异速查表

| 维度 | 小红书 | 脉脉 |
|------|--------|------|
| **默认是否删帖** | 一般不投诉删帖，**优先中好评对冲** | 严重则删帖 |
| **删帖前置** | 严重才删；需**证据 or 律师函** | 需**律师函** |
| **投诉成功生效** | **帖子立即删除** | 打码=名字变`***`(本人投诉即可)；删帖=**发律师函投诉→先沉底(非搜索不可见)→48h后删**（网信办要求） |
| **实名曝光处置** | （按不实/造谣走删帖） | **一律打码护隐私(名字变`***`)**：①本人投诉(最快无需律师函)→②业务PR(他人协助需律师函)→③集团PR+雇主品牌接口人 |
| **特殊证据** | 引用源已删 = 可作删帖证据 | — |
| **不严重时** | 中好评对冲 | 监测为主（脉脉越回应越热） |
| **处理人/升级出口** | BG业务PR主办+同步雇主品牌接口人；BG搞不定→集团PR+雇主品牌接口人联合 | 同左 |
