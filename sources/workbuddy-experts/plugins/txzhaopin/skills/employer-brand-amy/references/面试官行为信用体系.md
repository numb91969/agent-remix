## 一、信用体系指标（四个层级）

面试官作为公司**人才质量守护者**和**雇主品牌传播者**，对公司持续提升人才质量、建设卓越的雇主品牌有着重要意义。为帮助面试官变得更专业，公司建立了面试官行为信用体系，按照面试官不规范行为的严重程度可区分为四个层级：

> **高压线行为、较重违纪行为、违纪行为、日常信用行为。**

- **高压线行为**：为《阳光行为准则》中界定的行为在招聘场景中的具体展现，例如将公司机密信息或者敏感信息泄露给候选人。
- **违纪行为**：主要是在人才招聘中的内部不正当竞争行为，例如挖猎内部员工或其他部门已 offer 的候选人，被用人部门投诉的。
- **日常信用行为**：围绕面试**行为专业度、时效性、面试质量**三个维度进行评估，其中每个维度又包含具体的评估指标。

## 二、信用体系详情

### 1、违规违纪行为

发生以下行为的，**根据行为严重程度进行区分**：

| 造成的后果 | 定档 |
|-----------|------|
| 导致公司声誉、形象、价值观、雇主品牌受到**严重损害**或**大额经济损失** | **高压线行为** |
| 导致公司声誉、形象、价值观、雇主品牌受到**损害**或**一定经济损失** | **较重违纪行为** |
| **引发投诉** | **违纪行为** |

> ⚠️ 同一类行为，按"造成后果的严重程度"落到不同档位——这是三档判定的总规则，贯穿下面五类。

#### 五类不当行为明细

**① 泄露敏感信息**
> 将候选人简历、应聘行为、测评信息、面试官姓名、面试评价、薪酬信息等系统信息等敏感信息，以口头、截图、文字、录像等方式向候选人、媒体、其他组织进行传播的行为。

包括但不限于：
- **1.1** 招聘过程中因发布不当信息或产生不当言行，造成内外部舆论或其他不良影响，导致公司声誉、形象、价值观、雇主品牌受到严重损害的行为。不当信息或不当言行包括但不限于：在招聘广告中发布不当信息，在面试官过程中与候选人沟通中有不当言论；
- **1.2** 将面试官、面试评价以口头告知、系统截图等方式透露人选或其他不相关人士的行为；
- **1.3** 将候选人的简历、应聘行为、测评信息以口头、系统截图等方式透露给其他不相关人士的行为；
- **1.4** 将招聘系统信息通过口头、文字、截图等信息传达给候选人的行为（如：简历被锁定、测评未通过等）；

> 定档：若导致公司声誉/形象/价值观/雇主品牌受到**严重损害或大额经济损失**→**高压线**；若受到**损害或一定经济损失**→**较重违纪**。

**② 不当言论 / 不当信息发布**
> 招聘过程中因发布不当信息或产生不当言行造成内外部舆论或其他不良影响，导致公司声誉、形象、价值观、雇主品牌受到损害的行为。

包括但不限于：
- **2.1** 在面试过程中或与候选人沟通中出现**性别/宗教/政治倾向/种族歧视、不尊重贬低他人**等言论的行为；
- **2.2** 因对外发言（如参与外部活动、对外培训等场景）或发布内容（如平台内容发布）不当的行为。

> 定档：**严重损害/大额经济损失**→高压线；**损害/一定经济损失**→较重违纪。

**③ 不当得利**
> 招聘过程中通过不当方式获取利益。

包括但不限于：
- **3.1** 收受候选人及其相关利益方的贿赂（包括但不限于现金、礼品、服务、折扣、借款等）；
- **3.2** 对外售卖公司内部敏感信息等；

**④ 不当竞争**
> 在招聘过程中存在使用非正常手段恶意争夺招聘资源（候选人、经费等）行为。

包括但不限于：
- **4.1** 未经正式授权，使用脚本或自动化爬虫工具进行招聘系统操作；
- **4.2** 私自通过猎头进行候选人的开源和面试；
- **4.3** 挖猎内部员工，或其他部门已 offer 的候选人（含社招、校招），被用人部门投诉的；
- **4.4** 面试或对外宣讲活动中，贬低或诋毁其他部门，或者教唆候选人拒绝其他部门 offer，被投诉的；
- **4.5** 不遵守系统流程优先规则或特定项目规则，抢面其他部门面试流程中的候选人，被投诉的。特定项目包含校招技术大咖招聘、社招 AI 头部人才招聘项；
- **4.6** 不遵守校招宣传规则，如在校招过程中未经总部报批私自进校宣传面试、私建宣传群、以各种理由或方式引导学生私下投递简历，即未通过 **join.qq.com** 接收简历/邀约面试等破坏内部公平性的行为；

**⑤ 其他不当行为**
> 在招聘过程中存在其他不当行为或其他不合规行为。

包括但不限于：
- **5.1** 违反法律对候选人有**骚扰或侵害**的行为；
- **5.2** 与候选人串谋提供虚假信息；
- **5.3** 校园招聘宣讲、线路面试或其他集中招聘活动中，临时爽约或中途离开现场导致后续安排无法正常进行的行为；
- **5.4** 绕过系统权限：替没有面试官权限（含通道、面委面试官权限）的人进行系统操作，或让没有面试官权限的人代为面试；

### 2、评估周期

- **月度**为周期，对行为指标进行**动态监测**（保证及时性）；
- **年度**为周期，进行**综合评估**（保证面试官行为和面试质量数据评价的累积性）。

### 3、数据来源

信用分的统计结合了社招和校招场景，数据来源包含：**招聘系统数据、候选人问卷反馈、面试入职员工的绩效和稳定性**数据等。

---

### 4、应用

每个评估周期结束后，会将面试官信用得分情况同步至**招聘经理**，展现该面试官在部门人才引进方面所做的贡献。

#### 面试官激励
- 每年评选一定数量的**公司级优秀面试官**，在全公司范围内进行宣传表彰，并给予相应激励。
- 对信用分数比较高的面试官，公司还会精心安排进阶学习提升机会，例如**旁听顶尖面试官面试**，或参与**面试甄选专家的 VIP 课程**等。

#### 面试官权限取消与暂停（⭐处罚对照）

| 行为档位 | 处罚 |
|---------|------|
| **高压线行为** | 根据《腾讯阳光行为准则》进行相应处罚，同时**取消面试官权限，且一年内不得再次申请** |
| **较重违纪行为** | 根据具体细则（见附件），**取消面试官权限，一年内不得再次申请，已有信用分清零** |
| **违纪行为** | 根据具体细则，取消面试官权限一年内不得再次申请，或发生一次**扣 45 分信用分**；若**同一考核周期内发生 2 次违纪行为**，则取消面试官权限，且一年不得再次申请 |
| **单项不达标**（专业度/时效性/面试质量） | 评估周期结束后单项得分不达标 → **暂停**面试官权限（**连续两次面试质量不达标 → 权限被取消**），同时邮件通知本人及上级；需完成相应课程和环节后方可重新开通 |

#### 面试官惩处决议执行规范（⭐谁来通知）

| 行为档位 | 执行主体 |
|---------|---------|
| **高压线行为 / 较重违纪行为** | 由**集团面试官管理团队**进行惩处决议的说明与通知，**BG 招聘侧协助邀约** |
| **违纪行为 / 日常信用行为** | 由 **BG 招聘侧主导**进行惩处决议的说明与通知，如有需要集团面试官管理团队可协助 |

## 三、量化评分细则（加分与扣分规则 · 内部依据）🔒

> 官方评分表（6图录入）。信用分以扣/加分动态计算。**分值仅供内部定档参考，绝不对外引用。**

### 3.1 违规违纪类（直接扣大分）

| 行为分类 | 二级指标（触发行为） | 加/扣分规则 |
|---------|-------------------|------------|
| **高压线行为** | ①发布不当信息/不当言行致公司声誉形象价值观雇主品牌**严重损害**（招聘广告不当信息、面试中不当言论）②将公司机密/敏感信息泄露给候选人**且造成严重后果** ③泄露招聘相关机密/敏感信息造成严重后果（候选人简历/应聘行为/面试官姓名/面试评价等）④收受候选人及利益方贿赂（现金/礼品/服务/折扣/借款）⑤违反法律对候选人有骚扰或侵害 | 参照《腾讯阳光行为准则》处理，**同时信用分直接扣 100 分** |
| **较重违纪行为** | ①发布不当信息/不当言行致声誉形象价值观雇主品牌**损害**（未达严重）②将公司机密/敏感信息泄露给候选人**但尚未造成严重后果** ③泄露招聘相关机密/敏感信息但未造成严重后果（简历/应聘行为/面试官姓名/面试评价等） | 参照《腾讯阳光行为准则》处理，**同时信用分直接扣 60 分** |

### 3.2 违纪行为（扣 45 分档，部分二次取消权限）

| 触发行为 | 加/扣分规则 |
|---------|------------|
| 挖猎内部员工，或其他部门已 offer 的候选人（含社招/校招），被用人部门投诉 | 在总分基础上**扣 45 分，取消面试官权限，一年内不得申请** |
| 面试或对外宣讲中贬低/诋毁其他部门，或教唆候选人拒绝其他部门 offer，被投诉 | 同上（扣45+取消权限一年） |
| 不遵守系统流程优先规则或特定项目规则，抢面其他部门流程中候选人，被投诉（特定项目=校招技术大咖/社招AI头部人才招聘等） | 同上（扣45+取消权限一年） |
| 替没有面试官权限（含通道/面委面试官权限）的人做系统操作，或让无权限者代为面试 | 同上（扣45+取消权限一年） |
| 校招过程中以各种理由引导学生私下投递简历，即未通过 join.qq.com 接收简历 | **扣 45 分** |
| 校园招聘宣讲/线路面试/集中招聘活动中，面试官临时爽约或中途离开导致后续无法正常进行 | **扣 45 分** |
| 使用脚本或外挂进行招聘系统操作 | 扣 45 分，取消权限一年内不得申请（注：需释放名下简历） |
| 私自通过猎头进行候选人开源和面试 | 出现第一次扣 45 分；**出现第二次取消面试官权限，一年内不得申请** |

### 3.3 日常信用行为（满分 100 = 专业度50 + 时效性30 + 面试质量20）

> 日常信用是**加/扣分制**的动态评估，围绕三维度。以下为各维度评分要点（细则以官方表为准）。

**① 面试行为专业度（50 分）**

| 情形 | 加/扣分 |
|------|--------|
| 面试中让候选人产生正面积极印象，收到候选人调研问卷实名点赞（专业能力强/态度友好/职业化/主动介绍公司岗位非敏感信息，吸引候选人加入） | **出现一次 +1 分** |
| 面试迟到超15分钟、且未与候选人沟通，引发反馈/投诉 | 出现一次扣 6 分 |
| 面试迟到或爽约但有沟通，引发反馈/投诉 | 出现一次扣 4 分 |
| 面试迟到/爽约引发反馈或投诉（一般） | 出现一次扣 2 分 |
| 面试时长过短（社招<15min，校招<10min），引发反馈/投诉 | 出现一次扣 2 分 |
| 未做说明前提下全程不开摄像头/单方面看候选人打开摄像头 | 出现一次扣 2 分 |
| 面试即将结束时未给候选人主动提问机会，引发反馈/投诉 | 出现一次扣 2 分 |
| 对候选人背景/经历表现出嫌弃或嘲讽，引发候选人不忿 | 出现一次扣 2 分 |
| 面试中频繁看手机/电脑且未做任何说明 | 出现一次扣 4 分 |
| 与候选人面试时态度傲慢 | 出现一次扣 2 分 |
| 其他投诉行为按情节严重程度扣 2/4/6/8 分 | 视情节 |
| 给候选人作出薪酬/职级/户口/录用等不当承诺，且引发争议 | **出现一次扣 30 分** |
| 校招中未提前与学生沟通达成一致、使用系统操作延长流程有效期，引发学生投诉 | 出现一次扣 5 分，并立即处理系统流程 |
| 社招为延长简历锁定期、未经面试即填写面试评价，引发候选人投诉 | 出现一次扣 5 分，并立即处理系统流程 |

**② 面试时效性（30 分）**

| 情形 | 加/扣分 |
|------|--------|
| 校招简历期限内及时处理率（推荐/锁定3工作日；简历分配/面试8工作日）·收到校招简历≤4份 | 按未处理份数扣分：1份扣4分/2份扣8分/3份扣12分/4份扣16分 |
| 校招简历>4份 | 按处理比例赋分：处理率100%加3分；99%-95%加2分；94%-90%加1分；89%-80%不扣分；每低于80% 每5个百分点扣1分（如79%-75%扣1分、74%-70%扣2分依次类推） |
| 伯乐简历初筛期限内及时处理率（4工作日）·收到伯乐推荐≤4份 | 按未处理份数扣分：1份扣4分/2份扣8分/3份扣12分/4份扣16分 |
| 伯乐简历>4份 | 处理率≥90%不扣分；低于80%每5个百分点扣1分；每高于90%每5个百分点加1分（如90%-95%加1分、75%-80%扣1分、70%-75%扣2分依次类推） |
| 社招面试安排及时响应（3工作日内给小助手可面试时间）* | 国内：处理率100%加3分；每出现一次逾期未处理扣1分，扣完为止 |

**③ 面试质量（20 分）**（基于近2年带入候选人绩效 + 半年内离职率）

| 情形 | 得分 |
|------|------|
| 近2年有绩效人数≥4，候选人平均绩效≥4，且半年内离职率<10% | **20 分** |
| 有绩效人数≥2，平均绩效≥3.33且<4，半年内离职率<10% | **15 分** |
| 有绩效人数≥2，平均绩效2.75-3.33/或≥3.33但离职率10%-25% | **10 分** |
| 其他所有情况 | **8 分** |
| 平均绩效2.75-3.33且离职率10%-25% / 有绩效2或3且绩效2.5-2.75 | **5 分** |
| 有绩效人数不限、半年内离职率>25%且离职人数>1 / 绩效<2.5 / 有绩效>3且绩效<2.75 | **0 分** |

> 📌 分值只用于内部算信用分、定档、给招聘经理解释处罚力度。**对外一律不提分数。**

## 四、Amy 怎么用（③面试体验差舆情定性）

1. **先归档档位**：面试官被投诉 → 对照"五类不当行为 + 三档后果标准 + 量化扣分"，判定属高压线/较重违纪/违纪/日常信用哪一档、约扣多少分。
2. **给处罚预期**（仅内部/给招聘经理）：按"权限取消与暂停"表+量化细则说明（如高压线扣100分+取消权限一年；较重违纪扣60分；违纪扣45分）。
3. **说清谁执行**：高压线/较重违纪→集团面试官管理团队主导（BG协助邀约）；违纪/日常→BG招聘侧主导。
4. **🔒 话不说满·对外不引用**：对外只表态"经核实存在不当行为，已依据公司相关规定严肃处理"，**绝不透露本制度的条款/档位名/分值**，不点名。
