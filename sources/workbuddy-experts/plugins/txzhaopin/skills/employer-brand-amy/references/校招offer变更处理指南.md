## 一、整体原则（offer = 法律"要约"，不可单方撤销）

- offer（含意向书）在法律上是**要约，一经有效承诺即具效力**，不得随意更改/撤销，**严禁无背景单方面取消**。
- 确因**不可抗力**需变更/撤销 → **任何决定都要第一时间与「部门 GM + BG 校招团队 + HRD」对齐**，再**报备至：BG ER、集团校招与雇主品牌中心、集团法务、CER**；在**不损害同学权益**前提下友好协商，**协商一致后方可变更**。
- **原则上不允许单方调整**学生录用通道职位、薪酬、工作地；如属双方协商一致的调整（如与友商 offer 竞争而调薪）→ **保留沟通记录**。
- 仅组织架构调整、不涉 offer 明确约定内容、不影响落户/人才补贴 → 可**轻量沟通**（微信书面确认）；**影响落户等 → 必须发书面邮件**说明变更。

## 二、变更/撤销分类规则

### 1. 组织问题（公司侧）

**1）跨 BG / BG 内"整建制"组织架构调整**（组织仍在，仅 A 业务调到 B 业务）
- 若薪酬/录用通道职位/工作地等 offer 明确约定项**无变化** → 公司**无直接过错责任**，但沟通须友好协商。
- 学生**接受** → **无需重发 offer**，但需**书面留存沟通记录**，确保学生知悉组织架构变化。
- 学生**不接受** → 按**学生方毁约**处理。

**2）BG 组织裁撤/精简/业务调整致无法接收学生**（组织可能不存在，学生需支持其他业务）
- 组织变动后**及时与学生沟通**说明变动。
- **调整接收优先级**：本部门内 → 本 BG 内 → 跨 BG（跨 BG 可联系集团校招与雇主品牌中心专项讨论）；尽量选**与原职责相近**的岗位。
- 学生**接受** → 无需重发 offer，书面留存沟通记录。
- 学生**不接受** → 公司有**缔约过失责任**，造成缔约损失，需**酌情赔付补偿金**（能协商一致也可不赔）；金额一般为 offer **1-3 个月月薪**，参照公司赔偿标准、按同学具体情况定。

### 2. 学生问题

**1）学生延毕 / 延期入职**（毕业生=正式入职，实习生=实习入职 未按时完成）
- 部门/招聘经理按应对方案：可**延长最晚入职时间保留 offer**，或**协商解除录用关系**。

**2）学生个人健康问题**
- 学生问询健康是否影响入职 → **不做任何承诺，也不能立刻据此解除 offer**。
- 须引入**健康顾问评估**严重性 + 联动 BG 校招团队、BG ER、集团校招与雇主品牌中心、集团法务、CER 处理。

**3）学生违反 offer 条款 / 高压线**
- 需取得学生**违反条款/高压线行为的直接明确证据** → 联动 BG 校招团队、BG ER、集团校招与雇主品牌中心、集团法务、CER 处理。

**4）毕业生实习阶段工作表现严重消极**
- ⚠️ **法律上不能把"实习表现"与"正式 offer"直接关联**——不能在正式 offer 里约定"实习表现不佳即单方撤销"。
- 业务反馈"想撤销" → 先**卷入 BP、BG ER 评估情节严重程度**。
- 排除学校要求等客观因素后，**确认学生主观故意且严重消极怠工** → 才升级 BG 校招团队、集团校招与雇主品牌中心、集团法务、CER 处理。

## 三、赔偿金赔付标准（校招）

| 候选人情况 | 赔付标准（offer 月薪·税前） |
|-----------|------------------------|
| 学生已接受正式 offer 且**无交三方** | 不高于 **1 个月** |
| 已接受 + **已交三方**，学校**支持**毁约、**不影响落户** | 不高于 **2 个月** |
| 情况1：已接受+已交三方，**学校不支持毁约、影响落户** | 不高于 **3 个月** |
| 情况2：**毁约时间在学生毕业当年** | 不高于 **3 个月** |
| 情况3：**学生已在毕业生实习** | 不高于 **3 个月** |

- ⭐ **补偿金额以 alex 审批后金额为准**（社招是 kenny；校招是 **alex**）。
- 税务：该赔偿金属**非劳动合同下赔偿**，学生非腾讯员工、未提供服务 → **不属个税征税范围、不扣税**（合并工资计税选"否"、无票据）。

## 五、通用沟通流程与话术（电话沟通·6 段）

> ⚠️ **口径铁律：不能提敏感字眼**（不说"裁撤/砍业务/取消"），统一包装为"业务侧调整和安排"。

```
① 开场：介绍自己 + 确认本人 + 问是否方便接听（不便另约、提醒安静环境）
   "你好！请问是 xxx 同学吗？我是腾讯 HR XXX，目前方便接听电话吗？"

② 背景介绍：说明沟通目的，业务调整对录用的影响，不提敏感字眼
   "本次主要同步和你相关的业务侧调整。基于外部市场环境变化及公司产品策略和重心调整的需要，
    经慎重考虑，公司需要对 XXX 组织进行一些调整。你之前录用的业务组织是 X，目前有变动，
    录用信息也有调整——但不用担心，校招生是腾讯宝贵的人才资源，公司会尽可能倾斜资源保障权益。"
   （停顿 4-5s，观察情绪，有疑问及时解释）

③ 去向安排：讲清录用变化点 + 新去向介绍（强调尽量保障权益）
   "在调整大背景下，对你：薪酬、职位、工作地不会变动，校招 offer 也稳定有效，这点不必顾虑。
    但入职部门/中心会变化——之前你在 xx 部门做 xx，本次调整后进入 xx 线 xx 部门、支持 xx 业务；
    业务变了但职位没变，工作内容仍是 xxx。"

④ 询问意愿 → 三分支：
   · 直接接受 → 致谢 + 强调保密（见⑤保密话术）
   · 需要考虑 → 请 3 个工作日内给准确答复 + 保密提醒
   · 直接拒绝 → 了解原因 + 安抚引导；仍不接受则"公司理解尊重你的选择，将走 offer 协商一致解除流程"

⑤ 保密提醒（高压线，接受/考虑分支都要说）：
   "温馨提醒，薪酬及录用相关内容是腾讯公司高压线，不得与他人交流或在社媒传播，请务必保密；
    如发现信息泄露，公司会依据相关规定撤销录用。"

⑥ 结尾：
   · 接受变更 → 致谢 + 微信文字确认最终意向 + 表示抱歉给同学带来变化
   · 解除录用 → "稍后发双方协商一致解除录用关系邮件，按指引回复；完成解约会及时释放简历"
     （如赔付）"根据规定公司会赔付你 X 个月赔偿金，请在邮件写明个人信息；如需其他帮助也会尽力协助"
```

## 八、校招处理铁律（招聘经理记死）

1. **不可单方撤销**：offer 是要约，无背景不得单方取消；变更先与 GM+BG校招团队+HRD 对齐、再报备 ER/集团校招与雇主品牌中心/法务/CER。
2. **优先调整接收**：组织问题先本部门→本BG→跨BG 找相近岗位安置，能接收就不撤销。
3. **接受要书面留存，不接受才走毁约/赔偿**：整建制调整(无约定项变化)学生不接受=学生方毁约；组织裁撤致无法接收学生不接受=公司缔约过失，赔 1-3 月。
4. **健康/违纪/实习消极不可武断**：健康引健康顾问、违纪要直接证据、实习消极需主观故意+卷 BP/BGER 评估，都不能单方拍板撤 offer。
5. **沟通不提敏感字眼**：统一"业务侧调整/产品策略和重心调整"，电话沟通、停顿观察情绪。
6. **保密是高压线**：薪酬/录用内容不得外传，泄露可撤销录用。
7. **赔偿按档、alex 批**：交三方/落户/毕业当年/已实习对应 1-3 月，金额以 alex 审批为准，XZQX 项目走 fpp。
8. **撤销必落字**：协商一致解除发正式邮件（需/无赔偿两版）+ 微信/邮件确认，释放简历。
