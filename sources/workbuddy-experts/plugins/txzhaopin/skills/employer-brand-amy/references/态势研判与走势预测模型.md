# 舆情态势研判 + 走势预测模型

> Amy 的核心差异化能力。这是上次诊断中标注的"最大空白"。
> 回答两个经理最关心的问题：**「这条会不会发酵？」** + **「要不要马上处理、多急？」**
> 与 `舆情危机处理方法论.md` 配合使用：方法论讲"怎么定性判断"，本模型讲"怎么量化打分+预测走势"。

---

## 〇、第一决策：四象限「处理 / 不处理」判断（腾讯实际口径，最优先）⭐⭐⭐

> 这是 Kathy 团队真实使用的舆情决策核心。一条舆情进来，**先用四象限决定"要不要处理"**，再用后面的打分模型决定"多急、怎么处理"。

舆情出现 → 按「**数据高低 × 影响力高低**」分四象限：

```
                 影响公司（影响力高）
                        │
   数据低+影响力高        │      数据高+影响力高
   （无热度/初期但影响公司）│   （已成热度且影响公司）
        ✅ 处理          │        ✅ 处理
────────────────────────┼────────────────────────  数据高低
   数据低+影响力低        │      数据高+影响力低
   （不具热度不影响公司）  │   （有热度但不影响公司）
        ❌ 不处理         │        ❌ 不处理
                        │
                 不影响公司（影响力低）
```

**核心铁律：「是否影响公司」是处理/不处理的总开关**——
- **影响公司 → 处理**（不论数据高低，哪怕还在传播初期）。
- **不影响公司 → 不处理**（哪怕数据热度高，只要不伤及公司，也不动）。

**两个维度怎么判断**：
- **数据高低**：**先做全网搜索**摸清扩散面，用**各平台汇总数据**（非只看原帖）对照下方「五、数据阈值表」（腾讯口径：**点赞+评论 35** 为基准线）。
- **影响力高低（是否影响公司）**：是否伤及公司声誉/雇主品牌/价值观/招聘转化？是否点名公司+具体事？是否可能引发法律/监管/媒体跟进？是否戳中可代入的群体痛点？

> ⭐ **判断等级前先全网搜索**：以事件关键词在 6 平台（小红书/脉脉/微博/公众号/视频号/网媒）搜一遍，摸清「扩散到哪些平台、累计热度、增长速度、有无大V/媒体介入」——这才是定级的真实数据依据，不可只看单帖拍脑袋。详见《舆情处理执行流程SOP》步骤2.1。

> 判断完四象限 → 若结论是"处理" → 继续走下面 ①~⑤ 打分定级和走势预测；若"不处理" → 进入「监测7天规则」（见第五章末）。

## 一、整体研判流程（一条舆情进来怎么走）

```
发现一条负面
    ↓
〇 四象限判断：数据高低 × 影响力高低 → 处理 / 不处理（影响公司=总开关）
    ↓（判定"处理"才继续）
① 情绪烈度打分（这条本身有多负）
    ↓
② 传播势能打分（它正在以多快速度扩散）
    ↓
③ 发酵概率预测（会不会变大）
    ↓
④ 紧急度分级（多久内必须动手）
    ↓
⑤ 输出研判卡 → 交给行动建议框架
```

---

## 二、① 情绪烈度打分（事件本身有多负，满分 25）

判断这条内容**自身的杀伤力**，与传播量无关。四个维度各 0-5 分，再叠加"杀手锏"加权。

| 维度 | 0-1分 | 2-3分 | 4-5分 |
|------|-------|-------|-------|
| **负面强度** | 轻微吐槽/调侃 | 明确不满/批评 | 愤怒/控诉/号召抵制 |
| **指向性** | 泛泛而谈行业 | 指向公司某部门/某产品 | 点名公司+具体人/具体事 |
| **真实性观感** | 明显情绪宣泄/无证据 | 半真半假/有截图 | 有实锤证据/可被验证 |
| **可扩散性** | 圈层内自嗨 | 有共鸣潜质 | 戳中普遍痛点（人人代入） |

**杀手锏加权**（来自方法论第三章，每命中一项 ×1.2，可叠加）：
- 道德作风（歧视/PUA/不尊重/价值观崩塌）
- 物质利益（薪资缩水/福利降级/裁员/贫富对立）
- 民族情绪（涉国家地区表述/崇洋/不尊重本土）

> 计算：基础分（4维度合计，满分20）× 杀手锏系数 = 情绪烈度分（封顶25）。
> 例：基础14分，命中"道德作风"1项 → 14×1.2 = 16.8。

## 三、② 传播势能打分（扩散速度，满分 25）

判断这条**正在以多快的速度、多大的范围扩散**。区别于"绝对量"，**增长速度比绝对值更重要**。

### A. 绝对量档位（腾讯实际口径，0-10分）

> ⭐ **小红书基准线 = 点赞+评论 35**（团队真实阈值，源自《校招小红书舆情处理》SOP）。

| 平台 | 预警档(3-4分) | 预处理档(6-7分) | 危机档(9-10分) |
|------|-------------|---------------|---------------|
| **小红书** | 点赞+评论 ≥ 35 | 点赞+评论 ≥ 100 | 上热榜 |
| 抖音/视频号/头条 | 收藏评论>10 | >30 | 进推荐/热榜 |
| 公众号 | 阅读>5000 | >5万 | 核心号推送 |
| 脉脉 | 阅读>1万 | 当天>3万 | 出现转发 |
| 微博 | 转发>50/评论>100 | 转发>500 | 上热搜 |
| 机构媒体 | <5家核心转发 | 5家左右 | >5家/党央媒体转发 |

> 📌 小红书的 **35（点赞+评论合计）** 是团队判定"热度高/需介入"的硬线：
> - 点赞+评论 ≥ 35（且影响公司）→ 进入处理流程（官号私信+评论区回应）
> - 点赞+评论 < 35（热度低）→ 走「监测7天规则」，每天截图至监测群，7天无变化可不处理

### B. 增长速度档位（0-8分）⭐ 关键

| 速度 | 判断 | 分数 |
|------|------|------|
| 平缓 | 24h 互动增量 < 50% | 0-2 |
| 上升 | 24h 互动翻倍 | 3-5 |
| 陡增 | 6h 内互动翻倍 / 持续爬升 | 6-8 |

### C. 跨平台扩散档位（0-7分）

| 状态 | 分数 |
|------|------|
| 仅单平台、单帖 | 0-2 |
| 单平台多帖讨论 | 3-4 |
| 已跨 2 个平台 | 5-6 |
| 跨 3+ 平台 / 媒体介入 | 7 |

> 传播势能分 = A + B + C（封顶25）。

## 四、③ 发酵概率预测（会不会变大）⭐ 经理最关心

不是看现在多大，而是预测**未来 24-72h 走势**。用"发酵信号清单"，命中越多概率越高。

### 发酵加速信号（命中即加分，每项 +1）
- [ ] 有大V / 蓝V / 媒体账号介入或转发
- [ ] 内容带"实锤"截图/录音/聊天记录（可验证）
- [ ] 戳中当下社会情绪（反资本/反特权/反西化/反压榨）
- [ ] 命中"杀手锏"组合（道德+利益+民族 ≥2项）
- [ ] 我方是公众认知的"强者"（强弱身份不对等，舆论天然偏向弱者）
- [ ] 出现在敏感时间节点（公共事件期/纪念日/友商同类事件期）
- [ ] 标题/话题有"可二创/可玩梗"属性（B站/抖音易裂变）
- [ ] 已有"搬运/合集"出现（一个号搬到多个平台）

### 发酵抑制信号（命中即减分，每项 -1）
- [ ] 内容为纯情绪宣泄、无证据
- [ ] 发布者为小号/僵尸号/无影响力
- [ ] 我方在事件中处于"弱者"或"合理方"位置
- [ ] 话题专业门槛高、普通人难代入
- [ ] 已过黄金发酵期（事件发生 >72h 仍无声量）

**发酵概率判定**：

| 净信号数 | 发酵概率 | 含义 |
|---------|---------|------|
| ≥ +4 | 🔴 高（>70%） | 大概率扩大，必须前置介入 |
| +1 ~ +3 | 🟡 中（30-70%） | 需密切观察，备好预案 |
| ≤ 0 | 🟢 低（<30%） | 大概率自然消退，监测即可 |

## 五、④ 紧急度分级（多久内必须动手）⭐

综合烈度+势能+发酵概率，给出**响应时限**。这是经理拿到研判后第一眼要看的。

| 级别 | 触发条件（满足任一） | 响应时限 | 谁来拍板 |
|------|-------------------|---------|---------|
| **P0 火警** 🔴🔴 | 上热搜/热榜 · 党央媒体介入 · 命中高压线（泄密/严重造谣/政治） · 情绪烈度≥20 | **2 小时内**响应 | **涉事 BG 业务 PR 主办**，立即同步 雇主品牌接口人；影响过大→集团 PR + 雇主品牌接口人 联合 |
| **P1 高危** 🔴 | 发酵概率高 · 已跨3+平台 · 大V介入 · 传播势能≥18 | **当天**（4-6h内）出方案 | Amy 出方案 → BG 业务 PR 主办，同步 雇主品牌接口人 确认方向 |
| **P2 关注** 🟡 | 发酵概率中 · 单平台有一定声量 · 传播势能 10-17 | **24 小时内**预案就位，持续盯 | Amy 自主处理 |
| **P3 观察** 🟢 | 发酵概率低 · 零星负面 · 传播势能<10 | 记录入库，**定期巡检** | Amy 监测，不主动动作 |

> **综合分参考线**（情绪烈度25 + 传播势能25 = 50满分，辅助判断）：
> ≥35 → 大概率 P0/P1；20-34 → P2；<20 → P3。但**发酵概率和高压线可一票升级**。

### 「不处理」分支：监测 7 天规则（腾讯实际做法）

四象限判定为"不处理"（不影响公司，或热度低未达阈值），**不是放任不管**，而是走监测程序：
- **每天下班前截图**当前数据（点赞/评论/收藏），发到监测群留痕。
- **持续维持 7 天**：若 7 天内无明显热度变化、未升级 → 可正式不处理、关闭跟踪。
- **若期间数据破阈值（小红书点赞+评论达35）或开始影响公司** → 立即重新进入四象限判断 → 转处理流程。

## 七、周期性态势研判（非单点，而是看趋势）

用于"这周社媒舆情如何"这类周报场景——不只是罗列，而是**给出态势判断**。

### 情绪趋势打分（环比）
- 本周整体情绪指数 = 正面% − 负面%（-100 ~ +100）
- 与上周对比：↑改善 / →持平 / ↓恶化
- 标注**异常波动点**（哪天/哪个事件导致情绪骤降）

### 态势定性（四象限）
```
              声量高
                │
   🟡 热议期    │   🔴 风险期
（高声量+偏正）  │ （高声量+偏负）
────────────────┼────────────────
   🟢 平稳期    │   🟠 隐患期
（低声量+偏正）  │ （低声量+偏负）
                │
              声量低
```
- 🔴 风险期：立即重点投入处置
- 🟠 隐患期：声量虽低但情绪差，警惕单点引爆
- 🟡 热议期：顺势放大正面、引导话题
- 🟢 平稳期：常规监测

### 走势预判输出
- 下周需重点盯防的话题 TOP 3
- 潜在引爆点提示（哪些隐患帖可能发酵）
- 友商动态可能带来的连带影响

## 八、使用要点

1. **打分是辅助、定性是核心**——分数帮你快速排序，但"高压线""强者身份""杀手锏组合"可直接一票定级，不被分数束缚。
2. **速度 > 绝对值**——6小时翻倍的50条评论，比平缓的500条更危险。
3. **预测要给关键变量**——不说"可能会火"，要说"盯住XX大V是否转发，转了就升 P1"。
4. **每条研判都要落到行动**——研判卡末尾必须接《行动建议框架》，不做"只诊断不开药"。
5. **算分用脚本、定级别心算**——各维度打几分由你判断(看内容定0-5)，但把分值代入公式算总分/P级时，调用 `scripts/score.py` 算准算一致，别手算（情绪烈度×1.2系数、综合分阈值、一票升级容易算错）。小红书发布时间同理用 `scripts/xhs_time.py`。
