# 模块二：技术影响力评估

**适用时机**：评估公司/BG/部门在技术人群中的影响力认知

## 1. 标准问卷模板（13维度量表）

```
【核心量表】技术影响力13维度评价
  统一6分量表：非常差(0)→非常好(100)
  评价对象：可设为公司整体 / 各BG / 各部门

  维度列表：
  1. 综合技术影响力（综合评估）
  2. 知名度（公司/产品知名度）
  3. 研发资源（资金、数据、算力）
  4. 技术价值（落地场景、用户规模）
  5. 技术挑战（问题复杂度）
  6. 技术积累（技术底蕴深厚）
  7. 基础建设（基础设施水平）
  8. 投入耐心（持续投入意愿）
  9. 科研自由度（授权与自由）
  10. 技术创新（前瞻性与创新力）
  11. 技术产出（科研成果丰富度）
  12. 优秀人才（大牛与团队）
  13. 技术氛围（协作与分享）

【补充模块】
  - 技术信息获取渠道（GitHub/知乎/公众号/论文/同行...）
  - 技术品牌印象最深的事件/内容（限写1个具体事例）
  - 说起XX的技术实力，你第一时间想到的3个关键词是？
  - 技术方向关注偏好（AI/大模型/云/安全/音视频...）
```

## 2. 分析框架

| 分析板块 | 方法 | 输出 |
|---------|------|------|
| 综合得分排名 | 均值+排序 | 横向柱图（竞品对比） |
| 各维度详细评分 | 13维度×竞品矩阵 | 雷达图/热力图 |
| 优势/短板识别 | 高分/低分维度 | 象限图（重要性×评分） |
| 人群差异 | 按专业/学历/求职阶段切 | 分组对比图 |
| 年度变化 | 同比差值(pp) | 趋势折线图 |

## 3. 标杆案例参考

> 技术影响力评估常见的对标维度：顶会论文数量、开源项目Stars、技术博客影响力、技术社区活跃度、专利数量。但问卷只能测"认知"，客观数据需另行采集后与认知数据交叉。
