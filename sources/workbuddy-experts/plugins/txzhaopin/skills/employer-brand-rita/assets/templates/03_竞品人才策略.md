# 模块三：竞品人才策略调研

**适用时机**：了解竞品在人才争夺中做了什么、做得怎么样

## 引导制对话（通过问答明确需求）

```
Rita 会问：
Q1. 你想了解哪些竞品的人才策略？（列出3-5家）
Q2. 关注哪个层面？
   - [ ] 校招策略（宣讲、活动、渠道、品牌）
   - [ ] 社招策略（薪酬竞争力、人才通道、猎头策略）
   - [ ] 技术品牌（开源、顶会、技术博客、社区运营）
   - [ ] 雇主品牌传播（媒体投放、社交媒体、KOL合作）
   - [ ] 综合全景
Q3. 有具体想验证的假设吗？
   例如："字节今年在AI方向投入更大了"/"阿里校招规模缩减了"
Q4. 信息获取方式偏好？
   - [ ] 纯桌面研究（公开信息搜集分析）
   - [ ] 问卷调研（问候选人的看法）
   - [ ] 深度访谈（找有竞品经历的人聊）
   - [ ] 混合方法
```

## 标准分析维度

| 维度 | 具体内容 | 信息源 |
|------|---------|-------|
| 校招规模 | 招聘人数、岗位分布、目标院校 | 官网/宣讲信息/行业报告 |
| 薪酬竞争力 | 薪资水平、期权政策、签字费 | 候选人调研/社媒/猎头 |
| 品牌活动 | 宣讲会/hackathon/夏令营/开放日 | 官方渠道+社媒观察 |
| 技术品牌 | 顶会论文/开源项目/技术blog | GitHub/arXiv/官方公众号 |
| 雇主传播 | 投放渠道/KOL合作/内容策略 | 社媒监测+公开案例 |
| 人才政策 | 培养计划/晋升通道/内部转岗 | 候选人访谈/Glassdoor/脉脉 |
| 候选人口碑 | NPS/推荐率/面试体验评价 | 调研数据/社媒讨论 |
