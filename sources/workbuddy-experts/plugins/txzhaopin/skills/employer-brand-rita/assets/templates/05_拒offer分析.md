# 模块五：拒绝Offer原因分析

**适用时机**：offer接受率下降、想了解候选人拒绝的真实原因

## 1. 拒offer调研问卷

```
【基础信息】
Q1. 你申请的岗位类型（单选）
Q2. 面试轮次到了哪一步（单选）

【决策过程】
Q3. 你最终选择了哪家公司？（单选+其他填写）
Q4. 选择对方而非我们的核心原因？（多选TOP3）
    - 薪酬更高 / 发展空间更大 / 业务方向更感兴趣
    - 工作强度更合理 / 城市更理想 / 团队氛围更好
    - 技术挑战更大 / 公司前景更好 / 品牌更有吸引力
    - offer速度更快 / HR/面试官体验更好
    - 家人/朋友建议 / 其他：__
Q5. 有没有哪个因素是"一票否决"的？（单选+填写）
Q6. 做决定的过程中，谁影响了你？（多选）
    - 自己判断 / 家人 / 朋友/同学 / 学长学姐 / 导师 / 社交媒体

【体验反馈】
Q7. 整个招聘过程中，你对我们的体验如何？（5级量表）
Q8. 面试过程中有让你"减分"的环节吗？（多选）
    - 等待时间长 / 面试官不专业 / 流程不清晰
    - 反馈太慢 / 薪酬谈判不愉快 / 没有被尊重感 / 没有
Q9. 如果我们只改善1件事就能让你重新考虑，那件事是什么？（单行文本）

【竞品对比】
Q10. 你对比了哪些公司的offer？（多选）
Q11. 对方offer哪些方面优于我们？（多选同Q4选项）
```

## 2. 分析产出

```
一、拒offer全景数据（拒绝率×岗位/部门/时段）
二、核心拒绝原因TOP5排序（整体+分岗位）
三、竞品流向分析（人去哪了？为什么？）
四、"一票否决"因素识别
五、体验卡点定位（招聘流程中的减分环节）
六、挽回空间评估（什么条件下会重新考虑）
七、行动建议（对招聘经理 / 对薪酬团队 / 对品牌团队）
```
