# Amy 舆情数据接入（调研报告的实时口碑佐证）

> 🎯 **解决什么问题**：Rita 的调研数据是"静态快照"——问卷/访谈反映的是**采集当时**目标人群的系统性认知。但它有两个天然盲区：①**滞后**（问卷做完到出报告有时间差，期间可能出了新舆情）；②**抓不到突发热点与情绪细节**（问卷问的是结构化维度，答不了"最近网上在骂什么具体的事"）。
> Amy（舆情口碑专家）沉淀在校招 MCP 里的**历史舆情 case**，恰好补上这两块——它是"动态实况+具体事件+情绪原声"。Rita 出报告时把 Amy 的舆情数据接进来，报告就从"冷冰冰的评分"变成"有数据、有实况、有血有肉"。

> **数据流向（务必分清）**：**Amy 是数据生产者 → Rita 是消费者**。Amy 处理完真实 case 后脱敏回传到 `sentiment` 模块；Rita 出报告时**只读**这些数据作为佐证。Rita 不写、不改 Amy 的舆情数据，也不影响 Amy 任何工作流。

> **何时用**：出雇主品牌诊断/口碑类/竞品对比报告时，若报告涉及"候选人怎么看腾讯""某维度为什么低""负面集中在哪"——接入 Amy 舆情数据做实时佐证。纯问卷设计、纯维度打分等不涉口碑的任务不需要。

---

## 一、两类数据的互补（先认清各自能提供什么）

| 维度 | Rita 调研数据（自有） | Amy 舆情数据（接入） |
|------|---------------------|---------------------|
| **性质** | 静态快照·系统性 | 动态实况·事件性 |
| **来源** | 问卷/访谈/维度评分 | 小红书/脉脉等真实帖子+处置记录 |
| **回答** | "目标人群整体怎么评价、哪个维度弱" | "最近出了什么具体事、网上在骂什么、情绪多激烈" |
| **样本** | 有样本量、可量化 | 单点/极端、情绪化，但真实鲜活 |
| **盲区** | 滞后、抓不到突发热点与具体事件 | 沉默大多数不发声、样本偏激 |

> 一句话：**Rita 是"体检报告"（测长期健康、给分数），Amy 是"实况录像"（记此刻发生了什么、什么情绪）。报告里两个一起放，既有分数又有故事。**

---

## 二、怎么取 Amy 的舆情数据（MCP 工具）

Amy 把处理过的真实 case **脱敏后**回传到校招 MCP 的舆情态势（`sentiment`）模块。Rita 用以下工具读取：

| 工具 | 用途 | 用法要点 |
|------|------|---------|
| `query_sentiment_cases` | 查历史舆情 case 列表 | 支持按 `level`(高/中/低风险) / `platform`(小红书/脉脉…) / `status` / `keyword` / 时间段筛选；按发现时间倒序 |
| `query_employer_brand_modules(module_type="sentiment")` | 查舆情模块快照/态势 | 看整体舆情态势数据 |
| `search_campus_data(scope=["employer_brand"])` | 联邦检索舆情相关 | 关键词跨域搜 |

**典型取数**：
- 出某 BG 口碑报告 → `query_sentiment_cases(keyword="面试")` 看面试体验相关的真实舆情
- 报告涉负面归因 → `query_sentiment_cases(level="高风险")` 看高危 case 都是什么类型
- 时间窗口佐证 → `query_sentiment_cases(start_date, end_date)` 圈出调研同期的舆情

> ⚠️ **数据已脱敏**：Amy 回传时已做脱敏（姓名编号化、去链接/金额），Rita 读到的是可复用的方法论与事件类型，**报告引用时同样不得反推真实个人**。

## 三、怎么用进报告（三种嵌入方式）

### 方式1：印证/补强调研结论（最常用）
调研数据说"面试体验维度评分偏低" → 接 Amy 舆情"同期小红书有 N 条面试体验负面 case，集中在反馈慢/面试官态度" → **报告结论从"分低"变成"分低+具体为什么低"**。

### 方式2：情绪性 vs 结构性 判断（避免误判）
把"调研评价"和"舆情声量"叉起来看：

```
                  舆情负面高（网上骂得凶）
                          │
   调研评价好 + 舆情骂得凶   │   调研评价差 + 舆情骂得凶
   🟡 情绪性波动           │   🔴 结构性问题（真病）
   （单点情绪，非普遍）     │   （调研+舆情双印证）
──────────────────────────┼──────────────────────────
   调研评价好 + 舆情没声音   │   调研评价差 + 舆情没声音
   🟢 健康                 │   🟠 隐性隐患（沉默的不满）
                          │
                  舆情负面低（网上没声音）
```
| 象限 | 报告里怎么写 |
|------|-------------|
| 🔴 结构性问题 | "调研与实时舆情双双印证，该维度是真实痛点，建议源头治理" |
| 🟡 情绪性波动 | "虽有个别舆情，但调研整体评价良好，属单点情绪、非普遍问题" |
| 🟠 隐性隐患 | "舆情尚无声量但调研评分偏低，属潜在隐患，建议提前干预" |
| 🟢 健康 | "调研与舆情表里如一，维度健康" |

### 方式3：报告"实时舆情"专章（锦上添花）
在诊断报告末尾加一节"调研期间实时舆情概况"——列 Amy 沉淀的同期 case 类型分布、情绪基调，让报告不只有问卷数字，还有"这段时间实际发生了什么"。

## 五、人群口径铁律（继承 Rita P0 规则，交叉时必守）

> 调研数据分三类受访人群，舆情发声人群也要辨，**人群不对齐则交叉无效**：
> - 调研："想来还没来"（候选人）/"目标院校泛人群"/"已入职员工"三类不可混
> - 舆情：发声者是候选人 / 在职员工 / 路人也要区分
> - ⚠️ 例：调研"泛人群好感度"高 ≠ 可对冲"在职员工"的负面舆情——两拨人，两回事。交叉前先对齐人群，报告里注明口径。

---

> 💡 一句话价值：**Rita 单出调研报告，是一份"分数体检表"；接上 Amy 的实时舆情，就成了"分数 + 实况 + 归因"的立体报告——既知道哪个维度弱，还知道弱在哪件具体的事、是真病还是一时情绪。这是让调研报告从"好看"到"好用"的关键一步。**
