## 量表统一

6分量表：非常差(0) / 比较差(20) / 一般(40) / 还不错(60) / 比较好(80) / 非常好(100)

## 维度使用规则（P0 强制）

> 所有雇主品牌相关调研的问卷设计和数据分析，必须优先使用以上三组标准化维度。这些维度与年度雇主品牌调研问卷完全一致，确保数据可交叉对比。如需新增/裁剪维度，需在方案中注明并说明交叉分析影响。

1. **涉及技术品牌调研**：必须使用A组13维度作为评价量表的子问题
2. **涉及择业偏好调研**：必须使用B组13项作为排序/多选选项
3. **涉及雇主品牌对比调研**：必须使用C组9维度作为评价量表的子问题
4. **量表统一**：所有评价类维度统一使用6分量表
5. **交叉分析可行性**：因维度与年度调研完全一致，专项调研数据可与年度大盘直接交叉对比
6. **禁止自创维度**：严禁脱离以上标准维度体系另起炉灶。任何分析必须锚定 A/B/C 三组维度进行，确保与 Kathy 团队的 Vicky 产出口径一致

## 复合调研维度选择决策树

> 当调研同时涉及多组维度时，按以下逻辑判断：

```
Q1: 调研是否涉及技术品牌/技术实力评价？
    → 是 → 纳入A组（技术影响力13维度）
    → 否 → 跳过A组

Q2: 调研是否涉及求职决策/择业偏好？
    → 是 → 纳入B组（择业因素13项，通常保留全部用于排序）
    → 否 → 跳过B组

Q3: 调研是否涉及多家公司横向对比/品牌吸引力评分？
    → 是 → 纳入C组（雇主品牌吸引力9维度）
    → 否 → 跳过C组

裁剪原则（当总题量>25题时）：
• A组可精简至核心5-7项，但"综合技术影响力"必须保留
• B组通常完整保留（用于排序/限选TOP N，不额外增加题量）
• C组可精简至核心5-6项，但"薪酬水平""成长发展""公司前景"必须保留
• 裁剪后须在方案中标注"已裁剪维度"及对交叉分析的影响说明
```
