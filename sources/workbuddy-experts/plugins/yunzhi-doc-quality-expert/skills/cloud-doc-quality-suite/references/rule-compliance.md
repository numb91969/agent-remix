# 维度 7：法律合规检测规则

> 本规则用于检测腾讯云官网产品配套文档（白皮书 / 解决方案 / 案例集 / 产品介绍 / 计费说明 / 营销活动等）中的**法律合规风险点**。规则聚焦四大核心红线：国家相关元素、公序良俗、赛事元素、控标字眼。

## 一、目的

依据《中华人民共和国广告法》《消费者权益保护法》《反不正当竞争法》等法律法规，为业务部门在编写、更新腾讯云官网产品配套文档时提供**合规表述自动核查能力**，规避以下风险：

- 因违规使用国家元素造成政治舆情
- 因妨碍公序良俗、含有歧视 / 低俗内容引发监管处罚
- 因未授权使用赛事元素引发侵权纠纷
- 因出现"控标 / 控标项"字眼引发招投标合规风险

## 二、适用范围

本维度适用于以下文档类型：

- 腾讯云官网产品白皮书、解决方案、产品介绍、技术案例集
- 官网产品文档（功能介绍、计费说明、SLA、操作指南、API 文档）
- 营销活动文档与配套素材
- 国际站文档

**不检测对象**：代码示例、API 字段表、错误码表、纯参数清单等纯技术内容。

---

## 三、检测分类与规则

法律合规检测分为 **4 大类别**，命中即视为违规，必须修改。

### 类别 1：不得使用国家相关元素

| 编号 | 违规情形 | 关键词/模式 |
|------|----------|------------|
| 1.1 | **不得将已有的政府客户合作项目作为官网案例、宣传案例** | "XX 政府"、"XX 部委"、"XX 局"、"XX 委"作为客户案例标题或宣传素材 |
| 1.2 | **不得利用党和国家领导人的形象（包括离任或已故党和国家领导人）进行商业促销宣传**；不得使用党和国家领导人名义、形象在文档中发布商业广告；不得摆放党和国家领导人的题词、照片等形式进行商业宣传；不得使用特型演员以扮演党和国家领导人形象的方式发布商业广告 | 党和国家领导人姓名、肖像、题词、照片；特型演员照片 |
| 1.3 | **不得利用或者变相利用党和国家重大活动、相关决议决定、宣传报道、领导人讲话进行商业炒作与宣传推销产品** | "为 XX 大会献礼"、"响应 XX 讲话推出"、"配合 XX 政策发布" |
| 1.4 | **不得使用或者变相使用国旗、国歌、国徽、军旗、军歌、军徽**；不得使用军服和中国人民解放军曾经装备的制式服装、"军"字号产品或者"军需""军服""军品"等用语；不得出现涉军特定涵义字样、军队标志物图案或者类似图案 | "军用级"、"军工级"、"军方认证"、"军需"、"军服"、"军品"、"国旗"、"国徽"、"军旗" |
| 1.5 | **不得使用或者变相使用共青团、少先队、妇联、工会、残联、红十字会等机构的标志标识** | 上述机构 logo / 名称作背书 |
| 1.6 | **不得使用或者变相使用英雄烈士的姓名、形象及事迹**；不得污化、歪曲英烈姓名、肖像、名誉、荣誉、事迹 | 英雄烈士姓名、事迹描述 |
| 1.7 | **应当避免涉及党和国家的历史**；如涉及，不得歪曲党的历史或者宣扬历史虚无主义 | 涉党史敏感表述 |
| 1.8 | **不得出现损害国家尊严或者利益，泄露国家秘密的内容** | 涉密信息、损害国家利益的表述 |
| 1.9 | **不得使用或者变相使用国家机关、国家机关工作人员的名义或者形象**（其他情形） | "国家机关推荐"、"政府背书"、"国家级合作伙伴" |

**判定**：命中任一项 → 违规，必须修改

---

### 类别 2：不得出现妨碍社会公共秩序、违背社会良好风尚的内容

| 编号 | 违规情形 | 关键词/模式 |
|------|----------|------------|
| 2.1 | **不得在文档中宣扬恐怖主义、民族分裂主义、宗教极端思想**；不得含有民族歧视、种族歧视、宗教歧视、性别歧视、地域歧视、职业歧视等内容 | 恐怖主义、极端思想、歧视性用语（地域黑、性别刻板印象等） |
| 2.2 | **不得含有淫秽、色情、暴力、赌博、迷信及各类"软色情"** | 色情、暴力、赌博、封建迷信、软色情暗示 |
| 2.3 | **不得含有各类炫富、恶搞经典等不良内容**；不得含有低俗庸俗媚俗、制造噱头、吸引眼球或者无底线的内容 | 炫富、恶搞经典、低俗庸俗媚俗、噱头式表述 |

**判定**：命中任一项 → 违规，必须修改

---

### 类别 3：避免使用未经授权的赛事元素

**应当避免使用奥运、亚运等赛事元素**：

- 不得使用**奥运会、冬奥会、残奥会**及其徽标
- 不得标注"**奥运版**"、"亚运版"等
- 避免擅自在产品推销、商业广告中使用**国家队及其运动员、教练员**等形象、名义
- 或者借运动会报道、体育明星训练生活等**变相发布商业广告**

**豁免情形**：已获得奥委会等赛事官方授权（需在原文注明授权信息）。

**判定**：命中且未提供官方授权证明 → 违规，必须修改

**关键词/模式**：
- 奥运、奥运会、冬奥会、残奥会、亚运会、亚运
- 奥运版、亚运版、冬奥版
- 国家队、国脚、国手、中国队
- 体育明星姓名（结合上下文判定）

---

### 类别 4：不得含有"控标"、"控标项"字眼

**规则**：文档中**不得出现**以下字眼：

- "控标"
- "控标项"
- "控标点"
- "控标参数"
- "控标条款"
- "控标要求"
- 及其他与"控标"含义相同或近似的表述

**说明**：招投标场景中的"控标"表述涉及《招标投标法》《反不正当竞争法》合规红线，可能被认定为**限制或排斥其他潜在投标人**，构成串通投标或不正当竞争。

**判定**：命中任一"控标"字眼 → 违规，必须修改

**修复建议**：删除相关表述，改为客观描述产品特性 / 技术优势，不针对招投标场景设置排他性条件。

---

## 四、执行流程

### 第一步：识别检测范围

- 解析文档结构，逐段扫描正文、标题、图表说明、页眉页脚
- 跳过纯技术段落（代码块、API 字段表、错误码表、纯参数清单）

### 第二步：逐类执行检测

按 **类别 1 → 类别 4** 顺序执行，每个类别独立产出问题列表。命中任一违规情形均视为必须修改的合规问题。

### 第三步：汇总输出

## 六、执行约束

| 约束项 | 说明 |
|--------|------|
| **基于原文** | 仅基于实际文档内容判定，不联想、不推理、不主观扩展 |
| **豁免例外** | 赛事元素若已获得官方授权且原文注明，可豁免 |
| **避免误伤** | 客观陈述（如"公司成立于 XX 年，属于国家高新技术企业认定"中的"国家"用词）不视为违规 |
| **代码 / API 不检测** | 代码块、API 字段表、错误码、纯参数清单跳过 |
| **多语言敏感** | 中英文双语文档需对英文表述同步检测（perfect solution、100% guarantee、absolutely、Olympic 等） |
| **依据可追溯** | 每个问题必须提供法律条款引用 |

## 七、常见命中示例

### 示例 1：国家相关元素违规

**原文**：
> 本产品已服务于 XX 部委、XX 国资委等核心政府客户，并采用军工级安全标准，为庆祝 XX 大会献礼推出限时活动。

**问题**：
1. 将政府客户作为宣传案例（类别 1.1）
2. 使用"军工级"涉军字号（类别 1.4）
3. 利用党和国家重大活动进行商业炒作（类别 1.3）

**修复建议**：
> 本产品已服务于多家国内大型组织机构客户，并通过 XX 等保三级认证，现推出限时优惠活动。

---

### 示例 2：妨碍公序良俗

**原文**：
> 本产品让您的运维团队告别加班，一键甩掉那些技术水平差的西部小城运维人员。

**问题**：含地域歧视 + 职业歧视内容（类别 2.1）。

**修复建议**：
> 本产品通过自动化运维能力显著降低团队运维负担，帮助各类规模的企业提升运维效率。

---

### 示例 3：赛事元素未授权

**原文**：
> 特别推出腾讯云 XX 产品奥运版，助力中国队夺金！

**问题**：
1. 未授权使用"奥运版"标注（类别 3）
2. 擅自使用国家队形象作宣传（类别 3）

**修复建议**：
> 特别推出腾讯云 XX 产品体育赛事专属方案，为大型赛事直播场景提供专业支持。

---

### 示例 4："控标"字眼违规

**原文**：
> 本产品可作为招投标场景中的控标项，帮助合作伙伴锁定订单。

**问题**：出现"控标项"字眼（类别 4），涉及《招标投标法》合规红线。

**修复建议**：
> 本产品具备 XX 差异化技术能力，可为合作伙伴在项目投标中提供技术竞争力支持。

---
