# cloud-doc-quality-suite

> 云计算产品文档综合质量检测套件 · 七维一站式检测 + 百分制综合评分 · 标准化 JSON + 可视化 HTML 报告

## 这是什么

一个面向**云计算售前弹药库文档**的综合质量检测 Skill，内置 **11 套官方文档模板**：产品白皮书 / 案例集 / 产品解决方案 / 产品介绍 / 产品彩页 / 竞品分析 / 快速入门 / 销售一指禅 / 交付标准流程 / POC 测试申请指引 / 产品报价指引。
用户上传一篇文档，即可一键完成 7 个维度的全量质量检测 + **百分制综合评分**（0~100 分 + 等级：优秀 / 良好 / 合格 / 待改进），输出标准化的 JSON 结构化结果和可视化 HTML 报告。

## 七维检测能力

| 维度 | 检测内容 | 输出 |
|------|----------|------|
| 🏗️ 结构质量 | 基于模板对比的结构完整性、产品定位、场景、案例、技术深度 | 综合建议 + 建议详情（结构不完整时列出缺失部分与修改建议，结构完整或类型不明时返回 `[]`） |
| ⏰ 时效性 | 文档标题/Roadmap/版本/封面中超过 6 个月的过期时间 | 问题片段 + 修改建议 |
| 🔗 超链接异常 | HTTP/DNS/锚点/平台文档链接可用性 | 异常类型 + 修复建议 |
| 📐 排版格式 | 标题层级、空段落、列表、表格、标记闭合（**v1.7.0：pptx / xlsx 文件类型自动跳过**） | 问题类型 + 修复示例 |
| 📝 产品写作规范 | 依据《腾讯云产品写作规范》**三大类别**检测：① 用词规范（错别字/形近/音近/成语/英文拼写/口语/程度词/负面情绪/人称/账号）② 数字及数量规范（阿拉伯/汉字/范围/百分数/日期）③ 词汇表规范（一致性/定义）；**链接规范由维度 3 承担、货币规范由维度 6 承担；v1.7.0 完整移除「空格与标点规范（W-SPACE）」类别** | 规则编号（W-*）+ P0-P3 等级 + 原文片段 + 可直接替换的建议修改 |
| 💰 货币规范 | 非美元货币单位检测与上下文分析（**v1.7.0：中文文档 `language==zh` 自动跳过，仅适用于英文/海外/双语文档**）；货币符号格式规范（符号置于金额前、无空格、不重复附加中文单位） | 不匹配片段 + 换算建议；符号格式违规原文 + 修复建议 |
| ⚖️ 法律合规 | 五大核心红线：① 国家相关元素（政府案例/领导人形象/党史/军字号/共青团红十字会/英烈/国家秘密/国家机关名义 9 项）② 公序良俗（恐怖主义/分裂/极端/歧视/淫秽/暴力/赌博/软色情/低俗庸俗）③ 赛事元素（未授权奥运/亚运/国家队/运动员）④ 虚假宣传（完全解决/绝对保证/彻底消除/100% 承诺）⑤ 控标字眼（控标/控标项） | 类别 + 命中规则 + 法律依据 + 修复建议 |

## 综合评分（七维检测完成后执行）

七维检测完成后加载 `references/rule-scoring.md`，结合原文全文与七维检测结果做百分制评分：

| 评分维度 | 类型 | 满分 | 主要证据来源 |
|---|---|---|---|
| 内容时效性 | 主维度 | 45 | `timeliness` |
| 结构规范性 | 主维度 | 45 | `structure` |
| 内容准确性 | 主维度 | 10 | `typo_writing` + `currency` + `link` + `layout` + `compliance` |
| **主维度合计** | — | **100** | — |
| 内容价值性 | 加分项 | +0~10 | **不参考七维检测**，直接阅读文档原文，按四大价值支点判断（产品定位清晰度 / 案例实证 / 技术深度支撑 / 一线销售可复用性） |

> 无减分项；`final_score = 主维度合计 + 内容价值性加分`，裁剪到 [0, 100]。**内容价值性**独立评估，不依赖前 7 步检测结果，仅以原文内容为准。

- **区段优先、就低不就高**：每档区段有【必须】条件，任一不满足即降档
- 四维求和后统一做**加分项（+1~+5）与减分项（−1~−10）**调整，裁剪到 [0,100]
- 等级：**90~100 优秀 ｜ 75~89 良好 ｜ 60~74 合格 ｜ 60 以下 待改进**

## 使用方式

### 方式 1：AI 编排执行（推荐，主流程）

1. 在 workbuddy / CodeBuddy 等支持 skill 的平台上传本目录
2. 用户上传待检测文档（白皮书 / 案例集 / 解决方案 / 产品介绍）
3. 触发关键词（任选其一）：
   - 文档全面检测、文档综合检查、一键检测、文档体检
   - 法律合规检测、合规检测、文档合规
   - 产品写作规范检测、写作规范检查、用词规范、空格规范
   - full document check、comprehensive check、document audit、compliance check、writing standard check
4. AI 自动按 `SKILL.md` 编排流程，依次加载 `references/` 下 7 个规则文件执行检测
5. 输出标准化 JSON 检测结果

### 方式 2：脚本辅助生成 HTML 报告

当 AI 给出 JSON 检测结果后，可通过脚本生成可视化 HTML 报告：

```bash
# 单文档
python scripts/check.py --result ai_output.json --output ./reports/

# 批量
python scripts/check.py --result ./batch_results/ --output ./reports/ --batch
```

### HTML 报告结构（v1.7 · 三大模块版）

无论是 `scripts/check.py` 脚本渲染，还是 AI 直接生成 HTML，都严格遵循**三大模块**结构：

**模块 1 · 文档基本信息**（顶部蓝色渐变卡）
- 文档名称、文档类型、检测时间（3 项；缺失显示 `—`）

**模块 2 · 综合评分**
- **英雄条**：总评分（大字号，0~100）+ 等级（🏆 优秀/良好/合格/待改进，配色按等级切换）+ 一句话评分总结
- **评分明细卡片 × 4**（固定顺序）：
  1. 📊 **内容时效性**（`max=45`）
  2. 📊 **结构规范性**（`max=45`）
  3. 📊 **内容准确性**（`max=10`）
  4. ✨ **内容价值性（加分项）**（`max=10`；金黄色卡片；含四支点子项）
- 每张卡片：得分 / 满分 + 进度条 + 评分说明

**模块 3 · 检测明细**（按七维顺序，各一个 section）

维度顺序：① 🏗️ 文档结构质量评审 → ② ⏰ 时效性检测 → ③ 🔗 超链接异常检测 → ④ 📐 排版格式检测 → ⑤ 📝 产品写作规范检测 → ⑥ 💰 货币规范检测 → ⑦ ⚖️ 法律合规检测

每个 section 头：图标 + 维度名（不展示状态徽章）

每条问题明细**固定 5 字段**（字段顺序不可颠倒，缺失显示 `—`）：

| 字段 | 内容含义 |
|------|---------|
| **问题类型** | 该问题所属类型 / 规则编号 / 类别 |
| **问题描述** | 该问题的具体说明 |
| **问题位置** | 问题所在章节 / 段落 / 坐标 |
| **原文片段** | 出问题的原文摘录（等宽字体、代码块样式） |
| **修改建议** | 可直接采纳的修改方案（绿色） |

严重等级（P0/P1/P2/P3）以彩色标签展示，不占用 5 字段之一。跳过维度显示 `⏭ 该维度已跳过：{原因}`，无异常维度显示 `✅ 未检测到异常`。

## 输出格式

详见 `SKILL.md` 中的「JSON 输出格式」章节，关键字段：

- `文档名称`、`检测时间`、`文档类型`
- `检测结果.<dimension>`：各维度的状态、异常数量、问题列表
- `检测结果.compliance`：不含「问题分布/等级」字段，仅包含「类别统计」5 大类（国家相关元素/公序良俗/赛事元素/虚假宣传/控标字眼），命中即需修改
- `检测结果.typo_writing`（维度 5 产品写作规范）：包含「问题分布」P0-P3、「类别统计」3 大类（用词规范/数字及数量规范/词汇表规范；v1.7.0 移除「空格与标点规范」类别）
- `统计摘要`：总问题数、各维度分布、P0-P3 严重级别分布
- `scoring`：**综合评分**——`dimensions[]`（3 主维度 name/max/score/reason）、`value_bonus`（四支点加分）、`final_score`（0~100）、`grade`（优秀/良好/合格/待改进）、`summary`
- `总体评价`：基于七维结果的一段话总评

## 法律合规维度核心依据

法律合规维度（维度 7）严格基于以下权威依据，每条问题输出均可追溯至具体条款：

- 《中华人民共和国广告法》（2021 修正）第九条、第十七条、第二十八条
- 《市场监管总局〈广告绝对化用语执法指南〉》（2023.02.25）
- 《中华人民共和国消费者权益保护法》
- 《中华人民共和国反不正当竞争法》
- 《中华人民共和国招标投标法》及其实施条例
- 《中华人民共和国国旗法》《中华人民共和国国徽法》《中华人民共和国国歌法》
- 《中华人民共和国英雄烈士保护法》
- 《奥林匹克标志保护条例》

## 扩展指南

新增检测维度只需：
1. 在 `references/` 新建 `rule-<dimension>.md`，参照现有规则格式
2. 在 `SKILL.md` 流程中插入一步
3. 在 `manifest.yaml` 的 `capabilities` / `sub_skills` 中追加
4. （可选）在 `scripts/check.py` 的 `DIMENSION_META` / `DIMENSION_FIELDS` 中补充对应展示配置

## 设计原则

- **AI 主驱动**：检测逻辑由 AI 按 references/ 规则执行，脚本仅承担渲染
- **规则可独立维护**：7 个维度规则文件相互独立，可单独使用、单独迭代
- **多轮一致性**：相同输入产生完全一致的输出
- **基于原文**：所有判定基于文档实际内容，不联想、不推理、不夸大
- **模板驱动**：结构评审依赖标准化模板，新增文档类型零成本扩展
- **法务可追溯**：法律合规问题逐条标注法律条款与《指引》章节，便于法务复核
