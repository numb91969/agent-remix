# 来源忠实转录

来源忠实转录不是润色或代写。目标是让每一页的来源身份、机器观察、人工核对、修正依据和最终快照可区分、可复核。

## 平台中立边界

包内运行时不读取图片、PDF或工作区文件，不启动 OCR，不调用网络，也不写文件。调用方只能把已有的页描述、摘要和文本观察交给运行时；真实图像读取、OCR执行及最终保存属于宿主边界。

所有输出固定声明：

- `actualOcrExecutionAllowed=false`
- `ocrExecutionPerformed=false`
- `hostMutationAllowed=false`
- `externalActionCount=0`

页清单中的 SHA-256 是调用方提供的绑定，证据等级为 `digest_supplied_not_observed`，不能写成包内已经观察了源文件字节。

## 七步流程

1. 建立连续且唯一的页清单，明确主来源、页码依据、方向和风险。
2. 接收调用方提供的只读文本观察，保留为 `ocr_raw` 快照。
3. 把机器观察与来源人工核对分开；未经核对的页保持 `ocr_extracted_unreviewed`。
4. 对稀疏、密集、版式风险三类代表页建立人工抽样记录。
5. 把疑似乱码、OCR碎片、罕见词、数字单位冲突和跨页边界登记为独立问题。
6. 来源裁决只接受带 `sourceRef` 与 `sourceReading` 的决定。
7. 修正通过不可变快照的内存补丁完成；宿主决定是否把新快照保存到文件。

页面覆盖、页序、方向、原始观察、抽样和三项来源忠实门均通过后，状态最多为 `delivery_ready`，含义是“可交给宿主保存”，不等于文件已写入或已经交付。
