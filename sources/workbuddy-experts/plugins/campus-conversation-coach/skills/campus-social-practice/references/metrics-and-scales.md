# 指标读数、标注规则与自评量表

本文件定义确定性工具的使用方式。逐轮标注由教练完成，聚合计算由脚本完成，两者职责不互换。

## 一、什么时候给读数

- **自我介绍、面试回答等单段表达**：成稿或重练后可运行 `scripts/filler_analysis.py`，给填充词/模糊语密度读数。
- **多轮训练复盘**：训练过程中维护对话日志，复盘时运行 `scripts/dialogue_metrics.py` 聚合倾听与请求指标。
- **冲突类场景训练前**：用户想了解自己处理冲突的习惯时，可做 DUTCH 自评（见第三节），不做也可正常训练。
- 读数不是必选项。用户只想要成稿、或明确不想被量化时，不给读数。

## 二、标注规则（教练逐轮执行）

训练中对用户每轮发言按以下规则记录，只记录当前训练需要的字段：

### 提问

- `is_question`：本轮以提问为主动动作。
- `question_type`：
  - `open`：对方可以自由展开回答（“你们平时怎么安排值日的”）。
  - `closed`：答案被限定为是/否或单点事实（“你今天能倒垃圾吗”）。

### 承接（uptake）

- 本轮是否回应了对方上一轮的关键信息，再表达自己的内容。
- 只重复自己立场、直接开新话题，记为未承接。
- 对方上轮无新信息（如仅寒暄），本轮不标注。

### 请求（request）

用户提出请求时记录：

- `specific`：请求含明确对象、动作或时间（“今晚十一点后戴耳机”而非“你注意点”）。
- `allows_refusal`：表达给对方留拒绝或协商空间（“你看行不行”），而非对方无法拒绝的要求。

### 日志格式

JSONL，每行一轮：

```json
{"speaker": "partner", "text": "也没多大声吧"}
{"speaker": "user", "text": "你刷视频的声音我这边听得挺清楚的，能戴个耳机吗", "annotation": {"is_question": true, "question_type": "closed", "uptake": true, "request": {"specific": true, "allows_refusal": true}}}
```

## 三、指标与参考值

`dialogue_metrics.py` 输出：

| 指标 | 含义 | 参考值（训练启发，非判定线） |
|---|---|---|
| user_talk_share | 用户发言字数占比 | 倾听练习中 0.4-0.6 为宜；表达练习不设参考 |
| open_question_ratio | 开放问题占比 | 熟练参考 0.5，源自 MISC 公开手册阈值改编 |
| uptake_ratio | 承接率 | 训练内逐步提升即有效，不设绝对线 |
| requests.specific_ratio | 请求具体率 | 冲突训练的核心指标，优先看前后变化 |
| filler.density | 用户发言填充词每百字密度 | 不设绝对线，只看基线与重练对比 |

使用纪律：

1. 参考值来自动机式访谈训练研究（专业人员咨询场景），迁移到校园对话只是启发值，**不对用户说“你没达标”**。
2. 优先呈现同一用户的前后对比（`--compare`），不跨用户比较，不排名。
3. 读数必须能复算：报告读数时说明计算口径（如“开放问题占比 = 开放问题数 3 / 总提问数 5”）。
4. 读数服务于一个训练点，不一次罗列全部指标制造焦虑。
5. 标注口径拿不准时，倾向少标注、不硬标；信息不足的轮次跳过。

## 四、DUTCH 冲突风格自评

量表与计分规则在 `assets/dutch_conflict_styles.json`。

流程：

1. 说明用途和来源，征得同意后逐题进行，一次最多呈现一个维度（4 题），避免刷屏。
2. 5 点作答，用户可随时跳过或中止。
3. 完成后按维度求和，报告最高维度和次高维度，结合用户最近一次真实冲突讨论风格匹配度。
4. 结果用于选择训练重点：默认回避或迁就的，优先练具体请求与边界重复；默认坚持争取的，优先练承接与协商选项。
5. 不使用“你是回避型人格”之类标签；只说“这次自评里你回避得分最高，风格和当前这个场景的匹配度我们可以练一练”。

## 五、感受与需要词汇表

`assets/feelings_needs.json`，来源 CNVC 官方清单中文化。

使用时机：冲突与边界表达的准备阶段，用户表达全是评判（“他就是自私”“她总是针对我”）时引入：

1. 把评判还原为可观察事实（“这周他有四天十二点以后还在外放”）。
2. 用词汇表找真实感受（“烦躁、没休息好”）。
3. 找背后的需要（“休息、可预期的安静时间”）。
4. 形成具体请求。

伪感受词（被忽视、被针对、被利用……）是对他人的评判而非感受，对照表中有还原路径。不要求用户逐句套用四步，词汇表是候选池不是填空模板。
