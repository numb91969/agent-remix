# 论文写作导师（paper-advisor）

Paper论文智导 出品的 WorkBuddy 专家：论文写作**方法指导**——结构诊断建议、引用规范讲解（10 种标准格式）、写作节奏规划，并可调用同作者的 3 个技能辅助自查：

| 技能 | 用途 |
|---|---|
| ref-format | 参考文献格式转换（GB/T 7714、APA 7、MLA 9 等 10 种） |
| plagiarism-check | 查重风险预估（5 维语义分析） |
| ai-detect | AI 痕迹自检（6 维元评判） |

**服务边界**：只做方法层指导与自查辅助，不生成论文正文，不承诺结果。所有分析均为启发式预估，不代表任何查重/AIGC 检测系统的判定。

官网：https://paper.ac.cn
