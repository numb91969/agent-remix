## 三条只能看出来的事（人工校对 PNG 时）

1. **杂志页**外围留白常占 35–45%——那是刊眉/栏缝，**不是**让我们 480px 内容区空一半。
   内容带（166–646）须撑满约 85%（墨水底边 ≥ y=560）；矮图加高行高，见 `charts.md`。
2. 字重对比大于字号对比。
3. 色块缝 0–2px；缝一大就散成卡片墙。
