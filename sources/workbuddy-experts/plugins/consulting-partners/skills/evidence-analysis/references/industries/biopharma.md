## 0. 速查

**一句话结构**：创新药的价值 = **未来现金流的概率加权折现**，与当期利润几乎无关。
一家 Biotech 完全可能在亏损最深的年份手握最有价值的管线。
理解这个行业只需要抓住三件事：**成药概率、峰值销售、变现路径**。

**本赛道第一口径陷阱（必须先讲）**：**「总交易额」不是钱。**
BD 授权公告里的巨额数字是「首付款 + 全部里程碑潜在总额」，
其中里程碑是**或有的、需逐个达成的**，历史上大部分拿不满。
示例 as-of 2026H1：已披露交易的**首付款占总金额比例平均约 8%**。
**任何用「总交易额」论证公司价值的分析都是错的——只有首付款是确定到账的现金。**

**两个透镜的分界**：

| 你被问的是 | 走哪个透镜 |
|---|---|
| 管线怎么排优先级 / 自主出海还是授权 / 选哪种 BD 结构 / 商业化自建还是合作 | **§2 咨询透镜** |
| 这家公司值多少 / 哪条管线贡献主要价值 / 首付款够烧多久 / 数据读出前后怎么重估 | **§3 行研透镜** |

## 1. 产业地基（两透镜共用）

### 1.1 价值链与利润分布

```
靶点发现 → 临床前 → I 期 → II 期 → III 期 → 注册审批 → 商业化
    ↑                                                      ↓
  CRO/CDMO 配套                              医保准入 / 处方渠道 / 海外分成
```

**价值不是均匀分布在链条上，而是集中在「风险大幅下降的那几个跳跃点」**：
II 期概念验证读出、III 期成功、审批通过、BD 签约。
这几个点前后，同一条管线的估值可以差数倍。

**中国创新药的结构性特征（as-of 2026）**：出海授权已成为核心变现路径，
BD 首付款规模一度超过同期一级市场融资额，成为融资环境收缩期的重要外部现金来源。
**这改变了整个行业的商业模式——从「自己卖药」变成「把资产卖给能卖药的人」。**

### 1.2 核心驱动变量

用 **push-pull 四因素框架**理解中国创新药的结构性出海（券商框架 as-of 2026）：

| 方向 | 因素 | 含义 |
|---|---|---|
| 推力（国内） | 支付端控费与集采常态化 | 国内变现天花板受限 |
| 推力（国内） | 管线拥挤、同靶点内卷 | 差异化不足的资产在国内难赚钱 |
| 拉力（海外） | MNC 专利悬崖与远期收入缺口 | 大药企有「资产饥渴」 |
| 拉力（海外） | 跨市场资本成本与定价差 | 海外单价显著高于国内（示例口径 5–10 倍，须按品类复核） |

其他必须追踪的变量：

| 侧 | 变量 | 追踪方式 |
|---|---|---|
| 研发 | 关键临床读出时间表 | 公司公告、临床试验登记平台 |
| 研发 | 靶点拥挤度（同靶点在研数量） | 交易与管线数据库 |
| 支付 | 医保谈判降价幅度与准入节奏 | 官方目录与谈判结果 |
| 变现 | BD 交易量、首付款规模、结构演变 | 交易数据库月度/季度统计 |
| 资金 | 一级市场融资额、公司现金跑道 | 财报现金与季度烧钱率 |

### 1.3 关键指标与口径（本赛道翻车重灾区）

| 指标 | 定义 | 单位 | 口径陷阱 |
|---|---|---|---|
| **BD 交易总额** | 首付款 + 近期/远期里程碑 + 销售分成的潜在上限 | 亿美元 | **最大陷阱**。里程碑是或有的；必须拆成「首付款 / 开发里程碑 / 销售里程碑 / 分成比例」四项分别评估。示例 as-of 2026H1：首付款占比平均约 8% |
| 首付款 | 签约时确定支付 | 亿美元 | 唯一确定到账的现金；**判断交易质量的第一指标**是「首付款 / 市值」而非总额 |
| 权益保留 | 卖方保留的地区权益与股权 | — | 决定长期价值归属；NewCo 模式下还要看持股比例与后续稀释 |
| PoS（成功概率） | 各阶段推进到获批的概率 | % | **必须注明来源、适应症、阶段**。示例口径：全球 I 期到获批综合约 10%；分阶段常用 II 期 40–50%、III 期约 70%、阳性数据读出后约 90%（这些是**经验区间**，肿瘤等领域显著更低，必须按适应症校准） |
| 峰值销售额 | 生命周期内年销售最高值 | 亿元/亿美元 | 三种算法（流行病学自下而上 / 类比已上市药 / 分析师一致预期）结果能差数倍；**必须写清用哪种、扣没扣竞品侵蚀与专利到期** |
| 折现率 | WACC 或要求回报 | % | Biotech 常用 12–18%，**差 3 个百分点就能改变结论**，必须做敏感性 |
| 管线数量 | 在研项目数 | 个 | **管线数量与管线价值几乎无关**；一条 III 期资产可能顶过二十条临床前 |
| 现金跑道 | 现金 / 季度净烧钱 | 季度 | 是 Biotech 的生死线；须扣除已承诺的临床开支 |
| 医保后价格 | 谈判降价后价格 | 元 | 降价换量的净效应必须两边都算 |

### 1.4 数据源地图

| 你要什么 | 去哪 | 频率 |
|---|---|---|
| BD 交易明细（首付款、里程碑结构、权益划分） | 医药魔方等交易数据库、**公司公告原文** | 实时；**结构细节必须回到公告原文，媒体报道普遍只报总额** |
| 临床进展与读出时点 | 临床试验登记平台、公司公告、学术会议摘要 | 实时 |
| 靶点拥挤度 | 管线数据库按靶点检索 | 随时 |
| 医保准入与价格 | 官方目录与谈判结果 | 年度 |
| 一级市场融资环境 | 行业统计 | 季度 |
| 一致预期与研报 | `westock-data consensus`、`neodata`（`data_type=doc`） | 随时 |

### 1.5 周期定位

创新药的「周期」不是产能周期，是**资本周期 + 事件周期**：

| 层 | 驱动 | 观察指标 |
|---|---|---|
| 资本周期 | 一级/二级融资环境松紧 | 融资额、IPO 窗口、板块估值分位 |
| 变现周期 | BD 从「叙事」到「兑现」的阶段 | as-of 2026 的判断是：**现金流质量已取代交易流量成为核心变量**——市场不再为「签了大单」买单，而看首付款强度、买方后续投入、里程碑可达性 |
| 事件周期 | 关键读出与审批节点 | 临床日历 |

**定位动作**：先看融资环境（决定估值中枢），再看 BD 兑现质量（决定叙事能否延续），
最后排临床日历（决定短期波动）。

## 2. 咨询透镜（决策者 = 药企高管 / 董事会）

### 2.1 典型问题

管线优先级怎么排、砍哪些 / 自主出海还是授权出去 / BD 用 License-out、NewCo 还是 Co-Co /
海外商业化自建还是合作 / 研发投入怎么在早期与后期之间配置 / 并购标的怎么选。

### 2.2 框架组合

| 问题 | 框架组合 | 各自验证什么 |
|---|---|---|
| 管线优先级 | **管线价值矩阵**（§2.3）+ rNPV 排序 + 资源约束下的组合优化 | 科学价值、临床数据差异化、市场潜力、执行能力四维打分，再用 rNPV 落到钱上 |
| 出海模式选择 | 三方案对比（自主 / License-out / NewCo·Co-Co）× 现金流节奏 × 风险归属 | 自主出海保留全部上行但资金与能力门槛极高；授权立刻拿现金但让渡上行；NewCo 在保留股权与分散风险之间取中 |
| 商业化自建 vs 合作 | 单位经济学（自建销售团队的固定成本 / 覆盖医院数）+ 规模临界点 | 产品数量不足以摊薄销售团队固定成本时，自建必亏 |
| 研发资源配置 | 早期/后期投入的期权价值 + 现金跑道约束 | 现金跑道不足 24 个月时，组合优化让位于生存 |

### 2.3 行业特有分析动作

**① 管线价值矩阵**——把「管线很丰富」变成可排序的清单：
每条管线打四个维度分（科学价值 / 临床数据差异化 / 市场潜力 / 执行与资金），
再叠加 rNPV。**结论必须包含「砍掉哪些」**——不砍的管线组合评估等于没做。

**② 靶点拥挤度扫描**——同一靶点全球在研数量与最快进度。
**「我们进度国内第三」在全球第十五的靶点上没有价值**；出海授权的定价高度依赖全球竞争位次。

**③ BD 条款拆解**——把一笔交易拆成：首付款 / 开发里程碑 / 销售里程碑 / 分成比例 /
权益地区划分 / 开发责任归属 / 后续投入承诺。
**这是本赛道最高频、最容易做出差异的分析动作**——大部分外部讨论只停在「总额多少亿美元」。

**④ 现金跑道压力测试**——在「不发生任何 BD」的假设下，公司还能撑几个季度。
这决定了谈判桌上的议价能力，是所有战略选项的前置约束。

### 2.4 结论形态样例与高频误判

**合格结论**：
> 管线收敛至 X 条：A/B 推进至 II 期概念验证后寻求授权；C 因靶点全球位次落至第 N、
> 停止投入；D 采用 NewCo 结构引入海外资金，保留 Y% 股权与国内权益。
> 目标 18 个月内到账首付款 Z 亿美元，把现金跑道从 P 个季度延长至 Q 个季度。

**高频误判**：

| 误判 | 为什么错 |
|---|---|
| 用「总交易额」衡量交易质量 | 里程碑或有，首付款才是现金 |
| 用管线数量衡量研发实力 | 数量与价值几乎无关 |
| 只看国内竞争位次 | 出海定价看的是全球位次 |
| 忽略现金跑道 | 跑道不足时所有战略选项都会被迫打折 |
| 自建商业化默认更赚 | 低于规模临界点必亏 |
| 把 MNC 背书当成功 | 背书上修概率，但不等于获批 |

## 3. 行研透镜（决策者 = 投资人）

### 3.1 典型问题

这家公司值多少 / 哪条管线贡献主要价值 / 数据读出前后该怎么重估 /
首付款能烧多久 / 什么价位算把预期打满了。

### 3.2 估值主方法：rNPV（本赛道 PE/PB 系统性失效）

**为什么 PE/PB 不适用**：前期投入大、兑现周期长、当期亏损与未来价值无关，
账面净资产也不反映管线价值。**用 PE 给 Biotech 估值是方法论错误，不是保守或激进的问题。**

**rNPV 逐管线计算**：

```
rNPV(管线) = Σ_t [ 现金流_t × 累计成功概率_t ] / (1+r)^t

其中：
  现金流_t   = 销售额_t × (1 − COGS%) × (1 − 税率) − 研发/推广投入_t
  累计概率_t = 当前阶段到获批的各阶段 PoS 连乘
  r          = Biotech 常用 12–18%（必须做敏感性）

公司价值 = Σ rNPV(各管线) + 平台价值 + 净现金 − 债务
```

**做 rNPV 的四个必答项**（缺一项就不可交付）：
① 峰值销售怎么来的（哪种算法、扣没扣竞品侵蚀与专利悬崖）
② PoS 用了哪套、按什么适应症校准
③ 折现率取值理由
④ 上市曲线（爬坡多少年到峰值、专利到期后怎么衰减）

### 3.3 BD 交易的独立折现

出海条款可以**独立于自主商业化单独折现**，计入管线价值：

```
BD 价值 = 首付款（确定）
        + Σ 开发里程碑 × 达成概率 / 折现
        + Σ 销售里程碑 × (销售达标概率) / 折现
        + 海外销售 × 分成比例 × 成功概率 / 折现
```

**注意**：MNC 背书本身是对成功概率的独立验证，可以合理上修 PoS 与峰值销售预期——
这正是「数据读出 / BD 签约触发估值跳升」的机制。但**上修幅度必须写明理由**，
不能因为签了单就把概率拍到 90%。

### 3.4 估值锚与可比口径

| 公司阶段 | 主锚 | 交叉验证 | 常见误用 |
|---|---|---|---|
| 早期 Biotech（无收入） | **管线 rNPV + 净现金** | 现金跑道、单管线集中度 | 用 P/S 或 P/E |
| 成长期（部分商业化） | **分部估值**（已上市品种 DCF + 在研 rNPV） | 商业化执行力、销售爬坡曲线 | 把在研管线按已上市品种的倍数估 |
| 成熟期（多产品 + 全球化） | DCF / P/E，可给**平台溢价** | 全球销售放量、平台延展性 | 平台溢价无依据地加 |

> 🔴 **本赛道估值第一铁律**：**rNPV 对假设极度敏感。**
> 峰值销售、PoS、折现率三个假设各动一点，结论能差数倍。
> 因此 **rNPV 的输出必须是区间 + 敏感性表，绝不能是单点数字**。
> 给出单点估值的创新药报告，基本可以判定为没做透。

### 3.5 命门假设与敏感性

| 命门假设 | 翻转会怎样 | 观察哨 |
|---|---|---|
| 关键临床读出结果 | 单点事件即可让 rNPV 归零或翻倍 | 临床日历、期中分析 |
| PoS 取值 | 直接线性缩放全部管线价值 | 同靶点历史成功率、监管态度 |
| 峰值销售假设 | 竞品侵蚀与医保降价会大幅压低 | 同靶点在研数量、医保谈判结果 |
| 里程碑可达性 | 或有付款拿不到，BD 价值大打折扣 | 买方后续投入、开发责任归属 |
| 现金跑道 | 跑道断裂 → 折价融资 → 大幅稀释 | 季度烧钱率、融资窗口 |

**敏感性必须做三维中的至少两维**：峰值销售 × PoS、PoS × 折现率。

## 4. 两个透镜都会踩的坑

1. **把「总交易额」当钱。** 只有首付款是确定的；必须拆四项。
2. **管线数量当实力。** 一条 III 期顶二十条临床前。
3. **PoS 拍脑袋。** 必须注明来源与适应症，肿瘤等领域显著低于综合值。
4. **峰值销售不扣竞品侵蚀与专利悬崖。** 三种算法结果差数倍，必须写清用哪种。
5. **单点估值。** rNPV 必须给区间与敏感性。
6. **忽略现金跑道。** 它决定谈判地位，也决定稀释风险。
7. **国内位次当全球位次。** 出海定价看全球。
8. **拿 PE/PB 估 Biotech。** 方法论错误。
