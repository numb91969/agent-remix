> ⚠️ **本文件是分析框架，不是数据快照。最后校订：2026-08。**
> 文中数字仅作**口径示例**，一律带 `as-of`。**动笔前必须重新取数**

## 0. 速查

**一句话结构**：成熟平台是**用网络密度收租**的生意，新业务是**用亏损买入口**的生意。
一家平台公司里这两类资产同时存在、成熟度天差地别，
**所以合并报表看不出任何东西——本赛道的第一动作永远是分部拆解（SOTP）。**

**本赛道第一口径陷阱（必须先讲）**：**补贴的会计处理决定了收入和利润率是否可比。**
平台补贴可以**冲减收入**（用户侧补贴），也可以**计入销售费用**（营销投放），
还可以走**履约成本**（补贴骑手/商家）。三种处理下，同样的补贴力度会呈现出
完全不同的收入增速与利润率。**跨公司、跨期比较收入增速前，必须先确认补贴口径**——
这是平台财务里最隐蔽也最致命的可比性问题。

**两个透镜的分界**：

| 你被问的是 | 走哪个透镜 |
|---|---|
| 要不要进这个战场 / 补贴打到什么程度 / 新业务怎么排优先级 / AI 投多少 / 组织与生态怎么搭 / 格局 | **§2 咨询透镜** |
| 补贴退坡后利润能修复多少 / 新业务值多少 / 该给多少倍 / 什么会证伪 | **§3 行研透镜** |

## 1. 产业地基（两透镜共用）

### 1.1 平台资产的三层分类

**做任何分析前先把业务归到这三层，因为三层的指标、框架、估值锚完全不同：**

| 层 | 特征 | 核心指标 | 估值锚 |
|---|---|---|---|
| **现金牛层**（成熟货架电商、到店、广告） | 高毛利、稳态利润、增长个位数 | Take rate、经营利润率、用户留存 | P/E（成熟业务倍数） |
| **投入层**（即时零售、国际业务、新零售） | 高增长、亏损、补贴驱动 | 单均经济模型 UE、单均亏损收窄幅度、AOV | P/S 或 EV/Revenue；亏损未收窄时可给 0 |
| **期权层**（AI、出海新市场、无人配送） | 前景大、路径不确定 | 资本开支强度、商业化验证节点 | 概率加权预期价值，或直接不给 |

> 🔴 **最常见的错误是用现金牛层的稳定性给投入层背书，或者用期权层的想象空间给整体估值。**
> 三层必须分开算、分开给锚，最后再考虑控股折价（示例 as-of 2026：卖方常用约 15–20%）。

### 1.2 核心驱动变量

| 侧 | 变量 | 追踪方式 |
|---|---|---|
| 规模 | 订单量 / GMV / 交易用户数 | 注意口径（§1.3） |
| 变现 | **Take rate（变现率）** | 示例 as-of 2025：某头部外卖 take rate 约 14% |
| 单位经济 | **单均收入 − 单均履约成本 = 单均毛利** | 示例：配送单均收入约 4.9 元、履约成本约 4.2 元、单均毛利约 0.7 元——**利润极薄，靠规模** |
| 竞争 | 补贴强度与竞争烈度 | 本赛道盈利的第一破坏者 |
| 监管 | 从约谈 → 专项调查 → 国家标准 → 负面清单 | 示例 as-of 2026：监管已升级到标准与清单层面，竞争逻辑从"补贴抢份额"转向"履约效率与合规经营" |
| 新业务 | 即时零售增速与减亏节奏 | 示例：某平台闪购 FY2025 GMV 约 3,500 亿元、同比 +60%+，占总 GMV 从约 14% 升至约 18%；另一平台即时零售 FY2026 收入约 785 亿元、+47% |
| AI | **资本开支与折旧节奏** | 示例：某平台披露未来三年至少约 3,800 亿元 AI 与云基础设施投入、单财年资本开支约 1,260 亿元 |

**补贴战有固定的生命周期**，识别当前处在哪一段能预判利润拐点（示例 as-of 2026 的一轮）：
```
新玩家入局 → 老玩家加码 → 三方冲单 → 监管约谈 → 平台自律 → 财务承压 → 补贴退坡 → 利润修复
```

### 1.3 关键指标与口径（本赛道翻车重灾区）

| 指标 | 定义 | 口径陷阱 |
|---|---|---|
| **GMV** | 平台成交额 | **不是收入**。含不含取消/退货/刷单？是补贴前还是补贴后？各平台口径不同且很少披露细节。**GMV 是本赛道最不可比的指标** |
| **Take rate** | 收入 / GMV | 分母是 GMV 还是订单金额？分子含不含配送费与广告？口径不同差数个百分点 |
| **补贴** | 见 §0 | 冲减收入 / 销售费用 / 履约成本，三种处理不可比 |
| AOV | 客单价 | 提升可能来自品类结构而非用户行为；示例：某平台闪购单均 GMV 从约 40 元升至约 52 元，主因 3C/美妆/宠物等高客单品类进入 |
| 单均经济模型 UE | 单均收入 − 单均成本 | **必须写清含不含分摊的营销、技术、总部费用**，只算履约的 UE 会显著偏乐观 |
| 用户数 | DAU/MAU/交易用户/年活跃买家 | 四个完全不同的口径，**跨公司比较几乎总是错的** |
| **调整后利润（Non-GAAP）** | 加回股权激励等 | **各家加回项不同**，直接横比无效；至少确认是否加回 SBC、减值、投资损益 |
| 分部利润 | 各业务经营利润 | **网络复用时的内部结算价是人为设定的**（如新业务复用配送网络怎么分摊），分部利润率会因此失真 |
| 资本开支 vs 折旧 | 现金流出 vs 利润表费用 | **AI 投入期两者严重错配**：钱已花出去，折旧分多年计入，当期利润看不出真实投入强度。**必须同时看两张表** |

### 1.4 数据源地图

| 你要什么 | 去哪 | 频率 |
|---|---|---|
| 分部收入/利润、GMV、用户数 | 公司财报与业绩会**原文** | 季度 |
| 补贴与竞争强度 | 销售费用率变化 + 行业报道 | 季度/事件 |
| 用户与流量 | 第三方监测（下载量、活跃、投放金额） | 月度 |
| 监管动向 | 主管部门与行业标准**原文** | 事件驱动 |
| AI 资本开支 | 财报现金流量表 + 管理层指引 | 季度 |
| 一致预期与 SOTP 假设 | `westock-data consensus`、`neodata`（`data_type=doc`） | 随时 |

### 1.5 周期定位

本赛道的"周期"是**竞争周期**，不是产能周期：

| 阶段 | 特征 | 观察指标 |
|---|---|---|
| 补贴战 | 收入涨、利润塌 | 销售费用率、单均亏损、分部利润转负 |
| **退坡期（示例 as-of 2026）** | 监管与 ROI 约束下补贴回撤 | 亏损**环比**收窄、经营利润率回升 |
| 修复期 | 利润率回到稳态 | 稳态经营利润率、留存率 |
| 新一轮 | 新入口出现（如 AI 交互） | 新玩家的投入强度 |

**定位动作**：看**环比**而非同比（补贴战里同比毫无意义）→
先看销售费用率与单均亏损的方向 → 再看补贴退坡后**用户留存有没有掉**。
**第三步是全赛道最关键的证伪点**：如果补贴一停用户就走，那之前的增长全是买来的。

## 2. 咨询透镜（决策者 = 平台高管 / 业务负责人）

### 2.1 典型问题

要不要进这个战场 / 补贴打到什么程度、什么时候收 / 新业务怎么排优先级 /
AI 投多少、投在哪 / 生态与商家侧怎么搭 / 出海去哪、用什么模式。

### 2.2 框架组合

| 问题 | 框架组合 | 各自验证什么 |
|---|---|---|
| 进不进战场 | **网络密度护城河评估（§2.3）** + UE 可达性 + 对手成本结构 | 对手的密度优势有多深、自己烧到什么规模才有 UE |
| 补贴决策 | **补贴 ROI 与留存衰减模型（§2.3）** | 补贴买来的用户留存多久、LTV 覆不覆盖补贴额 |
| 新业务优先级 | 三层分类（§1.1）+ 战略契合度 × UE 可达性 | 哪些是真期权，哪些只是内部搬运 |
| AI 投入 | 资本开支 → 能力 → 变现的传导链 + 折旧承受力 | 投入能否转化为可收费的能力，而不只是成本 |
| 出海 | 市场吸引力 × 可复制性矩阵 + 本地化门槛 | 网络效应是本地的，不能跨市场直接搬 |
| 竞争格局（structure 题） | 集中度 + 战略群组 + 切换成本 | 结论是结构性判断，不是配置建议 |

### 2.3 行业特有分析动作

**① 单位经济模型（UE）拆解——本赛道的招牌动作**

```
单均收入（佣金 + 配送费 + 广告）
− 单均履约成本（骑手/仓储/物流）
− 单均补贴
− 分摊的营销与技术成本
= 单均利润
```
**必须做三件事**：写清哪些成本被分摊进来了；按城市/品类分层看（总体 UE 会掩盖结构差异）；
给出**规模与 UE 的关系曲线**——回答"再涨多少单量能转正"。
**只报总体 UE 而不分层、不给曲线的分析基本没有决策价值。**

**② 网络密度护城河评估**

平台的护城河不是骑手数量或用户数量，而是**特定城市、特定时段的配送密度**
所形成的效率优势与数据闭环。密度到临界点后，
**对手投入数倍成本也难以撼动**，因为密度直接决定履约成本与时效。
评估方法：分城市看份额与密度 → 算对手达到同等密度的成本 → 判断护城河深度。
**这解释了为什么补贴战里份额的"铁盘"部分很难被撬动，也解释了为什么新进入者往往先攻低密度城市。**

**③ 补贴 ROI 与留存衰减**

对补贴获取的用户单独建队列：补贴期后 1/3/6/12 个月的留存曲线 →
留存用户的 LTV → 与单客补贴成本比较。
**"补贴换来的增长里有多少会留下"是本赛道唯一重要的补贴问题**，
GMV 增速本身不回答任何事。

**④ 内部搬运检验**（做新业务时必须过这一关）

新业务的增量，有多少是**从集团内其他业务搬过来的**？
即时零售是否只是把原本在货架电商的订单换了个入口？
**如果是搬运，集团层面的增量为零，但成本实实在在增加了。**
检验方法：看集团总订单/总 GMV 增速，而不是新业务自身增速；看老业务的频次有没有真的被拉高。

**⑤ AI 投入的传导链检验**——资本开支要能走通
「算力投入 → 能力提升 → 用户价值 → 可收费产品 → 收入」这条链。
**在链条走通前，AI 资本开支是成本不是资产。** 关注两个节点：
云/推理收入的增速，以及自有业务的效率改善是否可量化。

### 2.4 结论形态样例与高频误判

**合格结论**：
> 不在 A 品类全面对攻，改为守住 X 个高密度城市的铁盘（对手复制成本为我方 3 倍）；
> 补贴从全域改为定向 B 客群（该队列 6 个月留存 M%、LTV 覆盖补贴 1.8 倍），
> 预计单均亏损 3 个季度内收窄至 N 元。若第二季度留存低于 M%，立即停投。

**高频误判**：

| 误判 | 为什么错 |
|---|---|
| 用 GMV 增速论证业务成功 | GMV 不是收入，且含补贴与退货口径 |
| 只算履约的 UE | 分摊成本没进来，系统性偏乐观 |
| 把内部搬运当增量 | 集团层面增量为零 |
| 用总体 UE 做决策 | 城市/品类分层差异极大 |
| 补贴只看拉新不看留存 | 留存才决定 LTV |
| 把 AI 资本开支直接当资产 | 传导链没走通前是成本 |
| 用骑手/用户数量论证护城河 | 护城河是密度不是数量 |

## 3. 行研透镜（决策者 = 投资人）

### 3.1 典型问题

补贴退坡后利润能修复到什么水平 / 新业务值多少 / AI 投入是资产还是黑洞 /
该怎么给锚、给多少 / 什么会证伪。

### 3.2 盈利驱动拆解式

```
现金牛层利润 = GMV × Take rate × 经营利润率
投入层利润   = 订单量 × 单均利润（当前为负，看收窄斜率）
集团利润     = 现金牛 − 投入层亏损 − AI 折旧与摊销（逐年抬升）
```

**关键结构**：现金牛层的利润是**稳态的**，投入层的亏损是**可收敛的**，
AI 折旧是**刚性且逐年上升的**。三者叠加会出现一个特殊阶段——
**老业务还在赚钱、新业务确实在增长、但合并利润越来越薄**。
识别这个阶段并判断它持续多久，是本赛道当前最核心的分析任务。

### 3.3 SOTP 分部加总（本赛道的标准动作，替代供需平衡表）

```
集团价值 = Σ(各分部价值) − 净债务 − 控股折价
```

| 分部类型 | 锚 | 关键假设 |
|---|---|---|
| 成熟电商/到店/广告 | Non-GAAP P/E（示例 as-of 2026：卖方常用 12–15x） | 稳态经营利润、Take rate 稳定性 |
| 云 / AI 基础设施 | EV/Revenue（示例：4–6x） | 收入增速、利润率改善节奏 |
| 即时零售等投入层 | P/S（示例：约 2.5x），**或在亏损未收窄时给 0** | 增速、减亏斜率 |
| 出海新市场 | **概率加权预期价值**：成功概率 × 成功后价值 | 跑通稳态盈利模型的概率 |
| 股权投资 | 最新交易/回购价折算 | 流动性折价 |

> 🔴 **SOTP 的三个纪律**：
> ① **每个分部的假设必须单独写出来**，否则 SOTP 就是把想象力加总；
> ② **投入层的保守情景应当给 0**——不是说业务没价值，而是**它的价值先被持续亏损抵消**；
> ③ **必须扣控股折价**，多元化集团的折价是真实存在的。
> 分部越多，SOTP 的自由度越大、越容易被用来凑目标价——**假设透明度是唯一的约束。**

### 3.4 估值锚与可比口径

| 场景 | 主锚 | 常见误用 |
|---|---|---|
| 集团整体 | **SOTP** | 用单一 P/E 覆盖成熟与亏损业务，两边都算错 |
| 成熟平台 | Non-GAAP P/E、FCF 收益率 | 各家 Non-GAAP 加回项不同，直接横比无效 |
| 高增长亏损业务 | P/S、EV/Revenue | 用成熟平台倍数给亏损业务 |
| 期权型业务 | 概率加权 | 按 100% 成功计价 |
| 重资本开支期 | **必须看 FCF 而非净利润** | 资本开支不进利润表，净利润会高估自由现金流 |

### 3.5 命门假设与敏感性

| 命门假设 | 翻转会怎样 | 观察哨 |
|---|---|---|
| 补贴退坡的持续性 | 决定利润修复能否兑现 | 销售费用率、监管口径、对手动作 |
| **补贴退坡后的用户留存** | 全赛道最关键证伪点 | 退坡后的订单量与频次环比 |
| 单均亏损收窄斜率 | 决定投入层何时能给正估值 | 分部利润率环比 |
| 新业务是增量还是搬运 | 决定集团层面是否真有增长 | 集团总订单/总 GMV 增速 |
| AI 资本开支的变现节奏 | 折旧先来、收入后到的错配期有多长 | 云/推理收入增速、资本开支指引 |
| 监管走向 | 直接改写竞争规则 | 标准与负面清单原文 |

敏感性至少做 **稳态经营利润率 × 成熟业务倍数**（现金牛层价值），
以及 **投入层增速 × 减亏斜率**（投入层价值）两组。

## 4. 两个透镜都会踩的坑

1. **补贴口径不确认就比收入。** 冲减收入/销售费用/履约成本三种处理不可比。
2. **GMV 当收入。** 且各家 GMV 口径不同。
3. **Non-GAAP 直接横比。** 加回项不同。
4. **合并报表看平台。** 必须分部。
5. **只算履约的 UE。** 分摊成本要进来。
6. **把内部搬运当增量。** 看集团总量。
7. **补贴只看拉新不看留存。** 留存是唯一重要的问题。
8. **资本开支期用净利润。** 要看 FCF。
9. **SOTP 不写分部假设。** 等于把想象力加总。
10. **用户数指标混用。** DAU/MAU/交易用户/年活跃买家是四个东西。
