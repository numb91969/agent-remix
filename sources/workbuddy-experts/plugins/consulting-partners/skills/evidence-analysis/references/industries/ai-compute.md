## 0. 速查

**一句话结构**：AI 算力是**瓶颈租金驱动**的产业——利润不流向「产值最大」的环节，
而流向**当期最稀缺、扩产时滞最长**的那一环。判断这条链的第一问永远是：
**现在卡在哪？下一个卡点是什么？**

瓶颈迁移路径（示例，as-of 2026-07，须复核）：算力芯片 → 先进封装与 HBM → **电力与电网接入**。
标志性证据是 CoWoS 先进封装售罄且交期超一年，而 AI 公司已开始垂直整合发电资产。

**两个透镜的分界**：

| 你被问的是 | 走哪个透镜 |
|---|---|
| 自建智算中心还是租算力 / 选址怎么定 / 国产算力路线怎么排 / AI 投入的 ROI 怎么算 | **§2 咨询透镜** |
| 这轮 capex 能持续多久 / 谁在赚瓶颈租金 / 折旧假设是否失真 / 给多少倍 | **§3 行研透镜** |

## 1. 产业地基（两透镜共用）

### 1.1 价值链与利润分布

```
加速器芯片(GPU/ASIC) → 先进封装/HBM → 服务器整机 → 智算中心(电力·冷却·网络)
                                                        ↓
                                        云平台 → 基础模型 → 应用/Agent
```

**利润分布不遵循固定微笑曲线，而是随瓶颈迁移。** 判断当期利润落点的三问：

| 问 | 怎么量 |
|---|---|
| 哪一环产能售罄且交期最长？ | 交期（月）、是否 sold out |
| 哪一环扩产时滞最长？ | 从决策到达产的月数（电网接入、变压器交期、封装扩产） |
| 哪一环有不可替代的技术锁定？ | 可替代供应商数量、迁移成本（如软件生态） |

三问都指向同一环时，该环节即当期利润中心。**不要用「产值占比」代替「利润弹性」**——
数据中心土建产值巨大但基本无租金。

### 1.2 核心驱动变量

| 侧 | 变量 | 追踪方式 |
|---|---|---|
| 需求 | 云厂商与 AI 公司**资本开支指引** | 季度财报指引汇总，本赛道第一驱动 |
| 需求 | **Token 消耗量**与推理占比 | 厂商披露、第三方估算；训练→推理的结构切换是本轮核心变化 |
| 需求 | 单 Token 推理成本 | 决定应用能否规模化；成本下降会**同时**压单价与放大用量 |
| 供给 | 先进封装 / HBM 产能 | 代工与存储厂扩产指引 |
| 供给 | **可用电力容量（MW）与电网接入排队周期** | 区域电网排队数据；as-of 2026 北美热点区排队以年计 |
| 供给 | 关键设备交期（变压器、CDU、冷板） | 厂商交期指引 |
| 政策 | 出口管制、主权 AI 投资、PUE 与能耗监管 | 官方文件原文 |

### 1.3 关键指标与口径

| 指标 | 定义 | 单位 | 口径陷阱 |
|---|---|---|---|
| 算力规模 | 常见三种口径：**卡数 / 算力（FLOPS）/ 上架功率（MW）** | 张、EFLOPS、MW | **三者不可换算**。FLOPS 还分精度（FP16/FP8/FP4），不注明精度的算力数字无意义。近年产业更常用 **MW** 作硬通货，因为电力才是真约束 |
| 算力利用率 | 实际有效计算 / 理论峰值（MFU 等） | % | 「上架率」「利用率」「MFU」是三个东西，常被混为一谈 |
| PUE | 数据中心总能耗 / IT 设备能耗 | 倍 | 设计值 vs 实测值差异大；年均 vs 峰值口径不同 |
| 单机柜功率密度 | kW/柜 | kW | 决定风冷还是液冷；示例：as-of 2026 主流 AI 机柜已进入 100kW 级 |
| Token 成本 | 单位 Token 的推理成本 | 美元/百万 Token | **必须注明模型、精度、批大小、是否含空转**；跨厂商报价口径几乎从不一致 |
| 资本开支 | capex | 亿美元 | 区分**已宣布 / 已签约 / 已落地**；口径混用会把意向金额当成真实需求 |
| 已获批电力容量 | 拿到电网批复的 MW | MW | 数据中心资产的真实稀缺性锚点，比土地面积有意义得多 |
| 加速卡出货 | 出货张数 | 万张 | 区分**训练卡/推理卡**、**国产/进口**；示例：as-of 2025 中国 AI 加速卡出货约 400 万张、国产约 165 万张（IDC，2026-04 发布），须复核当期值 |

### 1.4 数据源地图

| 你要什么 | 去哪 | 频率 |
|---|---|---|
| Capex 指引（最强需求信号） | 各云厂/AI 公司季报与业绩会 | 季度 |
| 先进封装与 HBM 紧张度 | 代工厂与存储厂季报、交期指引 | 季度 |
| 加速卡出货与国产份额 | IDC 等第三方跟踪报告 | 季度至年度 |
| 电力约束（排队周期、PPA 价格、变压器交期） | 区域电网机构、设备厂交期 | 季度 |
| 中国算力政策与主权 AI 投入 | 政策原文、地方招标 | 不定期 |
| 一致预期与研报 | `westock-data consensus`、`neodata`（`data_type=doc`） | 随时 |

### 1.5 周期定位

本赛道**不适用经典半导体库存周期**，而是「**资本开支周期 + 物理瓶颈**」双约束：

| 层 | 驱动 | 观察指标 |
|---|---|---|
| 需求端 | AI 应用变现能否支撑 capex 再投入 | Token 用量、应用侧收入、单位推理成本曲线 |
| 供给端 | 物理瓶颈解除节奏 | 封装/HBM 扩产、电网接入、变压器交期 |

**定位动作**：capex 指引是上修还是下修 → 瓶颈环节交期是拉长还是缩短 →
Token 用量增速是否仍快于单价下滑 → 应用侧是否出现可持续付费。
**前两项决定短期景气，后两项决定这轮是不是「泡沫」**——只看前两项会把供给紧张误读为需求健康。

## 2. 咨询透镜（决策者 = 企业高管 / 董事会）

### 2.1 典型问题

自建智算中心还是租算力 / 智算中心选址 / 国产算力替代路线怎么排 /
自研 ASIC 还是采购通用 GPU / AI 投入的 ROI 怎么测 / 模型自研还是调用 API。

### 2.2 框架组合

| 问题 | 框架组合 | 各自验证什么 |
|---|---|---|
| 自建 vs 租用 | 单位经济学（每 MW 或每卡年化成本）+ 利用率敏感性 + 期权价值 | 自建的成本优势**完全取决于利用率**；低于盈亏平衡利用率时租用永远更优 |
| 选址 | **电力可得性矩阵**（§2.3）+ 时间价值 | 电价便宜但排队 4 年的地块，实际价值可能低于电价贵但立即可接入的地块 |
| 国产算力路线 | 卡点矩阵（芯片/封装/HBM/软件生态）+ 迁移成本 | 硬件可替代不等于生态可替代，软件迁移成本常被系统性低估 |
| AI 应用 ROI | 用例分层 + 单位 Token 成本 × 调用量 + 人力替代测算 | 把「AI 战略」拆成可算账的用例，而不是笼统的降本增效 |

### 2.3 行业特有分析动作

**① 瓶颈迁移追踪**——本赛道的招牌动作。列出候选瓶颈（芯片 / 先进封装 / HBM / 电力 /
冷却 / 网络 / 软件生态），逐个标注「当期交期、扩产时滞、可替代性」，
**结论要给出「下一个卡点」而不只是「当前卡点」**——决策做的是 18-36 个月后的事。

**② 电力可得性矩阵**——选址决策的真实约束条件：
候选地 × （已获批容量 MW、接入排队月数、电价与 PPA 溢价、碳排与 PUE 监管红线、水资源）。
**「有地」不等于「有电」，「有电」不等于「现在有电」。**

**③ 利用率盈亏平衡**——自建算力的命门。把总成本（折旧 + 电费 + 运维 + 融资）
除以可售算力小时，求出盈亏平衡利用率，再对照真实负载曲线。
训练负载与推理负载的利用率特征完全不同，不可混算。

**④ 用例分层**——避免「AI 战略」变成 PPT 词云：按「数据可得性 × 单位价值 × 容错度」
把用例排序，先做容错度高、数据现成、单位价值可量化的。

### 2.4 结论形态样例与高频误判

**合格结论**：
> 不自建训练集群。以 X 年期合约锁定 Y MW 推理算力，自建仅覆盖峰值负载的 Z%；
> 同步在 A 地锁定已获批 B MW 电力容量作为 2028 年产能期权；
> 若单 Token 成本年降幅低于 C%，则触发方案二（全租）。

**高频误判**：

| 误判 | 为什么错 |
|---|---|
| 把「算力」当成单一同质商品 | 训练与推理、不同精度、不同互联规格，价格与可替代性完全不同 |
| 只算卡钱不算电钱与场地 | 电力相关 capex 占比已显著抬升（示例 as-of 2026：从传统数据中心的个位数升至 15% 以上） |
| 假设利用率长期高位 | 自建方案的 IRR 对利用率极度敏感，必须做敏感性 |
| 硬件国产化 = 可替代 | 软件生态迁移成本常是硬件价差的数倍 |
| 用「已宣布投资额」当真实需求 | 宣布 ≠ 签约 ≠ 落地 |

## 3. 行研透镜（决策者 = 投资人）

### 3.1 典型问题

这轮 capex 能持续多久 / 瓶颈租金归谁 / 折旧假设是否让利润失真 /
Token 单价下滑会不会打穿商业模式 / 该用什么锚。

### 3.2 盈利驱动拆解式（按环节）

| 环节 | 收入拆解 | 利润驱动 |
|---|---|---|
| 加速器芯片 | 出货量 × ASP | 先进封装与 HBM 供给上限决定出货天花板 |
| HBM / 先进封装 | 产能 × 稼动率 × 单价 | 供需缺口直接映射价格（见 `semiconductor.md` §3.3） |
| 服务器整机 | 出货台数 × 单价 | **毛利率极低**，是「过路财神」，收入大不等于赚钱 |
| 智算中心 / IDC | 上架功率(MW) × 单 MW 年收入 × 上架率 | 电力成本、PUE、折旧年限；**已获批电力容量是资产核心** |
| 云平台 | 算力租金 + 平台服务 | 利用率与折旧假设 |
| 模型 / 应用 | Token 调用量 × 单价（或订阅） | **单价长期下行**，靠用量增长跑赢价格下滑才成立 |

### 3.3 供需与瓶颈租金

不做传统供需平衡表，做**瓶颈环节的供需缺口**：

```
瓶颈产能（如先进封装月产能、可接入电力 MW）
   ↓  与
下游需求（加速器出货计划、在建智算中心功率）
   ↓
缺口 → 瓶颈环节的定价权与超额利润（瓶颈租金）
```

**租金会随瓶颈解除而消失**——判断某环节高毛利可持续性，等价于判断其扩产时滞多久被填平。

### 3.4 估值锚与可比口径

| 环节 | 主锚 | 交叉验证 | 常见误用 |
|---|---|---|---|
| 加速器 / 瓶颈芯片 | P/E（能见度高时）、EV/EBITDA | 在手订单、产能锁定协议 | 用瓶颈期峰值毛利率外推 |
| HBM / 存储 | 见 `semiconductor.md` §3.4（P/B 与 P/E 之争） | 正常化 EPS | 峰值 EPS × 成长倍数 |
| 服务器整机 | P/E，但须看**毛利率绝对水平** | 存货周转 | 用收入增速给成长股倍数，忽略其薄毛利 |
| IDC / 智算中心 | **EV/EBITDA**、每 MW 重置成本 | 上架率、合同期限、电力批复 | 用互联网估值法给重资产 |
| 模型 / 应用 | P/S（未盈利）→ 后期 P/E | 毛利率、留存率、单位经济学 | 把调用量增长直接当收入质量 |

> 🔴 **本赛道估值第一命门：折旧年限假设。**
> 加速器的经济寿命假设（3 年 / 5 年 / 6 年）会**大幅改变利润与自由现金流**。
> 拉长折旧年限可以在不改变现金流的情况下抬高账面利润——
> **比较公司前必须先统一折旧假设**，并做「若寿命缩短 1-2 年」的敏感性。
> 这是 2026 年最集中的多空分歧点之一（as-of 2026-08，须复核最新讨论）。

### 3.5 命门假设与敏感性

| 命门假设 | 翻转会怎样 | 观察哨 |
|---|---|---|
| Capex 持续性 | 需求端塌陷，全链条重估 | 云厂季度指引、订单取消或推迟 |
| 加速器经济寿命 | 折旧假设一变，利润与 FCF 重算 | 会计政策变更、二手残值 |
| Token 单价与用量的赛跑 | 单价跌速快于用量增速 → 收入见顶 | 用量增速、单价曲线、应用侧付费 |
| 电力与封装瓶颈解除节奏 | 瓶颈租金消失，高毛利环节回归常态 | 交期、扩产落地 |
| 出口管制与算力合规 | 直接改写可得性与国产替代节奏 | 官方清单 |

敏感性至少做 **利用率 × 折旧年限** 与 **Token 单价 × 用量** 两组双维表。

## 4. 两个透镜都会踩的坑

1. **算力口径混用。** 卡数、FLOPS、MW 三种口径互不换算；FLOPS 不注明精度等于没说。
2. **把宣布的投资额当需求。** 已宣布 / 已签约 / 已落地必须分开。
3. **忽略电力这条硬约束。** 芯片能买到不代表能开机；接入排队与变压器交期以年计。
4. **用产值代替利润池。** 整机与土建产值巨大、利润极薄。
5. **拿瓶颈期毛利率外推。** 瓶颈租金是暂时的，取决于扩产时滞。
6. **忽略折旧假设差异。** 跨公司比较利润前必须先统一折旧年限。
7. **把「Token 便宜了」当利好或利空的单向结论。** 它同时压单价、放大用量，
   方向取决于弹性——必须两边都算。
