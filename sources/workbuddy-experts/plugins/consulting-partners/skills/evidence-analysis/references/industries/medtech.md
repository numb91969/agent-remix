# 医疗器械与医疗服务 · 行业分析框架（双透镜）

> ⚠️ **本文件是分析框架，不是数据快照。最后校订：2026-08。**
> 文中数字仅作**口径示例**，一律带 `as-of`。**动笔前必须重新取数**
> （医保局/药监局公告原文、集采中选结果、公司财报、`neodata` 研报召回、`westock consensus`）。
> **直接把本文件的示例数字抄进交付物 = 交付事故。**
> 集采规则每轮都在改、续约结果与首轮可能完全相反——用上一轮的降幅推这一轮是典型错误。

## 0. 速查

**一句话结构**：器械是**「支付方定价 + 渠道重构 + 国产替代」三股力量交织**的生意。
集采不是单纯的利空，它同时是**降价压力**和**国产替代的流量入口**——
决定一家公司死活的，是**量的增幅能不能盖过价的降幅**，以及**降的是谁的价**。

**本赛道第一口径陷阱（必须先讲）**：**中标价 ≠ 出厂价 ≠ 集采前终端价。**
集采砍掉的很大一部分是**渠道与经销商加价**，厂商出厂价的降幅往往远小于终端降幅。
示例（as-of 2026 某轮冠脉球囊）：中选均价约 2,678 元，较最高有效申报价（约 5,600 元）降约 52%，
**但相对集采前的实际终端价，厂商侧仍保留约 20% 的毛利缓冲**。
**只看"降价 52%"就推毛利率崩塌，是本赛道最普遍的误判。**
问清楚三件事：降幅的基准是"最高有效申报价"还是"集采前终端价"？
这家公司原来是经销还是直销（决定它损失的是不是自己的钱）？出厂价实际降了多少？

**两个透镜的分界**：

| 你被问的是 | 走哪个透镜 |
|---|---|
| 集采怎么报价 / 产品组合怎么调 / 要不要出海、去哪 / 渠道怎么重构 / 并购标的怎么选 / 格局 | **§2 咨询透镜** |
| 集采后利润能剩多少 / 续约风险多大 / 创新产品值多少 / 该给多少倍 | **§3 行研透镜** |

## 1. 产业地基（两透镜共用）

### 1.1 分层：三类资产的逻辑完全不同

**做任何分析前先归类，因为三类的驱动、指标、估值锚都不一样：**

| 类型 | 代表 | 核心逻辑 | 关键指标 |
|---|---|---|---|
| **高值耗材** | 冠脉、骨科、神经介入、眼科、电生理 | **集采定价 + 国产替代**；量价博弈 | 中选价与出厂价、约定采购量、国产化率 |
| **医疗设备** | CT/MR/超声/内镜/手术机器人 | **医院资本开支周期 + 装机—耗材模型** | 装机量、保有量、单机耗材消耗、投资回收期 |
| **医疗服务** | 专科连锁、体检、CRO/CDMO | **单店/单产能模型 + 支付方式（DRG）** | 门诊量、次均费用、床位周转、单店爬坡 |

> 设备类要特别注意**「装机—耗材」的剃须刀模式**：设备本身可能微利甚至亏本，
> 真正的利润在后续耗材与服务。**只看设备中标金额会严重低估或高估价值，
> 必须看装机后的耗材消耗率（单台年手术量/年耗材金额）。**
> 示例（as-of 2026）：国产手术机器人的单台年均手术量与国际龙头仍有较大差距——
> **装机量领先不等于收入领先，耗材逻辑兑现才是分水岭。**

### 1.2 核心驱动变量

| 侧 | 变量 | 追踪方式 |
|---|---|---|
| 支付 | **集采规则演变** | 示例 as-of 2026：从"唯低价"转向"质量优先、价值导向"；规则引入 **A/B 双组、差异化比价、锚点价、复活机制**，框架是"稳临床、保质量、反内卷、防围标" |
| 支付 | **续约（接续采购）结果** | **比首轮更重要**：示例——冠脉支架、骨科关节（国产）、骨科创伤等前期降幅大的品类，续约实现**涨价**；多数品类续约与首轮拉平或略降 |
| 支付 | 集采覆盖范围扩张 | 省级联盟向全国性升级，形成**"一地集采、全国降价"**；示例：某省际联盟已覆盖 32 个省级单位 |
| 支付 | DRG/DIP 与创新支付 | 创新器械的除外支付、单独付费；医疗服务价格改革的**"技耗分离"**为创新留出支付空间 |
| 需求 | 医院资本开支与现金流 | 设备采购意愿取决于**投资回收期**；服务价格改革缩短回收期会提升采购意愿 |
| 竞争 | **国产化率** | 示例：某品类国产化率从 2019 年约 28% 升至 2025 年约 58%，集采后有望突破 70% |
| 出海 | **国内外价差** | 这是出海逻辑的经济基础：示例——外资冠脉支架海外单价普遍 300 美元以上，国内集采后终端价约 786–798 元人民币；某企业外周球囊海外均价约 1,200 欧元，约为国内集采中选价的 3 倍 |

### 1.3 关键指标与口径

| 指标 | 定义 | 口径陷阱 |
|---|---|---|
| **中选价 / 出厂价 / 终端价** | 三个价格层级 | **见 §0**，本赛道最重要的口径问题 |
| **降价幅度** | 相对什么降 | **基准是"最高有效申报价"还是"集采前实际终端价"？** 两个基准的降幅可能差 30pp 以上，且前者更容易被用来渲染 |
| 约定采购量 | 集采承诺量 | **不等于实际采购量**；实际执行率各地差异大，且超出部分的价格规则不同 |
| 国产化率 | 国产占比 | 按**金额**还是**数量**？按**中选**还是**实际使用**？口径不同结论可能相反 |
| 装机量 / 保有量 | 设备台数 | 新增装机 vs 存量保有量；**保有量才决定耗材需求** |
| 单台产出 | 单台设备年手术量/年耗材收入 | 决定"装机—耗材"模式能否兑现；**装机领先而单台产出低 = 设备闲置** |
| 注册证 | 获批产品数 | **不等于收入**：从获证到入院、到进集采、到放量，每步都以年计 |
| 入院数量 | 覆盖医院数 | 入院 ≠ 上量；要看单院产出 |
| 次均费用 / 门诊量 | 医疗服务 | DRG 下次均费用受控，**收入增长要靠量而非价** |
| 单店模型 | 医疗服务 | 爬坡期长（常 2–3 年），**用成熟店利润率推新店会严重高估**（做法见 `consumer.md` §2.3） |
| 海外收入占比 | — | 出海逻辑的兑现度；注意是**自有品牌**还是 OEM/ODM，两者定价权天差地别 |

### 1.4 数据源地图

| 你要什么 | 去哪 | 频率 |
|---|---|---|
| 集采规则与中选结果 | 医保局/联采办**公告原文**（含分组、锚点价、复活机制细则） | 事件驱动；**必读原文，媒体转述常丢规则细节** |
| 续约/接续采购结果 | 同上 | 事件驱动 |

| 医院采购与设备配置 | 招投标平台、大型医用设备配置规划 | 月度/事件 |
| 支付政策（DRG、创新支付、服务价格） | 医保局与地方医保局原文 | 事件驱动 |
| 公司经营 | 财报分产品线收入、毛利率、海外占比 | 季度 |
| 一致预期与研报 | `westock-data consensus`、`neodata`（`data_type=doc`） | 随时 |

### 1.5 周期定位

本赛道的"周期"是**政策周期**，节奏由集采日历决定，因此**可以排期、可预测性高**：

| 阶段 | 特征 | 观察指标 |
|---|---|---|
| 集采预期期 | 估值先杀，业绩未动 | 品类是否进入拟集采名单 |
| 首轮落地 | 价格大幅下调，份额重新分配 | 中选价、分组结果、份额变化 |
| **以价换量兑现期** | 量能否补上价 | 收入环比、国产化率提升、渠道库存消化 |
| **续约期（关键分水岭）** | 降幅温和甚至提价 | 续约规则与结果 |
| 后集采/新品类 | 老品类稳态，增长靠创新与出海 | 创新产品占比、海外收入占比 |

**定位动作**：先确认品类处在哪一段（未集采/首轮/续约后）→
再看这家公司的**收入结构**里已集采品类占多少 → 剩下的未集采品类风险敞口有多大。
**"这家公司被集采打垮了"的判断，必须先算清楚被集采的收入占比是 10% 还是 60%。**

## 2. 咨询透镜（决策者 = 器械企业 / 医疗集团高管）

### 2.1 典型问题

集采怎么报价、进哪个组 / 产品组合怎么调 / 要不要出海、去哪、什么模式 /
渠道从经销转直销吗 / 并购标的怎么选 / 服务网络怎么铺。

### 2.2 框架组合

| 问题 | 框架组合 | 各自验证什么 |
|---|---|---|
| 集采报价 | **以价换量的量价平衡测算（§2.3）** + 分组规则解读 + 竞争对手成本 | 降到多少价、拿多少量，利润总额才最大 |
| 产品组合 | 收入结构 × 集采敞口 + 创新管线接续 | 老品类稳住现金流，新品类接增长 |
| 出海决策 | **国内外价差 × 准入门槛矩阵（§2.3）** + 模式选择 | 价差是否覆盖注册、渠道与合规成本 |
| 渠道重构 | 价值链利润分布 + 直销投入产出 | 集采后渠道加价空间被压缩，直销的经济性变了 |
| 并购 | 管线互补性 + 渠道协同 + 估值锚 | 后集采时代常见的规模化路径 |
| 设备业务 | **装机—耗材模型（§2.3）** + 医院投资回收期 | 设备让利换装机是否划算 |

### 2.3 行业特有分析动作

**① 以价换量的量价平衡测算（集采决策的核心动作）**

```
收入变化率 = (1 + 量增幅) × (1 − 出厂价降幅) − 1
利润变化   = 新收入 × 新毛利率 − 原收入 × 原毛利率
```
**关键是用出厂价降幅而不是终端价降幅**（§0）。再叠加两个效应：
份额提升带来的**规模摊薄**（固定成本被更大产量分摊，毛利率可能不降反升），
以及渠道费用的减少（集采后不需要那么高的销售费用）。
**很多"集采毁灭利润"的测算，错就错在只算了价、没算规模摊薄与费用节约。**

**② 国内外价差矩阵（出海决策的经济基础）**

对每个目标市场列：当地终端价 / 国内集采价的倍数、注册周期与成本、
渠道模式（自建/代理/并购）、合规与关税门槛。
**价差 3 倍以上且注册门槛可控的市场，才值得优先。**
当前行业普遍路径是"国内集采养产能、海外高价赚利润"——
用国内的规模把成本打下来，再去价差高的市场赚毛利。
**这条路径成立的前提是产能可全球调配，只有国内份额没有海外渠道的企业套不上这个逻辑。**

**③ 装机—耗材模型（设备类必做）**

```
生命周期价值 = 设备毛利 + Σ(单台年耗材收入 × 耗材毛利率 × 使用年限)
```
决定"要不要低价甚至亏本卖设备换装机"。
必须同时估**单台年产出**——装机后不用的设备贡献为零。
还要看医院侧的**投资回收期**，这是采购决策的实际门槛。

**④ 集采敞口盘点**——把公司收入按「已集采 / 拟集采 / 短期不会集采」三栏铺开，
标注各自占比与毛利率。**这张表是器械公司战略讨论的起点**，
它直接回答"我们还有多少安全的现金流、需要多快找到接续品类"。

### 2.4 结论形态样例与高频误判

**合格结论**：
> A 品类进 A 组、报价 X 元（出厂价降 M% 而非终端降 N%），换取份额从 20% 到 35%；
> 规模摊薄后毛利率仅降 3pp，利润总额增加 Y%。
> 同时把产能的 Z% 转向 B 海外市场（价差 3 倍、注册周期 18 个月），对冲国内价格风险。
> 若续约规则转向纯低价，则第二年起收缩该品类投入。

**高频误判**：

| 误判 | 为什么错 |
|---|---|
| 用终端降幅推毛利率 | 砍的很大一部分是渠道加价 |
| 只算价不算规模摊薄与费用节约 | 集采同时降低销售费用率 |
| 用首轮降幅推续约 | 续约往往温和甚至提价 |
| 注册证数量当业绩 | 获证到放量隔着好几年 |
| 装机量当收入 | 单台产出才决定耗材收入 |
| 用成熟单店利润率推新店 | 爬坡期常 2–3 年 |
| 不盘集采敞口就谈战略 | 不知道风险有多大 |

## 3. 行研透镜（决策者 = 投资人）

### 3.1 典型问题

集采后利润还剩多少 / 续约风险多大 / 出海能不能兑现 / 创新产品值多少 /
该用什么锚、给多少倍 / 什么会证伪。

### 3.2 盈利驱动拆解式

```
收入 = Σ各品类(终端量 × 出厂单价 × 自身份额)
       ├ 已集采品类：量增 × 价降，关注续约
       ├ 未集采品类：正常增长，但要给集采概率折价
       └ 海外收入：价差高、毛利率高，是估值溢价来源

毛利率 = f(出厂价, 规模摊薄, 产品结构, 海外占比)
净利率 = 毛利率 − 销售费用率(集采后下降) − 研发费用率(创新投入上升)
```

**必查的三个质量问题**：
1. 收入增长里，**已集采品类的量增**贡献多少、**新品类**贡献多少、**海外**贡献多少？
2. 毛利率下降里，有多少是价格、有多少是产品结构（低毛利品类占比上升）？
3. 销售费用率有没有随集采下降？**没下降说明渠道成本没省下来，量价换算的假设就不成立。**

### 3.3 集采情景推演（替代供需平衡表）

器械没有供需平衡表，对应位置的硬功夫是**按品类的集采情景推演**：

| 对每个品类回答 | 说明 |
|---|---|
| 是否已集采、第几轮 | 首轮风险最大，续约风险显著下降 |
| 集采概率与时点 | 未集采品类要给概率折价，不能按永续高毛利估 |
| 预期降幅（出厂口径） | 参考同类品类的历史降幅，注意规则已转向价值导向 |
| 份额变化 | 国产替代能拿到多少 |
| 净收入影响 | 量价相乘后的净效应 |

**把各品类结果加总，才是这家公司的真实集采敞口。**
逐品类做过这张表的分析，和只说"集采利空"的分析，完全不是一个量级。

### 3.4 估值锚与可比口径

| 场景 | 主锚 | 说明 |
|---|---|---|
| 已集采、格局稳定的耗材 | **P/E（稳态）** | 集采后增长中枢下移，倍数应低于集采前，但价格风险也已释放 |
| 未集采、高毛利品类 | P/E，**但要给集采概率折价** | 按永续高毛利估值是最常见的高估 |
| 创新器械/管线 | **DCF 或类 rNPV** | 逻辑同 `biopharma.md` §3.4，但器械的成功概率通常显著高于创新药、开发周期更短，**不能直接套用药品的 PoS** |
| 设备类 | P/E + 装机—耗材的存量价值 | 保有量带来的耗材现金流是被低估的部分 |
| 医疗服务 | P/E 或 EV/EBITDA；单店模型加总 | 重资产、爬坡期长，注意成熟店与新店分开 |
| 出海占比高 | 可给溢价 | 但要检验是**自有品牌**还是代工 |

> 🔴 **本赛道估值第一提醒**：**集采落地往往是估值的转折点而非终点。**
> 预期阶段杀估值最凶，规则落地、降幅明确、份额确定之后，不确定性反而消失。
> **"集采尘埃落定 + 量开始兑现"通常是重估的起点**——判断错这个时点，
> 比估值区间算错影响大得多。同理，**未集采品类的高毛利不该按永续估**，
> 那是还没兑现的政策风险。

### 3.5 命门假设与敏感性

| 命门假设 | 翻转会怎样 | 观察哨 |
|---|---|---|
| 集采规则走向（价值导向 vs 唯低价） | 决定降幅与利润空间 | 联采办公告原文、分组与锚点价规则 |
| 续约降幅 | 比首轮更影响长期价值 | 接续采购结果 |
| 以价换量的兑现度 | 量补不上价则逻辑崩塌 | 收入环比、份额、国产化率 |
| 出海兑现 | 是毛利率与估值溢价的主要来源 | 海外收入占比、自有品牌比例、注册进展 |
| 创新产品放量节奏 | 决定接续增长 | 入院数、单院产出、支付政策 |
| DRG 对医院行为的影响 | 影响高值耗材的使用意愿 | 除外支付政策、次均费用 |

敏感性至少做 **出厂价降幅 × 份额提升** 的双维表（这是集采品类的两个核心杠杆）。

## 4. 两个透镜都会踩的坑

1. **中标价当出厂价。** 砍的很大一部分是渠道加价。
2. **降幅基准不写清。** 相对申报价 vs 相对集采前终端价，差异巨大。
3. **只算价不算规模摊薄与费用节约。**
4. **用首轮降幅推续约。** 续约往往温和甚至提价。
5. **未集采品类按永续高毛利估。** 要给集采概率折价。
6. **注册证/装机量当收入。** 单院产出、单台产出才是关键。
7. **国产化率口径混用。** 金额/数量、中选/在用。
8. **约定采购量当实际采购量。**
9. **医疗服务用成熟店利润率推新店。** 爬坡期长。
10. **把器械创新直接套用创新药的 PoS。** 器械成功率更高、周期更短。
