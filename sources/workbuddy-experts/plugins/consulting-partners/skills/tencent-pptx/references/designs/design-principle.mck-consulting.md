## 1. 风格 DNA

- **Action Title 优先**：正文页主标题必须是完整结论句，不能只写“市场分析”这类关键词。
- **白底 + 实测青蓝**：内页 / 封面 / 章节一律白底；文字与强调用 `#051C2C` / `#00A9F4` / `#2251FF` 体系（见 §3），**不是**通用咨询的 `#061F32` + `#08A6F6`。
- **结构图 / 图表优先**：能用结构图或麦式 exhibit 讲清的，不堆文字卡片。
- **左对齐纪律**：标题、正文、图表说明、封面、章节扉页默认左对齐；禁居中海报感。
- **数据 + Source 可信**：数据页、正文页、结构图页必须有 Source / Footnote；数字标证据等级。
- **中文楷体 + 西文 Arial**：按 `<Text>` 分配（见 §3），禁整页黑体/雅黑当中文正文字体。
- **极简不是空**：留白 25–40%，内容必须承担判断、论据、结论；一页只高亮一个系列。

## 3. 色彩与字体

### 色彩（19 值白名单，多一个即缺陷）

| 角色 | hex | 用途 |
| :-- | :-- | :-- |
| 深蓝 | `#051C2C` | Action Title、高亮柱、热力最深、封面/章节**文字** |
| 深靛 | `#061F79` | 深色变体、瀑布减项 |
| 深青 | `#034B6F` | 青色阶次深 |
| 亮青 | `#00A9F4` | **图表第二主色**、高亮系列、折线 |
| 靛蓝 | `#1F40E6` | 强调系列 |
| 主蓝 | `#2251FF` | 关键强调、标题下短装饰线、甘特条 |
| 灰青 / 亮青偏灰 / 中青 | `#3C96B4` / `#38A4DD` / `#027AB1` | 多系列过渡档 |
| 浅青 | `#AAE6F0` | **弱化主力** |
| 浅蓝 / 极浅青 | `#AFC3FF` / `#99E6FF` | 弱化 / 热力最浅 |
| 墨 / 次要灰 / 浅灰 / 中灰 | `#191919` / `#7D7E81` / `#B3B3B3` / `#CED0D1` | 正文、脚注、分隔 |
| 灰 track / 极浅底 | `#E6E6E6` / `#EFEFF0` | 条形 100% 底条、结论卡底 |
| 白 / 黑 | `#FFFFFF` / `#000000` | 底与极端对比 |

配色比：白底 ≥50%，深蓝/亮青系 20–35%，中性灰 ≤15%，单页强调系列 ≤8%。

**禁用**：`#061F32` / `#062032` / `#08A6F6` / `#001965`（通用咨询色）、渐变、阴影、3D、发光、圆角 >4px、暖色与绿色、彩虹、每系列一色。

**一页只高亮一个**：其余系列用 `#AAE6F0` 或中性灰。负向用深靛 + 位置/负号表达，不用橙红。

### 字体

| 这个 `<Text>` 装的是 | `fontFamily` |
| :-- | :-- |
| 含中文 | `'楷体'` |
| 纯西文或纯数字（KPI、页码、年份轴、英文术语块） | `'Arial'` |

引擎只取 `fontFamily` 第一个值并同时写入 latin/ea，**禁止**靠 `Arial, 楷体` 字体栈回退。

| 层级 | px | 字重 | 用途 |
| :-- | :-- | :-- | :-- |
| 章节编号 | 48–72 | Bold | 仅章节扉页；Arial；**白底深蓝字** |
| 封面主标 | 60–72 | Bold | 封面；楷体；**白底深蓝字** |
| KPI 大数 | 60–120 | Bold | 数据页；Arial |
| Action Title | 32–40 | Bold | B 区；楷体 |
| 口径副行 | 18–20 | Regular | 标题下灰行 |
| 副标 / 卡片小标 | 24–30 | Bold | 次级标题 |
| 正文 | 22–28 | Regular | 硬下限 ≥22 |
| 结构图节点标题 | 21–24 | Bold | 仅结构图内 |
| 结构图说明 / 数据标签 | 15–18 | Regular | 结构图 / 图表内豁免 |
| Source / Footnote / 页码 | 14 | Regular | 页脚 |

单页字号种类 ≤5；相邻层级差 ≥6px。大字优先：塞不下就精简文案或合并页，不缩小正文下限。

## 4. 信息密度与可读性

| 类型 | 下限 |
| :-- | :-- |
| 封面 | 主标 + 副标 + 署名 + 时间，≥20 字 |
| 目录 | 3–8 条，每条含编号、章节名、摘要，总字数 ≥80 |
| 章节扉页 | 编号 + 章节标题（英文副标可选），≥14 字 |
| 执行摘要 | 三栏 Context / Complication / Resolution，总字数 ≥160 |
| 单主题 | 正文 + 主视觉，≥120 字，图 ≥30% |
| 卡片组 | 每卡 ≥40 字，3 卡合计 ≥120 |
| 思维模型 | 模型名 + 所有维度，≥160 字，结构图 ≥50% |
| 数据图表 | 主图 ≥50%，洞察 50–90 字 |
| 信息结构图 | 结构图 ≥70% C 区 + Source |

可读性硬线：文字对比度 ≥4.5:1；浅灰底必须用墨色或深蓝字；卡片填充率 ≥75%；卡尾 y 差 ≤16px；正文行高 1.4–1.5。

| 等级 | 用途 | 规则 |

## 6. 页面类型规则

### ① 封面（白底 + 特刊风右侧生图 + 深蓝签名，默认）

- 底：`#FFFFFF`。**禁止**满铺 `#051C2C` / `#061F32` / `#062032`。
- **深蓝签名（必做，麦肯锡辨识）**：左侧竖轨 **24px** × 全高 `#051C2C`（**不要顶条**）。
- 主标：60–72px Bold `#051C2C`，楷体，左对齐，最多两行；**文本块宽 ≤580**（左起 100，右边界 680）；约从 y=200–240 起。
- 装饰线：主标下 **72 × 4px** `#051C2C` + **40 × 3px** `#00A9F4`（深蓝主、亮青辅）。
- 副标：22–26px `#7D7E81` 楷体，**≤24 字/行、最多两行**。
- **右侧概念图（默认必做，2026-08 改为出血）**：写 `01.slide` 前用 `ImageGen` 生成
  `assets/cover-accent.png`（议题相关 3D/静物 + 亮青波纹线；无字无 Logo 无人脸；**`aspect_ratio` 取 `3:4`**）；
  `<Image src=...>` **出血**贴右：`right:0 top:0 width:520 height:720`，`objectFit:'cover'`
  （属性名是 **`src`**，**禁止**写成 `source`，写错图不显示）。
  主体被右/上/下边缘裁断是刻意效果；**左侧 25–35% 要留干净白**，那是与版面唯一的接缝。
  🔴 **出血 ≠ 边角碎影**：主体占竖条约 **55–70%**，3/4 视角保留可辨大半身；
  边缘只**啃掉 15–25%**。禁止右下角小摆件、上下半出血、极端侧面局部特写。
  槽位 `520` **不要靠拉宽硬救碎影**——改 prompt 重出。
  生图失败才降级无图骨架（**深蓝签名仍保留**）。
  🔴 **生成后必跑 `deck-design/scripts/whiten_bg.py --seam left` 把近白底拉成纯 `#FFFFFF`。**
  提示词首句仍要写死「纯白 `#FFFFFF` 无缝背景、均匀平光」并禁掉灰底/渐变底/影棚背景纸/暗角，
  但**光靠提示词洗不白**：实测写死之后出图四角仍是 RGB(244,244,244)，与版面差 11 级，会显出灰方块。
  **不要用「大量留白」这类词**（模型会理解成灰调）。
- 🔴 **文本块宽度 ≤580 是硬约束**：出血图不透明，副标一长就钻到图底下，
  而门禁的「文字被压住」显式排除图片（`kind != "pic"`），这类事故只能靠几何提前防住。
- 署名左下：上方加 **32 × 3px** `#051C2C`；`丁笃行（Ding）· 战略咨询合伙人` 16px 灰；日期一行；**署名块底边 ≤640**。
- **禁止**：居中海报、白字压深蓝底、生图拉满整页再叠字、机构 Logo 墙、顾问包名当客户署名、只有细青线没有任何深蓝块面、
  封面主体碎切/右下角小摆件（见上条）。
- 骨架与 prompt 占比/裁切硬约束、出图自检表见 `deck-design/references/cover-and-chapter.md`。

### ② 目录

- 纯白底；主标左上 26–32px Bold `#051C2C`。
- 3–4 项单行 N 列；5–6 项 2×3；7+ 项 2×4。
- 条目 = 大编号 + 章节名 + 摘要；禁圆球编号、书法繁体、单列大目录。

### ③ 章节扉页（白底 + 深蓝签名，禁止反白巨字）

- 底：`#FFFFFF`。**禁止**满铺深蓝。
- **深蓝签名（必做）**：左侧竖轨 **24px** `#051C2C`（与封面同款，**不要顶条**）。
- 编号：**深蓝底块**约 120×88，内白字 48px Arial Bold（`01`/`02`）。**不是** 160–320px 半透明白字。
- 章节名：40–48px Bold `#051C2C` 楷体；装饰线 **72×4px `#051C2C` + 40×3px `#00A9F4`**；英文副标可选 20px 灰 Arial。
- 页数紧时可取消独立扉页，只保留目录大编号 + 正文右上角章节进度。
- 骨架见 `deck-design/references/cover-and-chapter.md` §2。

### ④ 执行摘要

- 纯白底 + 深蓝标题 + 三栏 Context / Complication / Resolution。
- 可用 0.5px 分隔线和 2px 深蓝顶线/竖条；装饰必须紧贴栏标题（间距 ≤8px）。

### ⑤ 正文

- ⑤a 三栏卡；⑤b 四/六栏小卡；⑤c 时间轴；⑤d 大图配文；⑤e KPI；⑤g 对比 VS；⑤h 关键词矩阵；⑤i 综合复杂（核心是结构图则改走 ⑨）。
- **卡片排布**：卡数与列数匹配，禁止末行残缺留坑；同组等宽等高。
- 正文页必须：完整母版、Action Title、口径副行、Source、Footnote、页码。
- **C 区撑满 ≥85%**；左右栏底大致对齐。

### ⑥ 思维模型

- 同模板成套；形状可用 SVG，**文字必须独立可编辑**，禁烤进 SVG。
- 单色阶深蓝/亮青 4–5 阶；线条 1–2px。

### ⑦ 数据图表

- 白名单：柱、折、瀑布、散点、树状、Mekko、2×2、热力、灰 track 横条。
- 黑名单：立体饼/柱、3D 散点、雷达、螺旋。
- 必备：Action Title、口径副行、主图 ≥50%、洞察、Source/Footnote、单位。
- 原生 `<Chart>` 须显式传 `colors`（白名单内）；折线默认关网格与 Y 轴（见 charts.md）。

### ⑧ 系统标记

- 母版省略；白底灰字一行；交付前删除。

### ⑨ 信息结构图

建议占全篇 ≥20%；占 C 区 ≥70%；标题陈述结构图结论。

通用约束：

- 节点：矩形、圆角 ≤4px、圆、椭圆、三角、箭头、chevron、平行四边形、梯形。
- 线条：直线或直角折线；禁曲线；主框架 1–2px。
- 配色：深蓝/亮青单色阶 + 少量 `#00A9F4` 高亮；禁彩虹、阴影、3D。
- 字号：节点标题 21–24 Bold，说明 15–18，标签 14–15。
- **文图分离**：形状层 SVG/原生组件；文字层独立 `<Text>`。

12 个子版式名称与结构约束沿用通用咨询 ⑨a–⑨l（战略房屋 / 2×2 / Issue Tree / 价值链 / 流程 / 瀑布 / Mekko / 甘特 / 多支柱 / 散点气泡 / 漏斗 / 利益相关方），但：

- 所有 Cyan / Navy 常量改为本文件 §3 白名单；
- 客户高亮用 `#00A9F4` 或 `#2251FF`，不用 `#08A6F6`；
- **实现优先**复制 `deck-design/references/jsx/structures.md` 成品片段，不要只按文字规格手搓。

## 7. 最终硬闸门

出现以下任一情况必须返工：

1. 正文页 Action Title 不是完整结论句，或 ≤8 字关键词。
2. ⑤/⑥/⑦/⑨ 缺 Source / Footnote / 右下页码。
3. B/C 分割线缺失；或 B 区起始 y 各页不统一（应固定 =72）；或标题上方大段空白；或缺口径副行。
4. 中文 `<Text>` 未用楷体、纯西文/数字未用 Arial；或出现衬线/艺术字/文字烤进 SVG。
5. 出现白名单外 hex（含通用咨询 `#061F32`/`#08A6F6`/`#001965` 等）。
6. 金色、朱砂红、中国正红、紫粉黄品红、彩虹色、暖色、绿色出现。
7. 单页字号种类 >5，或正文 <22px，或相邻层级字号差 <6px。
8. 文字对比度 <4.5:1。
9. 封面或章节扉页使用满铺深蓝 / 160–320px 反白巨字编号。
10. 结构图可用却堆卡片；全篇 ⑨ 占比明显不足。
11. ⑨ 使用曲线连接或非白名单形状。
12. 图表出现 3D、雷达、螺旋或装饰背景。
13. 任意页字数低于下限 70%。
14. 占位文未清零；或把顾问/包名写成客户署名。
15. 装饰竖条/顶线悬空（与所饰标题间距 >8px）。
16. 卡片组末行残缺留坑，或同组不等宽等高。
17. 正文页内容未撑满 C 区（累计高 <85%）；或使用 `pages/*.jsx` 而非 `slides/NN.slide`。
