# 备课易 26.9.6

在教师自己的备课工作区里，沿用教材和旧教案，完成一节课的备课、局部改稿、可编辑文件交付与后续修改。

## 从原来的方式继续

原专家身份、头像、默认提示和三个快捷问法保持。可以继续说：

- 先读我指定的材料，告诉我你理解的教学问题，再比较少量方案。
- 只改导入，其他教学目标、评价和作业不动。
- 我已选定方案，生成教案和教师复核清单，另存为新版本。

只需要理解卡时不会强制生成整套文件；已明确要求完整成果时，也不会让你重新走一遍选择流程。

## 本版能力

- 课时内容包含目标、前置知识、教师组织、学生任务、可观察证据、常见误解、调整办法、评价与课后任务。
- 生成真实可编辑的DOCX，以及Markdown、单文件HTML；按需生成不含教师答案与组织备注的学生任务单。
- 修改一个活动时保留其他内容。旧DOCX支持唯一普通文本段落内替换，可以跨多个文本run；其他ZIP成员与范围外正文保留。
- 支持经过适配的DOCX学校模板；普通复杂模板先检查并在副本上适配，不能保证任意模板无损转换。
- 最小项目记录保留已确认内容和版本；继续时检查当前文件，识别教师手改和材料变化。
- 旧卡片保留未知字段；不自动迁移、扫描、移动、删除或覆盖用户项目。

## 交付与边界

包内辅助脚本只用Python标准库。由当前WorkBuddy宿主提供Python 3.10或更新版本及文件/预览工具；本包不携带模型、解释器、连接器、MCP或常驻服务。宿主缺少文件能力时，仍先交付聊天正文，明确未完成的格式动作。

DOCX生成和解析回读完成不等于版式已检查。专家需在当前宿主中打开文件核对排版，并保留教师对学科事实、教材版次、学情和教学效果的最终判断。扫描PDF、复杂公式识别、图片语义及PPT依赖宿主实际能力，不能由文件名或模型标签推断。

默认新文件、原件保留。任务中已明确的读取和保存授权持续有效；资料库迁入、长期复用、分享和外部提交属于独立用途。取消和失败保留已完成内容，从当前阶段继续。

## 目录

- `contracts/`：兼容0.2.1的既有领域合同；新增严格数据结构位于Skill的 `schemas/lesson.v2.schema.json`。
- `examples/`：原场景与验收定义。
- `PRIVACY.md`、`SECURITY.md`、`TERMS.md`：数据、文件与使用边界。
