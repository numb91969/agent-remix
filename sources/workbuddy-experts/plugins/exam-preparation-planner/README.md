# 备考军师

版本：1.3.0

面向在校学生的考试复习规划师，根据考试范围、剩余时间、现实约束和掌握证据制定计划，并通过打卡复盘持续调整。

## 类型

Agent 型

## 核心能力

- 识别规划、执行、复盘、修复和考前收口场景
- 依据稳定裁决顺序安排多科优先级，不用伪精确总分
- 先计算净容量，再生成阶段计划、七天计划和今日 A/B/C 任务
- 区分任务完成度与知识掌握度
- 根据延期、耗时、自测和错题更新原计划，而不是重新生成无关计划
- 经用户启用后把考试、任务、掌握证据和计划变化记录到个人备考台账，按计划周期跨会话续接
- 区分首次学习与到期复习；用确定性日期计算安排 1 / 3 / 7 / 15 天复验，断档积压时保高权重内容
- 多门考试共用同一计划版本，以稳定关联键记录“保留 / 后移 / 删除 / 替换 / 新增”
- 在信息不足时标记假设，不伪造考纲、分值或高频考点

## 使用示例

- 我有三门期末考试，帮我根据考试时间和当前基础安排复习顺序
- 复习我备考台账里今天到期的内容，并安排下一步任务
- 这是我今天的完成情况和错题，帮我复盘并调整明天的任务

## 内置方法

`exam-preparation-playbook` 在真正进入计划、复盘或修复任务时按需使用，提供：

- 场景首问与资料路由
- 多科排序、容量分配和冲突裁决
- 简版、标准版和展开版输出模板
- 计划周期隔离、状态迁移、计划版本和差异记录
- 备考台账、跨会话续接、到期复习与按需学习看板（内置四表动态模板）
- `review_schedule.py` 确定性计算复习日期，`render_dashboard.py` 校验并生成当前周期看板
- 考试事实核验与常见考试入口
- 基础规划、资料库联动、多考试关联与看板回归用例

Agent 负责角色、开场、场景识别、表达与边界；Skill 负责专业工作方法；references 负责稳定规则、模板和来源。
