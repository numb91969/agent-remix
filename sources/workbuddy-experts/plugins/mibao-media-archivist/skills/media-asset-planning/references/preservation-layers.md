# Preservation layers

1. Original layer: source files and source manifests, never overwritten.
2. Preservation layer: verified long-term derivatives and preservation events.
3. Access layer: playable proxies, resized images, subtitles, and web derivatives.
4. AI-derived layer: OCR, ASR, labels, vectors, descriptions, and review state.

Each layer has its own checksum, lifecycle, and regeneration policy.
