# Media asset data model

Core entities:

- asset: original photo, video, audio, scan, or subtitle
- collection: family event, program, project, or archival group
- segment: time-bounded video/audio segment
- frame: keyframe or image region
- person: optional reviewed person identity
- place: GPS or reviewed location
- event: trip, interview, ceremony, program, or episode
- derivative: proxy, thumbnail, OCR, ASR, embedding, or report
- preservation_event: ingest, hash, convert, review, export, or delete approval

Raw files and derived AI results must remain separable and versionable.
