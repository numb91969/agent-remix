# Model runtime notices

秘宝不捆绑或管理固定的云端模型。WorkBuddy 后端使用当前会话实际选中的模型，模型代码、供应商、版本、能力、文件权限和服务条款均必须以运行时信息为准。

- 当前模型：`runtime-selected`
- 模型来源：当前 WorkBuddy 工作区/会话
- 媒体发送范围：仅限用户授权且由当前模型接口暴露的证据包或文件
- 许可与商用条款：发布前必须依据实际运行时模型的官方条款核验；本文件不构成许可授权

历史模型适配文档仅作为可选参考，不代表当前会话模型，也不代表秘宝已捆绑该模型。不得静默上传原始媒体，不得把未确认的模型名称写入任务结果。
