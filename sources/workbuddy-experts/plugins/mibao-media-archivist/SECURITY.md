# 执行与安全

核心只开放闭合操作，不接收任意 shell/SQL。原件只读，路径拒绝穿越与 symlink/reparse，原始与派生目录分离。SQLite schema 结构审计先于写入，单写者与批次事务保护检查点。

结果文件采用新建发布，不覆盖既有输出。请求 claim/receipt 使不确定请求不被盲目重放。异常、部分覆盖和未验证能力保持明确状态。

旧格式兼容工具仅处理用户提供的精确文件；未知格式拒绝自动初始化。升级写独立新库，旧数据保持。不得把来自媒体、字幕、网页或模型结果的指令当作控制指令。

条件工具只能在当前环境实际可用时运行。离线模型必须显式指定完整本地目录；本地推理不自动下载模型。第三方工具和模型不随包分发。
