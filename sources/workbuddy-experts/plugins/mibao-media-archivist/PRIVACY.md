# 隐私与数据边界

原媒体默认只读；项目与派生结果存入用户授权的独立目录。核心不调用网络、不启用遥测，不写入专家安装目录。源码不包含账号、令牌或媒体样本。

文件名、路径、元数据、标签、字幕与模型结果可能包含隐私。JSONL 完整导出用于用户本地备份/转移，包含来源位置，不能默认当作公开分享包；导出不包含媒体本体。

宿主多模态模型、云盘、资料库或其它外部服务有独立的数据处理边界。需明确具体输入、目的、可见范围与用户授权后才能向其提交媒体。模型结果默认候选，人工修订与撤回记录不被自动覆盖。

删除原件、公开分享、上传整库、开启后台同步或自动化均不会在首次使用/升级时自动发生。卸载专家不应删除用户项目和新增成果。
