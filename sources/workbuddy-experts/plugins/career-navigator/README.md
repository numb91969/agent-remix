# 生涯领航员

面向大学生的生涯决策顾问，帮助用户把方向迷茫转化为可比较的选项、可核验的事实和可执行的验证计划。

## 类型

Agent 型

## 核心能力

- 先归因再推进：区分"不知道从哪开始、信息不够、各有取舍、与他人意见不一致"四类卡点，对症处理
- 梳理兴趣、能力、价值观、现实约束和已有证据
- 对比专业方向、转专业、辅修、考研、就业与出国等选项，同口径比较
- 区分事实、个人偏好和待验证假设
- 用可逆性、机会成本、关键风险和适配证据辅助决策
- 设计访谈、旁听、体验任务、项目实践等低成本验证行动
- 根据验证结果形成短期行动与阶段复盘计划

## 内置数据

- **本科专业目录（2026 年）**：教育部教高函〔2026〕2 号附件全文转录，13 个学科门类、92 个专业类、875 个专业，专业代码与学位说明完整，专业归属以目录为准。
- **职业分类大典骨架（2022 年版）**：人社部等三部门发布，收录 8 大类、79 中类、449 小类、1636 职业的官方骨架；专业技术人员大类全量小类定义与职业，岗位族群候选从官方骨架取材。

数据文件按需加载，仅在涉及具体专业或职业时读取。

## 内置方法

`career-decision-playbook` 提供困难归因、场景路由、自我盘点、方案比较、事实核验、官方入口指路、低成本验证、纠偏换路、阶段检查点、输出模板和安全边界。模型先归因和识别决策阶段，再按需加载对应规则；涉及学校政策、项目要求、就业数据和近期变化时优先核验官方来源，查询不可用或失败时输出待核验清单，不凭模型记忆补全。

## 使用示例

- 我在两个专业方向之间犹豫，帮我梳理差异并设计一个验证计划
- 我完全不知道适合什么，能从一段真实经历开始帮我探索吗？
- 我想转专业，但爸妈不同意，帮我理清这个局面
- 我已经体验或访谈过一个方向，帮我根据结果更新判断和下一步
