# 英语学习动态看板契约

## 输入配置

`render_dashboard.py` 只接收三张既有档案表的真实 ID，不接收统计快照。

```json
{
  "schema_version": "2.0",
  "report_type": "dynamic_learning_dashboard",
  "title": "英语学习看板",
  "generated_on": "2026-08-30",
  "database_ids": {
    "errors": "<英语错误档案 database_id>",
    "sessions": "<英语训练记录 database_id>",
    "vocabulary": "<语境生词本 database_id>"
  }
}
```

规则：

- 三个 ID 必须来自资料库实际节点，且互不相同。
- `generated_on` 使用 `YYYY-MM-DD`。
- 输出 HTML 必须由包内模板 `templates/learning-dashboard.html` 渲染。
- 最终 HTML 不得残留 `{{...}}` 占位符。

## 页面数据

页面加载时使用资料库 Page Database SDK 分页读取三张表，不把记录快照写进 HTML。

| 区块 | 数据来源 | 口径 |
|---|---|---|
| 档案总记录 | 三张表 | 三表记录数之和 |
| 当前到期 | 错误档案、生词本 | 未掌握且下次复习不晚于今天 |
| 已掌握项目 | 错误档案、生词本 | 掌握状态为已掌握 |
| 训练次数 | 训练记录 | 实际训练记录数 |
| 近 8 周训练频次 | 训练记录 | 按周起始日聚合 |
| 错误标签分布 | 错误档案 | 按错误标签聚合 |
| 生词掌握状态 | 生词本 | 按掌握状态聚合 |
| 考试定档轨迹 | 训练记录 | 仅展示考试定档非空记录 |
| 反复问题 | 错误档案 | 近 90 天、未掌握、同标签至少 3 次 |
| 下一步训练重点 | 错误档案 | 近 90 天未掌握记录中最高频标签 |
| 到期复习清单 | 错误档案、生词本 | 按下次复习升序，最多 50 项 |

## 生成与上线

1. 读取三张表的最新 schema，核对页面所需字段；字段不匹配时停止，不自动删改字段。
2. 用真实 database ID 生成配置 JSON，运行 `render_dashboard.py` 输出新 HTML。
3. 对最终 HTML 分别使用三张表的真实 schema 执行 Database SDK lint；任一失败即停止。
4. 执行图片外链自检；本模板无图片时应为空结果。
5. 首次创建时，把 HTML 作为资料库在线 page 挂在“英语学习档案”目录下，并关联三张 database。
6. 只有拿到平台返回的 page 链接才算完成；本地 HTML 是中间产物。

## 更新纪律

- 档案记录变化：不重建页面，页面下次加载自动读取最新数据。
- 用户要求调整页面结构：读取远端最新版本，走 Page 增量事务，只提交改动文件。
- 页面引用的 database 集合变化：提交页面后同步更新 page 与 database 的关联关系。
- 用户明确要求整体重建时才允许整包重导入；不得用重导入覆盖用户在线手动修改。
- 已发布页面结构更新后，询问是否同步发布态；未发布页面不额外询问。
