# 资料库学习档案与复习联动

## 1. 定位

资料库是 WorkBuddy 平台原生能力，不是外部连接器。实际创建、查询、写入、页面生成、文档保存和提醒操作，先加载当前资料库能力，再按其最新 database、page、doc、link 与远端变更规范执行；本文件只定义英语学习档案的业务契约。

核心训练不依赖资料库。未授权、能力不可用或操作失败时，继续完成当前训练，并降级为会话内学习卡。

## 2. 进入条件

只在以下情况进入：

- 用户说“继续上次”“复习到期内容”“看我的进步”“我的生词/薄弱项”；
- 已进入具体训练任务，历史档案会改变本轮重点；
- 训练结束后产生了可复习的错误、训练记录或生词；
- 用户明确要求保存精读笔记、生成看板或剪藏材料。

普通问候、能力询问、快速查义和简单解释不查档案。

## 3. 授权优先级

冲突时按以下顺序执行：

1. 用户当轮明确说“这次不要存”或“本轮不记录”：本轮不写入，不再追问；不自动撤销未来授权。
2. 用户明确说“以后都不要存”“停止记录”或“撤销授权”：停止后续写入；已有档案不自动删除。
3. 当前上下文已提供有效的用户级长期授权并绑定唯一档案：按授权范围直接写入，完成后报告数量；不在每个新会话重复询问。
4. 用户本轮明确说“保存到资料库”“记进学习档案”“帮我建档”：该请求已授权本次在我的文档中创建或写入，不再二次确认。
5. 只有专家主动建议保存、且没有以上授权时，才询问一次是否保存。

授权只覆盖用户明确指定的对象和范围：

- 单表或单节点链接不扩展为全库检索。
- 我的文档中目标明确的创建和写入直接执行。
- 实际目标属于团队空间时，按平台当前规范展示最终变更并等待确认。
- 删除记录、删除表、删除字段、改字段类型、移动到团队空间不继承普通写入授权，单独处理。
- 定时提醒不继承档案写入授权，只有用户明确要求提醒时创建或更新。

## 4. 目标定位

按以下顺序定位，命中即停止：

1. 用户给出的目录页、表格或页面链接；
2. 当前上下文中已绑定的长期授权档案；
3. 当前会话已成功创建或读取的节点；
4. 用户明确要求继续、复习或查看历史后，在其授权范围内搜索标题“英语学习档案”。

多个同名目录时列出位置让用户选择，不猜。目录被改名、移动或表结构不匹配时，不自动重建、不自动改字段；说明差异并请用户选择现有档案或另建一套。

首次创建时，默认在我的文档建立“英语学习档案”目录页，并将三张表挂在其下：

1. 英语错误档案
2. 英语训练记录
3. 语境生词本

创建后返回目录页和三张表链接。公共专家包不写死个人节点 ID。

## 5. 档案结构

### 5.1 英语错误档案

| 字段 | 类型 | 规则 |
|---|---|---|
| 日期 | date | 当前训练日期 |
| 技能类型 | select | 写作 / 阅读 / 词汇 / 语法 / 翻译 / 精读 |
| 考试场景 | select | 通用 / CET-4 / CET-6 / 考研英一A / 考研英一B / 考研英二A / 考研英二B |
| 错误标签 | select | 使用 5.2 的固定集合 |
| 错误细目 | text | 如“主谓一致”“冠词缺失”；无必要时留空 |
| 原句或证据 | text | 定位错误所需的最小句子或题干片段 |
| 修正或正确路径 | text | 修正句、正确选项路径或处理动作 |
| 说明 | text | 一两句说明 |
| 材料出处 | text | 题目、材料或用户自定义名称；不得编造 |
| 掌握状态 | select | 新记录 / 复习中 / 已掌握 |
| 复习阶段 | number | 0 / 1 / 2 / 3 |
| 复习次数 | number | 初始 0 |
| 下次复习 | date | 由脚本计算；已掌握时为空 |

### 5.2 错误标签

- 任务理解
- 证据定位
- 主旨与结构
- 细节与推断
- 词义
- 搭配与词形
- 句法与语法
- 连贯与指代
- 信息遗漏
- 信息增添
- 逻辑关系
- 语域与自然度
- 时间分配
- 学术诚信

一条记录只选一个主标签。会话错误卡的次标签不另设数据库字段；确有复习价值时写入“错误细目”。

### 5.3 英语训练记录

| 字段 | 类型 | 规则 |
|---|---|---|
| 日期 | date | 当前训练日期 |
| 技能类型 | select | 写作 / 阅读 / 词汇 / 语法 / 翻译 / 精读 |
| 考试场景 | select | 与错误档案一致 |
| 考试定档 | text | 仅 CET/考研作文填写；其他任务留空 |
| 有效词数 | number | 仅脚本可靠统计且满足词数不变量后填写 |
| 本轮重点 | text | 1—3 个优先问题摘要 |
| 材料出处 | text | 用户材料或题目来源 |
| 重练结果 | text | 达到 / 部分达到 / 未达到，并附最短证据 |

### 5.4 语境生词本

| 字段 | 类型 | 规则 |
|---|---|---|
| 词条 | text | 单词或短语原形 |
| 语境释义 | text | 当前语境下的词性与释义 |
| 语境句 | text | 遇到该词的完整原句 |
| 材料出处 | text | 用户材料或题目来源 |
| 首遇日期 | date | 当前训练日期 |
| 掌握状态 | select | 新记录 / 复习中 / 已掌握 |
| 复习阶段 | number | 0 / 1 / 2 / 3 |
| 复习次数 | number | 初始 0 |
| 下次复习 | date | 由脚本计算；已掌握时为空 |

同一词在不同语境中可各有一条记录；同一词、同一语境句、同一出处不重复写入。单次最多保存 8 个最影响当前理解或表达的词。

## 6. 查询协议

### 6.1 查询前

1. 取得目标 database 的最新 schema，以服务端返回字段和选项为准。
2. 缺字段、字段类型不匹配或 select 选项异常时，不自动改表；本轮降级为会话内学习卡。
3. 查询使用服务端 filter 与 sorts；需要完整统计时持续读取 `has_more/next_cursor`，不得只统计第一页。

### 6.2 场景查询

- 写作、阅读、语法、翻译训练：同技能类型、未掌握、近 90 天错误。
- 词汇或精读：与当前材料或词条相关的未掌握生词；无匹配时不扩大为全库分析。
- “我最近怎么样”：近 90 天训练记录和未掌握错误，分页取全后统计。
- “我的薄弱项”：近 90 天未掌握错误，按错误标签计数，输出最高频 1—3 项及证据。
- “我的生词”：未掌握记录，先按下次复习升序，再按首遇日期降序；首批最多 20 条，需要时翻页。
- 到期复习：`下次复习 <= 今天` 且未掌握的错误与生词。

### 6.3 三态结果

- 查询成功且有记录：按记录调整训练。
- 查询成功且无记录：说明当前没有符合条件的历史记录。
- 查询失败或结果不完整：历史状态为未知；说明“历史记录读取失败/不完整，本轮未据此判断”，不得表述为“没有记录”或“没有到期项”。

同一错误标签近 90 天出现 3 次及以上时标为“反复出现”，纳入本轮优先问题。没有足够记录时不生成趋势结论。

## 7. 写入协议

只有完成实质训练且存在可复习证据时写入：

- 每次完成训练写入 1 条训练记录。
- 当轮 1—3 个优先问题分别写入错误档案。
- 词汇、阅读或精读任务最多写入 8 个语境生词。
- 正确表达迁移卡不写入错误表；用户要求保存时写入资料库文档。
- 简单解释、快速查义、未完成训练、用户尚未完成作答或没有作答证据时不写入。

执行顺序：

1. 依据第 3 节判定授权与目标空间。
2. 读取最新 schema；只写入存在且类型匹配的字段。
3. 错误记录按日期、技能类型、材料出处、原句或证据、错误标签查重。
4. 生词按词条、语境句、材料出处查重。
5. 查询分页直到确认无重复；结果未知时不写。
6. 新增或更新每批不超过 100 条；本专家默认批量远小于该上限。
7. 检查批量响应中的每条 `success`；汇总成功与失败数量。
8. 部分失败时只处理失败项；重试前重新查重，最多重试一次。
9. 写入完成后报告“错误 N 条 / 训练记录 N 条 / 生词 N 个”；当轮拒绝时不输出写入提示。

原句含姓名、学号、邮箱、手机号等信息时先脱敏。只保存定位学习问题所需的最小文本，不复制整篇作业或整篇版权材料。

## 8. 复习调度与提醒

使用包内 `scripts/review_schedule.py`，不由模型心算日期。

- 新记录：阶段 0，1 天后复习。
- 阶段 0/1/2 复习正确：进入阶段 1/2/3，分别在 3/7/15 天后复习。
- 阶段 3 复习正确：转为已掌握，下次复习为空。
- 任一阶段错误：回到阶段 0，1 天后复习。
- 每次实际作答后复习次数加 1；只查看答案不计复习。
- status、stage、review_count 组合不合法时停止回写，保留原记录并说明。

用户明确要求提醒时：

1. 汇总所有未掌握记录，取最近到期日。
2. 使用稳定名称 `英语学习复习·<档案节点ID末6位>` 定位提醒。
3. 已存在时更新，不重复创建；多个同名结果时先消歧。
4. 提醒内容只包含档案链接和“查询当日及逾期项目”，不写原句或个人信息。
5. 完成复习并回写后，再更新为新的最近到期日；没有未掌握项目时暂停或取消该提醒。

## 9. 学习看板

学习看板是关联三张 database 的动态资料库 page，不是静态数据快照。完整数据契约与上线步骤读取 `dashboard-schema.md`。

### 9.1 创建条件

同时满足：

1. 三张表合计至少 10 条有效记录；
2. 用户明确要求查看进展、制作看板或已有长期授权明确覆盖自动维护看板；
3. 三张表 schema 可读取且满足页面所需字段；
4. 资料库 Page 能力可用。

记录不足时只说明当前记录数量和补齐路径，不生成 HTML。

### 9.2 首次创建

1. 读取三张表的真实 schema 与 database ID。
2. 生成 `dynamic_learning_dashboard` 配置 JSON。
3. 运行包内 `scripts/render_dashboard.py`，由 `templates/learning-dashboard.html` 生成最终 HTML。
4. 分别使用三张表真实 schema 执行 Database SDK lint；再执行图片外链自检。
5. 把 HTML 导入为“英语学习档案”目录下的在线 page，并关联三张 database。
6. 只有平台返回 page 链接才可宣称完成；本地 HTML 只是中间产物。

### 9.3 后续维护

- 档案记录变化：不重建页面，页面加载时分页读取最新数据。
- 页面结构调整：拉取远端最新版本，走 Page 增量事务，只提交改动文件。
- database 引用变化：页面提交后同步 page 与 database 关联登记。
- 只有用户明确要求整体重建时才可整包重导入；不得用重导入覆盖用户在线修改。
- 已发布页面结构更新后，再询问是否同步发布态。

## 10. 文档与链接

- 用户要求保存精读笔记或表达迁移时，新建资料库文档；句卡包含原句、出处、表达、适用场景与限制、用户仿写。
- 用户提供外刊或范文 URL 并明确要求收藏时，可剪藏为 link 节点。
- 不主动批量剪藏，不根据只有标题的链接猜正文。

## 11. 失败与降级

- 原生资料库能力未加载：说明本轮未写入资料库，不把外部连接器状态当作资料库可用性依据。
- 找不到档案：询问用户提供目录链接或新建；不自动全库扫描。
- schema 不匹配：列出缺失或冲突字段，不自动删改；继续用会话内学习卡。
- 查询失败：历史状态记为未知，本轮不据此判断。
- 写入失败：训练结果照常交付，保留可复制的会话内学习卡。
- 部分成功：列出成功和失败数量，只处理失败项。
- 看板失败：不把本地文件当作已交付。
- 提醒失败：不影响档案和训练，不声称已创建或更新。
