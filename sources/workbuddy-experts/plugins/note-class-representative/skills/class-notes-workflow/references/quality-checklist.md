# 质量检查

## 材料

- [ ] 每份材料有来源编号、来源身份和读取状态
- [ ] 读取失败和异常未被静默忽略
- [ ] 本轮已覆盖和未覆盖范围明确
- [ ] 大材料任务已记录批次、阶段性状态和下一批起点

## 依据链

- [ ] 每条关键结论同时记录来源身份、加工方式和核验状态
- [ ] 原文摘录未改写，转述和归纳未使用引号伪装成原话
- [ ] 单一材料转述没有误标为多材料归纳
- [ ] 多材料归纳保留全部支持来源
- [ ] 模型推断说明依据，未写成老师原话或课堂事实
- [ ] 外部资料补充包含作者或机构、标题、版本或日期、核验日期与适用范围
- [ ] 模型通用知识只出现在独立拓展区

## 对齐与结构

- [ ] 重复内容保留全部来源，冲突内容并列展示
- [ ] 版本变化按课次、日期或版本保留
- [ ] 知识树无重复节点，前置、对比和应用关系说明具体
- [ ] 文科、理工科、编程和混合内容使用对应结构
- [ ] 材料没有提供的学习目标、示例、老师强调或易错点未被补写

## 复习材料

- [ ] 只生成用户当前需要的产物
- [ ] 一页纸总结未新增材料中不存在的重点或考点
- [ ] 卡片、对比表、自测题和答案与当前正文一致
- [ ] 卡片、对比表和题目保留完整三轴依据标记
- [ ] 多口径答案未被写成唯一确定答案

## 课程知识库与复习

- [ ] 历史内容只在会改变结果时读取，默认范围未超过课程主页、该课程卡片和最近一次笔记
- [ ] 资料库任务已先加载平台原生 `资料库` Skill，未用外部连接器状态判断可用性
- [ ] 首次保存且没有空间、空间链接、目录或当前会话位置时，已先让用户选择资料库空间；推荐当前课程独立空间，但未替用户决定我的文档或团队空间
- [ ] 定位范围未超过用户链接、当前会话已知或用户选定的课程空间；未获明确授权时没有遍历其它空间或全库
- [ ] 写入前已说明笔记与卡片数量；用户选定个人目标后按请求执行，用户选定或新建团队空间后按平台规则确认
- [ ] 当前课程独立空间只写入本课程资料；多课程共用空间按课程隔离课程主页、卡片库与看板数据范围
- [ ] 每张卡已记录卡片标识、核验状态和复习资格，并运行 `card_policy.py`
- [ ] 待确认、部分支持、模型补全或无可靠来源内容只作为候选卡保存，未初始化排期、未进入到期队列
- [ ] 最近自评只出现未复习、轻松、回想、困难、空白；没有“通过”或过程备注
- [ ] 复习日期与星期来自 `review_schedule.py`，到期筛选来自 Database 查询，没有模型心算
- [ ] 看板按包内模板生成：替换卡片库 ID、使用真实 schema 通过 SDK lint、无第三方外链、关联 Database、上传在线 Page 并回传链接（本地 HTML 不算交付）
- [ ] 数据变化只更新 Database；页面结构调整走 Page 增量编辑；用户未要求重建时未整包覆盖
- [ ] 写入失败时只交付会话内结果，没有创建本地影子知识库，也没有伪造成功
- [ ] 未创建提醒时没有承诺主动通知，写入或看板失败时没有伪造成功

## 用户纠正

- [ ] 用户纠正后已撤回或降级原结论
- [ ] 已标记受影响的正文、总结、卡片、对比表、题目和答案
- [ ] 明确纠正已直接重算下游产物；含糊纠正才暂停等待用户确认
- [ ] 修改后提供差异和仍待确认内容，没有为旧结论辩护

## 隐私与学术诚信

- [ ] 姓名、学号、手机号、邮箱、成绩、账号、头像和文件名中的个人标识等非必要信息未写入输出
- [ ] 第三方材料已确认提供权并只使用必要片段
- [ ] 原始材料未被移动、覆盖、重命名或删除
- [ ] 未主动向用户未授权的外部服务上传、公开或转发材料
- [ ] 未预测考试题、伪造课堂记录或代写需独立完成的作业与考试答案

## 交付

- [ ] 先说明本轮目标、使用材料、覆盖范围和读取异常
- [ ] 阶段性结果未被称为完整结果
- [ ] 产物能直接阅读或继续复习
- [ ] 结尾只提供一个推荐下一步；确有必要时至多附一个替代路径，没有展开操作菜单
