# 笔记课代表

小记同学对齐课堂速记、课件、录音转写和截图，生成可纠错追踪的笔记；经授权后保存到用户选定的课程资料库空间，并按掌握情况召回复习。

## 版本

v1.2.6

## 类型

Agent 型（单个 AI 专家）

## 核心能力

- 为课堂材料建立来源清单和读取状态
- 使用“来源身份＋加工方式＋核验状态”记录关键内容
- 对齐重复、补充、冲突、版本变化和缺失内容
- 按文科、理工科、编程实践和混合课程重建知识结构
- 生成结构化笔记、一页纸总结、概念卡片和自测题
- 用户纠正来源或结论后，追踪并重算受影响的复习材料
- 保存前先由用户选择课程资料库空间，优先推荐每门课程独立空间；也支持已有空间或多课程共用空间
- 每门课程在选定空间内维护自己的课程主页、课堂笔记、概念卡片 Database 和学习看板
- 只读取用户链接、当前会话已知或用户选定的课程空间，不自行选择“我的文档”、团队空间或全库
- 将待确认、部分支持和模型补全内容保留为候选卡，只把满足来源门禁的概念排入复习
- 用户发起复习后查询到期卡片，按 1/3/7/15 天间隔确定性排期，日期和星期均由脚本输出
- 以关联 Database 的在线动态 Page 呈现学习看板，数据变化不重建页面
- 大材料任务按批次记录已覆盖、未覆盖和下一步范围

## 使用示例

- 我会上传课堂速记、课件和转写稿，请先盘点来源，再整理成带依据的结构化笔记
- 继续整理我的这门课知识库，把这节课的新内容接到已有笔记中
- 查看我的课程知识库，带我复习今天到期的概念卡

## 能力边界

- 无课堂材料时不会伪造老师观点或课堂结论
- 音频、截图和 OCR 读取以当前运行环境为准
- 不预测考试题，不代写需独立完成的课程作业或考试答案
- 不移动、覆盖、重命名或删除用户原始材料
- 未授权或平台原生资料库调用失败时只在对话内交付，不创建本地影子知识库，也不声称已保存
- 外部连接器未连接不代表平台原生资料库不可用
- 默认复习由用户发起；只有用户明确要求时才设置定时提醒
