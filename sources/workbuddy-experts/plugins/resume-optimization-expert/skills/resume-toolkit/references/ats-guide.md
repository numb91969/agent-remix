# ATS 解析兼容与关键词策略

## 一、ATS 工作流程

`上传/解析` → `文本抽取` → `版块切分` → `关键词索引` → `匹配打分` → `人工复筛`

简历必须在**前两关（抽取、切分）不丢信息**，才有机会进入关键词匹配。

## 二、解析兼容规则（硬性）

### ✅ 应该做
- 使用标准版块标题：`工作经历`、`教育背景`、`项目经验`、`技能`、`证书`、`自我评价`
- 单栏、线性、从上到下的阅读顺序
- 日期统一格式：`2022.03 - 2025.06`
- 公司名称、职位、起止时间各占独立文本行
- 关键词同时提供全称与缩写：`整车控制器（VCU）`、`电池管理系统（BMS）`
- 提交 PDF 时保留文本层（由 HTML/Word 导出，非扫描/图片）

### ❌ 禁止做
- 文本框、形状、SmartArt 承载文字
- 多栏排版、表格嵌套、页眉页脚放关键信息
- 用图标字体（如字体图标表示电话/邮箱）
- 用图片放姓名、公司 Logo 占位关键信息
- 创意化标题（如"我的旅程"、"我是谁"）
- 关键词堆砌（同一词重复 5 次以上会被判作弊）
- 白字隐藏关键词（严重违规，一票否决）

## 三、JD 关键词提取法

1. **拆 JD**：把 JD 拆成 必备技能 / 加分技能 / 职责动词 / 行业术语 / 工具与标准 五类
2. **标频次**：出现 2 次以上 + 出现在"任职要求"中的词 = 高权重
3. **建对照表**：左列 JD 关键词，右列简历现状（有/无/弱）
4. **差距矩阵**：

| JD 关键词 | 权重 | 简历现状 | 融入位置 | 融入后表述 |
|-----------|------|---------|---------|-----------|
| 整车控制器 VCU | 必备 | ⚠️ 仅提"电控开发" | 摘要 + 经历 1 | 主导纯电轻卡 VCU 上下电与转矩协调策略开发 |
| ISO 26262 | 加分 | ❌ 缺失 | 技能 + 项目 | 按 ISO 26262 ASIL B 完成 X 模块功能安全设计 |
| HIL 测试 | 必备 | ✅ 有 | — | 保留并补充量化 |

5. **覆盖率计算**：已覆盖关键词数 ÷ JD 关键词总数 → 定制前后对比（如 62% → 89%）

## 四、关键词融入三原则

1. **自然贴合**：关键词必须落在真实经历句子里，不单独罗列
2. **分布均匀**：摘要、最近一段经历、技能区各出现一次核心词
3. **不夸大**：JD 要求但候选人确实没有的能力 → 标注为"差距 + 补强建议"，禁止写入简历

## 五、不同投递渠道的格式建议

| 渠道 | 格式 | 说明 |
|------|------|------|
| 企业官网 / 招聘平台 | PDF（文本层） | 版式稳定，主流 ATS 均可解析 |
| 明确要求 Word | .docx | 保留标准标题样式，不用表格布局 |
| 内推 / HR 邮箱 | PDF + 邮件正文摘要 | 正文放 3 行定位，附件放完整简历 |
| 学术 / 科研岗 | PDF（LaTeX 导出） | 可含完整论文列表，长度可放宽 |
| 外企 / 英文岗 | PDF（英文版） | 英文简历遵循一页惯例，不含照片与年龄 |

## 六、投递前终检清单

- [ ] 文件名含姓名 + 岗位（如 `张三-整车控制器工程师-5年.pdf`）
- [ ] 文本层可选中（PDF 打开后能复制文字）
- [ ] 无错别字、无未更新日期
- [ ] 手机/邮箱可正常联系
- [ ] 版块标题为标准词
- [ ] 核心岗位词在摘要与最近经历中各出现至少一次
- [ ] 页数符合年限要求
- [ ] 敏感信息已删除
